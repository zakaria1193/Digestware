Claudio Bantaloukas announces updates to the GCC forge. These updates include the start of archival of closed forge pull requests to the gcc-patches mailing list, the removal of the /allow command for new joiners, and updates to the GCC org's teams in forgejo. A filter can be used to avoid emails about old pull requests.
