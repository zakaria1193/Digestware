The compiler now emits a warning when an unnamed bit-field is declared with a cv-qualified type (e.g., `const int : 4;`). This behavior is mandated by the C++ standard, specifically [class.bit]/2, and clarified by DR 2229. This patch ensures compliance with the standard and helps catch potentially unintended code.
