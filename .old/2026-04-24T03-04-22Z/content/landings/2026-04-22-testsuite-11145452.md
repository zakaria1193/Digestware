This commit marks several tests related to AArch64 Scalable Matrix Extension (SME) as expected failures (XFAILs) in the GCC testsuite. This allows the related bug report to be downgraded in priority, deferring resolution to a later GCC release. The affected tests involve error diagnostics and potentially spurious diagnostics.
