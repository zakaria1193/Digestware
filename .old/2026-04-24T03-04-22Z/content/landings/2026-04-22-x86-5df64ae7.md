The x86-64 code generator's common subexpression elimination (CSE) pass now removes redundant thread-local storage (TLS) calls even when SSE2 is disabled. Previously, a check for SSE2 prevented this optimization, but it's no longer necessary due to changes introduced by commit 5cf1b9a03ec5b617af8c50c1e9c0d223083fd7f2.
