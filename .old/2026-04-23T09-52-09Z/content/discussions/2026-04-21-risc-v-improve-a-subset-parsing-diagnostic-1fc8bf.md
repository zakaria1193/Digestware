This patch improves the error message provided when an invalid RISC-V ISA extension is encountered during subset parsing. The original message only indicated that an invalid extension ending with a number 'p' was found, but did not specify the extension itself. The modified message now includes the specific invalid extension, making it easier for users to identify and correct the problem.
