The C++ grammar now correctly parses splice-type-specifiers in the context of mem-initializer-ids, which are used to initialize class members. The patch defers typename diagnostics and calls `cp_parser_splice_type_specifier` when nested-name-specifiers or :: are absent. New test cases have been added to verify the fix.
