The compiler was experiencing an internal compiler error (ICE) when the `counted_by` attribute was used with pointers to void. The code was attempting to use `TREE_CODE (NULL_TREE)`, which is invalid. This commit resolves this by using `size_one_node` as the pointee_size for void pointers and punting if the type is incomplete (other than void).
