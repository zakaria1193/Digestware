The PR ld/34088 test requires `libm.a`, which includes the `feclearexcept` function. This function is implemented for Linux/x86-64 and Linux/AArch64. The linker script uses `GROUP ( /usr/lib64/libm-2.42.a /usr/lib64/libmvec.a )`. This commit limits the test to these platforms.
