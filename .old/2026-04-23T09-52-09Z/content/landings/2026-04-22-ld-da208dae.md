The linker (`ld`) is modified to maintain the input file order when adding archives specified in linker scripts. Previously, such archives were appended to the end of the input file list, potentially disrupting the intended linking order. This change is particularly important when using link-time optimization (LTO) as the order of libraries can affect the optimization process.
