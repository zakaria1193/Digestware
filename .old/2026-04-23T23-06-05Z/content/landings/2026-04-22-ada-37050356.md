This commit fixes an issue in the Ada library where adding a trailing directory separator to a path would change the result of `Ada.Directories.Containing_Directory`. The fix streamlines the function and strips any trailing directory separators from the input name. A new test case, `directory1.adb`, is added to the testsuite.
