This commit fixes an internal compiler error (ICE) that occurred in the AArch64 backend when folding `svld1rq` with `-msve-vector-bits=128`. The `svld1rq` instruction, a replicated-quadword load for SVE, can be optimized into a normal load when the vector length is 128 bits. The fix replaces the problematic `VEC_PERM_EXPR` with a `VIEW_CONVERT_EXPR` when the SVE vector length equals the quadword width.  A new test case, `ld1rq_2.c`, is added.
