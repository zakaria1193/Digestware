The test for PR ld/34088 requires `libm.a`, which provides the `feclearexcept` function. Since the linker script using `GROUP ( /usr/lib64/libm-2.42.a /usr/lib64/libmvec.a )` is specific to Linux/x86-64 and Linux/aarch64, this commit limits the test execution to these platforms. This avoids test failures on other platforms where the required `libm.a` setup is not available.
