The C++ module streamer now includes location information for PTRMEM_CST (pointer-to-member constant) and TRAIT_EXPR (trait expression) nodes in the intermediate representation. This change ensures that when these constructs are streamed in and out during module compilation, their source code locations are preserved. This additional information improves debugging capabilities and provides more accurate diagnostics, particularly when dealing with complex C++ code involving modules.
