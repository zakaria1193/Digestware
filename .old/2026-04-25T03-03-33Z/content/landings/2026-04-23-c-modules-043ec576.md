When using C++ modules, pointer-to-member constants (PTRMEM_CST) were sometimes not being emitted, leading to linking failures. This commit fixes this issue by marking the member referenced by PTRMEM_CST as used during stream-in. By setting TREE_USED on PTRMEM_CST_MEMBER during stream-in, the compiler ensures that the member gets emitted, resolving the linking failure and ensuring correct code generation when using C++ modules.
