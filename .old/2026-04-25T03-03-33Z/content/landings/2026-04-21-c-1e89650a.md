GCC now recognizes the ``[[gnu::trivial_abi]]`` attribute (also spelled ``__attribute__((trivial_abi))``), which forces the compiler to treat types as trivial for ABI purposes, passing them in registers instead of via invisible references.  Previously, GCC ignored this attribute, leading to call convention mismatches when linking with Clang-compiled code.  This change enables interoperability with Clang when using types marked with ``[[gnu::trivial_abi]]``, which can improve performance.
