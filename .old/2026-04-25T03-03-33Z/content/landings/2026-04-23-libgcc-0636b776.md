The build process for the shared `libgcc` on Windows was not correctly incorporating `LDFLAGS_FOR_TARGET`, unlike other platforms. This commit modifies the build configuration to ensure that these linker flags are included when building the shared library.  This ensures that custom linker flags specified for the target architecture are properly applied to `libgcc` on Windows.
