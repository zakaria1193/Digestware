A redundant check for `CALL_P` has been removed from the `vxrm_unknown_p` function in the RISC-V backend.  The `reg_set_p` check already covers the cases where VXRM (vector reduction mask) is defined as call-used, making the explicit `CALL_P` check unnecessary. This simplifies the code without changing its behavior.
