The compiler now simplifies expressions of the form ``x != CST1 ? x + CST2 : 0`` into ``x + CST2`` when ``CST1 == -CST2``. This pattern frequently occurs in code that performs 'rtrim'-style operations (removing trailing characters). By recognizing and simplifying these expressions, the compiler can generate more efficient code sequences. This improvement reduces code complexity and improves overall performance, especially in string processing scenarios.
