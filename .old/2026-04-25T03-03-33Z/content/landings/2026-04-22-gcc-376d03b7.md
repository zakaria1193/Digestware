The feature test macros (FTMs) `__cpp_impl_reflection` and `__cpp_lib_reflection` were bumped from `202506L` to `202603L`. This indicates the implementation of P3795R2 (and possibly related issues) for C++ reflection. While `is_applicable_type`, `is_nothrow_applicable_type` and `apply_result` metafunctions are not yet fully implemented, the update aligns with LWG guidance for testing the availability of these features using feature test macros.
