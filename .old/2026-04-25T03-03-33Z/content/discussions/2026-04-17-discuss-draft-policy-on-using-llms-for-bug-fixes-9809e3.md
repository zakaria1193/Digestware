The GCC steering committee is considering a policy on the use of LLMs in GCC development. The draft policy would allow using LLMs for assistance, idea generation, and testing, but not for generating code, as the legal status of AI-generated code is unclear. Some developers express concern about LLMs reproducing copyrighted work and propose that patches should be checked to avoid verbatim copies of existing code. Other concerns include the inability to verify if LLM-generated code is original.
