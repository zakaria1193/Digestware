Claudio Bantaloukas provides updates on the GCC forge. Closed pull requests are being archived to the gcc-patches mailing list.  New users no longer need to be manually approved.  The GCC organization's teams in forgejo have also been updated, which include Collaborators, Write.After.Approval, Reviewers, Maintainers, Maintainers.Algol68, Maintainers.Global and Release Managers.
