The vectorizer now uses LOOP_VINFO_IV_INCREMENT to track scalar iterations within vectorized loop iterations, enabling loop-variant increments. This change simplifies pointer arithmetic logic by removing special cases for SELECT_VL and allows for more flexible data pointer updates. The new mechanism replaces VF in several vectorization routines and improves how loop controls are set and manipulated.
