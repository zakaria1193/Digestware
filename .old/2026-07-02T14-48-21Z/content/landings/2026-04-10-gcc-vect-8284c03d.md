The GCC vectorizer has been updated to be more efficient when handling data movement. Previously, it would use 'grouped gather/scatter' operations even for single pieces of data, which is an overhead if there's no stride involved. This change now guards these grouped operations, ensuring they are only used when there are at least two pieces, leading to more optimal code by avoiding unnecessary complexity.
