The GCC C++ front end previously defined the __FRACT_FBIT__ macro, which is specific to the C standard. This change removes the definition of this macro in C++ contexts, aligning GCC's behavior with the C++ standard and preventing potential issues when using the macro in C++ code. A new test case verifies this corrected behavior.
