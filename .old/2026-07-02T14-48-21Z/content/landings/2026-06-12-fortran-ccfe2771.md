This GCC Fortran commit fixes a memory leak in implied-do array constructors for derived-type function results containing allocatable components. The previous fix for PR fortran/125535 only corrected values but left behind leaky memory. The new `gfc_constructor_is_owned_alloc_comp` function now detects when all elements are owned, enabling a single, efficient whole-array deallocation instead of inadequate per-element finalization, thus preventing double frees and ensuring proper memory management.
