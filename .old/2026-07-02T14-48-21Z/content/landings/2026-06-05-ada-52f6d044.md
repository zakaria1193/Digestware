This commit completes the implementation of Ada Reference Manual (RM) rule 4.8(10.1) concerning accessibility checks for allocators that create types with access discriminants. The new approach mirrors the existing accessibility checks for function returns of such types, streamlining the process. Specifically, `Apply_Accessibility_Check_For_Allocator` is renamed to `Apply_Accessibility_Check_For_Class_Wide_Allocator`, and a new `Apply_Accessibility_Check_For_Discriminated_Allocator` is introduced to handle these cases.
