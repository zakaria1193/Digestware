This update to the GCC Rust front-end (gccrs) refactors the internal representation of builtin intrinsic names. Instead of using raw string literals, the compiler now utilizes constants defined within the `Values::Intrinsics` class. This change enhances code safety by reducing the risk of typos in string comparisons and improves maintainability by centralizing intrinsic definitions. The `BuiltinContext` mappings have been updated to reflect this new, more robust approach.
