A global variable named `Init_Or_Norm_Scalars` in the Ada front end has been converted into an expression function. This change eliminates redundant assignments in multiple files, including `opt.adb`, `frontend.adb`, `sem_prag.adb`, and `targparm.adb`, simplifying the code and improving maintainability.
