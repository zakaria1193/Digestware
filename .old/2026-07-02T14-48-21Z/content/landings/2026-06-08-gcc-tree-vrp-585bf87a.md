The `value-pointer-equiv` code within GCC, which managed a side table for Value Range Propagation (VRP), has been entirely removed. This cleanup is a direct consequence of VRP's transition to using the `prange` system for points-to information, making the older side table redundant. The removal involves deleting the `value-pointer-equiv.cc` and `value-pointer-equiv.h` files, along with associated build system entries and references within `tree-vrp.cc`.
