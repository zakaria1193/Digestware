This commit introduces support for unpredicated high-part multiplication operations (SMULH and UMULH) for the ARM Scalable Vector Extension 2 (SVE2).
While SVE provides predicated versions, SVE2 introduces unpredicated forms that are more efficient when a predicate is not needed. The changes involve splitting SVE2's predicated forms in the compiler's intermediate representation (RTL) to use the unpredicated instructions and adding new patterns for them.
New assembly tests cover various data types and operand combinations to ensure correct code generation.
