The Ada frontend's `sprint.ads` file contained an incorrect comment that has been present since the initial import of the frontend. The comment mistakenly referred to `Sprint_Line_List`, a function that never existed, instead of `Sprint_Node_List`, which is the correct procedure. This change updates the comment to accurately reflect the procedure it describes.
