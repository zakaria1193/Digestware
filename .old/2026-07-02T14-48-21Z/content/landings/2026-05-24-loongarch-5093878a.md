This commit corrects the stack-smashing protection (SSP) routines for the LoongArch architecture when using the ILP32 ABI. Previously, these routines did not correctly account for the ILP32 variant, leading to potential issues with stack integrity checks. The changes modify the RTL templates for stack protection to use appropriate instructions and conditions for LA32 (LoongArch 32-bit) in ILP32 mode, along with a new test case to verify the fix.
