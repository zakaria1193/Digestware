The `.pre-commit-config.yaml` file has been updated for the `pre-commit-setup` hook to include `pass_filenames: false`. This optimization prevents the `pre-commit` tool from passing individual filenames to the script, which is not necessary for this particular setup hook. The change results in a noticeable performance improvement, cutting the execution time of an all-files run by approximately half a second.
