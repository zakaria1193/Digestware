This commit adds support for the HYGON c86-4g-m8 processor to GCC, enabling the compiler to generate optimized code for this new CPU. It incorporates the processor's instruction set capabilities and defines its scheduling model, largely inheriting from the c86-4g-m7 with specific adjustments for certain operations. This ensures that developers targeting HYGON systems can leverage the compiler's full optimization potential for this new model.
