The GCC RISC-V backend updated its naming convention for the Tenstorrent Ascalon CPU. The official marketing name for the CPU is now Ascalon X, so the `-mcpu=` and `-mtune=` options will accept `tt-ascalon-x` as the canonical name. An alias `tt-ascalon-d8` has been created to ensure backwards compatibility with existing build scripts and configurations.
