This commit introduces an implementation of `__gnat_get_executable_load_address` for the Android platform. Unlike Linux distributions that provide the `_r_debug` struct, Android's `dl_iterate_phdr` does not offer a reliable method to distinguish the executable's load address from other loaded modules. To address this, the implementation now uses `dladdr(&main)` to determine the main module's load address, leveraging the fact that `main` will be available at load time.
