This commit fixes an Internal Compiler Error (ICE) in GCC's C++ frontend (PR125539) that occurred during template instantiation (`tsubst_expr`) when a `TARGET_EXPR` containing a comma expression was encountered in a `constexpr static` variable initializer. Previously, the `ocp_convert` function would create a `TARGET_EXPR`, which lacked the necessary early exit logic that `tsubst_expr` relies on. The fix ensures that `ocp_convert` now calls `perform_implicit_conversion` in templates, resulting in an `IMPLICIT_CONV_EXPR` instead of a `TARGET_EXPR`, thereby preventing the crash.
