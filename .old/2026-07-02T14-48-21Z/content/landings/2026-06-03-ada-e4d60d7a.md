Previously, the GCC Ada compiler failed to report an error when a formal parameter with an access discriminant was used in an allocator under certain conditions. This issue stemmed from the relevant rule in Ada Reference Manual 4.8(5.3) being split between the expander and analyzer phases. This fix unifies the implementation of this check within the analyzer, providing a more consistent and robust error detection mechanism. Additionally, error messages for accessibility checks have been streamlined for clarity.
