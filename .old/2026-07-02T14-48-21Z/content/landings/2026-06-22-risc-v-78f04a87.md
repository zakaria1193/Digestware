Binutils now provides comprehensive support for the SpacemiT Vector Dot Product II Extension (XsmTVdotII v1.0), a vendor-specific RISC-V extension for intrinsic matrix operations. This includes updates to the Binary File Descriptor (BFD) library, the GNU Assembler (GAS), and related opcode definitions to correctly parse, assemble, and disassemble code utilizing these new instructions. This integration allows developers to leverage specialized SpacemiT hardware for efficient matrix computations within the RISC-V ecosystem.
