The Rust front-end for GCC (gccrs) has gained the ability to report compilation errors for unsupported `Drop` reference patterns and subpatterns. This enhances compiler diagnostics by immediately flagging Rust code that attempts to `Drop` a reference type in a way that is not currently supported by gccrs. The change involves modifications to `CompilePatternLet::visit` in `rust-compile-pattern.cc` to check base types and emit a 'sorry' message for these unsupported constructs, preventing silent miscompilations.
