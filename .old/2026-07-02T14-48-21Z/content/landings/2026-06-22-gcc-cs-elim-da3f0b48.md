This commit modifies the Combined Scalarization and Elimination (CS-Elim) pass in GCC to no longer return `TODO_TODO_update_ssa_only_virtuals`. Following a previous change (r17-1753-g2e5184c4a93c4b0d4067), the CS-Elim pass now internally keeps virtual operands (VOPs) up-to-date, eliminating the need for a separate SSA update step for these specific elements. This change reduces overhead and simplifies the `cs-elim` optimization pass by removing a redundant request.
