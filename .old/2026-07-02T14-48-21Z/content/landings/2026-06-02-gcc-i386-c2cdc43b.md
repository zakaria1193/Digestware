This change enhances the i386 backend by adding new modes and define_expands for `cond_vec_cbranch_any` and `cond_vec_cbranch_all`. These allow the compiler to generate more efficient code for operations that involve checking if any or all elements of a narrow boolean vector meet a certain condition. This can lead to better performance for vectorized code on i386 processors.
