The AVR backend in GCC now features a significantly improved code generation strategy for `__builtin_avr_delay_cycles`. This overhaul relaxes register constraints to allow broader use of available registers, employs a dedicated C function for assembly output to enable better instruction selection (including `SBIW`), and refines the handling of delay loops. A key improvement is the allowance of zero as a valid cycle count, representing a power-of-2 delay, which expands the utility and efficiency of the intrinsic.
