The ELF linker now correctly sets the image base address to the maximum page size when generating Position Dependent Executables (PDEs). This change addresses a bug (PR ld/34184) where a lower base address could cause segfaults. The linker also now issues a warning if a command-line specified base address is lower than the maximum page size, improving diagnostic capabilities.
