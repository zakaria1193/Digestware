This commit introduces `GOMP_has_masked_thread_num(int tid)` as a new internal libgomp function within OpenMP. Previously, the `omp master` and `omp masked filter(x)` constructs handled thread ID checks by inlining `omp_get_thread_num() == filter`. Since `omp_get_thread_num` is a public API function, OMPT (OpenMP Tools) could not distinguish these internal compiler checks from explicit user calls. By encapsulating this check in a dedicated function, the change improves OMPT's ability to precisely monitor and analyze OpenMP program execution.
