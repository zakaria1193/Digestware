This commit refines the Common Subexpression Elimination (CSE) pass in the x86 backend by changing how floating-point `CONST_VECTOR`s are handled when they originate from integer constants. Instead of directly using a floating-point `CONST_VECTOR` definition, the compiler will now use an integer `CONST_VECTOR` to represent the same bit pattern. This optimization is particularly relevant when integer constants are implicitly converted to floating-point values and then vectorized, leading to more efficient code generation by potentially leveraging integer move instructions to load these constant vectors into general-purpose registers before further processing.
