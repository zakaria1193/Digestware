The i386 backend's stv2 pass now recognizes patterns where a memory SImode value is zero-extended to DImode. This is achieved by loading the SImode value into an SSE register, which effectively clears the upper bits, and then using this for Scalar-To-Vector (STV) conversion. This optimization can lead to more efficient code generation, as demonstrated by a reduction in instructions for a specific test case.
