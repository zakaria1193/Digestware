The COBOL front end in GCC now employs more efficient algorithms for `MOVE BINARY/COMP-5` operations when converting data to packed-decimal and numeric-display formats. This includes new routines for faster binary-to-packed and binary-to-numeric-display conversions, as well as an improved generic routine for COBOL rounding during these moves. These changes specifically target performance improvements for numerical data handling in COBOL applications.
