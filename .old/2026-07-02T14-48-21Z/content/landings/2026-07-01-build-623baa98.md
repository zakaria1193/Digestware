This commit removes the now-obsolete $gnu_ld variable from GCC's build system. Several configurations in config.gcc have been updated to use the new 'ld_flavor' variable or have unconditional settings. Checks for gnu_ld in configure.ac have been replaced with checks for 'ld_flavor', and methods for detecting linker options like --version-script and -soname have been updated to inspect the linker's --help output.
