This commit aligns GCC with the C++ standard by enforcing consistent `noexcept` specifiers in explicit instantiations of templates. Previously, GCC incorrectly allowed mismatches between the `noexcept` specification in an explicit instantiation and the original template declaration. The compiler now detects and reports these mismatches, ensuring correct exception specifications and improving ABI compatibility.
