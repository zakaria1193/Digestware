This commit significantly improves the GCC testsuite's coverage by adding explicit support for checking the Mach-O object file format. Previously, the testsuite already included checks for ELF and PE/COFF, but Mach-O was not formally integrated. The change also updates the developer documentation in `sourcebuild.texi` to explicitly outline the existing and newly added object file format validation capabilities, making it easier for developers to understand and extend these checks.
