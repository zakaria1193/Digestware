When analyzing a generic package declared within a structural instance of a parent generic package, the compiler previously encountered an assertion failure due to an unnecessary access to an uninitialized entity. This fix prevents the `Body_Needed_For_Inlining` flag from being set on the current semantic unit in such cases, as activity within an instance does not affect the unit. Additionally, the change adds a missing call to `Unit_Requires_Body` for generic packages, similar to how generic subprograms are handled.
