The GCC compiler for the i386 `c86-4g-m7` target now incorporates more precise instruction scheduling reservations. This update resolves several existing inaccuracies in how resources like decode units, branch and call execution units, and FPU pipelines were described. It also ensures that memory operations correctly reserve store resources that were previously missing. Additionally, some reservation names have been clarified to better match their corresponding instructions, and duplicate memory attribute checks have been simplified, leading to more efficient and accurate instruction scheduling.
