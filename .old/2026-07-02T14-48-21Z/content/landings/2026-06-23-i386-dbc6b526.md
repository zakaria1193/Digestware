Existing `avx512f_movddup512` and `avx_movddup256` patterns in GCC's i386 backend only supported memory source operands for the `movddup` instruction. Consequently, duplicating even-lane values from a register necessitated spilling the register to memory and reloading it, incurring performance penalties. This update introduces a register-source alternative that emits the `vunpcklpd` instruction, which directly performs the even-lane interleave on register operands, leading to more efficient code generation and eliminating unnecessary memory access.
