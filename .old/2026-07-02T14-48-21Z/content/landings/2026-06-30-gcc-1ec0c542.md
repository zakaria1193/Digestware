This commit implements the C++29 feature P3540R3, which adds an offset parameter to the `#embed` preprocessor directive. This allows developers to embed a portion of a file starting at a specified byte offset, enhancing control over static asset inclusion. The change includes updates to documentation, compiler options, preprocessor builtins, and new test cases for both C and C++.
