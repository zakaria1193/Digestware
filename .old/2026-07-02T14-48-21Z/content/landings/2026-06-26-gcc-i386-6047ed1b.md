GCC has removed the `HAVE_AS_IX86_QUAD` configure check and any code guarded by it. This is because all currently supported versions of the Solaris/x86 assembler, for both `as` and `gas`, reliably support the `.quad` directive for defining 64-bit integer constants. Eliminating this redundant check simplifies the build configuration and reduces conditional compilation, streamlining the GCC codebase without affecting functionality or compatibility on target platforms.
