This commit modifies BFD's configuration on Solaris systems to always define `CP_ACP=1`. This addresses a bug (PR11280) where Solaris's `iconv` library lacks support for the "MS-ANSI" codepage name, causing issues with tools like `windres` and `windmc`. By explicitly setting `CP_ACP=1`, BFD ensures the correct codepage (WINDOWS-1252) is used across all Solaris versions tested.
