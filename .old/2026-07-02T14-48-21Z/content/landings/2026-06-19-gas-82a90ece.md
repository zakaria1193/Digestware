The GNU Assembler for ARM has been updated to support CPU-specific instruction set extensions when using the `-mcpu` flag. Previously, `+ext` and `-noext` modifiers were only available with `-march`, but now developers can enable or disable extensions like DSP or floating-point units directly with `-mcpu=<cpu>+ext` or `-mcpu=<cpu>+noext`, mirroring GCC's command-line interface. This change adds a per-CPU extension table and updates existing CPU feature definitions, primarily impacting how developers specify ARM architecture features during assembly.
