This commit addresses an issue in the RISC-V backend where `define_insn_and_split` was generating multiple instances of an instruction with the same name. By adding a `*` prefix to the instruction name in `riscv.md`, these names are now treated as debugging aids only, preventing naming conflicts and improving the compiler's internal consistency for RISC-V targets.
