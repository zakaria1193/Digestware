This commit refines macro definition and invocation mappings in the Rust front-end by adopting `find_leaf_definition`. This change allows the compiler to resolve macros to their true definitions, rather than a potential import, improving accuracy and providing more robust error checking during the resolution process. The `insert_once` API has also been renamed to `try_insert_once` with improved logic.
