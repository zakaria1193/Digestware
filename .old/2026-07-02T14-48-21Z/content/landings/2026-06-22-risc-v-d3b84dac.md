Binutils now supports the RISC-V Zvabd extension, which introduces vector integer absolute difference instructions. This includes the `vwabda.vv` and `vwabdau.vv` widening accumulate mnemonics, allowing the assembler and other Binutils components to correctly parse, assemble, and disassemble code using these new vector operations. This addition enhances the ability of RISC-V systems to perform efficient computations involving absolute differences on vectors.
