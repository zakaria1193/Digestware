The `pr29655` test, which validates how the linker resolves function addresses with Position-Independent Code (PIC), now explicitly 'xfails' (expected to fail) on additional architectures including M68k, RISC-V, S390, SH, and Tile. This accommodates variations in how different linker port maintainers handle the assignment of function addresses to Procedure Linkage Table (PLT) stubs, particularly when PIC is involved.
