This commit adds a new test case to verify the correctness of the ATOMIC_*_LOCK_FREE macros provided by the <stdatomic.h> header. The test is a copy of an existing test for <atomic> with the header include adjusted to test the freestanding header provided by the C standard. This change ensures that the libstdc++ implementation adheres to the requirements of LWG 4480, which mandates the presence of ATOMIC_CHAR8_T_LOCK_FREE.
