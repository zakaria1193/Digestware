This commit fixes an issue with NVIDIA GPU NUMA node information within the OpenMP runtime library. Previously, the `numa_node` member for NVIDIA GPUs was not reliably initialized, leading to incorrect or random values being reported. This change initializes `numa_node` to zero, ensuring that the OpenMP offload system can distinguish between a node being at NUMA distance 0 and an uninitialized state, thus providing correct NUMA node information for GPUs.
