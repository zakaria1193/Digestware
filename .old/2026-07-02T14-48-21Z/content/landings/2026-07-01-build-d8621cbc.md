This commit introduces `as_flavor` and `ld_flavor` variables to GCC's build system, replacing older, platform-specific variables like `solaris_as`. These new variables default to 'gnu' and can be set to other values like 'aix', 'darwin', or 'hpux' to indicate the type of assembler or linker in use. This change simplifies the handling of diverse vendor toolchains and prepares the build system for the removal of `HAVE_GNU_AS` and `HAVE_GNU_LD`.
