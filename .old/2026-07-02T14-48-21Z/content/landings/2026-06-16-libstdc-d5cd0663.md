This commit updates the internal helper functions for libstdc++'s random number generation module to use `const void*` for relevant parameters. Previously, these functions accepted `void*`, which implied that the pointed-to data could be modified. Changing to `const void*` accurately reflects that these functions only read the data, enhancing type safety and clarifying intent within the library's internal implementation for PR125684.
