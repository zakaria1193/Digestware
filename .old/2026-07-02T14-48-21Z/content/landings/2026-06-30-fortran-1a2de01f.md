A memory leak in the Fortran compiler's handling of parameterized derived types (PDTs) has been fixed, addressing PR121972. The issue occurred when a PDT contained a derived type component, which itself had allocatable components. The compiler now correctly marks such PDTs as having allocatable components, ensuring proper memory management. Additionally, a test case has been updated to verify the fix, and a new test case ensures that a related leak in non-PDT scenarios is also resolved.
