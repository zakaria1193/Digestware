This commit ensures that the 'nnd' debug hook is activated when the `Change_Node` function is called. Previously, this hook was only triggered by `Mutate_Nkind`. Since `Change_Node` implements a specific form of node kind mutation, enabling the 'nnd' hook for it provides more comprehensive debugging capabilities during tree transformations.
