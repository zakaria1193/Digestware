This change simplifies the instruction selection for `avx512vl_<code><mode>v4hi2_mask_store_1` on Intel 386-compatible processors. Previously, the code used conditional logic to choose between two very similar output patterns for mask stores, depending on the mode's size. Since a prior fix (PR106095) made these patterns identical, the conditional logic is now redundant. The commit removes this redundancy by using a single, unconditional output pattern, making the generated assembly more streamlined.
