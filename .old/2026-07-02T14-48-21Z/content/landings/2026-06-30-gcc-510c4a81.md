For C23 and subsequent standards, the primary keyword for boolean types is `bool`, with `_Bool` serving as a backward compatibility alias. This change updates GCC to use `bool` in generated debug information and diagnostic messages for C23+ code, improving clarity and adherence to the modern C standard. Code targeting C17 and earlier will continue to use `_Bool` as before.
