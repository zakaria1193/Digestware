The C++ front end in GCC simplifies an overly complex and difficult-to-read condition within the `check_initializer` function. Previously, this condition included a disjunction that caused `build_aggr_init_full_exprs` to be called unnecessarily for aggregate initializations using empty braces (`{}`). The simplified logic now avoids this redundant call, leading to cleaner code and potentially more efficient handling of such initializations.
