This commit improves code clarity within GCC's `build_vector_from_ctor` function by renaming confusing variables. The variable `nelts` is clarified to mean the number of patterns, not necessarily the number of encoded elements, and `step` is renamed to accurately reflect its meaning as elements per pattern. This change aims to reduce confusion in compiler development discussions and maintenance.
