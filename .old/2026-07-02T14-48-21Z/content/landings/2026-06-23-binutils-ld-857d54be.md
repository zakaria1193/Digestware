This update to the AVR linker script (avr.sc) adds pattern rules to explicitly include `.gnu.linkonce.t*` sections in the `.text` output section and `.gnu.linkonce.b*` sections in the `.bss` output section. This change ensures that relevant sections for deduplication are correctly placed, which is particularly useful for compilers generating such sections, although modern G++ uses COMDAT for similar purposes. Previously, `.gnu.linkonce.d*` for data and `.gnu.linkonce.r*` for read-only data were already handled.
