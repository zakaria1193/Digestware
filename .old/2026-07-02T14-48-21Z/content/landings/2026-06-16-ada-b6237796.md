This commit resolves an internal error that occurred when deriving a new type from an untagged controlled private type. The issue stemmed from an incorrect assumption about the presence of a dispatch table for such derived types. The fix ensures that the associated class-wide type is not incorrectly built, preventing the internal error and maintaining type system integrity.
