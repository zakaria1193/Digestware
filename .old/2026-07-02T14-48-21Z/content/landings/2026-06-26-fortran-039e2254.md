This commit addresses a bug in the GCC Fortran front end related to how it handles certain attributes within allocatable components. Specifically, the `has_class_alloc_comp` function in `trans-array.cc` was incorrectly checking a generic `atte` attribute. The fix changes this to `atte.class_pointer`, ensuring that the compiler correctly identifies and processes Fortran allocatable components that are polymorphic, which prevents compilation errors for valid Fortran code.
