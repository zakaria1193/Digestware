Support for the AMX-TF32 instruction set has been disabled for Intel's upcoming Diamond Rapids processors. This decision aligns with the Instruction Set Extension (ISE) updates, which indicate the removal of this feature from future hardware. The change is being backported to GCC versions 15 and 16 to ensure consistency across supported compiler releases.
