  contains loops that iterate over section headers using `i-- > 0`. When no match

A bug in the `elf32_arm_copy_special_section_fields` function for ARM ELF files could lead to an out-of-bounds read when processing section headers. The loop controlling the search for corresponding output sections iterated incorrectly, resulting in a negative index when a match was not found. This change modifies the loop condition to ensure correct loop termination and prevent potential memory access errors.
