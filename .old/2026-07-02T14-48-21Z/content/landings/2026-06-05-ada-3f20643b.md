The Ada front end's internal code for discarding abstract syntax tree (AST) nodes has been refactored. Instead of using dedicated local variable blocks, functions like `Build_Implicit_Copy_Constructor` and `Build_Implicit_Parameterless_Constructor` in `exp_ch3.adb` now consistently use the `Discard_Node` function, making the code cleaner.
