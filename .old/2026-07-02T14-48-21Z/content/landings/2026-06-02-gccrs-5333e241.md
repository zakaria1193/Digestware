This commit refines the `GlobbingVisitor` in the GCC Rust front-end to prevent it from incorrectly descending into certain Rust item types. Previously, the visitor would improperly glob-import items nested within other constructs, leading to incorrect name resolution. The updated code adds specific overrides for various item types, ensuring that only top-level items from a glob container are considered for import, thereby maintaining correct semantic behavior for glob imports.
