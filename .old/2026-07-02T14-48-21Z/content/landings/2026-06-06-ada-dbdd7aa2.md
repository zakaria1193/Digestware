This update to the Ada front end enables the use of abstract constructors, which can be declared in the visible part of a package but must be defined in the private section. This mechanism allows developers to expose an interface for object construction without revealing implementation specifics. The change involves modifications to how attributes are analyzed, how full views are processed, and how constructors are collected, ensuring proper error reporting for incorrect abstract constructor calls.
