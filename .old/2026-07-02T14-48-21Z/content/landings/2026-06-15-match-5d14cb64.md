The `match.pd` file in GCC, used for pattern matching and optimization, now correctly identifies the condition `X % Y < Y` as always true when both `X` and `Y` are known to be nonnegative integers. This relaxation is applied by utilizing `tree_expr_nonnegative_p`, which covers both unsigned types and cases where nonnegativity is otherwise established. By simplifying this condition earlier in the compilation process, the compiler can potentially perform better optimizations.
