This commit introduces the foundational structure within GCC Rust for tracking local variables that require explicit dropping. A new `DropCandidate` struct is added to `rust-compile-context.h`, which will be used to manage these variables. This change is crucial for ensuring correct resource cleanup and memory safety in generated Rust code by correctly handling destructors.
