This commit resolves build issues for the RISC-V assembler and disassembler when using older versions of GCC (prior to 11) or Clang. The problem was caused by using a C23 extension where a label was followed directly by a declaration, which is not supported by older compilers. The fix involves adding braces around these declarations, ensuring compatibility with a wider range of compiler versions.
