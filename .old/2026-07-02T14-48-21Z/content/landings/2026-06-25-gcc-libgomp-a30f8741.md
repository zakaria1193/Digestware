This commit addresses a documentation issue in `libgomp.texi`, the manual for GCC's OpenMP runtime library. Specifically, it corrects missing `@end smallexample` arguments within the sections for 'Implementing MASKED and MASTER construct' and 'Implementing FOR construct'. This fix ensures proper formatting and prevents potential build problems with the Texinfo documentation.
