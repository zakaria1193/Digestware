GCC's RISC-V backend has been improved to synthesize logical operations more efficiently when the Zbb (Bit Manipulation) extension is enabled. Instead of solely relying on later optimization passes, the compiler now proactively checks if synthesizing an inverted constant (`~C`) is cheaper than the original constant (`C`). If so, it uses the cheaper inverted constant with instructions like `andn`, `orn`, or `xnor` to generate better code earlier in the compilation pipeline.
