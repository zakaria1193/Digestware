The libstdc++ filesystem library now includes additional test cases for `std::filesystem::status` and `std::filesystem::symlink_status`, specifically targeting directory symlinks. While POSIX systems typically handle these transparently, Windows requires distinct handling for directory and file symlinks. These new tests ensure that the library's behavior is correct and consistent across different operating systems, particularly in anticipation of improved Windows symlink support, enhancing the portability and robustness of filesystem operations.
