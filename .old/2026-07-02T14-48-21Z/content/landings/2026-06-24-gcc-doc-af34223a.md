This commit removes whitespace characters that previously appeared directly after the `@code` directive in the `doc/ifn.texi` documentation file. Older versions of Makeinfo, a documentation tool, are sensitive to this additional whitespace and would fail to process the file correctly. This seemingly minor change ensures broader compatibility for GCC's documentation build process.
