This commit enhances GCC's x86-64 backend by making bounded `memset` and `memcpy` expand similarly to `memmove`. Previously, these functions generated extra branches and moves due to not fully utilizing known maximum size information. By renaming and extending `ix86_expand_movmem` to handle `memset` and `memcpy`, and calling it for bounded operations, GCC reduces generated code size by up to 9% in some benchmarks.
