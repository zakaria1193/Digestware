The COBOL frontend in GCC now uses `tree_type_from_field()` and introduces `tree_type_from_refer()` to standardize how data types are determined within the compiler's intermediate representation. This change eliminates many specialized, repetitive routines. Additionally, numerous file-static variables are replaced with non-specific variable definitions, reducing potential for bugs and improving the overall structure of the code base. The fix also addresses an issue with the `DIVIDE ... GIVING REMAINDER` calculation when negative parameters are used.
