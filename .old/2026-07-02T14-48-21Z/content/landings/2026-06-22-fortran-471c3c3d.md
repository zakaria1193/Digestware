The GCC Fortran runtime library `libgfortran` now correctly handles the `FMT_X` edit descriptor, which specifies a character position skip in formatted I/O. Previously, the `nspaces` variable was not properly updated, leading to incorrect whitespace in output. The fix ensures `nspaces` accurately reflects the number of skipped positions, resolving issues with formatted string output and adjusting test cases to reflect this corrected behavior.
