primer_general: In C++, 'lambdas' are short, anonymous functions you can write directly
  within your code. As C++ evolves, new rules are designed to ensure different compilers
  (like GCC) agree on how certain features work, especially when it comes to things
  like how types are ordered or represented, which impacts how different parts of
  a program can communicate with each other (its 'Application Binary Interface' or
  ABI). This update adds new tests to GCC to check if its current handling of lambdas
  already matches a proposed C++29 standard (P3847R1) that deals with how lambdas
  are 'lexically ordered' – meaning how their unique identity is determined based
  on where they appear in the source code. These tests confirm that GCC is already
  compliant, which is good news for future C++ development, as it means consistent
  behavior when using lambdas.

This commit introduces new test cases to validate GCC's behavior regarding C++29 P3847R1, which specifies the lexical ordering for lambdas. The tests confirm that GCC already adheres to this proposed standard, which is crucial for ABI compatibility and consistent behavior across different compilers. By adding these tests, the project verifies the correct implementation of an upcoming C++ standard feature related to how lambdas are ordered.
