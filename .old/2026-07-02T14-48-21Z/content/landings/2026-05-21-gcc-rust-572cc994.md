This significant change in the Rust front-end alters how name resolution works by requiring consumers of the finalized name resolution context to specify the namespace(s) in which usages should be looked up. Instead of a single map, there is now a dedicated usage map for each namespace, and new APIs have been introduced to facilitate looking up usages in one or multiple namespaces. This refactoring impacts numerous components across the backend, various checkers, and early name resolution, ensuring greater precision and control in name resolution.
