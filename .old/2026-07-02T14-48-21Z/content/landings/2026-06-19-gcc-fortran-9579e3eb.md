The Fortran compiler has been updated to fix a memory leak that specifically affected array structure-constructor elements containing allocatable components. This fix ensures that when such elements are processed, dynamically allocated memory for their components is properly freed. By introducing a new helper function to identify derived types with `CLASS` components and adjusting the freeing logic, the compiler now correctly manages memory for these complex data structures, preventing leaks and improving program stability.
