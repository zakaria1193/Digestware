The Algol 68 frontend in GCC now provides more informative diagnostics when encountering multiple declarations of the same identifier. The functions `already_declared` and `already_declared_hidden` in `a68-parser-taxes.cc` now utilize a new `attr_descr` function. This change allows the compiler to output more detailed attribute descriptions, helping developers better understand and resolve multiple declaration errors.
