GCC now supports the RISC-V Zvabd vector extension, which introduces new instructions for vector absolute difference operations. This update provides auto-vectorization patterns for `vabs`, `vabd`/`vabdu`, and `vwabda`/`vwabdau` instructions, improving performance for relevant computations. Developers can now leverage these specialized vector instructions through GCC, leading to more efficient code on RISC-V platforms that implement the Zvabd extension.
