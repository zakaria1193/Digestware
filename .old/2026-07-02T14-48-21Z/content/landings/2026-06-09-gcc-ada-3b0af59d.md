primer_general: In programming languages, a "type" defines the kind of values a variable
  can hold and the operations that can be performed on it. In Ada, a "limited type"
  is a special kind of type where objects of that type cannot be copied or assigned
  directly. This is often used for things like file handles or network connections,
  where copying wouldn't make sense or would lead to errors. "Declare expressions"
  in Ada 2022 are a way to declare a local variable and use its value within a larger
  expression. Previously, when the GCC Ada compiler encountered a declare expression
  involving a limited type, it would try to create a temporary copy of the object,
  which is forbidden for limited types. This led to an incorrect error message. The
  fix ensures that the compiler now recognizes limited types within declare expressions
  and avoids creating these forbidden temporary copies, allowing your Ada 2022 code
  to compile correctly.

The Ada compiler in GCC has been fixed to properly manage declare expressions when dealing with "limited types." Previously, the compiler would incorrectly generate an error because it tried to create temporary objects for these types, which is incompatible with their definition. The change ensures that declare expressions involving limited types are now handled without error.
