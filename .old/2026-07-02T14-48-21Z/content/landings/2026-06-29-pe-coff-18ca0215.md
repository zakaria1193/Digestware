PE/COFF object files now automatically switch to the 'bigobj' format when the number of sections exceeds the limit of 16-bit section numbers. This change, implemented in `coff_compute_section_file_positions`, ensures that larger object files can be generated without manual intervention, provided the backend supports bigobj targets. New tests are included to verify this automatic promotion.
