This commit introduces the `rustc_std_internal_symbol` attribute to the GCC Rust compiler, which is essential for the Rust standard library. When applied, this attribute prevents the compiler from 'mangling' the names of internal runtime symbols. This ensures that these symbols retain their original names, facilitating proper linking and interaction within the Rust runtime environment, which relies on consistent symbol names.
