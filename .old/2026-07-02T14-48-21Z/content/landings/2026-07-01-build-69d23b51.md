The build system option `--with-gnu-ld` has been removed as it is no longer necessary. This change eliminates the corresponding `gnu_ld_flag` variable and simplifies configure messages, as GCC's compatibility with GNU ld is now a standard assumption. Documentation related to this option has also been updated.
