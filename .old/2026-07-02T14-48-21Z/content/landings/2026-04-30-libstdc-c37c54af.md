This commit enhances the Doxygen documentation for algorithms in `<bits/stl_algo.h>` within libstdc++. It addresses issues with generating ill-formed XML by switching some Doxygen commands to Markdown, improving the clarity of half-closed range notation (e.g., `[first, last)`), and using `@cond`/`@endcond` to hide internal helper functions from the documentation. Additionally, an obsolete Doxygen configuration variable has been removed.
