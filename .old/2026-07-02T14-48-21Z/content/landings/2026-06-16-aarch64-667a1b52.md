This commit corrects an issue in the AArch64 backend that caused incorrect code generation for 128-bit Advanced SIMD constants where the high 64 bits are zero. Previously, when the low 64 bits were not a valid Advanced SIMD immediate, the compiler would erroneously fall through to SVE immediate forms. This resulted in the entire 128-bit vector being replicated with the low 64-bit value, leading to wrong code. The fix prevents this fallthrough when the output width is already set, ensuring that constants are materialized correctly or handled via alternative methods like literal-pool loads.
