The Binutils pre-commit configuration now uses `unsupported_script` as the language specifier for hooks that do not require a dedicated environment. This change addresses the deprecation of the `script` alias in `pre-commit` v4.4.0. Additionally, the `check-include-guards` hook, which uses standard Python modules, has been switched from `python` to `unsupported_script`, further streamlining `pre-commit`'s environment management by reducing unnecessary virtual environment creation. This makes the pre-commit configuration compatible with future `pre-commit` versions.
