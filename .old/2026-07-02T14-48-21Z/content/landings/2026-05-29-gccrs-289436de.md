The Rust front-end for GCC (gccrs) now correctly inserts `Drop` calls for values when they go out of scope at the end of a block. This ensures that resources associated with these values are properly released, aligning gccrs's behavior with Rust's ownership and lifetime rules. This feature was implemented by adding a new helper function, `compile_drop_call`, and updating `CompileBlock::visit` in `rust-compile-block.cc` to emit these crucial cleanup calls.
