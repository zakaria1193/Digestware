This patch significantly improves the error messages generated when a program attempts to call a constructor that is unavailable or uses an incorrect number of parameters. This specific issue is common because constructors in Ada are not inherited, meaning a constructor for a parent tagged type might not exist for its derived types. Additionally, the commit fixes a compiler crash that occurred during the initialization of a limited record type, by ensuring correct accessibility level handling and proper initialization of parent components.
