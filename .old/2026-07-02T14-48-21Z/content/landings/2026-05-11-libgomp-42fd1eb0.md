The `oacc-parallel.c` file within libgomp, which handles OpenACC parallel constructs, moved from `libgomp/config/nvptx/` to `libgomp/config/accel/`. This relocation addresses an issue where GCN targets incorrectly compiled the host version of the file instead of the intended accelerator-specific empty version. The move ensures that accelerator backends can correctly select the appropriate OpenACC parallel implementation.
