This commit addresses build and test case regressions found in GCC's OpenMP implementation related to the `uses_allocators` clause. It fixes an issue where `libgomp/config.h.in` was not regenerated, causing configuration errors, particularly when compiler intrinsics for atomic operations were unavailable. Additionally, it resolves type-related errors in `allocator.c` concerning the initialization of mutexes for offloading, ensuring correct pointer handling and compatibility.
