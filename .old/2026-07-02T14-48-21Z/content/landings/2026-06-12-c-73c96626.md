This commit fixes a bogus error in the C++ frontend of GCC (PR125770) that occurred when using `meta::members_of` in conjunction with the `__integer_pack` built-in parameter pack. The compiler's `mark_used` function was incorrectly issuing an error about the use of `__integer_pack` outside of a template, even when called with `tf_none`. The fix ensures that `mark_used` now properly checks error conditions, preventing the erroneous diagnostic and allowing valid reflection code to compile without issues.
