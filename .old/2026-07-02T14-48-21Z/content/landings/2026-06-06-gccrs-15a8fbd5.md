The Rust front-end for GCC (gccrs) now searches the `lang_prelude` when performing name resolution at module boundaries. This ensures that common items from the Rust standard library are automatically in scope when entering a new module, aligning the compiler's behavior with the Rust language specification. The change affects the `NameResolutionContext::resolve_segments` function in `rust-name-resolution-context.hxx`, which now includes a check to trigger the `lang_prelude` search.
