This commit adds sanity checks to the M32R HI/LO relocation code in the Binary File Descriptor (BFD) library. These checks ensure that relocation offsets are within the valid range of the input section, preventing potential out-of-bounds memory accesses during relocation processing, and addresses a fuzzer-reported vulnerability.
