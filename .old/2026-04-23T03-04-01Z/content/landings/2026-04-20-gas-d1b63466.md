The assembler's ``snapshot_symbol()`` function was not properly accounting for the addend (X_add_number) when encountering a local symbol.  This commit ensures that the addend is correctly incorporated, preventing potential errors in code generation. The fix also makes sure that the symbol's value isn't added if the result is still going to be O_symbol.
