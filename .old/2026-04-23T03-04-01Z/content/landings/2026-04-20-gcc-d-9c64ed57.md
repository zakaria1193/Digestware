A recent change to lower associative array literals in the frontend caused a regression on 32-bit SPARC targets. The runtime function `_d_assocarrayliteralTX()` returns a `void*`, but the expression was expected to be of type `struct { void* ptr; }`. This commit corrects the return type by constructing the appropriate struct.
