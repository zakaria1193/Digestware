The commit removes a call to `labs` in `ctf-link.c` that could trigger a signed/unsigned comparison warning when compiling for a 32-bit host. The `labs` function was used to check the number of inputs, but the error status is now checked directly. The commit also improves error reporting by using `%lu` for the number of inputs.
