This commit fixes an internal compiler error (ICE) in the SCCVN pass when compiling code that uses large bit-precise integers on RISC-V. The fix involves using `build_bitint_type` instead of `build_nonstandard_integer_type` when the size of the bit-precise integer exceeds `MAX_FIXED_MODE_SIZE`. This ensures that the compiler correctly handles these larger bit-precise integer types during value numbering.
