Richard Biener responds to a discussion about the risk of LLMs reproducing copyrighted code verbatim. He argues that the more likely concern is LLMs copying concepts, which raises questions about derived works and software patents. He suggests the legal ramifications of using LLMs in code contributions need clarification, particularly whether disclosing LLM usage provides sufficient legal protection.
