The x86 common subexpression elimination (CSE) pass now uses integer loads when loading constant vectors that are no larger than an integer register. This improves code generation for certain vector constants.  The change introduces an `ix86_broadcast_inner` mode to handle the scalar mode for constant vector loads, and adds a new test case to verify the functionality.
