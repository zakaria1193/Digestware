The testsuite now correctly identifies the configured assembler, even when a non-default path is used. Previously, tests in `gcc.misc-tests/options.exp` would fail if `--with-as` pointed to an assembler whose name didn't end in "as". The fix uses newline-sensitive matching and checks for the actual configured assembler name.
