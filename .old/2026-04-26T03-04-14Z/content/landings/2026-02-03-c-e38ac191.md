GCC now enforces the C++ standard rule against declaring unnamed bit-fields with cv-qualified types (e.g., `const int : 4;`). This commit adds a pedwarn (a warning that is issued when the code violates the C++ standard) when such a declaration is encountered, aligning GCC's behavior with the standard and preventing potential undefined behavior.
