The x86 common subexpression elimination (CSE) pass now removes redundant thread-local storage (TLS) calls even when SSE2 is disabled. Previously, the `x86_cse::gate` function checked for SSE2, preventing TLS call elimination in some configurations. Removing this check enables more aggressive optimization, potentially improving performance for code that uses TLS.
