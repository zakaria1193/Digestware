This commit introduces a vector cost model tailored for the Spacemit-X60 RISC-V core, using data from the Camel CDR project. The model caps long-latency instructions at 7 cycles, aligning with discussions from the RISC-V Patchwork Meeting. This new cost model should improve the accuracy of compiler estimations and scheduling decisions for this target, leading to better performance of vector code.
