The x86 compiler backend now uses integer loads for `CONST_VECTOR` loads when the vector size is no larger than the size of an integer register.  This optimization avoids using more expensive vector load instructions when a smaller integer load suffices. This improves code generation for cases where constant vectors can be efficiently loaded using integer registers.
