The RISC-V backend optimizes specific equality comparisons. When testing the result of a logical AND for equality and one operand requires synthesis, the compiler can now right-shift trailing zeros from the constant and shift the other input. This optimization removes data dependencies, slightly improving code density and efficiency by reducing the instruction count. The change focuses on low-level RISC-V codegen and addresses a specific issue reported in PR rtl-optimization/56096.
