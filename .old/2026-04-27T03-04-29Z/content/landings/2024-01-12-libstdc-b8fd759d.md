primer_expert: Updates the embedded copy of the IANA tzdata database used by ``std::chrono``
  in C++20 and later. This affects the ``std::chrono::time_zone`` class and related
  functions, which rely on this data for accurate time zone calculations and conversions.
  The update involves replacing the ``tzdata.zi`` file and modifying the leap seconds
  expiry date in ``chrono::__detail::__get_leap_second_info`` and ``tzdb_list::_Node::_S_read_leap_seconds``.
primer_general: The C++ standard library includes facilities for working with dates,
  times, and time zones.  A key part of time zone handling is the time zone database,
  which contains the rules for converting between UTC and local time for various time
  zones around the world. This database is maintained by IANA and updated periodically
  to reflect changes in time zone boundaries, daylight saving time rules, and leap
  seconds. This commit updates the library's embedded copy of that database.  If your
  C++ application uses ``std::chrono`` to work with time zones, this update ensures
  it has the latest information.

The libstdc++ library has been updated with the latest tzdata (time zone database) release, 2026a. This includes updates to the leap seconds list and the corresponding expiry date.  Users relying on accurate time zone information in their C++ applications will benefit from this update.
