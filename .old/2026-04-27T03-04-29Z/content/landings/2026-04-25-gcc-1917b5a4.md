This commit resolves an RTL checking abort that occurred when classifying THead-specific addressing modes on RISC-V. The issue arose from the code referencing the wrong object when extracting a constant value from a multiply operation. The fix involves correcting the object reference, preventing the abort and ensuring proper handling of THead memory address classification.
