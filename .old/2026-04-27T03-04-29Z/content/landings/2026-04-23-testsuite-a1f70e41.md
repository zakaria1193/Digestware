This commit introduces a new effective-target keyword, `sleep`. This keyword allows testsuite code to conditionally execute tests based on whether the `sleep` function is available on a given target.  This is necessary because `libgfortran` calls `sleep`, but it is not available on all targets. The change also documents the new keyword.
