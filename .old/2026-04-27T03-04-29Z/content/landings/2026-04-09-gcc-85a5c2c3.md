This commit removes `STMT_VINFO_SLP_VECT_ONLY_PATTERN` as it is no longer needed for cleanup operations. The SLP pattern is now only reachable from the pattern SLP nodes representative, simplifying the code and removing dead code paths in several files related to tree vectorization, specifically in loop analysis and SLP pattern building.
