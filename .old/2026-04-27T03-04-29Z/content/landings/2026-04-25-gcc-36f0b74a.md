The RISC-V backend now simplifies shifts with counts expressed as 31-N or 63-N using a bitwise NOT operation.  Instead of loading 31 or 63 into a register and then subtracting N, the compiler now uses the bitwise NOT operation.  This is possible due to the `SHIFT_COUNT_TRUNCATED` semantics of the RISC-V architecture, which means that only the lower bits of the shift count are relevant.  This reduces code size by eliminating a constant load.
