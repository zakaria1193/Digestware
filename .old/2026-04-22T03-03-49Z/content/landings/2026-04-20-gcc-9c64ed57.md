This commit fixes a regression in the D language frontend that affected 32-bit SPARC targets. The regression was introduced by a switch to front-end lowering of AA (associative array) literals. The runtime function `_d_assocarrayliteralTX()` returns a `void*`, but the expression should be of type `struct { void* ptr; }`. The fix ensures the correct type is returned.
