This commit rewrites the "Building a shared library" section in the `gm2.texi` documentation, providing up-to-date information about the default dynamic module scaffold. It also includes an example of C++ code calling a Modula-2 shared library. Additionally, it corrects the parameter types in the `m2rts.h` header file for several runtime functions.
