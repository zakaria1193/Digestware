This commit fixes an internal compiler error (ICE) in the D frontend. The error occurred when an enum type was defined within another enum (``enum : enum A``). The compiler would incorrectly overwrite the size of the underlying type, leading to the ICE. The fix ensures that `layout_type` is only called on the main variant of the enum.
