This commit updates the API for injecting external crates in gccrs. The `Crate::inject_extern_crate` function now returns the node identifier of the newly injected crate. This change facilitates better integration with other compiler components that may need to reference the injected crate's internal representation, improving the overall management of external dependencies within the compiler's Abstract Syntax Tree (AST).
