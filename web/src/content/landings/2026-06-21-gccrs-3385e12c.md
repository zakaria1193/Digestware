This commit reverts changes that made language item segment names optional in gccrs. It was found that these names are not fixed and are declared within the core crate. Making them optional prevented accurate dumping of the Abstract Syntax Tree (AST), as the exact paths to language items could not be reconstructed. The segment name argument has been added back to relevant AST builder functions.
