This commit tidies up the Modula2 build process by introducing a new `safeRemove` function. This function checks if a file name is not `None` and if the file actually exists before attempting to remove it. The `quietSystem` function now uses `safeRemove` for deleting temporary files and output files, making the build process more robust.
