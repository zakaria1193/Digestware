This change unifies node trees within gccrs's ForeverStack, allowing multiple instances to share the same set of nodes. Previously, each ForeverStack built its own tree, leading to redundant memory usage. By introducing ForeverStackBase and making nodes shareable, this commit reduces memory overhead and simplifies the handling of node objects originating from ForeverStacks with different namespaces. This is a key step towards more efficient memory management in the Rust frontend.
