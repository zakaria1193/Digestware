Support for half-float elements within vector constants has been added for the s390 architecture. This change registers the necessary modes (`V{1,2,4,8}HFmode`) for constant vectors loaded from the constant pool, enabling their correct handling. A new test case (`vec-const-hf-1.c`) has been added to verify this functionality.
