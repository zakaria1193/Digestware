Several tests related to PR 125436 were failing during `check-function-bodies` due to the generated code using AVX instructions (e.g., `vmovaps`) when the expected code used non-AVX equivalents (e.g., `movaps`). This commit applies the -mno-avx flag to these tests to prevent AVX instruction generation and resolve the failures.
