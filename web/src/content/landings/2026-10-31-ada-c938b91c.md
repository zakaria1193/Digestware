A recent optimization in GCC's Ada front-end introduced a regression where function calls returning on the secondary stack were not correctly adjusted when used in an allocator. This commit fixes `Expand_Ctrl_Function_Call` to ensure that if a qualified expression of an allocator is a call returning on the secondary stack, the result is properly copied to the allocated memory by calling `Adjust` if the type is controlled.
