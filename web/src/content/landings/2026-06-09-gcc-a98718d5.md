The AC_HEADER_STDC autoconf macro, which checks for C89/C90 compatibility, has been removed across various GCC components including GCC itself, fixincludes, libcpp, libgrust, and others. This change assumes that a C89/C90 compliant environment is available for building GCC, simplifying the build configuration and aligning with autoconf 2.70's deprecation of this check. This addresses PR bootstrap/112422.
