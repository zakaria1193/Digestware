A GCC testcase (`g++.dg/torture/pr128147.C`) was failing on Arm architectures at optimization level -O1 due to a trapping load instruction occurring at the very beginning of a function. This caused an issue with exception handling during unwinding. The fix modifies the testcase by loading the pointer through an intermediate variable first, ensuring the trapping load is no longer the initial instruction. This change allows the test to pass on Arm without altering the generated code's correctness, as reported in PR128147.
