The binutils linker now performs more thorough checks for invalid GOT (Global Offset Table), PLT (Procedure Linkage Table), and TLS (Thread-Local Storage) relocations on x86 architectures. Specifically, it will now report errors for TLS, GOT, and PLT relocations in non-allocating sections, and for TLS relocations targeting non-thread-local symbols. These checks address issues reported in PR ld/34444 and PR ld/34448, enhancing linker robustness and error reporting.
