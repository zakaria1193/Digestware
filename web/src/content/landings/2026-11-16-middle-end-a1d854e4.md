GCC's `prepare_cmp_insn` function has been corrected to exclusively use the `cmpmem` pattern for comparing BLKmode operands (blocks of memory). Previously, it would attempt `cmpstr` and `cmpstrn` if `cmpmem` failed, but these patterns stop at null bytes and can produce incorrect results for blocks containing nulls. The change ensures that block comparisons are performed correctly by retrying with the next mode only if `cmpmem`'s expander fails.
