A regression in the `wi::copy` function for GCC's wide-integer type caused a "maybe used uninitialized" error during bootstrap when the integer length was zero. This change ensures that the function checks for a non-zero length before attempting to copy, resolving the build issue. The problem was exposed by a change in thread backedges that revealed an uninitialized pointer path.
