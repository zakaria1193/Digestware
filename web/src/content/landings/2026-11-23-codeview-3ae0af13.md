This commit modifies the CodeView debug info generation to use `switch_to_section` for `.debug$S` and `.debug$T` sections. Previously, directly manipulating the assembler's section could lead to incorrect state tracking (`in_section`), causing errors like 'can't resolve .debug$T - .Ltext0'. Using `switch_to_section` maintains the correct current section, resolving these issues and ensuring proper debug information generation.
