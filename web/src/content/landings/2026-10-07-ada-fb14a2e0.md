A wild memory access occurred in the Ada compiler when using `pragma Warnings (On|Off, "*")`, particularly when such pragmas were located in configuration files. The issue arose because `Find_Direct_Name` attempted to manually walk the scope stack while it was still empty. This commit adds a necessary guard to prevent this manual stack walk under such conditions.
