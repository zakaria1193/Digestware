A new lint has been added to gccrs to detect and warn about 'unsafe' blocks that do not contain any operations necessitating an unsafe context. The unsafe checker now tracks which 'unsafe' blocks are actually utilized by such operations, flagging any that are not. This feature, gated by `-frust-unused-check-2.0`, aims to improve code quality by identifying potentially unnecessary or dead 'unsafe' code.
