This commit adds a necessary `visit` call within the Argument Position Impl Trait (APIT) desugaring process in gccrs. When desugaring APITs in a function, the compiler must now also visit the function's internal block and any nested items. This ensures that APITs within inner functions are correctly processed, preventing potential issues where nested structures might be overlooked.
