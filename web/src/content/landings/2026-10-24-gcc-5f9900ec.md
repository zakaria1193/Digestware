This commit refactors code generation in several GCC backends (compare-elim, alpha, arc, arm, cris, lm32, loongarch, riscv, s390, sh, stormy16, visium) to use `rtx_insn *` for local variables that are assigned values returned by functions which themselves return machine instructions. This change enhances type safety and clarity in the RTL emission process by ensuring that variables intended to hold instructions are explicitly typed as such, rather than using more generic pointer types.
