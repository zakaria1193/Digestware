This commit enhances the SH architecture's handling of memory access by introducing stricter predicates and constraints, particularly for the Local Register Allocation (LRA) phase. New constraints 'Rab', 'Rai', and 'Sgb' are added, and existing ones are updated to use specific constraint combinations. The changes also reject invalid hard-registers for memory addresses during LRA and differentiate between old reload and LRA behaviors to manage the transitional period, addressing PR target/55212.
