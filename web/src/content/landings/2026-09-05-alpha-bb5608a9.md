This commit refactors the Alpha ELF backend by extracting the logic for determining a symbol's name, as referenced by a relocation, into a new function called `elf64_alpha_sym_name`. This common function is then used by `relocate_section`, replacing duplicated code. The new function also adopts `bfd_elf_sym_name` for consistency with other backends, which handles section symbols and unknown symbol names more robustly.
