This commit resolves an ICE in the LoongArch backend when handling moves of V1TI and V2TI vector constants. The issue arose because the `loongarch_output_move` function incorrectly checked for `CONST_INT` instead of `CONST_WIDE_INT` for these vector types. By changing the check to `CONST_SCALAR_INT_P`, the compiler now correctly handles these constants, preventing the ICE and allowing new test cases for V1TI and V2TI constants to pass.
