This commit enhances optimizations for 32-bit floating-point math functions in Glibc on PowerPC processors (power9 and later). It revises how floating-point values are converted to logical representations, leveraging specific vector instructions like XXLAND and XXSPLT to improve efficiency. Previously, these optimizations were present for power8 but regressed for newer architectures.
