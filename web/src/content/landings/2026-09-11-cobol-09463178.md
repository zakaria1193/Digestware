The COBOL compiler now supports implicit PICTURE clauses for data items as defined in ISO 13.16.2. A data item with a VALUE clause but no explicit PICTURE is now initially marked as invalid and then validated if subsequent data items meet specific conditions. This change also corrects currency symbol validation, addressing RT 3681.
