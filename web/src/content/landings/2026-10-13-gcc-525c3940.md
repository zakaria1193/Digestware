This commit introduces support for the picolibc C library within GCC, specifically for hosted environments. It mirrors the mechanism used by glibc by including `stdc-predef.h`, which provides essential preprocessor definitions required when no C library header has been directly included. This integration ensures that picolibc-configured builds have the correct predefined macros available.
