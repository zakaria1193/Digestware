This commit lays the groundwork for ACEv1 support in GCC by introducing initial configurations and option handling. It adds ACEv1 to the CPU feature list, defines associated compiler options, and updates internal ISA definitions. Documentation for ACEv1 is also included in the GCC manuals. This sets the stage for subsequent commits that will add specific instruction support.
