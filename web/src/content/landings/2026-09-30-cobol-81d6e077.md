GCC's COBOL compiler now correctly handles source file formats when files are included via the `-include` option. Previously, the heuristic used to determine fixed or free format for an included file could incorrectly influence the format detection for the main source file. This commit assigns separate source format state stacks to included files and the main compilation unit, ensuring format consistency.
