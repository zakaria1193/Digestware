This commit addresses a compiler warning (`Wunused-function`) in GDB's Ada lexer source file (`gdb/ada-lex.l`). To prevent build failures caused by this warning, the code now explicitly ignores it. This workaround is necessary due to how certain versions of the `flex` tool generate code, leading to unused static definitions that trigger the warning.
