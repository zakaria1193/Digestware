Several redundant and vacuous tests have been removed from the `ifcvt` pass. Specifically, `noce_try_shifted_store_flag` no longer tests for a null value after it has already been handled. `noce_try_store_flag_mask` is simplified to avoid an assignment within a disjunction, ensuring correct flag behavior. Lastly, `noce_convert_multiple_sets` removes redundant calls to `set_used_flags` and associated local variables, as these were already processed. These changes are code cleanups with no functional impact.
