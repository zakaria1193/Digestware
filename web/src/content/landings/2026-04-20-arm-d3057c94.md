The compiler was incorrectly using VLD1/VST1 instructions for FP16 moves on ARM targets that only have FP16 support, but lack Advanced SIMD (Neon).  This commit corrects the code generation to use VLDR/VSTR instructions in these cases, which will assemble correctly on those targets.  The constraint was also corrected to allow offset addressing on platforms with Neon.
