The compiler now uses `VLDR/VSTR` instructions instead of `VLD1/VST1` when moving half-precision floating-point values on ARM targets lacking Advanced SIMD (NEON). This resolves PR124933. The constraint `Uj` now allows offset addressing for all targets but only allows Neon addressing when both Neon and FP16INST are present. The testsuite has been updated with a new architecture variant and a new test case to verify the fix.
