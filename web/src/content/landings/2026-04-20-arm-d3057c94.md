The code generation for moving half-precision floating-point values on ARM has been corrected for devices that only support FP16 instructions, resolving PR124933. The compiler will now use `VLDR/VSTR` instructions instead of `VLD1/VST1` when auto-increment addressing is not available or when NEON is not present, ensuring correct assembly on targets lacking Advanced SIMD. Additionally, the constraint has been updated to allow offset addressing on platforms with Neon.
