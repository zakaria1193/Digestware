This commit assigns node identifiers to both the extern and language preludes within gccrs. Previously, these nodes lacked explicit IDs, which could lead to confusion and potential issues with duplicate IDs during compiler processing. This change ensures each prelude node has a distinct identifier, improving the robustness of name resolution.
