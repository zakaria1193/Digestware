std::atomic member functions in <atomic> might not be inlined at -Os, causing the std::memory_order parameter to become a runtime argument and forcing fallbacks to seq_cst operations. This change adds the always_inline attribute to these functions. This ensures that a compile-time constant memory order is propagated to the atomic builtins, potentially enabling more efficient implementations than the default seq_cst.
