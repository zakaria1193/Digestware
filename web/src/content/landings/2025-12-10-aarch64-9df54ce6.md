This commit refactors aarch64 builtins to use optional arguments where UNSPEC_NONE was previously passed explicitly. This change simplifies constructors and `map_to_unspec` functions by allowing arguments to default to UNSPEC_NONE if not provided. It also removes unnecessary UNSPEC_NONE arguments from several implementation functions, leading to cleaner and more maintainable code.
