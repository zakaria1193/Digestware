This commit reverts a previous change that removed calls to mark C++ nondeduced contexts as used. The removal led to callers incorrectly inspecting TREE_TYPE of unresolved specializations, causing issues with standard_conversion and build_conditional_expr. The fix ensures that nondeduced contexts are properly resolved, addressing bugs in C++ template instantiation and type deduction.
