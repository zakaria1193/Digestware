This commit resolves an issue in ARM's NEON 16-bit lane duplication for big-endian architectures, addressing PR128324. The problem stemmed from an incorrect statement ordering in a previous patch. Specifically, the `subreg_regno_offset` call, used to determine the core register for extraction, must now occur before adjusting the element number. This adjustment is crucial for mapping the big-endian byte ordering to the ARM lane ordering, ensuring correct lane duplication.
