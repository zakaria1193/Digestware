This commit introduces support for ACEv1 BSR instructions, implementing specific naming conventions like `bsr0` and using `insert`/`extract` in intrinsic names to align with existing load/store conventions. It also uses the term 'full' for `bsrmovf` to clarify it refers to the entire data, not floating-point. Changes span intrinsic headers, builtin definitions, and machine-specific instruction patterns, with new test cases added.
