A vulnerability in the Mach-O parser allowed for a heap out-of-bounds read when processing `LC_PREBOUND_DYLIB` load commands. The `bfd_mach_o_read_prebound_dylib` function incorrectly calculated pointers into a shared buffer, leading to reads outside the allocated memory. This fix modifies the parsing logic to read the name and linked modules separately using validated offsets and `bfd_mach_o_alloc_and_read`, ensuring proper memory bounds and null termination, and preventing potential information disclosure or corruption.
