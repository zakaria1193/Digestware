This patch improves SSA name analysis by inlining previously ignored pointer ranges. Function-local addresses within these ranges are now safely removed, restoring information that was lost when carried in a `ptr_info_def`. This recovers details like alignment and non-null properties, which are now managed by the bitmask and range analysis respectively.
