The test case `sse2-shiftqihi-constant-1.c` was failing because the GFNI instruction set, enabled by default, generated instructions like `gf2p8affineqb` which conflicted with the expected SSE2 instructions. This commit adds the `-mno-gfni` flag to the test's options, preventing the use of GFNI instructions and resolving the test failures.
