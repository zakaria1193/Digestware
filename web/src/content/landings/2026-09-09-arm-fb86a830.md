This commit refactors the Arm minipool code by introducing a `minipool` class to encapsulate data related to a pool under construction. This change eliminates several file-scope variables, which are now members of the new class, and converts associated functions into member functions. This is the first step in addressing issues with alignment and insertion logic in the minipool code.
