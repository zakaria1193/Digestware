This commit enhances the Static Single Assignment (SSA) prepass by refining the lexical comparison of Value Number (VN) references. Previously, the comparison missed crucial details about the base and clique of references, causing restrict-qualified references to be treated the same as non-qualified ones. The fix ensures that the comparison now includes base and clique information, allowing the prepass to correctly prefer unrestricted variants when appropriate, improving the accuracy of SSA optimizations.
