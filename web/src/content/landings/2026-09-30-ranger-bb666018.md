The GCC ranger (Value Range Propagation) pass now walks constant array initializers by index when processing loads from arrays with unknown indices. Previously, it would union all initializer elements regardless of their position, potentially leading to inaccuracies if elements were missing. This change improves the analysis by correctly identifying missing elements and adds new tests for this behavior.
