This commit simplifies AArch64 NEON and SVE builtins by removing local aliases that stored the result of `f.ret_type`. These aliases are no longer needed as `f.ret_type` is now a direct member. This change streamlines the code by allowing direct access to the member variable, improving readability and maintainability.
