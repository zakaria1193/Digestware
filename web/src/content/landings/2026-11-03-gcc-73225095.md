This commit enhances RISC-V code generation for saturating unsigned truncation operations by utilizing the `umin` instruction from the Zbb extension. When truncating a larger integer type to a smaller one with saturation, the compiler now loads the maximum value of the target type (e.g., 255 for `QI`) and performs a `umin` operation with the input. This approach is simpler and more efficient than previous methods, reducing instruction count for operations like `DI->QI` truncation, as demonstrated in tests for the x264 benchmark.
