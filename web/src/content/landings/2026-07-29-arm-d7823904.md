This commit refines register preferencing for the Thumb2 variant of the `movsi` instruction when using VFP registers. It addresses an issue where the compiler previously hid alternatives from the register allocator, potentially leading to unnecessary spills and reloads between core and VFP registers. The changes aim to align Thumb2 behavior more closely with ARM (A32) mode to improve register utilization.
