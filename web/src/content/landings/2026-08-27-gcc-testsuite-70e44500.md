This commit introduces new test cases for the C++26 standard's P4136R2 concerning the `#line` directive. The tests ensure that GCC's implementation aligns with the standard's requirements for line and column number reporting, particularly regarding out-of-range values, and confirms its behavior as conditionally supported or ill-formed as per the standard.
