A fix for Fortran addresses issues with array actual arguments that have non-contiguous elements when passed to `TARGET` or `POINTER` dummy arguments. Previously, these were incorrectly copied, leading to stale pointers. The compiler now passes a descriptor for such arrays, ensuring correct pointer association and only copying data if necessary.
