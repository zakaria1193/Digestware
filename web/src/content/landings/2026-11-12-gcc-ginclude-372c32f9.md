For MinGW targets on 32-bit x86 systems, `__float128` is now excluded from `max_align_t`. This change aligns GCC's behavior with the Microsoft C runtime, which provides 8-byte alignment for `malloc` and defines `max_align_t` as `double`, and also matches the behavior of mingw-w64 headers.
