This change sets the `REGMODE_NATURAL_SIZE` for AArch64's advsimd vectors to the size of a single vector element. This aligns with recent RISC-V changes and ensures that subregisters representing parts of a vector are correctly identified as invalid if they are smaller than a full vector, preventing incorrect code generation.
