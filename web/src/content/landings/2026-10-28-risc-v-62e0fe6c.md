primer_expert: This commit reverts GCC's RISC-V backend to disallow register overlap
  for the `vfw{macc,msac}.vv` instructions. These instructions involve a vector register
  (vd) accumulator with EEW = 2 * SEW, and source registers (vs1, vs2) with EEW =
  SEW. The RVV specification reserves encodings where a single register supplies operands

GCC reverts changes that allowed register overlap for RISC-V vector widening floating-point multiply-accumulate (vfwmacc.vv) and multiply-subtract (vfwmsac.vv) instructions. This reversion enforces compliance with the vector specification's rule against register overlap when different Effective Element Widths are involved. Test cases and instruction definitions are updated.
