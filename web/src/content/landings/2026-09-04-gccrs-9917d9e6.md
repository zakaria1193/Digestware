This commit adds new indexes for implementation item names within gccrs, specifically enhancing the `rust-hir-map` utility. These indexes are used in `rust-hir-dot-operator.cc` to improve the efficiency of method resolution, allowing the compiler to more quickly find associated functions or methods within trait implementations.
