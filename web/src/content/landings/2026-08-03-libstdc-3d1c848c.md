The `chrono::parse` function in libstdc++ has been updated to correctly parse and validate leap seconds. It now accepts '23:59:60' as a valid time for UTC, provided it's a recognized leap second. For other time types, ':60' is still rejected for seconds. This change ensures that formatting UTC times to include a leap second and then parsing them back is fully supported, addressing PR126543.
