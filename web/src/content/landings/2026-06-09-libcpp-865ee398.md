The libcpp component now unconditionally includes <stddef.h>, removing the need for a header check. This is safe because GCC now requires a C++14 compiler, and libcpp is entirely C++. This change is part of the ongoing effort to simplify build configurations, motivated by PR bootstrap/112422.
