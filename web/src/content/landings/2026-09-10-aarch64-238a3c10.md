This change introduces new AArch64 instruction patterns to match rounding narrowing shifts (RSHRN) when the operation is expressed at the source data width, rather than requiring a wider intermediate representation. This improves code generation for common narrowing operations, reducing instruction counts in areas like video encoding and media processing.
