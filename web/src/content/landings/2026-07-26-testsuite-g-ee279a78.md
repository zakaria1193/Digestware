This commit modifies the `xtreme-header-8.C` test case in the GCC testsuite to force the use of the serial PSTL backend. This prevents test failures caused by third-party headers (like TBB) exposing TU-local entities, which are ill-formed in modules and unrelated to the actual test's purpose concerning C++ modules and standard library features.
