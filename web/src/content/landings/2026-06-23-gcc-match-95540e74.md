This commit enhances GCC's instruction matching capabilities by introducing a new pattern for the unsigned scalar SAT_MUL form 14. This pattern allows the compiler to recognize and potentially optimize this specific type of saturated multiplication operation, which involves multiplying two unsigned integers and saturating the result if it exceeds the destination type's maximum value.
