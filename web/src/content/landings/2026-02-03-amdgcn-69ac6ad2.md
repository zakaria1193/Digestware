This commit introduces new vector widening multiply instructions to the AMDGPU backend, mirroring the scalar widening multiply instructions already present. Additionally, a scalar multiply instruction has been renamed to adhere to standard naming conventions. These additions enhance the instruction set available for AMD GPU code generation.
