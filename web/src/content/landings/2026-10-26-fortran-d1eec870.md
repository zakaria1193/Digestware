The Fortran test case `unsigned_45.f90` was found to fail on 32-bit targets. To address this, the test is now skipped on these architectures. A new test, `unsigned_46.f90`, has been added which is constrained to handle up to 64-bit integers, providing a valid test case for platforms that previously encountered issues.
