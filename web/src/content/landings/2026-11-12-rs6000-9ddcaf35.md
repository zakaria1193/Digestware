The code generation for `__builtin_bswap16` on rs6000 pre-Power10 processors has been improved. Previously, it used a less optimal sequence of multiple `rlwinm` and `or` instructions. The new implementation employs a more efficient rotate-insert idiom, reducing the instruction count and improving performance.
