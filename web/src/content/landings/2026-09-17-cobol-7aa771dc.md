A previous commit that added null-termination for OS filenames in `CBL_OPEN_FILE.cbl` has been reverted. The change was redundant as `posix-open` already performs this operation. Additionally, filename length validation no longer relies on hardcoded values, instead deferring to the kernel's error handling.
