The COBOL front-end has been significantly refactored to reduce the number of `VAR_DECL` nodes generated, particularly for large programs. This optimization stems from a better understanding of when variables need to be materialized versus when they can remain as temporary expression tree nodes. The changes also improve the consistency of GENERIC representation with other front-ends and fix several type-related bugs.
