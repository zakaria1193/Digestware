The `ignored_return_1.c` test for AArch64 inadvertently passed the function `bar` itself to the `vld1q_u8` intrinsic instead of calling it. With recent changes moving load intrinsics to the pragma-based framework, this led to type-checking errors. This commit fixes the test by correctly calling `bar`, ensuring it still validates that ignored intrinsic results do not cause an ICE.
