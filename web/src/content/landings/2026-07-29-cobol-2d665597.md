GCC's COBOL front-end now supports the `SET` statement when used with `NUMERIC` data types, specifically for emulating GnuCOBOL behavior. This involves adding new diagnostic messages, handling a corresponding compiler option (`-Wset-numeric`), and updating documentation and internal language specifications to reflect this capability.
