GCC's MIPS backend now supports the `-mmxu` and `-mno-mxu` options, which control the use of the MIPS Multimedia Extension (MXU).
These flags are now passed through by the driver to the compiler.
New test cases verify that the driver correctly handles these options, ensuring that code generation for MXU instructions is enabled or disabled as specified.
