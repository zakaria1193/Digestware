The ifcvt (if-conversion) pass now improves its ability to transform conditional arithmetic operations by looking through extraneous copy instructions. The `noce_try_cond_arith` function can now pierce a single copy instruction if its definition is the first instruction in a block, provided certain conditions are met. This allows for more aggressive if-conversion, particularly in cases where the 'else' block was simple but a preceding copy instruction masked the simplicity of the 'then' block. This change aims to enable more optimizations without introducing regressions.
