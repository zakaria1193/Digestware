This commit adds missing target requirements to several GCC testsuite files. The `dg-require-effective-target` directive is added to tests that require specific features such as `label_values`, `named_sections`, `nonlocal_goto`, `alias`, and `signal`. This ensures that these tests are only executed on targets that support the necessary features.
