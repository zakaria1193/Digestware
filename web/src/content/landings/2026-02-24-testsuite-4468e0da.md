Several testsuite files were missing `dg-require-effective-target` directives for features like `label_values`, `named_sections`, `nonlocal_goto`, `alias`, and `signal`. Adding these requirements ensures that tests are only run on targets that support the necessary features. This prevents spurious test failures and improves the reliability of the testsuite.
