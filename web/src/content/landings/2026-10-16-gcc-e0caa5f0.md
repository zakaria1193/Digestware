This commit refines the signatures of several GCC internal functions to directly accept an `rtx_insn *` argument. Functions like `multiple_sets`, `sel_mark_hard_insn`, `invert_br_probabilities`, and `maybe_copy_prologue_epilogue_insn` previously involved unnecessary casts or conversions. By accepting `rtx_insn *` directly, the code becomes cleaner and safer, as callers already provide this type. The change also improves the `delete_insn` function by using `dyn_cast` for label handling.
