The SPREAD intrinsic in Fortran was producing incorrect results when the number of copies (``ncopies``) was negative. This commit corrects the logic in ``spread.m4`` to properly handle the scalar source case with ``ncopies < 0``. Several generated files are regenerated, and a new testcase is added to verify the fix.
