This change prevents function nodes in gccrs from being treated as named links during name resolution. By ensuring that function names are not passed as path parameters in `NameResolutionContext::scoped`, the compiler avoids potential ambiguities and incorrect linking. A new test, `mod_fn_conflict.rs`, is added to confirm this behavior.
