This change implements the `R_XTENSA_32_ABS` relocation type, which calculates a 32-bit absolute address as Symbol + Addend. Unlike the existing `R_XTENSA_32`, this new type follows the generic SHT_RELA ABI by storing the addend solely in `r_addend`, not in the relocated word. This allows LLVM to emit it for 32-bit absolute data and enables linking with objects using `R_XTENSA_32`. New command-line options control its usage.
