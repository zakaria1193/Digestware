This patch extends GCC's middle-end to recognize floating-point dot product expressions, similar to how it handles integer dot products. It allows the vectorizer to utilize target-specific instructions for widening dot products where inputs are converted to a wider type before multiplication and accumulation. This is crucial for performance in numerical computations, provided the target architecture supports such operations and the calculation allows reassociation.
