Recent changes to the ivopts (induction variable optimizations) pass have altered code generation decisions for the RISC-V architecture, impacting the loop unroller. This commit adjusts the expected output for several RISC-V tests to match the new, albeit different, code generation. The changes are verified on RISC-V hardware designs, acknowledging that the generated code may be neither better nor worse, just different.
