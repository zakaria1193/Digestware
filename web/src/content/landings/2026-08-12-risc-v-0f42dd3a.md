The LDINDEXED macro-fusion recognition in GCC for RISC-V has been generalized to allow ADD, ADDW, or ADD.UW instructions to precede an undisplaced scalar integer load. This enables the load instruction to use the result of the ADD-type instruction as its memory address, even if the destination register of the load overwrites the address register. This change shares structural matching logic with the ADD_ST fusion, making the ADD classifier more versatile by optionally reporting wordness for fusion rules.
