This commit introduces platform wait functions for Darwin (macOS/iOS) starting with macOS 10.12. It enables the use of kernel-level facilities for wait/notify operations within the standard library. The platform wait type is set to 32 bits for compatibility across supported OS versions.  This enhancement will provide more efficient implementations for synchronization primitives such as `std::semaphore`.
