This commit addresses two bugs in a RISC-V optimization that converts sequences of `ADDI`, `AND`, and `CTZ` (count trailing zeros) instructions into a more efficient `CTZ` followed by `BCLR` (bit clear). The first bug caused the original `AND` instruction to be incorrectly retained, leading to the clearing of two bits instead of one. The second bug was an off-by-one error in the safety check for moving the `CTZ` instruction, which could lead to incorrect transformations when the `AND` instruction modified a value used by `CTZ`. Both issues are now fixed, and a new test case is added.
