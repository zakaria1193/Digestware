The Ada compiler in GCC has been updated to make the `Error_Msg_Sloc` internal type visible to `gigi`, a component used for improving diagnostics. This change allows the compiler to provide more detailed and accurate error messages, particularly for style warnings controlled by the `-gnatw.q` compilation flag, helping developers to better understand and rectify code style issues.
