primer_glossary:
- term: STATIC_TLS
  definition: Static Thread-Local Storage refers to variables with storage duration
    that is static but local to each thread. The compiler and linker must generate
    code to ensure each thread accesses its own copy of these variables.
- term: TLS Initial Exec (IE)
  definition: A model for accessing Thread-Local Storage where the address of the
    TLS block is determined at runtime. This is generally efficient but requires runtime
    support.
- term: DF_STATIC_TLS
  definition: A flag in the ELF header's `e_flags` field that indicates the presence
    of static TLS in the executable, signaling to the runtime linker that it needs
    to handle TLS setup.
- term: GOT_TLS_IE
  definition: A flag indicating that a symbol reference uses the TLS Initial Exec
    model, typically involving a Global Offset Table (GOT) entry to resolve the TLS
    address at runtime.

The handling of STATIC_TLS in the RISC-V ELF backend has been moved to a dedicated function, `riscv_elf_record_tls_type`. This change improves code clarity and organization within `bfd/elfnn-riscv.c`. Additionally, an early return was added for the R_RISCV_TPREL_HI20 case, and logic was introduced to set the DF_STATIC_TLS flag when GOT_TLS_IE is encountered in a dynamically linked executable.
