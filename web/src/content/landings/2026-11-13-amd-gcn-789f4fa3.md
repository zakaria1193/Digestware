This commit introduces the `-mmin-waves-per-cu` option to tune the minimum number of wavefronts per compute unit for AMD GCN GPUs. This helps optimize performance by allowing more wavefronts to fit on a compute unit when kernels use excessive registers. The commit also corrects outdated register calculations and moves occupancy parameters to `gcn-devices.def` for consistent use between the compiler and libgomp plugin. It also refines register limit calculations for normal functions, ensuring better resource allocation.
