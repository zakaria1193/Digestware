The `genopinit` tool now groups optab patterns by their availability conditions, significantly reducing compilation time and code size for targets like aarch64 and riscv64. Instead of evaluating each `HAVE_*` macro individually, it now numbers distinct tests, maps patterns to these tests, and evaluates each test only once. This change dramatically cuts down on assignments and code bloat in `init_all_optabs`.
