This commit addresses an instruction stack overflow issue in the Xtensa assembler when relaxing `loopgtz` instructions using L32R widening. The `MAX_ISTACK` limit has been increased from 12 to 16, and the error reporting mechanism is improved to use `as_fatal` which explicitly mentions `MAX_ISTACK`. A new test case `loopgtz-relax.s` is added to verify the fix.
