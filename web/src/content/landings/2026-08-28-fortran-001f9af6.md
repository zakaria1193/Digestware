The Fortran compiler has refactored the creation of array descriptors for null() actual arguments. Previously, this logic was duplicated, leading to incorrect initialization and type. The changes consolidate this into a common function, ensuring correct initialization and rank. Additionally, a workaround for a gimplification failure related to copy-back code has been removed.
