The libvtv component has updated its configure.ac file to replace the obsolete AC_LIBTOOL_DLOPEN macro with the recommended LT_INIT([dlopen]) option. This change, driven by PR103459, aligns the build system with current libtool practices. Although the macro was called before LT_INIT, indicating no prior functional impact, this update ensures better maintainability and adherence to libtool standards.
