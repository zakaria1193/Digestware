The GIMPLE range optimization pass now recognizes non-negative properties for a subset of floating-point built-in functions. This enhancement allows the optimizer to infer that certain function return values are always non-negative, potentially enabling further optimizations. This is the first step towards replacing the older `gimple_stmt_nonnegative_p` with a more integrated range analysis.
