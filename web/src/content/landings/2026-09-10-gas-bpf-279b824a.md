This commit enables the `spacing-pseudoc` test for the BPF assembler, which was previously disabled in the test suite configuration (`bpf.exp`). Additionally, it corrects a byte order mismatch in the test's input file (`spacing-pseudoc.d`), changing it from big-endian (`-EB`) to little-endian (`-EL`) to align with the expected encodings and the test file's name. With these fixes, the test now passes and validates the flexible spacing rules for BPF instructions in the pseudo-C dialect.
