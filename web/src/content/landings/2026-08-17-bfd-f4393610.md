This commit removes redundant assignments to the ``dynobj`` variable in the ``kvx_elf_create_got_section`` function (elfnn-kvx.c) and ``loongarch_elf_check_relocs`` function (elfnn-loongarch.c). These assignments were duplicates of earlier assignments, making the code slightly less efficient and harder to read.
