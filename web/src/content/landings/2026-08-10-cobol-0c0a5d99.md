This commit corrects how COBOL's EXTERNAL data definitions are handled, bringing them in line with Fortran's COMMON data behavior. Previously, these were mistakenly treated as C global variables, causing linking problems. The fix now uses DECL_WEAK references for metadata and DECL_COMMON for data areas, enabling correct interoperability with C modules and proper runtime behavior for EXTERNAL data.
