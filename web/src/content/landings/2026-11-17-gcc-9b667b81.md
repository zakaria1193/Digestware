This commit introduces `TARGET_ATOMIC_ASSIGN_EXPAND_FENV` for the Xtensa architecture, enabling correct handling of floating-point environment (fenv) results for atomic operations. This fix addresses an issue where atomic operations on FP values did not properly update the floating-point status flags. By implementing the necessary built-in functions and patterns, GCC can now correctly expand atomic assignments involving floating-point types on Xtensa, ensuring accurate fenv behavior as verified by the `c11-atomic-exec-5.c` test.
