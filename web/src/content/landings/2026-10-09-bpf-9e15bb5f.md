This commit corrects the spelling of indirect calls in GCC's pseudo-C dialect for the BPF target. Previously, both direct and indirect calls used the same `call` template, causing assembly errors when compiling with `-mxbpf` because the assembler expected `callx` for indirect calls. The fix separates the call target constraint into two alternatives, using `callx` specifically for register-based indirect calls.
