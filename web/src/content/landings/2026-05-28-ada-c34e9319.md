This patch resolves a compiler crash that occurred when allocating memory for tagged record types that possess a constructor initializer, specifically when using a class-wide access type. The fix, implemented in `Expand_N_Allocator`, adds a type conversion to the specific type. This prevents an unnecessary dispatching call, as constructors are not dispatching primitives in Ada, ensuring correct allocation behavior.
