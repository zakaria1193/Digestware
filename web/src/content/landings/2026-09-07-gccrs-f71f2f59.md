This commit addresses an issue in gccrs where constant evaluation could fail during type-checking. Previously, resolving function signatures separately from their bodies could lead to unresolved function calls within a const context. The fix introduces a const context stack, allowing the compiler to override normal behavior during const evaluation and ensure that necessary function definitions are available, resolving Rust-GCC/gccrs#4855.
