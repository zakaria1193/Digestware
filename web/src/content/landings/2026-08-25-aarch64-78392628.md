This commit ports a set of NEON rounding intrinsics, including `vrnd`, `vrnda`, `vrndi`, `vrndm`, `vrndn`, `vrndns`, `vrndp`, and `vrndx` (along with their vector variants), to the pragma-based framework on aarch64. By moving these intrinsics into this unified framework, GCC can manage their lowering and optimization more consistently. This change removes direct function definitions from `arm_neon.h` and introduces new function bases and definition groups in `aarch64-neon-builtins-base.cc` and `.def`, respectively. New test cases are added to verify the functionality of these ported intrinsics.
