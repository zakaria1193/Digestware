The Instruction Recognition and Allocation (IRA) pass now treats hard register constraints identically to constraints for single register classes. This change standardizes how operand constraints are processed, ensuring that register numbers are correctly computed for both types of constraints. The update simplifies logic within the `process_single_reg_class_operands` function and renames related helper functions for clarity. Some test cases were adjusted to account for potential changes in instruction selection and register allocation.
