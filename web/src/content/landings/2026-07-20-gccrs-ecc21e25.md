The gccrs typechecker has been updated to support unsized coercions between Algebraic Data Types (ADTs). This change refactors the existing `coerce_unsized` function into smaller, more manageable helpers for improved readability and maintainability. It lays the groundwork for more complex type coercions involving unsized ADTs.
