This commit refactors RISC-V vector subvector extraction by introducing a `vec_perm_const` recognizer. This allows arbitrary vector pieces to be extracted using a permute operation, removing several special-case `vec_extract` patterns. The change simplifies the RISC-V vector backend by relying on generic permutation logic, which is expected to streamline the code and potentially improve maintainability. Test cases for subregister extraction have been updated to reflect this new approach.
