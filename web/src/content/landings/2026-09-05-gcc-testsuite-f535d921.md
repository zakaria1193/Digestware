primer_glossary:
- term: LTO
  definition: Link-Time Optimization. A build process optimization where the compiler
    performs optimizations across multiple source files after they have been compiled
    to intermediate object files but before the final executable is linked. This allows
    for more aggressive optimizations than whole-program optimization at compile time.
- term: Darwin
  definition: The name of Apple's Unix-like operating system, on which macOS, iOS,
    and other Apple platforms are based. GCC's Darwin support includes specific build
    and linking behaviors.
- term: dg-extra-ld-options
  definition: A GCC test suite directive that adds extra options to the linker command
    line for a specific test case. These options are typically used to configure linking
    behavior for that particular test.
- term: _main symbol
  definition: In C and C++, `_main` (or `main`) is the entry point of the program.
    Its absence typically indicates a linking error, often occurring when a program
    intended to be linked as a shared library is linked as an executable.
