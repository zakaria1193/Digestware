GCC's RISC-V backend now supports `-mtune=native` and `-mcpu=native` flags. This allows the compiler to automatically detect the host CPU's architecture and tuning parameters by inspecting `hwprobe` or `/proc/cpuinfo`. The flags behave similarly to other architectures, overriding compiler defaults without affecting explicitly set `-march` or `-mtune` values.
