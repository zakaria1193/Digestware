GCC now supports `[[gnu::suppress_coverage]]` attribute and `#pragma GCC suppress_coverage` to exclude functions or code blocks from coverage reports. This is useful for code like unreachable asserts or library code that shouldn't impact user-facing coverage metrics. It provides finer-grained control than existing file-level filtering.
