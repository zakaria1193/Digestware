This commit updates the `__cpp_lib_clmul` feature test macro in libstdc++ to reflect the final version of the carry-less multiplication (CLMUL) library feature. Previously lowered for potential specification changes, the macro is now set to `202611` to align with the finalized standard. This ensures that code relying on this macro correctly identifies the availability of CLMUL support.
