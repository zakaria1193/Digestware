An internal compiler error (ICE) in the Fortran compiler has been fixed. The issue occurred in `gfc_get_symbol_decl` when asserting that a deferred-length string's length variable resided in the same scope as its symbol. This commit corrects the scope comparison for function results within contained procedures, resolving the ICE for PR95542.
