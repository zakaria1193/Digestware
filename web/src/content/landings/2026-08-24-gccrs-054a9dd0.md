This commit addresses an internal compiler error (ICE) in gccrs related to struct patterns used with enum variants. The `StructPattern::is_refutable` assertion incorrectly assumed the Abstract Data Type (ADT) was not an enum. The fix allows the compiler to correctly handle struct patterns on enums with multiple variants by returning true and proceeding with field checks, while single-variant enums continue with existing logic.
