The pattern matcher for vector averages now folds signed vector additions followed by a right shift into average operations. This applies when the sum does not overflow, which is guaranteed for types with undefined overflow behavior. This optimization can replace multiple instructions with a single rounding halving add, improving performance in vectorized code like DCT butterflies.
