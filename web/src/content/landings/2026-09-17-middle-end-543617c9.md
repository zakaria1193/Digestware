primer_glossary:
- term: GIMPLE
  definition: GCC's internal representation of code, used after initial parsing and
    before the generation of RTL. It's an intermediate representation designed to
    be suitable for optimizations.
- term: LTO
  definition: Link-Time Optimization. A compilation process where optimization is
    performed not just on individual source files, but across the entire program during
    the linking phase. This allows for more aggressive optimizations that depend on
    inter-procedural analysis.
- term: IPA ICF
  definition: Inter-Procedural Function Cloning. An optimization pass that duplicates
    identical functions to improve locality and potentially enable further optimizations.
    When used with LTO, it can clone functions before their final symbol names are
    determined.
- term: cfgexpand
  definition: A GCC pass that expands control flow graphs (CFGs) and performs various
    code-related expansions before RTL generation.
- term: RTL expansion
  definition: The process of converting GCC's GIMPLE intermediate representation into
    its lower-level RTL (Register Transfer Language) representation, which is closer
    to machine code.

This change defers section resolution for GIMPLE wrappers until the cfgexpand pass. Previously, section names could become stale during LTO if IPA ICF turned equivalent functions into GIMPLE wrappers before privatization. This deferral ensures that sections are resolved based on the final assembler names, preventing issues with stale names being streamed into LTRANS. The change also updates documentation and adds new test cases.
