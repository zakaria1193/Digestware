primer_expert: The `copy_bbs` function, part of GCC's CFG manipulation utilities,
  is responsible for copying basic blocks. This commit introduces the concept of a
  'prevailing exit edge' to `copy_bbs` and `can_copy_bbs_p`. This is crucial for the

primer_glossary:
- term: basic block (BB)
  definition: A contiguous sequence of zero or more imperative statements in which
    the execution enters at the top and proceeds through the bottom without any branches
    in or out, except possibly at the beginning or end.
- term: Control Flow Graph (CFG)
  definition: A representation of all the execution paths through a function or program.
    It is a directed graph where nodes represent basic blocks and edges represent
    the possible transfers of control between blocks.
- term: backwards threader
  definition: A component within GCC's compiler passes that analyzes and updates control
    flow information, often propagating information backward through the CFG. It is
    used here to handle the threading of control flow after basic blocks are copied.
- term: prevailing exit edge
  definition: A specific edge leaving a basic block or region that is considered the
    primary or 'normal' exit, even if other abnormal exits exist. This commit teaches
    the BB copier to identify and respect such an edge.

The basic block (BB) copier in GCC's control flow graph (CFG) handling has been enhanced to recognize a 'prevailing exit edge'. This allows the backwards threader to correctly manage abnormal edges (like exceptions or early returns) that leave a copied region. The changes modify `cfghooks.h` and `cfghooks.cc` to incorporate this new concept, ensuring that such abnormal exits are handled properly without misinterpreting the control flow. New test cases verify this functionality.
