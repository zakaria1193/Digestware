This commit updates the `libgomp.texi` documentation to include new GOMP (GNU OpenMP runtime) entry points. These new functions, such as `GOMP_has_masked_thread_num`, `GOMP_barrier_ext`, and `GOMP_reduction_start`, are designed to improve OMPT (OpenMP Tools) observability for various OpenMP constructs including `MASKED`, `MASTER`, `ATOMIC`, `BARRIER`, `REDUCTION`, and `FOR` loops. The update also fixes stale function names and clarifies usage details.
