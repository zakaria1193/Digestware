GCC's match patterns for `cond_carry_add` and `cond_carry_add_neg` have been simplified by using the `:c` specifier. Previously, these patterns explicitly handled swapped operands for less-than/greater-than comparisons. The `:c` specifier allows the pattern to more elegantly express these conditional operations, making the patterns easier to maintain without changing the generated code.
