The GNU Cobol compiler (`gcobc`) now enables the `-export-dynamic` option by default. This change addresses an issue where dynamic `CALL`s between programs within the same executable could fail if symbols were not exported to the dynamic symbol table. By default, GCC does not export unreferenced symbols, and since GNU Cobol uses dynamic linking for `CALL`s by default, this could lead to 'symbol not found' warnings. `-export-dynamic` ensures all symbols are exported, resolving this potential runtime problem.
