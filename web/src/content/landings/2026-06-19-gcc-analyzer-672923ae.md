The static analyzer's exception handling has been improved to correctly identify when a thrown exception, which is a derived class, is caught by a handler expecting a base class. This is achieved by introducing a new `exception_matches_type_p` langhook, implemented by the C++ frontend using `can_convert_eh`. This change ensures more accurate static analysis of exception flows.
