This commit refactors the expansion of vector constant broadcasts on i386 architectures to improve efficiency. It now exclusively uses dedicated broadcast instructions (AVX, or AVX2 for 16-bit elements) for floating-point constants when available. For integer constants, it respects the `TARGET_PREFER_BCST_FROM_INTEGER` flag, avoiding inefficient sequences like `movss + shufps` and ensuring optimal code generation for vector operations.
