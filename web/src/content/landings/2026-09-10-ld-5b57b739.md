This change enhances the linker's handling of the `--as-needed` option for shared libraries. Previously, an explicit symbol reference (`-u symbol`) on the command line would not cause an `--as-needed` shared library to be loaded if it wasn't otherwise required. This commit modifies the linker to treat such symbols as a need, ensuring that `--as-needed` libraries are loaded when explicitly referenced, similar to how archives behave.
