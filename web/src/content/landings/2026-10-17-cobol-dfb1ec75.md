This commit introduces several miscellaneous fixes to the GCC COBOL compiler. It updates error message handling for `Werrno`, removes vertical positioning from `SEQUENTIAL` files while enhancing I/O plugin support for it, and reintroduces support for the `#line` directive. Additionally, it adds support for the GnuCOBOL `DEFLIT` directive and corrects a bug where the `-ffree-from` command-line option was ineffective. Changes also touch whitespace and internal data structures for file handling.
