This commit enhances the Cobol compiler's handling of fixed-point arithmetic by utilizing a `struct int128` that includes an `rdigits` member. This structure simplifies the implementation by embedding the number of digits to the right of the decimal point directly within the data type, rather than managing it through external logic. The change impacts various functions across `gcc/cobol` and `libgcobol` that deal with numeric comparisons, multiplications, divisions, and formatting.
