Binutils' BFD library has been updated to include support for DWARF5 debugging sections in mach-o object files. Previously, sections like `.debug_str_offsets` and others were not recognized, leading to errors in GDB when processing DWARF5-formatted debug information. This change adds these sections to the `dwarf_section_names_xlat` table, resolving a bug where GDB reported missing `.debug_str` sections when `.debug_str_offsets` was actually the issue.
