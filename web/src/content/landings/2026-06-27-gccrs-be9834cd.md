A new lint has been added to gccrs that warns developers when a generic parameter is given an explicit `Drop` bound. In Rust, the `Drop` trait is implicitly handled for types that need cleanup, and explicitly adding it as a bound to a generic parameter typically does not provide any useful constraint and is often a sign of a misunderstanding. This warning helps catch potential errors early in the development process.
