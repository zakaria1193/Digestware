This commit fixes a miscompilation caused by an incorrect simplification rule in `match.pd`. The rule `(a & b) == (a ^ b) -> !(a | b)` was applied too broadly, especially when operands had different types or were not strictly boolean. The fix ensures the simplification correctly handles type conversions and uses bitwise NOT (`~`) for 1-bit precision types while employing XOR with 1 for wider types, thus preserving correctness.
