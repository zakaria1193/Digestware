The aarch64 linker incorrectly applied an erratum workaround by default because the test for fix_erratum_843419 was a simple boolean check, and ERRAT_NONE is not zero. This commit modifies the tests in `elfnn-aarch64.c` to explicitly compare against ERRAT_NONE, ensuring the workaround is only applied when requested by the user. This prevents unnecessary link-time overhead.
