This commit addresses regressions in OpenMP C++ target offloading related to lambda objects within aggregates, as reported in PR 127559. Because a previous commit caused these lambdas (and their by-reference captures) to be unmapped, leading to runtime crashes when dereferencing host stack addresses on the device, several test cases are now marked as 'Expected Failure' (XFAIL). New tests are also added to cover nested aggregates and constant array indices, further documenting the regression.
