This commit fixes an Internal Compiler Error (ICE) in the Fortran frontend when dealing with recursively defined derived types that contain allocatable arrays. The fix extends a mechanism for handling allocatable arrays of the same type to scalars within these structures. It ensures that descriptors are created for these scalars and passed to the deep copy library, resolving the ICE and enabling compilation of such code. New test cases are added to cover this scenario.
