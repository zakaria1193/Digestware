This commit prevents the AddressSanitizer (ASan) from emitting an `__asan_handle_no_return` call before `__asan_report_*` calls in certain scenarios. Previously, calls generated during the bitintlower pass were incorrectly instrumented, leading to redundant calls. The fix adjusts how ASan handles these built-in calls and ensures correct type matching for arguments, resolving an issue reported in PR126084.
