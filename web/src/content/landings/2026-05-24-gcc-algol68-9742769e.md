  the Algol68 compiler opens source files. It now opens them in 'binary mode', which
  tells the system to read the file exactly as it is, without trying to interpret
  or change the newline characters. This ensures that the compiler reads the correct
  number of bytes and avoids errors when compiling Algol68 code on Windows.

The Algol68 compiler now opens source files in binary mode to prevent incorrect handling of CRLF newlines on Windows.  Without this change, CRLF sequences were being converted to LFs, causing `a86_file_read` to return incorrect byte counts and trigger assertions.
