This commit implements missing dynamic accessibility checks for subpool access types, as mandated by Ada Reference Manual (RM) rules 13.11.4(24-27). This enhancement ensures that memory accesses through these types are safe at runtime. The changes introduce a new `Get_Pool_Object_Or_Dereference` function in `sem_util` and integrate its calls within `sem_ch13.adb` and `exp_ch3.adb` to apply these essential checks during type freezing.
