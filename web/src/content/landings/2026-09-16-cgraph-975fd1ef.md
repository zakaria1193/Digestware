This commit refactors sanity checks within GCC's cgraph component related to callback edges. Previously, callback edges without a carrying edge were disallowed, but this restriction has been relaxed to include internal callback edges. The check has been moved to a different loop, allowing it to be performed in the Whole Program Analysis (WPA) context as well. This change ensures that internal callback edges are correctly validated and that the checks are consistently applied across different analysis stages.
