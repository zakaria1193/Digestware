This commit updates GCC's configuration scripts to use `LT_PATH_LD` instead of the now-obsoleted `AC_PROG_LD` macro. This change aligns GCC with updates in libtool and simplifies the linker detection process by removing an extra execution path that checked for GNU ld specifically. The update affects multiple libraries within the GCC project, including libatomic, libgomp, libitm, and libstdc++-v3.
