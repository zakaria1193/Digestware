This commit addresses several edge-case bugs in the COBOL compiler. It enhances the lexer and parser to correctly handle missing closing parentheses and double or single quotes, improving robustness. Additionally, it tightens validation for `ADD CORRESPONDING` and `SUBTRACT CORRESPONDING` statements, rejecting operands that are not groups. A new warning flag, `-Wrefmod`, is introduced to flag invalid use of reference-modified strings as targets, aligning with ISO standards while accommodating common extensions.
