This commit fixes an issue with the Arm ADDP SIMD instruction on big-endian systems where the lane order was incorrect. The problem stemmed from the use of GCC's lane numbering, which differs from the architectural numbering on big-endian targets. The fix involves swapping input operands for the ADDP instruction patterns on big-endian targets and adjusting the expander to match the correct lane ordering, ensuring correct results for vectorized operations.
