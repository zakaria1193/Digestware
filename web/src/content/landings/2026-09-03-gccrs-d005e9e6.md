This commit restructures how gccrs handles method resolution by introducing separate indexes for trait implementations. This change aims to improve the performance of this computationally expensive operation. It modifies the `MethodResolver::select` function to utilize these new indexes and updates `Mappings::insert_hir_impl_block` to accommodate them.
