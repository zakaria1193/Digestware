This commit introduces necessary machine patterns and predicates for the RISC-V Zvdota and Zvbdota instructions, which handle dot-product operations. It includes patterns for vector multiplication and fused multiply-add operations, tailored for these specific instructions. The changes also ensure that dot-product types are correctly handled by the AVL (Approximate Value Propagation) mechanism and exclude them from propagation to avoid incorrect optimizations. New predicates and file definitions are added to support these instructions across various RISC-V configurations.
