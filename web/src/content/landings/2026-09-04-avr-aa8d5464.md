The libgcc library for the AVR microcontroller architecture has been updated to include support for two new division functions: `divsq3` for signed division and `udivusq3` for unsigned division. These functions are added to the AVR target's configuration, enabling more comprehensive arithmetic capabilities for AVR applications compiled with GCC.
