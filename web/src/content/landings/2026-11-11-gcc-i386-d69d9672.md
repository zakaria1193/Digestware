GCC's support for AMD's AOCL vector library has been extended to versions 5.3.1 and 6.0.0. This update adds new functions like erfc, cbrt, and atan2, and adjusts existing ones for improved accuracy across various vector widths. The changes also include test suite updates to verify these new capabilities and address potential pattern matching issues.
