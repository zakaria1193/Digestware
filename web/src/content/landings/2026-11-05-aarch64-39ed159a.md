This commit migrates several NEON intrinsics for saturating shifts by an immediate value (like vqshl_n) to the pragma-based framework. This change ensures these operations are consistently handled within GCC's intrinsic processing pipeline for the aarch64 architecture. The update streamlines the codebase by removing deprecated direct intrinsic definitions and tests, relying on the new framework for generation.
