This commit reverts a previous change to cobol's CBL_CREATE_FILE function. The revert corrects an issue where filenames were being created with an unintended trailing null character (e.g., 'myfile.txt0'). It also removes filename length validation that incorrectly relied on hardcoded values, as the kernel already handles this by returning ENAMETOOLONG.
