GCC now defines the `__ARM_FEATURE_CSSC` macro, as specified by ACLE 2025 Q3. This macro is set to 1 when the Common Short Sequence Compression (FEAT_CSSC) instructions are available on the aarch64 architecture. Although GCC has generated code for these instructions since version 13, it previously did not define this feature test macro, unlike Clang. This change ensures feature compatibility and correct preprocessor behavior for code targeting these instructions.
