This commit significantly improves the middle-end processing time for COBOL code, reducing it by factors of three to five. It achieves this by collecting variable initialization into table-driven library calls and by grouping GENERIC nodes into batches for more efficient processing. These changes streamline how COBOL variable initializations are handled, leading to faster compilation for COBOL programs.
