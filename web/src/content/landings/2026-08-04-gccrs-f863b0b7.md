This commit updates the gccrs test suite by enforcing the Rust 2018 edition for minicore and related tests. Previously, the edition was managed per-crate, leading to potential inconsistencies. By controlling the edition at the test suite level, the compiler ensures that core components are compiled with the expected edition, simplifying development and aligning with the requirements of core 1.49 which targets Rust 2018.
