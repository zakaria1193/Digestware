This commit changes gccrs to resolve extern crates independently. This is necessary because extern crates are exported with their own declarations, and references like `crate::` within the current crate should point to the extern crate's root, not the current crate's root. Resolving them in isolation simplifies the process and avoids complications with late name resolution, which is not required for extern crates.
