On x86, the VCOMX instruction is now used for floating-point equality (EQ) and inequality (NE) comparisons only when the compiler is configured to honor NaN (Not-a-Number) values. Previously, VCOMX was used unconditionally, which could lead to unnecessary code generation and performance degradation when NaNs were not relevant. This change optimizes comparison logic by avoiding VCOMX when simpler instructions suffice, preventing unintended SSE to GPR moves.
