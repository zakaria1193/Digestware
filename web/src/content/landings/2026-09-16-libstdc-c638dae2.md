This commit rectifies an issue in GCC's libstdc++ where the `param()` function for several random number distributions (negative_binomial_distribution, student_t_distribution, fisher_f_distribution) did not correctly update their underlying gamma distributions. By invoking the `param()` function on the respective internal gamma distribution members, the distributions now behave as expected, ensuring consistent random number generation. A new test case `distribution_param.cc` has been added to validate these corrections.
