This commit addresses warnings generated during the documentation build for GNU Modula-2's info files. It corrects the navigation node ordering within the `gm2.texi` documentation and introduces new `README.texi` files for the `gm2-libs-{cor,iso,pim}-common` libraries. Additionally, build logic for these libraries has been updated to ensure the READMEs are created when necessary.
