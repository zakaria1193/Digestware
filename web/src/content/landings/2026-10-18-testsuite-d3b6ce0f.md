This commit adjusts a test case for C++ modules on hppa64-hp-hpux11.11 to accommodate differences in constructor symbol generation. Using the GNU assembler, the compiler produces a different clone type than expected, requiring the test's regular expression to be widened to match either the base or complete-object clone.
