primer_expert: The AIX emulation in `ld/emultempl/aix.em` previously maintained an
  `is_64bit` static variable to track whether the linker was operating in 32-bit or

The `is_64bit` variable in the AIX linker emulation was found to be unused and set but not used, causing compiler warnings. This variable was introduced in 2001 and has not been relevant since then. It has now been removed to clean up the codebase.
