The `cfg_select!` macro, essential for compiling Rust's `c_char` type used in widespread `CStr` implementations, has been backported into `gccrs`. To manage compatibility, its usage is now gated behind the `-frust-compat-version=1.90` flag. This ensures that newer Rust features are available while maintaining stability for older projects.
