Multiple commits add new test cases for RISC-V vector instructions, specifically focusing on the `vfwred[ou]sum.vs` operations. These tests aim to prevent scenarios where the destination register (`vs1`) overlaps with the source register group (`vs2`), which is disallowed by the RISC-V vector specification when different element widths are involved. The tests cover various data types and multiplication factors to ensure correctness.
