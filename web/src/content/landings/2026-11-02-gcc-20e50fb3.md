GCC's internal code has been refactored to use a more general API for creating symbol table nodes. Instead of checking the type of a declaration (variable or function) and calling specific creation functions like `varpool_node::get_create` or `cgraph_node::get_create`, the code now utilizes `symtab_node::get_create` where applicable. This change improves code consistency and maintainability across various parts of the compiler, including `cgraphunit.cc`, `tree.cc`, `varasm.cc`, and `cp/decl.cc`.
