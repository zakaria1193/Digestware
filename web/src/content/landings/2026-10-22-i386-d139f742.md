This commit increases the threshold for inlining `memcmp` when performing word-sized comparisons on i386 architectures, particularly when SSE2 is not fully utilized or configured. Previously, the compiler inlined `memcmp` only up to 32 bytes for 64-bit and 16 bytes for 32-bit targets due to overheads. By adjusting the cost model to treat word-sized pieces more efficiently, the inlining thresholds are now raised to 64 bytes for 64-bit and 32 bytes for 32-bit, aligning them with SSE2 behavior and potentially improving performance for small memory copies.
