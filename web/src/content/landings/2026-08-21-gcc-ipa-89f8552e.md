The Inter-procedural Analysis (IPA) pass failed to apply computed profile scaling factors to call graph edges. This resulted in stale counts after clone redistribution and verification failures, triggering an internal compiler error (ICE) during AutoFDO LTO compilation. This commit corrects `cgraph_node::scale_profile_to` to apply the computed scale, ensuring accurate profile data for subsequent optimization passes.
