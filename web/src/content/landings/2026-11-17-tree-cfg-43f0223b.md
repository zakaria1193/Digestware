This commit improves GCC's code coverage analysis by ensuring that debug statements do not affect the tracking of coverage suppression regions. Previously, debug statements could split non-suppressed regions, leading to incorrect CFG checksums when debug information was enabled. The change modifies the CFG construction to only update coverage suppression state for non-debug statements.
