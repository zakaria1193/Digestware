The GCC Rust frontend introduces explicit filtering for checking if a trait bound is satisfied by a type. This change refines the `TypeBoundsProbe` to accept an optional trait argument, allowing for more targeted validation. The probe can now more reliably determine trait satisfaction, enhancing the compiler's ability to handle complex generic constraints.
