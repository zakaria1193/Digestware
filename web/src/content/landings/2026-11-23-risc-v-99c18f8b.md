The RISC-V linker now supports the Zcmt extension, enabling table-jump relaxation for eligible jumps and calls. This optimization, when enabled, analyzes target groups and constructs profitable jump tables to rewrite selected sites before final alignment. It is opt-in, intended for non-PIC executables with compatible ISA attributes, and considers factors like page alignment and table slot capacity. This change introduces new data structures and logic within BFD and the linker to manage jump table targets and rankings.
