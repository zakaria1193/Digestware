The vectorizer's pattern recognition for `popcount`, `clz`, `ctz`, and `ffs` intrinsics has been updated. Previously, it only checked the second argument against the target value when the argument and result precisions differed. This commit modifies the logic to perform this check for all precisions, ensuring that scalar calls remain scalar even when lanes produce zero, which is crucial for correctness on platforms like AArch64.
