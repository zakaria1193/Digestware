The function ``_bfd_elf_link_create_dynstrtab`` in ``elflink.c`` has been split into two new functions: ``_bfd_elf_link_dynobj`` and ``_bfd_elf_link_dynstr``. This change improves code organization and modularity by separating the responsibility of identifying the dynamic object from the creation of the dynamic string table. No changes in linker behavior are expected.
