This commit modifies the `cfgrtl` component to allow duplicated RTL basic blocks that end in tablejumps to share a single dispatch table. Previously, such blocks could not be duplicated reliably because the instructions computing the table address might be outside the block. Now, an opted-in pass can mark a table with the `JUMP_TABLE_SHARED_P` flag, enabling multiple dispatches to reference the same immutable table. The pass ensures the table remains accessible by moving it if the block it originally followed is deleted, and correctly handles shared tables in various RTL operations.
