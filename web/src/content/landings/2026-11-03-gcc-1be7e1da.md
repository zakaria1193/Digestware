This commit enhances code correctness and maintainability within GCC's call summary functionality by adding `const` qualifiers to relevant arguments. Specifically, functions in `symbol-summary.h` that deal with `call_summary` objects now accept `const cgraph_edge` pointers, and associated `cgraph_edge` methods are marked `const` where appropriate. This change reflects that these arguments are not modified and improves the compiler's ability to perform optimizations and checks.
