The GCC COBOL compiler has been updated to correctly interpret absolute copybook names. Previously, the compiler might have incorrectly tried to resolve paths for copybooks specified with a leading slash, which signifies an absolute path. This change ensures that the `copybook_elem_t::open_file` function recognizes leading slashes and does not prepend search paths, allowing for correct inclusion of copybooks regardless of the current directory or compiler search path settings.
