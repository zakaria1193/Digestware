On big-endian Power10 systems, the SSE `_mm_movemask` intrinsics produced masks with bits in an incorrect order due to the native vector element ordering. This change reverses the vector element order using `vec_reve()` before calling `vec_extractm()`, ensuring that the generated masks match the expected SSE behavior on both big and little-endian targets.
