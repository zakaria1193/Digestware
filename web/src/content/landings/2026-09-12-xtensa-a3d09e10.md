The `xt_true_regnum()` function, used for Xtensa target-specific register number handling, has been made `static`. This change reflects that the function is only used internally within its defining file (`xtensa.cc`) and is not called by any other source files in the GCC build. Making it `static` improves encapsulation and avoids polluting the global namespace.
