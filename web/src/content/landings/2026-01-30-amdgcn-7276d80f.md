This commit adds vector counterparts for the scalar count leading zeros (ctz) and count leading ones (clz) instructions on AMD GPUs. Previously, only scalar versions were available. This enhancement provides more complete bit manipulation capabilities for vector data types on the AMDGPU architecture.
