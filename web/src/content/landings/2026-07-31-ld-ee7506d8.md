This change prevents the linker from garbage-collecting `_tls_used` and `_load_config_used` symbols in PE executables. These symbols are crucial for optional TLS directory linking in mingw-w64. Without this change, data sections containing these symbols could be removed if not otherwise referenced, leading to broken executables when TLS is used.
