GCC's RISC-V driver now unconditionally runs its specialized 'smart' multilib matcher, preventing regressions where a generic text-based matcher might select an incorrect multilib. Previously, the driver would sometimes skip the smart matcher if a multilib directory was already identified by the generic matcher. This change ensures that the smart matcher, which properly understands RISC-V architecture supersets, is always used. This leads to more accurate multilib selection, especially when command-line `-march` flags are used with complex configurations.
