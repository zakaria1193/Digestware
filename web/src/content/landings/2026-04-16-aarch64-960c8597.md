This commit fixes a ZA state transition issue in the AArch64 backend of GCC, specifically affecting Scalable Matrix Extension (SME) code. In the transition from INACTIVE_CALLER to INACTIVE LOCAL, the code now ensures that the ZA state is active and zeroed before setting `tpidr2_el0`. A new test case `za_state_8.c` is added to the testsuite.
