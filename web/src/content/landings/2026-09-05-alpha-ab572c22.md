This commit corrects an issue in the Alpha ELF backend where the `DF_TEXTREL` flag was being incorrectly set by ORing `DT_TEXTREL` into `info->flags`. This unintentionally introduced other flags like `DF_SYMBOLIC` and `DF_STATIC_TLS`, causing shared libraries with text relocations against global symbols to be treated as if linked with `-Bsymbolic`. This could lead to `dlopen` failures and incorrect relaxation of TLS references. The fix directly sets `DF_TEXTREL` using its correct value.
