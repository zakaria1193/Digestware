This commit corrects the behavior of Fortran array constructors that lack a type-specifier. Previously, such constructors defaulted to the type of their first element, leading to issues when used with polymorphic (CLASS) types. This could result in compiler internal errors (ICEs) during allocation or incorrect type checking. The change ensures that an untyped array constructor correctly assumes the declared type of a CLASS value and enforces that all elements match this type, resolving ICEs and aligning with F2023 standards.
