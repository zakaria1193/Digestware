This commit fixes an issue in the ifcombine optimization pass where XOR operations involving type conversions were not optimized correctly. When a constant operand had a wider type than the outer type after a conversion, it retained upper bits. This led to incorrect assumptions about the comparison's result, causing the optimization to erroneously deem the condition false. The fix ensures the constant operand is converted to the outer type, allowing correct optimization.
