An internal compiler error (ICE) occurred in the Fortran frontend when a %LEN or %KIND inquiry was made on a deferred-length character variable inside an ASSOCIATE construct. This was due to the inquiry's result retaining a 'deferred' flag, which caused a segfault when later processed. The fix clears this flag and correctly handles the character length for such inquiries, also resolving an issue where inquiries on ASSOCIATE names incorrectly reverted the type to CHARACTER.
