To improve the usability of GCC's Python scripts, a `pyproject.toml` file has been added to the repository. This file formally declares dependencies for various Python scripts, making it easier for developers to set up their environment using standard tools like `pip` or `uv`. While not enforcing installation, it clarifies requirements and allows for consistent formatting with tools like `black`. Dependencies are specified with broad compatibility, except for `black`, which is pinned to its 2026 edition for consistent formatting.
