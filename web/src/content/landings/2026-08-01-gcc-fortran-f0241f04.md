This commit enables the inlining of `MATMUL(TRANSPOSE(A),B)` when B is a rank-1 matrix. While loop ordering presents challenges due to dependencies, GCC's unrolling capabilities allow for better code generation, especially for smaller matrices. The change modifies frontend passes to handle this specific matrix case.
