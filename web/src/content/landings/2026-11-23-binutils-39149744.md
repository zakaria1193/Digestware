This commit forces the `HAVE_FNMATCH=1` configuration option within gnulib's build process. This change ensures that gnulib's implementation of `fnmatch` is consistently used, prioritizing it over the one provided by libiberty. This resolves issues where link order might otherwise cause libiberty's version to be chosen, leading to unexpected behavior in file matching tests, as observed in msys2-ucrt64 and macOS environments.
