This commit adds support for the `.insn smi` pseudo-mnemonic to the s390 GNU assembler. The SMI (System Management Instruction) format was introduced with the IBM zEC12 processor. The changes include updating opcode definitions, adding documentation for the SMI format, and introducing new test cases in the assembler's test suite.
