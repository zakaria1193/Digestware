This commit introduces the ADAC configuration option to explicitly specify the Ada compiler used during the build process. This is particularly useful during bootstrapping stages for building GNAT and related tools. The option is integrated into the top-level configure and make processes, ensuring that the correct Ada compiler is selected for various build stages and toolchain components.
