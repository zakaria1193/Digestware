For the hip12 core, this change modifies the compiler's behavior to prefer full-vector SVE loops over partially-masked ones. This optimization addresses performance regressions observed on hip12 when using `WHILELO` loops, where register dependencies between `WHILELO` computation and subsequent load instructions hindered performance. By setting `param_vect_partial_vector_usage` to 1, the compiler will now generate full-vector main loops, improving instruction-level parallelism and throughput.
