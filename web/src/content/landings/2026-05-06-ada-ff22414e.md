This commit introduces initial support for the new `Modifies` contract in SPARK, allowing its use as an aspect. The implementation involves significant changes across parsing (`par-ch13.adb`), contract analysis (`contracts.adb`, `sem_ch13.adb`), and documentation (`doc/gnat_rm`). While the legality checks for modified objects are still being developed, this lays the groundwork for more expressive specifications of side effects in SPARK programs.
