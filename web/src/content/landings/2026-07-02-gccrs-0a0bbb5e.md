GCC's Rust compiler has been updated to emit block-scope `Drop` calls through `TRY_FINALLY_EXPR`. This change ensures that destructors are correctly invoked when blocks are exited, even if cleanup code is involved. A new function, `Context::pop_block_with_cleanup`, is introduced to facilitate this, allowing cleanup logic to be passed as part of the block-popping operation.
