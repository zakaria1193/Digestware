The AArch64 compiler support has been updated to include atomic store intrinsics that utilize hints from the FEAT_CMH extension. The existing `atomic_store_with_stshh` has been generalized to `atomic_store_with_hint`, allowing it to accommodate new hints like STCPH. This enhancement aims to improve performance for atomic store operations.
