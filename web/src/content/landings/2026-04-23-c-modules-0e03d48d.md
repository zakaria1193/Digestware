This commit enhances C++ module support by streaming location information for `PTRMEM_CST_LOCATION` and `TRAIT_EXPR_LOCATION`. This allows the compiler to preserve location data from the module when these expressions are used, which can be helpful for debugging and diagnostics in code that uses C++ modules.
