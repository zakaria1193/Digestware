This commit corrects the behavior of AutoFDO's partial training mode. When a new clone of a function is created, and its call count exceeds the original, the original's profile should be lowered. Previously, under partial training, the original's profile was incorrectly forced to a global setting even when a local profile was intended. This change ensures that when `-fprofile-partial-training` is used, the original node's profile is correctly set to local, preserving intended profiling information.
