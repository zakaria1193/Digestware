This change fixes a bug in gprofng's profiling map generation where the file offset for `gmon.out` was not being correctly determined. Previously, a hardcoded offset of 0 was used, leading to incorrect profiling data on some platforms, specifically Linux/x86-64 as indicated by a test failure. The fix retrieves the correct file offset from the `filepos` field of the `core_text_sect` structure, ensuring accurate profiling map generation.
