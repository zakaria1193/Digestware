This change fixes an issue where Ada extension aggregates with inherited discriminants were wrongly rejected. The problem occurred in expression functions due to elements being analyzed twice non-idempotently. The fix ensures that the discriminant is not returned early if already present and removes inherited discriminants from the rewritten aggregate's component list.
