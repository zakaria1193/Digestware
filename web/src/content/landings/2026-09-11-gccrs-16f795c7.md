This commit updates the GCC Rust compiler's test suite to use Rust edition 2018 when testing the `alloc` crate. Previously, the mock core crate used did not support edition 2018. This change modifies the `alloc.exp` test file to use the newer edition and adjusts the mock `core.rs` to fix its use declarations and use raw identifiers for 'try', ensuring compatibility with edition 2018.
