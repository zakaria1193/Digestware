This patch adds support for unsized coercions from arrays to slices in the GCC Rust front-end. Previously, only dynamic trait coercions were handled, and array-to-slice conversions were rejected. The compiler now correctly identifies and tags valid array-to-slice coercions, improving type compatibility.
