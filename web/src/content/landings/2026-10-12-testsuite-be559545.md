A test case for PowerPC's `vec_xst_trunc` intrinsic was failing on big-endian (BE) targets because its expected values assumed little-endian byte ordering. This commit modifies the test to use endian-specific expected values for halfword, word, and doubleword truncating stores, ensuring the test passes correctly on both big-endian and little-endian PowerPC systems. It also corrects a DEBUG output variable.
