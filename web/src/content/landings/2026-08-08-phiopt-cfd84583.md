This commit addresses an issue in the `phiopt` optimization pass where the `factor_out_conditional_load` function did not correctly handle the `REF_REVERSE_STORAGE_ORDER` attribute. This oversight could lead to the loss of this attribute or incorrect handling when conditional loads were factored out. The fix ensures that this storage order information is preserved and correctly matched, preventing potential code generation errors.
