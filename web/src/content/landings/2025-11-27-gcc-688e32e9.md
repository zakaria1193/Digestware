The `dg-extract-results.sh` and `dg-extract-results.py` scripts, used for combining test summary and log files, have been enhanced to accept input file lists via a new `-f` option. This option allows reading file paths from a specified file or from standard input, which is crucial for environments like Windows where passing a large number of files as command-line arguments can exceed length limits and cause failures. This change ensures the test suite can complete successfully even with thousands of test output files.
