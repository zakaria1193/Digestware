The AArch64 backend now implements the `ctz2` instruction for Advanced SIMD's byte and halfword modes. Previously, these modes were expanded into a less efficient generic sequence involving bit reversal, AND, CLZ, and subtraction. The new implementation directly uses `RBIT` and `REV16` where appropriate, reducing the instruction count and eliminating the need for vector constants. This leads to faster execution for bitwise operations involving trailing zeros in these data types.
