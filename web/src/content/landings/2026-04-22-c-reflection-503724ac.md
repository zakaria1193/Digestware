Fixes a bug in the C++ reflection implementation where an access check was incorrectly performed on a dependent splice expression. When processing `&[:R:]` in `cp_parser_splice_expression`, access checking is disabled around the call to `build_offset_ref`. This same protection was missing in `tsubst_splice_expr`, leading to compilation failures when access control checks should have been suppressed. The patch adds the missing access control disabling to `tsubst_splice_expr`.
