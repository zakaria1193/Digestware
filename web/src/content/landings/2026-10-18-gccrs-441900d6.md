This commit introduces support for atomic minimum and maximum operations within the GCC Rust frontend. Since the GCC backend lacks direct equivalents, these operations are implemented using compare-exchange loops, similar to other projects like rustc_codegen_gcc. This enables Rust programs to correctly utilize these atomic primitives for thread-safe manipulation of shared data.
