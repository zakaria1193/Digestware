This commit optimizes the i386 backend's `ix86_expand_sse_movcc` function, which handles SSE vector conditional move instructions, particularly when dealing with constant vectors. It now generates an `AND` then `XOR` sequence instead of the traditional `pand`, `pandn`, `por` sequence when both conditional operands are constant vectors. This change reduces the number of instructions and required registers, yielding a more compact and potentially faster code for operations like conditional assignments within loops, as illustrated by a one-instruction reduction in typical scenarios.
