This commit resolves an issue in the RTL (Runtime Linearization) reordering phase where debug instructions between consecutive labels could be misinterpreted. The `skip_consecutive_labels` function previously treated debug instructions as regular instructions, causing it to stop prematurely and hide later labels. This could lead to incorrect branch redirection and mismatches in debug-related tests. The fix modifies the function to ignore debug instructions, ensuring correct label processing and passing associated regression tests.
