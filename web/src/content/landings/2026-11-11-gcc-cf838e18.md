GCC's bundled 'cuda.h' header incorrectly included the `CUDA_ERROR_COOPERATIVE_LAUNCH_TOO_LARGE` error code. This code is not defined in CUDA 8.0, which GCC's header corresponds to. To prevent potential behavioral divergence, especially in configurations using '-DPLUGIN_NVPTX_INCLUDE_SYSTEM_CUDA_H', this commit removes the extraneous error code.
