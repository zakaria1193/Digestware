This change addresses an issue in Fortran's DO CONCURRENT loops where loop limits and step values were re-evaluated in each iteration. This behavior contradicted the F2018 standard, which specifies that limits should be evaluated once. The compiler now correctly evaluates the start, end, and step values once for outermost DO CONCURRENT constructs, ensuring predictable loop execution.
