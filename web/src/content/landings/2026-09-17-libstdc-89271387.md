This commit updates a libstdc++ test suite helper procedure to use a variable for the C++ standard version instead of a hardcoded value. This prevents test cases from becoming outdated, such as the one that previously used '-std=gnu++26' when '-std=gnu++29' was the correct standard for newer tests.
