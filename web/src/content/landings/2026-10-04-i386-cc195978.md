This patch modifies the i386 backend's Machine Description (`i386.md`) to ensure it is "any-or-plus (AOP) safe". This means the backend can now correctly recognize `shld` and `shrd` instructions when they are represented in RTL using PLUS, IOR, or XOR operations. This change is a prerequisite for fixing PR tree-optimization/108477 and includes documentation for the `aop<mode>3` named pattern.
