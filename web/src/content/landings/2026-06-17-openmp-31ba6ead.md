This commit introduces `GOMP_loop_static_worksharing` and `GOMP_distribute_static_worksharing` as new libgomp entry points for static-scheduled OpenMP loops. Previously, the compiler would make two separate public API calls (e.g., `omp_get_thread_num()` and `omp_get_num_threads()`) to get thread or team identifiers and counts. Consolidating these into a single internal call, returning a complex value, prevents OMPT (OpenMP Tools) from confusing these compiler-generated queries with user-level API calls and preserves optimization opportunities in subsequent compiler passes.
