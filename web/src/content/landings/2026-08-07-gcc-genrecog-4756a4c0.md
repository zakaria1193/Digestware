The genrecog tool in GCC previously emitted each pattern condition inline, leading to duplicated code and large generated files. This commit refactors genrecog to define a helper inline function for each unique condition and call that function from the generated code. This significantly reduces the size of insn-recog-*.cc files, speeds up compilation, and lowers memory usage, as demonstrated on AArch64.
