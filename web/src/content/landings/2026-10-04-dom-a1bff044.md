The `record_conditions` function within the DOM (Dominator Tree) analysis pass no longer derives implied conditions, as this functionality is now handled more effectively by the ranger pass. This change eliminates redundant computations and simplifies the DOM pass. Testing on various benchmarks, including C++ bootstrap files and Fortran LAPACK builds, showed no difference in generated assembly or test outcomes, indicating the removal is safe.
