This update refines the LoongArch `mov<mode>cc` expander to support conditional floating-point moves based on integer comparison outcomes. It also adjusts the cost estimates for moving data between general-purpose registers (GPRs) and floating-point condition registers (FCCs). By setting these costs more accurately, the compiler can avoid unnecessary register spilling and generate more efficient code for conditional assignments involving floating-point values.
