gccrs now assigns a single, consistent node ID and HIR ID to all builtin types, regardless of where they are created. This addresses an issue where resolving multiple crates led to duplicate node IDs for the same builtin types. By using a singleton to store these IDs, the compiler ensures type consistency across different crate resolutions.
