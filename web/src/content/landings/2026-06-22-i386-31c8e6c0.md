This commit improves the i386 compiler backend by allowing the `bt` (bit test) instruction followed by a conditional move (`cmov`) to be optimized even when one of the conditional move's target values is an immediate constant. Previously, this optimization only worked if both target values were registers. The change enables folding patterns like `(a & (1 << b)) ? c : immediate_value` into a more efficient `bt + cmov` sequence, reducing instruction count.
