The GCC installation manual's `install.texi` file had mismatched internal node pointers and menu orderings, leading to `makeinfo` warnings. This commit corrects the `@node` pointers in `install.texi` and `fdl.texi` to accurately reflect the intended chapter order ('Installing GCC', 'Specific', 'Binaries'). It also rearranges the chapters physically in `install.texi` to ensure consistency between the node structure and the output of PDF/HTML generation tools.
