GCC reverts changes that allowed register overlap in RISC-V vector widening multiply-add instructions (vwmacc[u].vx) which use a scalar register as one of the operands. This revert enforces compliance with the vector specification that prohibits a single register from supplying operands with different Effective Element Widths simultaneously. Test cases and instruction definitions are adjusted.
