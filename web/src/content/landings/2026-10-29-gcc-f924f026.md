This commit centralizes AVX10.2 convert intrinsics by moving them from their original header file to the new avx10v1auxintrin.h. This change aligns with the ongoing integration of the AVX10V1AUX feature into GCC's i386 backend. It involves updating various configuration and machine description files to reference the consolidated header and correctly associate these intrinsics with the new feature.
