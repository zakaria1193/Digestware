This commit introduces RISC-V Vector (RVV) intrinsics for the Zvdota extension, supporting integer, BF16, and FP8 data types for dot-product operations. It includes distinct FP8 vector types and selects static instruction patterns for each source-type combination. The changes also preserve generated type-index mappings and handle new accumulator and FP8 type indexes, enabling efficient computation with these specialized data formats.
