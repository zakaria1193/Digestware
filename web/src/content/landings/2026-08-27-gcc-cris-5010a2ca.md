This commit simplifies a bit test pattern in the CRIS backend (`config/cris/cris.md`). Following a fix for PR rtl-optimization/126276, the pattern was made slightly more complex than necessary. This change reverts it to a simpler form by correctly handling the zero-extending nature of `zero_extract` and ensuring the pattern iterates only over relevant conditions, reducing complexity without impacting correctness.
