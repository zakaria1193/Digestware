The vectorizer can now represent first-order recurrences as scalable permutations, specifically recognizing the two-input permutation pattern. It builds a predicate for D elements and uses the SVE SPLICE instruction. This change improves code generation by utilizing specialized hardware instructions, as demonstrated by a before-and-after assembly comparison showing more efficient code for a recurrence loop.
