GCC's Dead Code Elimination (DCE) pass has been modified to prevent the removal of the left-hand side (LHS) of a call instruction when the `no_delete` attribute is active. This change addresses a problem where removing the LHS and subsequently inserting an assignment could violate basic block invariants, particularly concerning exception handling and functions that require specific statement ordering (e.g., 'returns twice' functions). Instead of inserting a new statement, the LHS is now simply not removed, ensuring program correctness.
