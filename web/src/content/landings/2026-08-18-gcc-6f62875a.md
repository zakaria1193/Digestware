This commit cleans up the `final.cc` source file by removing four static variables: `override_filename`, `override_linenum`, `override_columnnum`, and `override_discriminator`. These variables, added for DBX debugging info, are no longer used as their last relevant functionality was removed in 2022 with the deprecation of `-gstabs` and `-gxcoff` support. Their removal simplifies the code and removes dead state.
