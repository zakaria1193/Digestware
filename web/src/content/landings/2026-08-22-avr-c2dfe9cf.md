This patch adds the `.gnu_attribute 4 (Tag_GNU_AVR_VTABLE_AS)` tag to AVR object files, indicating the address space used for C++ virtual tables. This tag will be valuable for future extensions that might support vtables in non-generic address spaces. The compiler identifies vtable usage by tracking indirect calls to vtable entries and checking for vtable declarations in the varpool.
