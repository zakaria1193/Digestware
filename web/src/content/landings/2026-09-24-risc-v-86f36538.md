The RISC-V linker previously used a chain of conditional branches to select relax functions and hard-coded the number of passes. This refactoring introduces a `riscv_relax_pass` structure to describe each pass, including its reloc selector and optional hooks. This change lays the groundwork for adding new relax passes, such as vendor-specific ones or those for Zcmt table jumps, without requiring extensive code modifications.
