New AVX10/v2 intrinsic functions have been added to GCC to facilitate conversions between FP8 and FP4 (4-bit floating-point) formats. This includes support for various vector sizes (128, 256, and 512 bits) and masked operations. The changes also introduce new built-in types and definitions, along with test cases to ensure the correct implementation of these low-precision floating-point conversions.
