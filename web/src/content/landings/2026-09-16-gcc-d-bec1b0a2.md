This commit corrects how vector comparison expressions are handled in the D language frontend when the target architecture uses mask registers that are narrower than the vector data size. Specifically, on targets with AVX512 masks (which are 32x narrower than operands), the D frontend's rule of using a same-size integral vector for the result caused type reinterpretation rejections. The solution mirrors the C/C++ frontends by computing a separate, appropriate return type for vector boolean operations.
