This commit significantly improves the diagnostics for the OpenMP `allocate` directive in C++. It introduces checks and provides clearer error messages for several problematic scenarios, including multiple uses of the same variable within a single directive, using parameters as variables, referencing variables in different scopes, and using reference types. These enhancements ensure that developers receive more precise feedback about incorrect usage, facilitating faster debugging and correct implementation of OpenMP features.
