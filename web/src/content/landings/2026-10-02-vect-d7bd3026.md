primer_expert: This commit fixes an integer underflow bug in the vectorizer's alignment
  peeling logic for loops that utilize partial vectors (e.g., SVE with `mrvv-vector-bits=zvl`).
  When `LOOP_VINFO_USING_PARTIAL_VECTORS_P` is true, the vectorizer previously skipped
  generating an epilog and an iteration check, which, combined with certain loop bounds,
  led to an underflow in the calculation of remaining iterations. The fix ensures
  correct bound calculations in these scenarios, preventing incorrect loop termination
  or crashes.

- term: alignment peeling
  definition: A loop transformation technique in vectorization where a small number
    of initial loop iterations are executed separately to align data access with vector
    register requirements.
- term: partial vectors
  definition: In vector processing, refers to operations that do not utilize the full
    width of the vector registers, often occurring at the end of a loop or when data
    is not perfectly aligned.
- term: RISC-V SVE
  definition: Scalable Vector Extension for the RISC-V architecture, allowing vector
    registers to dynamically adapt their size.
- term: underflow
  definition: An arithmetic condition where a calculation results in a value smaller

    to a large positive number.
