This commit fixes an issue in `profile_probability::apply` where signed input values were not handled correctly, leading to incorrect rounding and potential overflow. The function uses division, and the rounding behavior for negative numbers was problematic. The fix scales the magnitude of the signed value using `safe_scale_64bit` and then restores the sign, ensuring correct results. It also preserves the sign for unit probabilities and handles uninitialized probabilities as before. New selftests verify the corrected behavior.
