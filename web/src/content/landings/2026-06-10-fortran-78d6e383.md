This commit resolves an Integer Compiler Error (ICE) in Fortran's structure constructors when assigning an allocatable character to an allocatable component. The fix replaces a scalar fold_convert with gfc_trans_string_copy for explicit-length allocatable character components, ensuring correct value copying. A new test case is added.
