This patch introduces the `range_inclusive_new` lang item to the GCC Rust compiler. Inclusive range expressions are now desugared into a function call targeting this lang item during AST-to-HIR lowering, rather than being directly lowered into a static struct. This change aligns with the removal of the `HIR::RangeFromToInclExpr` class.
