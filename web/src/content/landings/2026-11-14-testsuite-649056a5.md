Floating-point rounding mode tests on ARM targets that support single-precision (SP) but not double-precision (DP) floating-point hardware are now marked as expected to fail (xfailed). This is because the software routines used for DP arithmetic on these targets do not respect the specified rounding modes, aligning with a previous change in the fp-double-convert-float-1.c test file.
