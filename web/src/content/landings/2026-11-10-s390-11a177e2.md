This commit adds support for six new `.insn` pseudo-mnemonics (ss_a through ss_f) to the s390 GNU assembler. These mnemonics represent different variants of the SS (Store String) instruction format. The changes include updates to opcode definitions, extensive additions to the z/Architecture test suite, and improvements to the ESA/390 test suite for the `ss` instruction.
