This commit performs a modernization effort within the GCC analyzer by converting the `enum memory_space` to a C++ `enum class memory_space`. This change improves type safety and namespace management without altering the functionality of the analyzer's memory space tracking. Various files within the `gcc/analyzer` directory have been updated to reflect this change.
