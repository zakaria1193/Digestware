This commit adds a comprehensive suite of new test cases for the RISC-V architecture, specifically targeting the unsigned scalar saturating multiplication (SAT_MUL) instruction in its form 13. These tests verify the correct behavior of the recently implemented support for this instruction form, covering various operand sizes and scenarios to guarantee its reliability and accuracy within the compiler's code generation. The additions help ensure the compiler adheres to saturating arithmetic semantics for RISC-V targets.
