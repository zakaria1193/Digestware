This commit removes the `STMT_VINFO_SLP_VECT_ONLY_PATTERN` flag, which was used in the tree vectorizer's SLP (superword-level parallelism) pattern matching. The flag was intended to mark statements that only exist as part of a vector pattern, but the associated cleanup logic was unnecessary. This change simplifies the code and removes dead code paths. The SLP patterns are reachable from the pattern SLP nodes representative.
