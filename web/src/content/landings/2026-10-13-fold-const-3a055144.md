The functions minmax_from_comparison and fold_cmp_float_cst_p in fold-const.cc previously took large wide_int arguments by value. These arguments are only read, so they are now passed by const reference. This change avoids copying 80-byte wide_int values on x86_64, improving efficiency without altering program behavior.
