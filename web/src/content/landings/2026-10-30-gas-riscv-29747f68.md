The RISC-V assembler incorrectly accepted some unimplemented architecture extensions when specified using the `.option arch` directive. This commit corrects the validation logic in `riscv_update_subset1` to ensure that any unimplemented extensions result in an error, consistent with the handling of full, unimplemented specifications. It also renames and clarifies the purpose of the `explicit_subset` parameter.
