This commit corrects an issue in `bfd_generic_get_relocated_section_contents` where debugging sections were incorrectly excluded. Previously, a change intended to generalize section merging incorrectly filtered out `SEC_DEBUGGING` sections. This led to broken debug information in the resulting binaries, causing warnings with tools like objdump when inspecting debug info. The fix ensures these sections are handled appropriately, resolving testsuite fallout and preserving debug information.
