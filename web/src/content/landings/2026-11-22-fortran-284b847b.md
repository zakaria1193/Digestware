This commit addresses a Fortran compilation issue where function results passed as actual arguments were not being properly finalized when used in specific contexts like operator operands or conditions. This violated the F2023 standard (7.5.6.3). The fix repositions the finalization step for such arguments to occur at the beginning of the 'post block' of the enclosing call, which is preserved across all expression types. It also refines logic to correctly count nested argument evaluations, ensuring finalization happens appropriately.
