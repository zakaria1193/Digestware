This commit integrates NEON shift-by-immediate intrinsics (e.g., vshl_n, vshr_n, vsra_n) into the pragma-based framework for the aarch64 architecture. This consolidates the handling of these operations within a unified framework, removing outdated direct expansion logic and specific machine-dependent code. The change also includes updates to fix tests that were affected by the new handling of zero shifts.
