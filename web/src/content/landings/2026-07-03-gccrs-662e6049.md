The gccrs Rust compiler now registers the `#[global_allocator]` attribute. This commit enables gccrs to recognize this attribute and perform initial sanity checks, such as ensuring it's applied only to static items. While this does not implement the full functionality for custom allocators, it's a necessary step for understanding and validating the attribute's presence in the code.
