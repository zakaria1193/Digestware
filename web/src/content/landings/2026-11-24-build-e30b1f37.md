This commit addresses an issue in GCC's configure script that caused failures when a cross-compiler was used to build a native compiler (host != build). The problem occurred because a check for `gmp.h` was unconditionally performed during the nested configure run for the build machine, which lacked the necessary include paths. The fix guards this check with `GENERATOR_FILE`, ensuring it's skipped when appropriate and allowing the build to proceed correctly without requiring GMP headers on the build machine.
