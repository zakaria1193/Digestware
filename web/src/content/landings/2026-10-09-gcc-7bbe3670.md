The compiler's ifcombine pass previously merged comparison operations that tested the same bit in different ways, leading to incorrect code generation for certain edge cases involving negative numbers. This change adds a check to reject such merges, ensuring that if bits are tested by both comparisons, they are tested consistently. New test cases are included to cover these scenarios.
