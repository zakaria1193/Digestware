This commit introduces a centralized output management system in `gensupport` for GCC's machine description generators (genemit, genrecog, genattrtab). It consolidates logic for file naming, opening, selection, and closing, improving consistency and reducing code duplication. The changes enable better handling of partitioned outputs and fixed outputs like headers, ensuring a unified lifecycle management across generators and addressing issues found in previous PRs.
