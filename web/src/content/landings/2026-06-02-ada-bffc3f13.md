This commit significantly expands Ada's attribute subprogram feature, adding support for indexing, literal aspects, the Default_Iterator, Put_Image, and stream attributes. It refactors internal naming for attribute subprograms to use a simpler type'apostrophe'aspect format and improves error reporting by associating messages with the attribute subprograms themselves. Furthermore, it allows direct calls to attribute subprograms using their attribute names and integrates them into expanded name constructs.
