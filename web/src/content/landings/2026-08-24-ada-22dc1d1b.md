A regression in the Ada compiler that caused a failure when assigning an array aggregate to an unconstrained formal parameter has been fixed. The compiler previously failed to implement the necessary 'sliding' due to an incorrect predicate that only considered object declarations. This update ensures correct handling of such assignments across multiple GCC branches.
