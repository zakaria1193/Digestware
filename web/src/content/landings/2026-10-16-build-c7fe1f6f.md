The `contrib/gcc_update` script has been enhanced to support Git worktrees, a feature allowing multiple checkouts to share a single repository. A new `--no-fetch` option suppresses the `git pull` command and instead uses `git rebase`. This is beneficial for worktrees as it avoids redundant upstream syncs while still updating revision files, mirroring the behavior of a standard fetch.
