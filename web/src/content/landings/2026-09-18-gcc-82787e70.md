This commit implements the `umul<mode>3_highpart` intrinsic for V2DI, V4DI, and V8DI vector types using SSE2 instructions, specifically `pmuludq`. This provides a hardware-accelerated path for calculating the high-order part of unsigned integer multiplications on vectors of double-words. The implementation targets specific vector types and instruction sets (VI8_AVX2_AVX512F) and includes cost modeling for the new operation. This change is expected to significantly speed up workloads like `750.sealcrypto_r` by approximately 20% on Zen4 processors, recovering performance lost in a previous revision.
