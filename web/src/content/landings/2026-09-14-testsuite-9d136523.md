This commit addresses two issues in the ARM test suite. First, the `short-it-ifcvt-2.c` test is now skipped on M-profile targets where `-mrestrict-it` is disabled, preventing false failures. Second, the branch scanning logic has been updated to correctly match branch mnemonics, including equivalent signed comparisons like `rsblt` and `rsbge`. These changes ensure the test suite accurately reflects compiler behavior and avoids spurious regressions.
