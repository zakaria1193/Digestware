This fix in the `cfgexpand` pass ensures that stack-allocated local variables are consistently aligned. Previously, `defer_stack_allocation` and `expand_one_stack_var_1` used different methods to calculate alignment, causing variables deemed small enough by one function to trigger a large-alignment assertion in the other. The change standardizes alignment computation using `align_local_variable`.
