This patch introduces new built-in functions to GCC for the PowerPC rs6000 architecture, enabling developers to utilize specialized SHA2 and SHAPAD cryptographic instructions. It defines numerous builtins, including those for extended mnemonics, and adds parameter checking to catch errors early in the compilation process. These additions prepare for potential future processor support of these instructions.
