The function `range_from_missing_constructor_part` in the ranger analysis pass previously returned a boolean indicating success. Since pointers are no longer specially handled in `range_from_readonly_*`, this function now always returns true. The change makes it return `void` and updates its callers accordingly, simplifying the analysis logic.
