This commit adds memory clobbers to the AArch64 `aarch64_gcsss1` and `aarch64_gcsss2` patterns, which handle GCS stack switches. These instructions validate and consume a cap token while writing a return token, implicitly affecting memory. Without explicit memory clobbers, RTL optimizers incorrectly assumed memory was unchanged, leading to incorrect code generation, such as Common Subexpression Elimination reusing stale loads. The addition ensures that memory is treated as potentially changed across these instructions.
