This commit cleans up conditional compilation code related to the OpenMP 'indirect' clause. It removes legacy preprocessor macros like `!USE_HASHTAB_LOOKUP` and `!USE_HASHTAB_LOOKUP_FOR_INDIRECT` from `target-indirect.c`, `plugin-gcn.c`, and `plugin-nvptx.c`. This simplifies the codebase by removing unused or obsolete conditional paths.
