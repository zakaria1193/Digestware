primer_glossary:
- term: DST
  definition: Dynamically Sized Type. A type whose size is not known at compile time,
    such as a slice `[T]` or a trait object `dyn Trait`. DSTs can only be used behind
    pointers like `&` or `Box`.
- term: Box
  definition: A smart pointer in Rust that owns data on the heap. It's analogous to
    a unique pointer in C++.
- term: auto-deref
  definition: An automatic dereferencing mechanism in Rust that allows method calls
    and field access on a smart pointer (like `Box` or `&`) to automatically follow
    the pointer to the underlying data.
- term: fat pointer
  definition: A pointer that contains not only the memory address of the data but
    also additional metadata. For slices, this is the length; for trait objects, this
    is a vtable pointer.

This patch enhances gccrs' support for Rust's `Box` type by enabling it to handle Dynamically Sized Types (DSTs). It also refines the auto-deref mechanism for `Box`, ensuring method dispatch, indexing, and tuple field access function correctly. Changes include modifications to how DST guards are handled, fat pointer creation, and expression type checking.
