The commit removes a `labs` call in `ctf-link.c` that was causing a signed/unsigned comparison warning when compiling for 32-bit hosts. The `labs` call was used to check the number of inputs, but it's unnecessary since the error status is not a negative count (only -1). The code now casts `ninputs` to `size_t` instead.
