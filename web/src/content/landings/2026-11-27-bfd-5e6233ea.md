A fix has been implemented in BFD's `bfd_xcoff_build_dynamic_sections` function to prevent crashes when a linker script selects a non-XCOFF output format. Previously, this scenario led to an out-of-bounds read due to the use of a generic hash table instead of the expected XCOFF-specific one. The function now returns early if the output BFD does not have the XCOFF flavor, aligning with existing checks.
