This change introduces a partially dynamic small-integer model for Ada accessibility checks in GCC, moving beyond the previous static model. The static model, based on master construct nesting depth, struggled with Ada 2012 requirements like strict caller/called level ordering. The new model augments static nesting depth with dynamic levels passed to subprograms, offering better compliance while keeping runtime overhead minimal. Compile-time changes are localized to the Accessibility unit.
