This commit fixes a null pointer dereference in the linker's AVR and M68HC11 emulation hooks by adding checks for a valid `stub_file`. Previously, when a generic ELF output format was selected via `OUTPUT_FORMAT`, no stub file was created, leading to crashes in emulation-specific code that expected one. The linker now correctly refuses the link in such cases.
