The libstdc++ library previously included a workaround for a constant expression bug in `std::optional`. This commit restricts that workaround to Clang, as GCC's own fix (r16-8767) has resolved the underlying issue. This prevents unnecessary code from being executed in GCC, while still addressing the bug in Clang.
