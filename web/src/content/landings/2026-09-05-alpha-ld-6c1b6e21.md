This commit updates the Alpha linker to reject specific relocation types that cannot correctly refer to IFUNC symbols. Relocations such as `R_ALPHA_BRADDR`, `R_ALPHA_BRSGP`, general GP-relative relocations, and `R_ALPHA_SREL*` directly name the symbol, bypassing the IFUNC resolver. `R_ALPHA_REFLONG` only has a 32-bit field, insufficient for the resolver's return address. These invalid relocations are now reported, allowing the linker to report all such errors in a single pass.
