gccrs has been updated to properly support type checking for Rust's `#[repr(transparent)]` attribute, specifically for zero-sized types (ZSTs). New functions are introduced to determine if a type is zero-sized, and these checks are integrated into the type-checking logic for transparent structs, ensuring correct handling of types like `PhantomData` within them.
