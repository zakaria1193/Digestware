This change introduces a new helper function, `is_dwo_section`, in `binutils/dwarf.c` to determine if a DWARF section has the `.dwo` suffix. This function is then used by `read_and_display_attr_value`, `display_debug_macro`, `display_debug_loc`, and `display_debug_str_offsets` to simplify code and improve readability when identifying DWO sections.
