This commit improves code generation for the iq2000 port by steering the AOR (Arithmetic OR) optab to use IOR instead of PLUS when they are equivalent. It also optimizes the low-part IOR operation when one operand is zero, transforming it into a simple copy. For constant loads, this means emitting only the LUI instruction. These changes resolve poor code generation issues previously observed for the iq2000 port.
