This commit ensures that signed vector arguments passed to AArch64's `vclz` and `vcnt` intrinsics are correctly converted to their unsigned equivalents before being folded into `.CLZ` and `.POPCOUNT` internal functions. This resolves a type mismatch issue where signed arguments were incorrectly used with intrinsics defined only for unsigned types. The generated code remains the same, but the internal representation is now type-safe.
