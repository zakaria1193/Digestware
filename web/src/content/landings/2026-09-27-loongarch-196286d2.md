Binutils has enabled support for building shared libraries and Position-Independent Executables (PIE) for LoongArch ELF targets (`loongarch*-elf`). Previously, these targets withheld the necessary scripts (`GENERATE_SHLIB_SCRIPT`, `GENERATE_PIE_SCRIPT`), preventing the linker (`ld`) from accepting `-shared` and `-pie` flags. This change aligns LoongArch with RISC-V by unconditionally enabling these scripts, allowing for more flexible and modern executable and library creation on the architecture.
