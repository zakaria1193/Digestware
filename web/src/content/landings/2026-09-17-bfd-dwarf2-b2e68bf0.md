This commit modifies how addr2line breaks ties when multiple functions have the same source code range. Previously, it used the memory address of the function's struct funcinfo, which could vary due to allocator behavior. Now, it uses the DIE offset, which is stable and deterministically indicates the innermost function, resolving inconsistencies in addr2line output for inlined subroutines.
