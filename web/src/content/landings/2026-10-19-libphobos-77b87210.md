This commit fixes an issue in libphobos's build system where libtool's language configuration was incorrectly defaulting to C instead of D. The change updates the autoconf macros to properly use AC_LANG_PUSH and AC_LANG_POP, ensuring that D language features are recognized and used during the build configuration process.
