This commit addresses a bug in C++ parsing related to default member initialization within constructors. Previously, the parser incorrectly handled cases involving default member initializers for class-type members when performing early parsing. The fix modifies the parser to correctly check for `MAYBE_CLASS_TYPE_P` instead of an empty initializer list, ensuring proper handling of these constructs. A new test case validates the correction.
