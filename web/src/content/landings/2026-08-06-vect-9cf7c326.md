This change enhances the vectorization pass to recognize high-part multiply operations even when the widened type (e.g., 128-bit result of a 64-bit multiply) does not have a direct vector form on the target architecture. Previously, the pattern matching would fail in such cases, preventing vectorization. Now, the pattern matching continues even without a vector type for the output, allowing the cast to be recognized and the over-widening machinery to handle it, thus enabling scalar code using these operations to be vectorized.
