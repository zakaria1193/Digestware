The class template instantiation logic in `pt.cc` has been refactored to utilize the `maybe_push_to_top_level` helper function. This change aims to consolidate code and improve consistency by moving entities that don't need to remain local to the class template's scope to the top-level scope, similar to how lambda handling was previously adjusted. This refactoring contributes to cleaner internal code management.
