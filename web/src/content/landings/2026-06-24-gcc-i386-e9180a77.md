This commit updates the declaration of the `_m_prefetchw` intrinsic function for i386 architectures within GCC. The parameter type is changed from `void *` to `volatile const void *`. This modification ensures consistency with how Clang declares the same intrinsic, thereby preventing the need for `const_cast<void *>` at call sites in user code. This improves code cleanliness and interoperability for developers using both compilers.
