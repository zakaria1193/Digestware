This commit optimizes DWARF location list generation for LoongArch by conditionally using `DW_LNS_fixed_advance_pc`. Previously, this opcode was used even when linker relaxation was not involved between symbols. The change introduces finer control using FROM and TO symbols, employing `DW_LNS_fixed_advance_pc` only when linker-relaxable instructions are present, and using special opcodes otherwise. A new macro `DWARF2_USE_FIXED_ADVANCE_PC_FRAG` is added to prevent unnecessary calls for other targets.
