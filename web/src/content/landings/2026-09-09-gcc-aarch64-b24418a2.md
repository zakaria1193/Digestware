GCC's intrinsic folding logic for aarch64 NEON instructions previously skipped folding if the result was unused. This was based on an incorrect assumption that all intrinsics would have an `expand` implementation. This commit corrects the logic to compute and store the result in a variable, allowing later passes to discard it if truly unused. A new test case verifies this fix.
