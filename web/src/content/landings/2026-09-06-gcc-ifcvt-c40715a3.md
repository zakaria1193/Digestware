The `ifcvt` (if conversion) pass now factors its common precondition checking code into a new helper function, `if_case_blocks_ok_p`. This function consolidates the twenty-two lines of code previously duplicated in `find_if_case_1` and `find_if_case_2`, which checked hot/cold partitioning and terminal conditional jumps. This change is a code refactoring with no functional impact.
