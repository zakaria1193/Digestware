- term: -Wstrict-aliasing
  definition: A GCC warning option that diagnoses violations of the strict aliasing
    rule, which states that pointers of different types should not be used to access
    the same memory location. The front-end check is type-based, while the back-end
    performs flow-sensitive analysis.
- term: -fno-strict-aliasing
  definition: A GCC optimization flag that disables optimizations that rely on the
    strict aliasing rule. This can lead to incorrect behavior if the code violates
    the rule, but may improve performance by allowing more aggressive optimizations.
- term: strict aliasing rule
  definition: A C/C++ language rule that restricts how memory can be accessed through
    pointers of different types. It ensures that aliasing does not disrupt compiler
    optimizations. Violating this rule can lead to undefined behavior.
- term: type-based diagnostic
  definition: A compiler check that analyzes code based on the declared types of variables
    and pointers, without considering runtime execution flow or optimization state.

The C-family front-end now correctly honors an explicit -Wstrict-aliasing warning flag, even when -fno-strict-aliasing is also enabled. Previously, -fno-strict-aliasing would unconditionally silence this warning. This change ensures that users who explicitly request strict aliasing checks receive them, as the front-end's type-based check does not require optimization to be active. The back-end's more complex flow-sensitive checks are still subject to optimization flags.
