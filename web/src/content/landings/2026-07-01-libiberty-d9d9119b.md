A signed integer overflow vulnerability in the `d_compact_number` function within libiberty's C++ demangler has been fixed. The issue, reported in Bug-Binutils, is resolved by performing the addition using unsigned arithmetic, preventing overflow when handling large numbers. This change ensures the demangler's correctness and stability.
