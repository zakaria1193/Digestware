This commit enhances the GCC Rust frontend's attribute handling by recognizing both the basic `#[used]` attribute and its argument-based variant, gated by `feature(used_with_arg)`. The feature gating logic for the `used` attribute on static items is now implemented. While this commit adds recognition and gating, the actual backend implementation for preserving the static item is noted as a future step.
