The binutils assembler now supports various RIE instruction formats (RIE-a through RIE-g) using the .insn pseudo-mnemonic on s390. These formats were introduced across different processor generations, starting with IBM z900. The changes include updates to opcode definitions, assembler documentation, and test suites.
