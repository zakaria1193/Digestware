This commit corrects the behavior of `ctz(0)` and `clz(0)` for the ARCompact architecture. While the instruction set defines these operations on zero to return 31, the emulation using the `norm` instruction on ARCompact incorrectly returned 32. The fix adjusts the emulation patterns for `clzsi2` and `ctzsi2` to produce the correct result of 31 for a zero operand, aligning with the architecture's definition and preventing incorrect calculations.
