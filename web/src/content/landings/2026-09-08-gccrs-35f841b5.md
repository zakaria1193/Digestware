This commit enhances GCC Rust's type checking by ensuring that generic arguments within type bindings are properly walked to identify unconstrained issues. This fix addresses two specific cases (Rust-GCC/gccrs#4862 and #4863) where the compiler failed to detect or correctly handle situations involving unconstrained generics in bindings.
