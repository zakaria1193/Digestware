The neg[sd]f2 machine description patterns for Xtensa have been refined to prevent performance regressions caused by interactions with other patches. The changes focus on using only floating-point instructions and a peephole2 pattern to improve code size when both source and destination are address registers in TARGET_DENSITY configurations. This approach avoids complex instruction selection based on operand constraints.
