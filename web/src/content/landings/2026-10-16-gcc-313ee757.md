This commit improves const correctness in GCC's exception handling code by changing the `get_eh_region_from_rtx` function to accept a `const rtx_insn*` parameter. This ensures that the function, which is intended to query information about an exception handling region, does not modify the instruction it is examining. Both the header and the implementation file were updated to reflect this change.
