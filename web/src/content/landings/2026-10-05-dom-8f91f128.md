The Dominator (DOM) optimization pass has changed how it simplifies conditional statements. Instead of a 'singularity' transformation that rewrites comparisons into equalities, it now uses a simpler folding mechanism that only evaluates the conditional to a constant if possible. This change avoids a transformation that was problematic for loop analyzers and was redundant given other range analysis optimizations.
