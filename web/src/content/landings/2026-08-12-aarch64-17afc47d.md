binutils now supports emitting Structured Exception Handling (SEH) information for the AArch64 architecture. This implementation, based on Microsoft's ARM64 exception handling model, generates .pdata and .xdata records. The process required modifications to the object file generation, including relaxing the code segment to accurately calculate function sizes and emitting these SEH records later in the assembly process via a new `md_finish` hook.
