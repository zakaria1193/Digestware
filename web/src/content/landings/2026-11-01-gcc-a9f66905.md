The configuration option `HAVE_SWAP_IN_UTILITY` has been removed from GCC's build system. This option was related to the availability of `std::swap`, which was moved to the `<utility>` header in C++11. Since GCC now requires C++14, this option is obsolete and has been cleaned up.
