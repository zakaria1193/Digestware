This commit modifies GCC's reorg pass to ignore debug instructions when checking for BARRIERs that immediately precede jump targets. Previously, debug instructions could interfere with these checks, leading to incorrect analysis of code flow, especially after the `pass_cleanup_barriers` pass. The change introduces `prev_nonnote_nondebug_insn` for these checks and adds SPARC tests to cover the corrected logic.
