This commit fixes an issue in x86 load combining peepholes that could lead to incorrect instruction scheduling. When combining two adjacent stack loads into a wider V2DFmode load using `adjust_address`, the `MEM_EXPR` and `MEM_ALIAS_SET` were not properly updated. This allowed later scheduling passes to move the widened load before a preceding store, causing incorrect program behavior. The fix replaces `adjust_address` with `widen_memory_access`, which correctly updates `MEM_EXPR` and resets `MEM_ALIAS_SET`, while also adjusting operand checking to avoid merging loads from different parameters.
