The testsuite's ``options.exp`` test was failing when GCC was configured with an assembler whose name didn't end in ``as`` (e.g. ``gas-2.46``). The testsuite now uses newline-sensitive matching and checks for the actual configured assembler name, avoiding false negatives. This ensures that assembler-related tests pass even when a non-default assembler is configured.
