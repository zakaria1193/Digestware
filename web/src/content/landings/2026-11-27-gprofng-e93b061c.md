Gprofng has been updated to properly handle DWARF 5 range lists that employ an offsets table, a format used by Clang for non-contiguous code sections. Previously, gprofng misinterpreted these tables, leading to incorrect range information and failures in source location display. This change ensures accurate parsing of these new DWARF 5 constructs.
