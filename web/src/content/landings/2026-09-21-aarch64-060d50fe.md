The AArch64 assembler instructions `umov` and `smov`, used for extending 16-bit values, were previously guarded by the `fp` (floating-point) architecture attribute. This commit corrects this by guarding them with the `base_simd` attribute instead. This ensures that code compiled without SIMD support (e.g., with `-march=armv8-a+nosimd`) will correctly fall back to memory-based extension, preventing assembler errors.
