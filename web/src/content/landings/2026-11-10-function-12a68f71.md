This change corrects how __builtin_dwarf_cfa determines the Call Frame Address (CFA) in function frames that are realigned using a Dynamic Realign Argument Pointer (DRAP). Previously, on x86, this could lead to an incorrect CFA address because the argument pointer was not accounted for correctly in a realigned frame. The fix ensures that __builtin_dwarf_cfa uses the DRAP pseudo with the correct offset, resolving a crash in test cases involving frame realignment.
