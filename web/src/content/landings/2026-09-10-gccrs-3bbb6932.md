Philip Herron refactored the `query_type` function in `gccrs` to only fully resolve `const` functions when operating within a constant evaluation context.
Previously, the system could inadvertently query and resolve non-const functions during method resolution, leading to unnecessary work.
This change optimizes the handling of constant expressions by preventing the full evaluation of unrelated non-constant code paths.
