  section (`.rsrc`), a tree-structured table of icons, manifests, and other embedded

  even GDB reading debug symbols…
primer_glossary:
- term: BFD
  definition: Binary File Descriptor library—the shared object-format abstraction
    inside binutils and GDB. BFD provides a uniform API to read, write, and manipulate
    ELF, PE/COFF, Mach-O, and dozens of other formats so higher-level tools need not
    reimplement parsers.
- term: PE/COFF
  definition: Portable Executable / Common Object File Format—the native binary and
    object format for Windows and UEFI. PE wraps COFF with additional headers for
    sections like `.rsrc` (resources), `.reloc` (base relocations), and import/export
    tables.
- term: .rsrc section
  definition: The resource section in a PE binary, holding icons, manifests, version
    strings, and dialogs as a tree of directories and data entries. Each entry may
    be named (Unicode string) or numbered (ID), and the linker must merge and de-duplicate
    `.rsrc` trees from multiple object files.
- term: peXXigen.c
  definition: BFD's PE/COFF generator/parser, using XX as a stand-in for 32 or 64.
    It implements section-specific logic—`.rsrc` merging, import-table fixups, base
    relocations—that generic BFD cannot handle. Lives in `bfd/` and is compiled twice
    (pe-i386.c / pei-x86-64.c) with different pointer widths.
- term: rsrc_string
  definition: A BFD-internal structure pairing a pointer to a byte array with a length
    field. Used to represent resource names parsed from the `.rsrc` directory; the
    string may be UTF-16LE and is not guaranteed null-terminated, so all accesses
    must respect the length.
- term: CVE-2026-19582
  definition: The assigned CVE identifier for this buffer-overflow vulnerability in
    `rsrc_print_name`. An attacker embedding a crafted resource name in a PE file
    could trigger out-of-bounds writes when BFD formats diagnostic output, leading
    to denial-of-service or potential code execution in toolchain processes.

The patch replaces unbounded `sprintf` calls in `rsrc_print_name` and related helpers with length-checked `snprintf`, preventing an attacker-controlled PE resource name from overwriting stack or heap buffers during `objdump` or linker invocations. The 116-line expansion adds two new helper functions, `rsrc_string_print_str` and `rsrc_string_print_int`, that track remaining buffer capacity and bail early if truncation would occur. Because malformed PE/COFF resource sections are common in the wild—both from fuzzing and legitimate but exotic toolchains—this fix defends a critical parsing path that every BFD consumer inherits.
