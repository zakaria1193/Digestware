This commit refactors the naming of Scalable Vector Extension (SVE) Floating-point Matrix Multiply Accumulate (FMMLA) patterns in the AArch64 GCC backend. It unifies existing non-widening FMMLA patterns by giving them both result and input modes, and renames widening patterns from `aarch64_sve2*` to `aarch64_sve*`. This change simplifies the `svmmla_impl::expand` function, allowing it to select all relevant floating-point FMMLA patterns through a single interface and prepares for the addition of new non-widening forms.
