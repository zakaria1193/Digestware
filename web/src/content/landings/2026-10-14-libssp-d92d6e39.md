The libssp library has removed redundant checks for C89 functions like memmove, strncat, and strncpy, which were found to be unnecessary. The configure script will now unconditionally search for the non-C89 function mempcpy. This cleanup aims to streamline the build process and resolve issues reported in bootstrap PRs.
