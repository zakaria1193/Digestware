This commit optimizes certain forms of the OR and XOR instructions on x86 with the APX extension when small immediate values are used. Specifically, it allows the assembler to use shorter byte or word forms of these instructions when the non-EVEX.ND byte/word operations leave upper bits unaltered. This optimization is restricted to size improvement, acknowledging potential performance implications like length-changing prefixes or partial register stalls.
