This commit refactors runtime aliasing checks for loop versioning, simplifying certain AND/OR conditions into unsigned maximum (umax) or minimum (umin) comparisons. This optimization significantly reduces instruction count, providing a performance boost particularly on RISC-V architectures by enabling more efficient selection between scalar and vector loops.
