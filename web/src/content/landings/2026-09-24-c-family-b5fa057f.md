GCC now rejects functions that do not have prototypes when they are used with the `callback_only` attribute. This change addresses a potential issue where unprototyped functions could lead to undefined behavior or compilation errors in certain contexts.

This update enhances type safety and clarifies attribute usage, preventing misuse of `callback_only` with incomplete function declarations. Documentation and a new test case have been added to reflect this change.
