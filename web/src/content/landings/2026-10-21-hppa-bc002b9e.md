This commit partially reverts a previous optimization on the HPPA target concerning the loading of symbolic operands. The original change, intended to improve code generation for `ldil`/`addil` sequences, caused failures with GNU ld when resolving unresolved weak symbols. The linker could not correctly fix up the sequence, leading to incorrect code. This reverts the problematic alternative, requiring a linker fix for full resolution.
