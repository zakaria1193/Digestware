This commit corrects how the D language front-end (CFE) interprets the `-fcf-protection=check` compiler flag regarding Control-flow Enforcement Technology (CET). Previously, this flag, which is ignored at compile time but sets internal flags, caused the D front-end to incorrectly report CET as enabled. The fix ensures that CET-related version identifiers and features (`GNU_CET` and `__traits(getTargetInfo, "CET")`) are only defined and reported when actual CET protection mechanisms like IBT or SHSTK are enabled, aligning D's behavior with C family front-ends.
