The build process for AVR's libgcc has been simplified by removing a hack that copied multilib variants when the target code didn't depend on specific floating-point settings. This change restores the standard multilib build procedure, eliminating manual copying of multilibs even when their target code is identical. The affected files `t-copy-libgcc` and parts of `t-avrlibc` have been removed or modified.
