Gfortran will now issue a compile-time warning when a real number output format string has a field width too small to accommodate the number's digits. This warning is enabled by default via `-Wall` and is triggered by the new `-Wformat-width` option. The check is performed in two passes to handle labeled FORMAT statements correctly.
