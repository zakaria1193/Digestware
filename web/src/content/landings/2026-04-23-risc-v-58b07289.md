The expansion for signed and unsigned min/max operations on `si3` (32-bit integers) in RISC-V was missing the `SUBREG_PROMOTED` annotation.  This caused GCC to emit a redundant `sext.w` (sign-extend word) instruction because the result was always sign-extended.  Adding the annotation prevents this redundant instruction, improving code efficiency.
