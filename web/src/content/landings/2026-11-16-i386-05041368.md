This commit corrects how array elements are classified for the x86-64 calling convention. Previously, GCC only classified the first element of an array and replicated its classification, which could lead to incorrect register allocation or data transfer when element sizes were not multiples of word sizes or when elements straddled eight-byte boundaries. The fix now classifies each array element at its actual offset and merges classifications for elements within the same eight-byte word, improving accuracy for complex array types.
