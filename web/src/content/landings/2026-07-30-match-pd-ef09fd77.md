A new simplification rule in `match.pd` allows the compiler to drop operands from bitwise XOR or OR operations when all their set bits are below the shift count. This optimization, inspired by real-world code where flag bits are packed into a word, improves generated code by eliminating unnecessary operations. The rule applies to both GENERIC and GIMPLE expressions and has been verified on aarch64.
