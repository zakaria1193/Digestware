The C++ compiler (`cc1plus`) could encounter an internal compiler error (ICE) on systems lacking `mmap` support. This occurred when module output processing was attempted after earlier errors prevented the `elf_out::begin` function from running. The fix ensures that `elf_out::end` does not attempt to finalize output that never properly began, preventing the ICE.
