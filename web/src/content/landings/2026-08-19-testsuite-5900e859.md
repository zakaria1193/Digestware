This commit improves the AArch64 SVE2 hardware probe by explicitly selecting SVE2. Previously, the probe program was compiled without architecture options, causing the assembler to reject SVE2 instructions. This resulted in the probe incorrectly reporting that SVE2 was not available, skipping relevant tests. By adding a target pragma, the probe now correctly identifies SVE2 hardware, allowing SVE2-specific tests to pass.
