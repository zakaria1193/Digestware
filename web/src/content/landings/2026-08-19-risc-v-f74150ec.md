RISC-V CRC optimization logic has been updated to prevent the use of a large, 256-entry lookup table when optimizing for code size (-Os, -Oz). This table-based fallback significantly increases code size, especially when CLMUL expansion is unavailable. The compiler now checks `TARGET_OPTAB_SUPPORTED_P` for `crc_rev_optab`, allowing the table fallback only for speed optimizations, and for size optimizations only when hardware CLMUL extensions (Zbc, Zbkc, Zvbc) are available and the result mode is small.
