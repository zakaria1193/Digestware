This commit refactors the GCC i386 backend by moving shared byte and word intrinsics for AVX10.2 and VNNI instructions into a new header file, avx10v1auxintrin.h. This consolidation simplifies the codebase and aligns the intrinsic definitions with the AVX10V1AUX feature, updating relevant machine description files and compiler logic to use the new consolidated header.
