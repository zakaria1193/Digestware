This commit addresses a crash in the Ada compiler's code generation phase, specifically within the `can_equal_min_or_max_val_p` function. The function previously attempted to compare minimum or maximum values for pointer types, for which such concepts are undefined. The fix adds a guard to ensure this check is only performed when dealing with known integral types, thus preventing the crash.
