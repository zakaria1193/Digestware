This commit introduces several new test cases to the libgomp test suite to specifically target the behavior of OpenMP's 'requires self_maps' clause when used in conjunction with global static variables. One of these tests (`usm_env_handling-1-self.c`) is marked as xfailed due to a segfault observed during compilation with NVPTX offloading and optimization level -O1, with the issue tracked in a separate bug report (PR target/127273).
