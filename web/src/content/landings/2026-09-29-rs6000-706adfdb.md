The rs6000 backend incorrectly used DImode for an operand in __builtin_set_fpscr_drn, while the builtin argument was SImode. This mismatch caused an Internal Compiler Error (ICE) when the function was called with an integer variable. The fix changes the operand mode to SImode and converts it to DImode as needed, resolving the ICE and adding a new test case.
