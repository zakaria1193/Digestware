- term: vwsub.wv

- term: vs1
  definition: The first source vector register in a RISC-V vector instruction. It

- term: vs2

This commit introduces a suite of new test cases for the RISC-V vector extension, specifically targeting the `vwsub.wv` instruction. The tests focus on ensuring that the `vs1` register does not overlap with the `vs2` register group, which is a critical aspect of correct vector register allocation and instruction execution. These tests aim to prevent miscompiles related to register constraints in vector operations.
