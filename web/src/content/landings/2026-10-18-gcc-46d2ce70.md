GCC's experimental code for 'any-or-plus' (AOP) operations, intended for investigating code generation possibilities in RTL optimizers and backends, has been removed. The AOP code was a placeholder without functional impact, but it caused issues when interacting with `REQ_EQUAL` notes in RTL expansion, leading to unexpected behavior in later optimization passes. This cleanup removes the experimental code and changes the associated optab from `OPTAB_DC` to `OPTAB_C`.
