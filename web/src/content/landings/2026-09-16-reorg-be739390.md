primer_expert: This patch modifies the `redundant_insn` pass in `reorg.cc` to exclude
  `DEBUG_INSN`s from consuming the search budget. Previously, these debug instructions
  could decrement the budget, potentially causing the pass to miss actual redundancies
  in the code. The change ensures that only executable instructions affect the budget,
  improving the effectiveness of redundancy elimination.

    within the code to improve performance and reduce code size.

This change prevents debug instructions from consuming the search budget when looking for redundant instructions. By skipping `DEBUG_INSN`s, the compiler ensures that these non-executing instructions do not mask actual redundancies, leading to more accurate optimization. A new test case for SPARC is included.
