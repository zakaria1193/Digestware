The RISC-V linker has been updated to parse and process the `--relax-tbljal` and `--no-relax-tbljal` options. These options control the enablement of table-jump relaxation (Zcmt extension) and are registered within the RISC-V emulation parameters. The feature is disabled by default, and unsupported schemes are rejected. Documentation has been updated to describe the new options, supported link modes, and requirements for jump table base initialization.
