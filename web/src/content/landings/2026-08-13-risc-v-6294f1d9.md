GCC will no longer create a separate multilib directory for RISC-V configurations that exactly match the default march and mabi, unless other distinguishing options like `mcmodel` are present. This change addresses an issue where a redundant multilib caused incorrect path configurations, such as breaking Ada builds by causing `lp64d` to be incorrectly appended to the library path. The optimization streamlines multilib generation by only creating distinct multilibs when necessary.
