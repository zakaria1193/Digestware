This commit updates gccrs to recognize the `#[cfi_encoding]` attribute. While the attribute is now parsed and acknowledged, the compiler issues a warning indicating that it does not currently perform any action. This is because the functionality relies on an upstream patchset that is still under review. The change includes adding the attribute to the feature gate definitions and test cases.
