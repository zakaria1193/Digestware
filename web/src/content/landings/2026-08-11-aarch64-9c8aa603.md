On AArch64, conditional floating-point comparisons can mask exceptions, such as those raised by quiet NaNs. This commit modifies the code generation to prevent such trapping comparisons from becoming conditional, preserving the expected exception behavior. It ensures that operations like `(a < b) & (c < d)` correctly raise exceptions if `c` or `d` is a quiet NaN when `a < b` is false. New tests are added to verify this behavior.
