primer_glossary:
- term: LRA
  definition: Local Register Allocator. A compiler pass responsible for assigning
    hard registers to virtual registers within a local code region. It runs after
    global register allocation and performs final register assignments.
- term: Invariant
  definition: A value or expression whose result does not change during a particular
    loop or code section. Optimizations often try to compute invariants once and reuse
    the result.
- term: Pseudos
  definition: Pseudoregisters. Virtual registers used by the compiler during intermediate
    representations. They are later mapped to physical hardware registers.
- term: Inheritance Pseudos
  definition: Pseudoregisters created when an invariant value is used in a context
    that requires a register, and this invariant value is 'inherited' by the pseudoregister.
- term: Spilling
  definition: The process of storing the value of a pseudoregister into a memory location
    (on the stack) because there are not enough available hardware registers to hold
    all the live values.
- term: Immediate Range
  definition: The range of values that can be directly encoded into an instruction
    as an immediate operand. If a calculated offset exceeds this range, it must be
    loaded into a register first.

The Local Register Allocation (LRA) pass has been enhanced to propagate invariant information for inherited pseudos. Previously, the elimination of invariants led to offsets falling out of immediate range, causing instructions to be reloaded. This reloaded state could trigger further invariant inheritance, creating a slow feedback loop. The fix records equivalence for inheritance pseudos, avoiding unnecessary spilling and the associated frame size changes that invalidated subsequent optimizations. This significantly speeds up compilation for code with many invariant occurrences.
