GCC's Interprocedural Analysis (IPA) pass now uses a new `callback_info` summary struct for callback edges, replacing the previous `callback_id`. This change aggregates necessary information directly into the summary, eliminating the need to recalculate it each time and reducing per-edge storage. This optimizes the analysis by providing faster access to edge attributes.
