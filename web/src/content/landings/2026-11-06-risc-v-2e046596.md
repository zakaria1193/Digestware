This commit fixes a register overlap issue in the RISC-V `vwadd[u].wv` vector instruction. The problem occurred when the `vs1` operand's effective element width (EEW) was twice that of the `vs2` operand's EEW, violating vector spec constraints. The fix applies a `Wn4` constraint to the `vs2` operand, preventing `vs1` from falling within the `vs2` register group, similar to the handling in `vfwadd.wv`.
