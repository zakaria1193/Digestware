This commit adds a check to ensure that an operand is a `CONST_INT` before attempting to extract its `INTVAL` in the `simplify-rtx` optimization. This prevents potential RTL checking failures and correctness bugs that could occur when treating non-constant values as integers, especially in compiler versions with RTL checking disabled. The fix ensures that the optimization correctly handles constant values for creating adjusted masks.
