A new script, `contrib/vendor-libs.sh`, has been added to the gccrs project to automate the generation of `rustc-lib`. This utility is intended to make the process of upgrading bundled Rust libraries, particularly those related to `stdarch`, more straightforward when bumping the target Rust compiler version.
