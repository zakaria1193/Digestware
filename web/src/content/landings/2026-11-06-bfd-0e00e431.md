This change corrects two issues in addr2line's DWARF parsing. First, it ensures that compilation units referenced via `DW_FORM_ref_addr` are properly queued and processed, preventing them from being skipped when generated by clang. Second, it adjusts the DWARF5 line table parsing to correctly handle cases where the first file entry is missing, preventing errors with single-file line tables.
