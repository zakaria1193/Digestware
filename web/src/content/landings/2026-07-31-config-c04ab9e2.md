Autoconf macros used to detect GCC and Clang plugin options have been updated. The change replaces `AC_TRY_COMPILE` with `AC_COMPILE_IFELSE`, a more modern and robust macro for conditional compilation checks. This update improves the build system's reliability without altering any generated files.
