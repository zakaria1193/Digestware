This change modifies the LTO streamer to preserve the order of predecessor edges, which in turn preserves the order of PHI operands. This is necessary because the previous implementation did not guarantee operand order, causing issues with IPA Inter-Chaining Function (ICF) reference comparisons. A new test case is included to verify the fix.
