This change modifies GCC's built-in function expansion to pass the frame count to the `FRAME_ADDR_RTX` macro. This allows target architectures to distinguish between requests for the current frame (depth 0) and deeper frames, enabling them to provide more accurate behavior or diagnostics when stack frame access is not supported.
