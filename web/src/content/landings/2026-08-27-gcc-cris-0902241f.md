This commit adds new patterns to the CRIS backend for handling bit-field tests that feed conditional store instructions. Spotted during work on another bug fix (PR126276), these patterns improve the compiler's ability to generate efficient code for specific bit manipulation scenarios on the CRIS architecture. The single-bit case is noted as being left for later.
