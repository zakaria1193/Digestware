This commit resolves several issues related to parameterized strings in the Fortran compiler, specifically addressing PR127146. It modifies `gfc_match_rvalue` to prioritize the entry's name from the parameter list over the component name when available. A new test case, `pdt_96.f03`, has been added to verify these fixes.
