This commit rectifies misclassifications of Fortran pointer arrays and derived types within OpenMP's `defaultmap` clause. Pointer arrays were incorrectly treated as aggregates, and derived types passed by pointer were mishandled. The fix implements these checks as language hooks, aligning behavior with allocatables and scalars. Additionally, it introduces a missing diagnostic for `defaultmap` and adds parser support for the `optional` modifier from OpenMP 6.1.
