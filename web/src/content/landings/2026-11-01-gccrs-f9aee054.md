This commit enhances gccrs by implementing intrinsic code generation for slice indexing. It modifies the type checking and expression compilation for `HIR::ArrayIndexExpr` to correctly handle slice types. This ensures that operations like indexing into a slice, which were previously problematic, are now efficiently translated into machine code.
