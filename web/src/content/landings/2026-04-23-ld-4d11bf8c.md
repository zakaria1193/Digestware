A linker test (PR ld/34088) requires ``libm.a``, which contains the ``feclearexcept`` function. Since ``feclearexcept`` is only implemented for Linux/x86-64 and Linux/AArch64, this commit restricts the test to run only on those platforms. This ensures that the test will pass on supported platforms and be skipped on others, avoiding unnecessary failures.
