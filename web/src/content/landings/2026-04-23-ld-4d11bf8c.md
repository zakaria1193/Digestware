The test case for PR ld/34088 in the binutils ld testsuite requires `libm.a` which includes `feclearexcept`. Because `libm.a` with `feclearexcept` is only implemented for Linux/x86-64 and Linux/aarch64, this commit limits the test to run only on those platforms.
