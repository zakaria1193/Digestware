The test case for PR ld/34088 relies on `libm.a` and its `feclearexcept` function, which are provided by the OS.  Since `libm.a` is not universally available, this commit restricts the test to Linux on x86-64 and AArch64, where the necessary library is present. This avoids test failures on platforms lacking the dependency.
