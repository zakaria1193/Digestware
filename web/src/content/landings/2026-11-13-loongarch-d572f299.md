This commit optimizes LoongArch's vector pick instructions (`vpickve2gr`) by exploiting the overlap between vector and floating-point registers. It reduces the effective vector width used by these instructions, replacing them with simpler scalar operations when possible. This optimization targets specific variants like `xvpickve2gr.w` and `xvpickve2gr.d` to improve code generation efficiency on LoongArch architectures.
