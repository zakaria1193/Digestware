This commit fixes an issue where temporary guard variables controlling the cleanup of structured binding variables were not surviving across `co_await` expressions. The problem stemmed from using `TARGET_EXPR`, which has a limited lifetime, to hold values that needed to persist as long as the structured binding itself. The solution uses `get_temp_regvar` for these guards and manually `pushdecl`s them to ensure visibility and correct lifetime management, resolving PR124584.
