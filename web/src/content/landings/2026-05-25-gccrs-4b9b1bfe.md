This update introduces two new attributes, `rustc_allocator` and `rustc_allocator_nounwind`, to the GCC Rust compiler. These attributes guide the backend to treat functions as `malloc` equivalents and to apply `nothrow` semantics, respectively. This change allows for better optimization and interoperability with system allocators, particularly when dealing with memory allocation and error handling in Rust code compiled by GCC.
