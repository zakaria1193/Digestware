The GCC Algol 68 frontend eliminated redundant `HAS_ROWS` checks from callers of `a68_low_dup`. Previously, `a68_low_dup` always performed a deep copy, requiring callers to check for rows to avoid unnecessary operations. Now, `a68_low_dup` handles this check internally and returns the original expression if a deep copy is not needed. This change simplifies the calling code in `a68_lower_collateral_clause` and `collect_call_arguments`.
