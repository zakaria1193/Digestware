This commit introduces basic support for the Spacemit-x100 RISC-V processor core. It adds the 'spacemit-x100' to the compiler's database of known RISC-V cores and tuning profiles. The scheduling information for this new core is mapped to the existing generic out-of-order (ooo) scheduler. This enables developers to use options like -mcpu=spacemit-x100 or -mtune=spacemit-x100 when compiling for this specific hardware.
