Previously, the linker ignored errors that occurred when closing and writing the PDB file. This meant that if the PDB file write failed (e.g., due to disk full or permissions), the linker would still report success, leaving a potentially truncated or empty PDB file. This change modifies `create_pdb_file` to check the return value of `bfd_close` and report any write failures.
