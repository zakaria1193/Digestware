This commit introduces new simplification patterns to the GCC MATCH (Machine Description) system. It allows the compiler to replace expressions like `min(clz(x), clz(y))` with `clz(x | y)` and `min(ctz(x), ctz(y))` with `ctz(x | y)`. This optimization can lead to more efficient code by reducing the number of operations required.
