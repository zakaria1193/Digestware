This commit addresses a buffer overflow vulnerability in the `xtensa_insnbuf_from_chars` function used by binutils and GDB. The overflow occurs when processing zero-sized relocations (R_XTENSA_ASM_SIMPLIFY), which can be triggered by fuzzers. The fix modifies the function to return buffer size information, passes actual buffer lengths where it's used, and checks return statuses to prevent overflows.
