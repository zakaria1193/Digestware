This patch revises the iterative DFS regex executor to avoid pushing and popping stack frames when a match is expected to continue. For repeated subexpressions, the executor now attempts to consume the state immediately, keeping values in registers to minimize memory accesses and function call overhead. This significantly improves performance for patterns involving repetitions, while maintaining the memory usage improvements of the original iterative approach.
