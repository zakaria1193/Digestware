This commit enhances the `cond_move_process_if_block` function in the GCC ifcvt pass by utilizing `auto_vec` for register lists. Previously, these lists were raw `vec<rtx>` requiring explicit cleanup via a goto label upon failure. By switching to `auto_vec`, the cleanup label, flag, and associated gotos are eliminated, resulting in cleaner code and reduced complexity without altering the pass's functionality.
