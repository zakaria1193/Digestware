The emulation code for the `vcvtneps2bf16` instruction, used in `truncsfbf-5.c` and `truncsfbf-6.c`, has been updated to flush denormal floating-point inputs to zero. This change ensures consistent behavior by treating small, subnormal numbers as zero before conversion, and includes new test cases to verify this behavior.
