This commit canonicalizes extending byte loads on RISC-V to improve common subexpression elimination (CSE). By extending the value to word mode in a temporary register and then using a lowpart extraction, the code exposes more opportunities for CSE. This change enables RTL simplification and addresses issues related to different-sized destinations for sign-extended QI loads.
