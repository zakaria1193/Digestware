GCC has added an optimization for PowerPC (specifically VSX instructions) that improves the 'splat' operation when applied to an extracted element from a V2DI (two double-precision integers) or V2DF (two double-precision floats) vector. Previously, similar optimizations existed for other vector types but were missing for these double-word vector types. The new combiner instruction significantly reduces the generated code for such operations, as demonstrated by a comparison on Power9.
