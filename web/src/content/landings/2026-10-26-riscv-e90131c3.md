This commit addresses several inaccuracies in instruction length calculations within the RISC-V port of GCC. LLM reviews identified discrepancies in patterns related to the Zba extension, internal CFI calls, and stack protection sequences. The incorrect length computations, though not causing functional issues, have been fixed to accurately reflect the generated machine code size.
