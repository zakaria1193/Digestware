This change addresses destruction ordering issues within GCC's statistics gathering infrastructure. File-local static variables responsible for tracking data structure allocations could be destroyed before the structures they were monitoring, leading to internal compiler errors (ICEs). The fix ensures these statistics objects are never destroyed, as they are intended to persist for the entire process duration.
