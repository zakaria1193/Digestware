Several commits address issues with Fortran's parameterized derived types (PDTs). Changes in `match.cc` and `decl.cc` improve the compiler's ability to detect deferrable components and handle NULL rvalues in pointer assignments. New test cases verify these fixes, ensuring more robust handling of PDTs.
