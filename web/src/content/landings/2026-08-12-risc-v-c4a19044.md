GCC has added support for macro-fusion of ADD/ADDI-type instructions followed by an ANDI instruction on RISC-V architectures. This optimization applies when the result of the ADD/ADDI instruction is a required dependency for the ANDI instruction. The implementation reuses RTL parsing logic for ANDI, allowing for shared code with existing B_ALUI fusion rules. This new fusion is disabled by default and is verified by new test cases.
