This commit adds support for the RISC-V XAndesVPackFPH extension, enabling packed FP16 fused multiply-add instructions. Updates were made to BFD for ELF handling, GAS for assembler directives and tests, and the opcode library for instruction recognition. This allows for more efficient floating-point operations on compatible Andes architectures.
