Recent changes to the RISC-V threader caused it to miss fewer loops, leading to unexpected rounding mode changes. To maintain test stability, this commit disables jump threading for specific floating-point dynamic rounding mode tests. This ensures the tests continue to verify basic rounding mode tracking behavior without being affected by the threader's new activity.
