GCC reverts changes allowing register overlap for the RISC-V vector widening signed-unsigned multiply-add instruction (vwmaccsu.vx), which uses a scalar register. This ensures compliance with the vector specification's prohibition on a single register serving operands with disparate Effective Element Widths. Test cases and instruction definitions are updated accordingly.
