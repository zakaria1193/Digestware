This commit synchronizes the zstd compression library detection logic in binutils' configure scripts with that of GCC. It ensures consistent support for compiler-based zstd detection and configurable search paths. Additionally, it adds ZSTD_LIBS to binutils link commands for tools using zstd via BFD and bases gold's zstd test on the final detection result.
