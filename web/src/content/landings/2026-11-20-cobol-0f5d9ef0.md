This commit addresses multiple bugs in GCC's COBOL compiler front-end. Fixes include correctly setting subscripted level-88 named-conditionals, rectifying linear search logic, properly handling fractional index parts during operations, resolving an ICE with ADD CORRESPONDING, and optimizing subscript calculations for corresponding operations. Exception processing has also been refined to prioritize exact matches.
