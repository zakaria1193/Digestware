This commit updates the Ada compiler's aggregate expansion logic to consistently use `Is_Inherently_Limited_Type` instead of `Is_Limited_Type`. This change aligns the checks for whether a type is limited with the expander's existing mechanism for deciding when to use the build-in-place optimization for aggregates.
