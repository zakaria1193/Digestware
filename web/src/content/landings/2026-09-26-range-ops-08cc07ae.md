The range-ops optimization pass in GCC has been enhanced to derive information from comparisons even when they don't involve singletons at the edges. Previously, it was limited to scenarios like `a == CST` on the true edge. This update allows GCC to infer range information from more complex comparisons, such as recognizing `a != 0` from `a = b - c` where `b != c`, thus improving constant propagation and dead code elimination.
