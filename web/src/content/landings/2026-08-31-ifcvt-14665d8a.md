The `ifcvt` (if-conversion) pass has been improved to handle conditional arithmetic operations that are wrapped in sign or zero extensions. The compiler now correctly identifies when the unchanged value of such an operation already has the necessary extension. This is achieved by directly querying the promoted lowpart, rather than searching for its definition, leading to more robust code generation for conditional arithmetic, particularly on architectures like RISC-V.
