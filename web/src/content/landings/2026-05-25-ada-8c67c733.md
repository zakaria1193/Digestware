Previously, the compiler failed to issue an error for nonaliased formal parameters that had access discriminants within a function's return type, a violation of Ada's static accessibility rules. This change introduces the necessary check by modifying `Check_Return_Construct_Accessibility` to properly handle formal parameters and the 6.8(5) rule for expression functions. It also removes an incorrect implementation of this check from `Apply_Accessibility_Check_For_Anonymous_Return`, which was intended for dynamic checks.
