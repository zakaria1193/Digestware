The STATIC_LIBCXXFLAGS, which previously helped the testsuite find uninstalled static libraries, has been removed from the libstdc++ testsuite. This flag is no longer needed as the C++ compiler now provides the necessary -B option. Its removal prevents duplicate -B and -L linker flags, which could cause warnings or errors with some linkers.
