The compiler now eliminates branch mispredictions in specific bitwise operations. When checking if a single bit is not set and then setting it, the compiler always sets the bit. Similarly, when checking if a bitmask is set and then clearing it, the compiler always clears the bitmask. This removes conditional branches that lead to mispredictions, improving performance.
