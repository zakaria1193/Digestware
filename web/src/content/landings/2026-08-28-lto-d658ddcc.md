This commit modifies the linker's Language Support module to skip format checks for IR dummy files. Previously, the linker attempted to check the format of these files, which could lead to errors or unexpected behavior, as documented in PR ld/34572. The changes also allow empty DESTLIST in `lang_list_remove_tail` and introduce new test cases to ensure correct handling of IR dummy files.
