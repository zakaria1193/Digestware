The COBOL compiler used a stash to temporarily store original values during assignments with ON SIZE ERROR clauses. An issue where the stash pointer was declared as an automatic variable but assigned to a static tree led to an Internal Compiler Error (ICE) due to incorrect context handling. This change resolves the ICE by giving the stash pointer file-static scope.
