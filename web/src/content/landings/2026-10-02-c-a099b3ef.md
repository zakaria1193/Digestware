This commit resolves an Internal Compiler Error (ICE) occurring in `std::meta::reflect_constant` when used with memory allocated by `std::allocator`. The issue stemmed from `reflect_constant`'s requirement that its argument must be a constexpr-representable object, which dynamically allocated memory from `std::allocator` is not. The fix involves refining checks in `invalid_tparm_referent_p` and related functions to correctly identify heap-allocated variables, ensuring `reflect_constant` throws an appropriate meta::exception rather than causing an ICE.
