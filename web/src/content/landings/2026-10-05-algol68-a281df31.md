The Algol68 compiler now supports nested pragmas, a new language extension identified as GNU68-2026-002. This change introduces syntax modifications for nested pragmas, updates the documentation to clarify dialect options like -fbrackets, and includes new test cases to verify the functionality. The compiler also restricts the use of -fbrackets to upper stropping, preventing conflicts with supper stropping.
