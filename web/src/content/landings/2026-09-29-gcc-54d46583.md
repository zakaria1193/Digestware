GCC's internal zstd detection mechanisms have been replaced with the shared AC_ZSTD macro. This change ensures that GCC consistently uses the same zstd detection logic as other components, such as libbacktrace, simplifying build configurations and defining HAVE_ZSTD_H when support is enabled.
