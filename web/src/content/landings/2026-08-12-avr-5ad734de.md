This patch introduces support for saturating shift left operations on fixed-point types for the AVR microcontroller architecture. It adds new instruction patterns to the AVR backend and includes corresponding support in `libgcc` and new test cases. This enables efficient implementation of saturation arithmetic, which is crucial for DSP and signal processing applications.
