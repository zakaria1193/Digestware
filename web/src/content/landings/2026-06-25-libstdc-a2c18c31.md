Libstdc++ has updated its `acinclude.m4` file to replace occurrences of the deprecated `AC_HELP_STRING` macro with `AS_HELP_STRING`. This change modernizes the way `libstdc++` defines help messages for its configure script options, adhering to current Autoconf best practices. The update affects several `GLIBCXX_EXPORT_INSTALL_INFO`, `GLIBCXX_ENABLE`, and `GLIBCXX_ZONEINFO_DIR` macros, improving the consistency of the build system's user-facing documentation.
