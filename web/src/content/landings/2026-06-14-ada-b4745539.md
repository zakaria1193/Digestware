This commit addresses an issue on Android where non-tasking Ada programs failed to correctly account for `pragma Interrupt_State` when handling signals. The changes add necessary guards to the `__gnat_install_handler` function, specifically checking for a possible 'S' (System) interrupt state before calling `sigaction`. This ensures that signal handling behaves as expected on Android, respecting Ada's concurrency and interrupt management features.
