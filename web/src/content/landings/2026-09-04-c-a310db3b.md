A bug in C++ lambda capture has been fixed, resolving an ICE that occurred when generic lambdas interacted with typeid expressions. Previously, the compiler could incorrectly skip capturing local entities required by the C++ standard when evaluating typeid. This change modifies how the compiler determines if a typeid expression necessitates a capture, ensuring correct behavior even within template contexts and for complex nested typeid expressions. A new mechanism, cp_unevaluated_typeid_cutoff, is introduced to manage this evaluation process.
