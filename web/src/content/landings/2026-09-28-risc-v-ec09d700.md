A new expansion, neg<mode>cc, has been added for integral comparisons on RISC-V architectures. This expansion implements the pattern 'X ? -X : X' using a sequence of compare, mask, XOR, and add operations. The new pseudo instruction helps existing if-conversion paths by providing a distinct output pseudo for the XOR result, ensuring it's assigned only once. This change enables more efficient conditional negation for integral types on RISC-V.
