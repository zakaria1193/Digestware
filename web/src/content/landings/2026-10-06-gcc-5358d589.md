This commit performs a small cleanup in the `update_addresses_taken` pass by moving, privatizing, and renaming helper functions from `gimple.cc` to `tree-ssa.cc`. This refactoring allows the `set_addresses_taken_1` function to be called directly for processing PHI nodes, eliminating duplicated logic. The changes improve code organization and maintainability within the SSA optimization pipeline.
