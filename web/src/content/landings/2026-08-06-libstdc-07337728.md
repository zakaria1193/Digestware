The C++ standard library's `vector<bool>::reference` type now supports `constexpr` formatting. This change, part of the P3391R2 "constexpr format" proposal, ensures that formatting operations on specialized boolean vectors can be performed at compile time, improving performance and enabling new compile-time checks.
