This change modifies the AMDGPU backend to spill scalar values to SGPRs instead of AVGPRs. AVGPRs are a more limited and expensive resource, especially around function calls. Using SGPRs for spills is more efficient and also ensures compatibility with devices lacking AVGPRs. Test cases were updated to reflect this change, with vector spills now tested for AVGPRs and scalar spills tested for SGPRs.
