This change adds a no-operation relax pass at the start of the RISC-V linker relaxation process. This ensures that all output section Virtual Memory Addresses (VMAs) are consistently updated before the shortening pass runs. Previously, increases in `SIZEOF_HEADERS` could cause discrepancies in VMAs between output sections, leading to incorrect PC-relative offset calculations and potential `relocation truncated to fit` errors for `R_RISCV_JAL` relocations.
