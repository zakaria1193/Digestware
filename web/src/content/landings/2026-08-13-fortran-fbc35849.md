This commit fixes an issue in the shared memory implementation of Fortran's collective subroutines where the array descriptor's 'span' field was incorrectly used as the element size. This larger-than-actual size estimate led to memory over-allocation and, crucially, a mismatch in element indexing between the collective subroutine and its packing/unpacking functions, resulting in corrupted data. The fix uses the correct 'element length' field instead.
