A new option has been added to GCC's Dead Code Elimination (DCE) pass, allowing it to replace dead statements with assignments to zero instead of completely removing them. This change provides more control over the optimization process, particularly useful for debugging or specific analysis scenarios where the presence of zero assignments is informative.
