The RISC-V vector code generation, specifically for the -mrvv-max-lmul=conv-dynamic option, now accounts for potential data spills. Previously, this mode solely relied on the size ratio of the largest and smallest types, sometimes leading to unexpected spills in applications like x264. This change integrates spill estimation into the 'conv-dynamic' mode and refactors related logic for clarity.
