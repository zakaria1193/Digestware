This commit corrects an issue where the `fold_binary_op_with_conditional_arg` function would sink scalar-result operations into the arms of a `VEC_COND_EXPR`. This happened even for whole-vector comparisons used in early-exit tests. Folding each arm independently with constant values could lead to incorrect constant results for the comparison. The fix ensures that the function now punts when a vector operand has a scalar result within a `VEC_COND_EXPR`, preventing miscompilation, particularly on RISC-V architectures with vector extensions.
