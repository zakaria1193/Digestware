The `readelf -wL` command in Binutils now correctly validates the bounds of filenames specified in `DW_LNE_define_file` operations within DWARF line number information. This prevents a heap-buffer-overflow vulnerability that occurred when processing malformed DWARF data with no null terminator before the end of the opcode payload.
