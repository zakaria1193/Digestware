This patch introduces support for LUTI2, LUTI4, and LUTI6 instructions on AArch64, enhancing the compiler's ability to perform constant vector permutations. These instructions allow for efficient lookup-based shuffling of elements within vector registers, supporting both Advanced SIMD and SVE. The implementation prioritizes using immediate moves for LUTI2 and LUTI4 when possible, avoiding memory loads for permutation tables and significantly reducing code size and improving performance for operations like `__builtin_shufflevector`.
