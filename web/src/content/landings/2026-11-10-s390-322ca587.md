This change modifies the s390 assembler to treat the R2 operand as optional for the RR instruction format when used with the .insn pseudo-mnemonic. This aligns the assembler's behavior with the actual RR instruction format, which includes an optional R2 field. Documentation and tests are updated accordingly.
