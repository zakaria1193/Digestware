This commit fixes an issue in the microblaze ELF relocator where relocations against symbols in discarded sections were not handled correctly. This led to relocations surviving and resolving against dead symbols, resulting in garbage data in debug sections where zeros were expected. The fix ensures that these relocations are properly neutralized, and new test cases demonstrate the correction.
