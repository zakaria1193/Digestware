The libstdc++ standard library now defines `iterator_type` for the `basic_const_iterator` class. This resolves LWG 4253, which requested that `basic_const_iterator` provide this type alias for consistency with other iterator types.  This allows generic code to access the underlying iterator type of a `basic_const_iterator`.
