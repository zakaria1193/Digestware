GCC now correctly rejects friend declarations that attempt to use explicit object parameters, a feature intended only for member functions. Previously, the compiler allowed such declarations, leading to internal errors and crashes later in the compilation process due to incorrect access checks. This fix ensures that only member functions can employ explicit object parameters, improving the robustness of C++ parsing and access control.
