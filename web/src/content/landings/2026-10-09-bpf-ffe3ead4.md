This commit introduces the `-mcallx` option for the BPF backend, which enables the use of the `callx` instruction for indirect calls. This instruction is part of the BPF CPU v1 ISA and is now enabled by default for v1 and above. The `-mno-callx` option reverts to the previous behavior of diagnosing indirect calls as errors. This change also removes the `TARGET_XBPF` specific handling, as `-mxbpf` is now solely for the assembler.
