This commit prevents the GCC combine pass from generating compares that reorder volatile memory accesses. Previously, volatile loads could be incorrectly reordered by the register allocator when forming compare instructions, potentially altering the intended sequence of read operations. This change ensures that volatile memory accesses maintain their specified order, crucial for code like the Linux kernel that relies on strict read ordering.
