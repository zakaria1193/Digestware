The compiler was crashing (ICE) when encountering pointer arithmetic on incomplete types while processing the `counted_by` attribute. This commit fixes this by avoiding dereferencing `element_size` when it is NULL.  It also corrects the use of `build_one_cst` for void pointers, using `size_one_node` instead.
