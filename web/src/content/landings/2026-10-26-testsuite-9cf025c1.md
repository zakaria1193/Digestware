This commit addresses a testsuite failure on hppa targets for the g++.dg/gomp/deprecate-1.C test. The issue arises because the leading '#' character, which is part of the expected diagnostic output, is stripped on PA-RISC (hppa) architectures, where '#' can be an assembly comment delimiter. The fix employs a wildcard pattern '.*pragma' in the output verification to accommodate both variants of the diagnostic output without altering absolute line indices or duplicating output blocks.
