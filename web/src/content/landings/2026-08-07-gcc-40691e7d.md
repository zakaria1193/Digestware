This change enables the use of PC-relative addressing with the `-mcmodel=large` option for PowerPC processors, including Power10 and Power11. Previously, PC-relative addressing was only supported for the `-mcmodel=medium` option. This update allows for greater flexibility in code generation for large models on these architectures.
