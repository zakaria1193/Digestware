This commit skips the `pr28796-2.c` test case on AVR targets. The AVR architecture's `double` type is not fully compliant with the IEEE 754 standard, causing this specific test, which likely relies on IEEE floating-point behavior, to fail. Skipping the test prevents spurious failures on this platform.
