GCC's i386 backend has corrected inline assembly wrappers for Intel SGX (ENCLS, ENCLU, ENCLV) and PCONFIG intrinsics. These wrappers did not declare "memory" as a clobbered operand, leading the compiler's data-flow analysis (DSE) and constant folding (FRE) passes to incorrectly optimize away stores to input structures or loads from output buffers. By adding the "memory" clobber, these intrinsics now accurately inform the compiler about their memory access side effects, preventing such optimizations and fixing PR128283. Additionally, the `__encls_edbgrd` intrinsic now correctly clobbers the "cc" flags.
