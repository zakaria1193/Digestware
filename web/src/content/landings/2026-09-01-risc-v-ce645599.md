This commit adds support for the RISC-V XAndesBFHCvt extension, enabling scalar conversion instructions between BF16 and FP32 formats. Changes include updates to BFD for ELF handling, GAS for assembler syntax and tests, and the opcode library for instruction definitions. This improves the efficiency of mixed-precision floating-point operations.
