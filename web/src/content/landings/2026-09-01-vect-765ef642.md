The vectorizer's fallback mechanism for average calculations previously only supported unsigned types. This change removes that restriction, allowing signed integer types to be vectorized. The core logic remains the same, as arithmetic right shifts and subsequent adjustments work identically for both signed and unsigned types. The implementation now uses `target_supports_op_p` for better portability in checking operation support.
