Previously, an Ada warning message could incorrectly apply warning-insertion characters, leading to the `-gnatw.j` switch being overridden for warnings related to late primitives after private extensions. This fix ensures that the correct warning character is used, allowing the `-gnatw.j` switch to function as intended. Developers will now see the expected warning behavior when compiling Ada code with this option.
