This commit enhances the RTL verifier to rigorously check shared jump table references after each compiler pass. Previously, broken table references could cause the `tablejump_p` check to be bypassed, leading to undetected issues. The updated verifier now enforces requirements such as live table and label references, adjacency, and sharing flags, and strengthens CFG checks to cover all destination sets. This ensures the integrity of shared jump tables throughout the compilation pipeline, preventing potential crashes like `rtl_split_edge`.
