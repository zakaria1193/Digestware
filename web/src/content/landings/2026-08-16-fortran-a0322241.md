primer_expert: The `generate_component_assignments` function in `resolve.cc` incorrectly
  generated both a whole-derived-type assignment and a separate defined-assignment
  call for components when handling intrinsic assignment to a derived type with component
  assignment. This led to double finalization. For scalar LHS without pointer or allocatable
  components, the assignment now uses a `finalize_only` mechanism, performing a finalization
  of the LHS structure first, followed by individual component assignments. This avoids
  finalizing a stale temporary copy of the LHS.

A regression in Fortran (versions 13-17) caused duplicated finalization during intrinsic derived-type assignments that involved component assignments. This fix ensures that only one finalization occurs for the LHS, and subsequent component assignments correctly operate on the finalized value, preventing issues with temporary copies and stale data.
