The compiler was crashing due to attempting to use the tree code of a null tree when the `counted_by` attribute was applied to a pointer to void. The fix now uses `size_one_node` as the pointee_size in such cases, consistent with the GNU extension for pointer to void arithmetic. Additionally, the patch now handles the case of pointers to incomplete types other than void by punting and diagnosing the error later.
