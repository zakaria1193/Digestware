The x86 test suite was failing because it expected specific rounding instructions like 'roundss' but encountered 'vrndscaless' when AVX512 was enabled by default. This commit updates the test suite to scan for both 'round[sp][ds]' and 'vrndscale[sp][ds]' instructions. This ensures that the tests correctly identify the generated assembly regardless of which specific rounding instruction is used, preventing false positives in the test results.
