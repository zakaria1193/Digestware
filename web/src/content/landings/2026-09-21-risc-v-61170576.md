The compiler previously asserted that destination register counts must exceed source register counts for widening instructions in RISC-V. This commit modifies the `riscv_v_widen_constraint_ok` function to return false instead of asserting when the destination has fewer registers than the source. This resolves an internal compiler error (ICE) that occurred in specific scenarios, such as when widening a vector register group.
