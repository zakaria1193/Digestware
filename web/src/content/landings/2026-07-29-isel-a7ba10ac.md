The instruction selector (isel) pass in GCC could encounter an internal compiler error (ICE) when processing out-of-bounds vector element accesses. This was due to incorrect bounds checking logic that mishandled constant indices, particularly negative ones. The fix ensures correct handling of these cases by punting when indices don't fit expected types and by using a more accurate comparison for bounds checks, preventing ICEs and ensuring correct code generation.
