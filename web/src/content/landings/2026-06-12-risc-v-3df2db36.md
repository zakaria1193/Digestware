The SLP vectorizer in GCC for RISC-V now successfully vectorizes additional test cases involving vector intrinsics. This improvement stems from a recent change allowing the SLP discovery phase to retry operand swapping for commutative parent operations before falling back to scalar execution. Consequently, the assembly checks in several `vx-[5|6]-i[8|16].c` test files have been updated to expect operations like `vadd.vx`, `vmul.vx`, `vsadd.vx`, and `vssub.vx`.
