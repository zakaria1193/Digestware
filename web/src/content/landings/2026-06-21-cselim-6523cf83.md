This commit refactors the statement insertion logic within GCC's Conditional Store Elimination (cselim) pass, specifically in `cond_store_replacement` and `cond_if_else_store_replacement_1`. Historically, this code performed complex checks to insert statements at the beginning of a basic block, dealing with edge cases for inserting at the end. With modern compiler infrastructure that supports `gsi_insert_before` combined with `gsi_after_labels`, the code now directly uses `gsi_insert_before`, yielding a simpler and more readable implementation.
