This commit addresses issues in libstdc++ tests that opened FIFOs with `ios_base::in|ios_base::out` (equivalent to O_RDWR). POSIX explicitly states the result is undefined when O_RDWR is applied to a FIFO. This commit changes the tests to open FIFOs with the necessary access mode only (read-only or write-only), preventing deadlocks and ensuring correct behavior on systems that strictly follow the POSIX standard.
