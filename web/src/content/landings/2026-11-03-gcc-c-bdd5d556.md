This commit fixes a bug in GCC's C front-end where the visible type for an enumerator was incorrectly handled during the redefinition of an enumerated type. Previously, the underlying type was used internally, leading to visibility issues. The fix ensures that the visible type remains the enumerated type itself, aligning with the language standard and resolving PR128335. A new test case is added to verify the correction.
