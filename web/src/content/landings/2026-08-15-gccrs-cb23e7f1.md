This commit addresses two critical issues in gccrs: a missing error diagnostic during the parsing of constant expressions and a crash during type checking when evaluating constants. The fix ensures that the parser correctly handles default expressions by forcing braces, and that the type checker can safely evaluate constants even when type checking fails, preventing crashes caused by invalid error nodes. This resolves Rust-GCC/gccrs#4173.
