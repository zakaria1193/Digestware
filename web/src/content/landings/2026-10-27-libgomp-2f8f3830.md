This change introduces the `omp_get_gprivate_limit` OpenMP runtime API routine. This function returns the maximum possible limit for group-private variables, whether specified via directives or the `dyn_groupprivate` clause. While the API is added, the current implementation always returns 0 for simplicity, as support for `groupprivate` is device-specific and `dyn_groupprivate` is still under development. New tests are included for C and Fortran.
