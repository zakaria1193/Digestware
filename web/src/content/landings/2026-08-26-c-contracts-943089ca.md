This change unifies the conditions under which contract postconditions are parsed and substituted in pseudo-template mode within the C++ frontend. Previously, differing conditions led to issues when substituting non-template trees. The fix ensures this approach is consistently applied only to postconditions that have result identifiers and deduced return types.
