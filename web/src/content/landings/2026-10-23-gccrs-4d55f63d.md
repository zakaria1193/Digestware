An internal compiler error in GCC's Rust frontend when evaluating deeply recursive `const fn` calls has been fixed. The issue stemmed from the compiler reserving space in the call cache even when recursion depth exceeded caching limits, leading to a hash table check failure. The fix ensures that cache insertions are only requested when a call will actually be cached, mirroring the behavior of the C++ frontend.
