This commit enhances the parallel cost estimation used in GCC's if-conversion optimization by accurately tracking register availability. Previously, the cost model could retain dependencies on overwritten register values and miss inputs not directly in SET sources. The update uses register properties and an availability map to precisely determine dependency levels, ensuring that register overwrites are handled correctly. This leads to more accurate cost estimations, especially for complex instruction sequences, and is a prerequisite for improving if-conversion profitability on architectures like AArch64.
