This commit refactors the Libgomp (OpenMP runtime library) by moving its internal NUMA (Non-Uniform Memory Access) functions into a newly created `numa.c` file. Previously, both the real and fallback implementations of these functions resided in `affinity.c` when `HAVE_PTHREAD_AFFINITY_NP` was unset, leading to less modular code. This change improves code organization and maintainability by centralizing NUMA-related logic.
