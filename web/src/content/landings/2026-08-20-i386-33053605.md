This commit corrects the CPU identification for the AVX512BMM instruction set on AMD Zen 6 processors. Previously, the `bit_AVX512BMM` flag was incorrectly checked against the standard CPUID leaf. This patch moves the detection to the extended features section of CPUID, aligning with how newer instruction sets are exposed. New compile-time and run-time tests are added to verify the fix for `__builtin_cpu_supports('avx512bmm')`.
