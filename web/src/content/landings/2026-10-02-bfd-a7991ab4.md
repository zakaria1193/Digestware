This patch introduces the `--prune-vectab` linker option for AVR targets, which removes unused entries from the interrupt vector table. It operates during the relaxation phase, cleaning up tail-end entries that typically point to `__bad_interrupt`. This feature helps optimize code size and resolves an issue with AVR-LibC's vector table structure (PR ld/34679).
