This commit addresses two instances in the RISC-V backend where the `[U]INTVAL` operand check was used without ensuring the operand was a `CONST_INT`. This could lead to incorrect code generation when non-constant values were used as immediate operands in certain instructions. The fix restricts the relevant machine definition operands to `const_int_operand`, ensuring that only constant integers are accepted, thereby improving code generation safety and correctness.
