This commit fixes two issues that emerged after recent changes to static aggregate handling in the Ada compiler. It corrects the duplication of elements in multi-dimensional array aggregates with 'others' choices and ensures that constants with static array aggregate values retain the correct dynamic subtype. The changes also refine the aggregate expansion machinery.
