This commit adds the `-mthumb` flag to the `nomve_fp_1.c` test case in the ARM testsuite. This change prevents compilation errors that occur when the test is run with `-marm` and certain ARMv8.1-M MVE features, where the compiler incorrectly attempts to use ARM mode with features only supported in Thumb mode, leading to an "target CPU does not support ARM mode" error.
