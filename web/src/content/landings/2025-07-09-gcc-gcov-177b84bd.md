For targets that only support 32-bit atomic operations, such as 32-bit RISC-V, the 64-bit atomic bitwise-or operation for updating gcov counters is now split into two 32-bit operations. This change optimizes counter updates by avoiding calls to libatomic and folding away compile-time zero halves, while maintaining the existing behavior for targets with 64-bit atomic instructions.
