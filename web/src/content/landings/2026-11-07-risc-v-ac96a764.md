This commit adjusts RISC-V `vwadd[u].wv` test cases for `m4` configurations. Following the application of a `Wn4` constraint to the `vs2` operand, register allocation behavior changed under high register pressure. The changes ensure the assembly checks in these test cases correctly reflect the new allocation, maintaining consistency with `vfwadd.wv` behavior regarding `vs1` register overlap.
