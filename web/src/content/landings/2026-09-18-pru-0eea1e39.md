The `pru_insert_loop_label_last` function in the PRU backend incorrectly counted debug instructions as opcodes when calculating padding for repeat loops. This led to an extra NOP instruction being inserted. This change modifies the function to ignore debug instructions, ensuring correct padding and preventing unnecessary instructions. A new regression test was added to verify the fix.
