This commit addresses an issue in GCC's C++ frontend where implicit typedefs were not being created correctly for `source_location` and `bad_alloc`. By ensuring the `TREE_PUBLIC` flag is set on these types during their lookup, the compiler can now properly handle C++26 contracts and maintain consistency with C++98 standard library declarations.
