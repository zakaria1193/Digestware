This commit ensures that the necessary Ada compiler tools, specifically `gnatdll.exe`, are built for the Cygwin environment. Previously, this tool might have been omitted for Cygwin builds. By enabling `EXTRA_GNATTOOLS` for the `gnattools-native` target, this change guarantees that the Ada development environment on Cygwin is more complete.
