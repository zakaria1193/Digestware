A bug in the Fortran compiler's simplification of the `TRANSFER` intrinsic for derived types with array components has been fixed. Previously, if an array component was initialized by a scalar constant, only the first element of the array was being set to that value. This change ensures that all elements of the array component are correctly initialized with the scalar constant, as intended.
