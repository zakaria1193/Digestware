This commit updates the GCC testsuite to ensure that tests which rely on AVX (Advanced Vector Extensions) or AVX512 instructions are properly flagged. For several torture-compile tests, a `dg-requires` directive has been added to specify that the assembler must support the relevant AVX instruction set.

This prevents these tests from running on architectures or configurations where AVX is not available, ensuring that the test results accurately reflect the compiler's capabilities for supported instruction sets.
