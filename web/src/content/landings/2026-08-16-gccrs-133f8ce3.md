GCC Rust (gccrs) now includes additional execution tests covering various scenarios of the `Drop` trait. These new tests specifically target function parameter drop order, explicit returns, ownership transfers via function arguments and return values, and branch-local value drops. The goal is to ensure robust and correct handling of resource cleanup through the `Drop` trait in all supported contexts.
