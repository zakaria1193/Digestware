This commit adjusts regular expression expectations in several AArch64 test cases to pass when compiled with the '-fweb' option. The -fweb option alters GCC's register allocation strategy, and some existing tests had overly strict requirements that now fail under this new allocation method. The changes loosen these expectations without compromising test integrity.
