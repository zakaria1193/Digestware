- term: Loop Vectorizer

The loop vectorizer can now identify when the offsets used in gather load operations are uniform across all lanes of a vector. By analyzing Scalar Evolution (SCEV) information, it detects if expressions like `i >> 6` evaluate to the same value for all lanes in a given iteration. When uniformity is detected, the vectorizer replaces multiple scalar loads with a single load and a broadcast operation, significantly improving performance for such memory access patterns.
