On SPARC V9, loads from a function's own frame are now disallowed in the delay slot of return instructions. This is because the delay slot executes after the register window has been restored, meaning such loads would access memory below the stack pointer. A trap or signal during this operation could corrupt the loaded data, leading to incorrect behavior. This change also simplifies related logic for identifying eligible instructions in delay slots.
