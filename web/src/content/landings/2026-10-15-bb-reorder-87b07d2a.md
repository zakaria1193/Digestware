The block reordering pass now unfactors loop switch dispatches, a common pattern in bytecode interpreters. Instead of a single jump table dispatch at the loop head, each eligible predecessor is given its own computed goto. This transformation aims to improve indirect target prediction by making the dispatch targets more explicit. The pass copies single-predecessor fall-through chains, using shared table representations and respecting existing constraints like function partitioning and stack register usage.
