This commit establishes symbol versioning for the libgcobol shared libraries, setting a baseline of `@GCOBOL_17.1`. This is achieved by including version script maps in the Makefiles, which guides the linker in managing symbol versions exported by `libgcobol.so`, `libgcobol_posix.so`, and `libgcobol_compat_gnu.so`.
