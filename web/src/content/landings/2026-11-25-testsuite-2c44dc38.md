An aarch64 Scalable Vector Extension (SVE) test case, `fneg-abs_4.c`, has been updated to reflect a recent optimization. Specifically, the idiom `memcpy/IOR` for sign-bit manipulation is now folded into a `.COPYSIGN` operation, similar to how `-fabs(x)` is handled. Consequently, the test now expects the same generated code as `fneg-abs_2.c`, which already accounted for this optimization. This ensures the test suite remains accurate with compiler improvements.
