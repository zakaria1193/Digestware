The GCC configure script previously accepted the `--with-long-double-64` option without error, despite it not being supported, and it was silently ignored. This patch modifies the configure script to actively reject this option and related flags, directing users to the correct `--with-long-double-128` option. The documentation in `install.texi` has also been corrected to remove the erroneous mention of the 64-bit long double option.
