The Value Range Propagation (VRP) pass can now fold less-than-or-equal (LE) or greater-than-or-equal (GE) tests between two variables into an equality test. This occurs when the relation oracle implies that if x <= y, then x must equal y, or similarly if x >= y. This change improves intermediate representation simplification by moving this logic from DOM to the simplifier.
