The bitintlower pass was not correctly clearing padding bits after signed multiplication or division operations on bitint types, especially when `-fwrapv` was used, which defines signed overflow behavior. This commit extends the padding bits clearing logic to cover signed multiplication and division when `TYPE_OVERFLOW_WRAPS` is enabled, ensuring correct results. A new test case is added to verify this behavior.
