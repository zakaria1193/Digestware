The `emit_jump` function, found in `gcc/rtl.h` and `gcc/stmt.cc`, now takes an `rtx_code_label *` parameter. This change enhances type safety by ensuring that jump instructions are associated with specific code labels. Related functions for stack clash protection probes are also updated to accept these label types.
