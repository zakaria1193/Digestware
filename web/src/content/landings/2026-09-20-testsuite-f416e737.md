This commit modifies the testsuite to prevent forced execution of vector saturation tests on hardware that can compile vector code but not run it. Previously, the `_BitInt` availability incorrectly triggered runtime execution, leading to linker errors on embedded targets like Cortex-M3 due to mixed architecture profiles. The change allows these tests to be compiled-only when runtime execution is not possible, resolving linker issues and ensuring broader testability.
