This commit corrects an optimization on the x86-64 architecture that generated inefficient code for moving a single byte when the source and destination memory locations could overlap. Previously, the compiler might use a sequence of instructions that handle overlapping memory moves, even for a single byte, which is unnecessary and slower. The fix ensures that for 1-byte moves, a simpler and more direct instruction is used, improving performance in such cases.
