This change ensures that the Algol 68 runtime library (`libga68`) is linked with the math library (`libm`) on targets that provide it. Several standard Algol 68 operators, such as `floor` and `ceil`, rely on mathematical functions implemented in `libm`. This change aligns `libga68`'s behavior with other GCC runtime libraries like `libgfortran` by explicitly adding the dependency using `LT_LIB_M`.
