This commit adds support for the RISC-V XAndesVSIntLoad extension, which handles vector load operations for INT4 data into 8-bit elements. The changes update BFD for ELF compatibility, GAS for assembler syntax and tests, and the opcode library for instruction recognition. This enables the use of specialized vector load instructions for improved data handling efficiency.
