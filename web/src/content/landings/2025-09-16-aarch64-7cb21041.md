This commit adds documentation comments to a variety of `DEF_*` macros across several aarch64 builtins definition files. These macros are used for defining SIMD, SVE, and SME functions and types. The documentation explains the purpose and arguments of each macro, improving understanding and maintainability for developers working with the aarch64 backend.
