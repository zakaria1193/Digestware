Test cases related to int128 support on x86 architectures have been simplified. Previously, conditions explicitly excluded the 'ia32' target when checking for int128 support. This commit removes the redundant '&& { ! ia32 }' clause, as ia32 inherently does not support int128, making the test directives more concise.
