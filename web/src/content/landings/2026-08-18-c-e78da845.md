This commit adjusts an assertion within GCC's C++ frontend's `build_vec_init` function to prevent an ICE (Internal Compiler Error). Recent compiler changes, particularly an optimization that modifies how cleanups handle rvalues, caused the existing assertion to fail. The patch modifies the assertion to match the new behavior, ensuring compiler stability and correctness during vector initialization, especially with C++ initializer lists.
