This commit ensures that libgomp's plugins (for nvptx and gcn) are linked using the same options as libgomp itself. Previously, the plugins were missing the `-Wl,-O1` optimization flag due to differences in Makefile.am configurations. By introducing a new `libgomp_plugin_LINK` variable, the plugins now correctly inherit essential linker flags, aligning their build process with the main libgomp library and improving build consistency.
