This commit introduces hardware-accelerated implementations for `clmuldi3` and `clmul_widendi3` on s390x processors starting from the z13. These functions perform 64-bit carry-less multiplication. The implementation leverages specific s390x instructions to improve performance. The commit also includes a new test case to verify the functionality. The author notes the potential for further optimization by implementing `clmulsi3` and `clmul_widensi3` using vector instructions.
