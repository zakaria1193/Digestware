Gfortran now supports the VALUE attribute for Fortran CHARACTER dummy arguments with assumed or non-constant lengths, conforming to the Fortran 2008 standard. Previously, the compiler enforced a stricter rule from the Fortran 2003 standard, rejecting these cases. The change involves relaxing length requirements for VALUE dummies and ensuring a caller-side copy is made, scaled appropriately by character kind size.
