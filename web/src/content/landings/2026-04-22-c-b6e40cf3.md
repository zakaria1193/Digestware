This commit addresses issues in C++ related to constant evaluation, array initialization and module loading. Specifically, it prevents the compiler from attempting to constant-evaluate certain expressions prematurely during module loading, which could lead to errors when dealing with `consteval` functions and array constructors. The fix involves delaying certain folding operations until after genericization and suppressing conditional folding when handling non-ODR (One Definition Rule) uses.
