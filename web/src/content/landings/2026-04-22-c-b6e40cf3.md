This commit addresses a bug in C++ module loading related to `consteval` functions and array initialization. The issue occurred when loading a function from a module, where the compiler would attempt to constant-evaluate the array constructor prematurely. This commit defers the folding of `TARGET_EXPR` within `INIT_EXPR` to the `ff_genericize` pass, preventing the incorrect constant evaluation and resolving the compilation error.
