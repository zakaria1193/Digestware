This commit addresses an issue in C++ where constant evaluation during module loading could trigger errors, specifically when dealing with array constructors and `consteval` functions. The problem arose because the element constructor wasn't cloned before the element_array constructor was evaluated. The fix involves suppressing certain folding operations when only non-ODR (One Definition Rule) uses are considered, preventing premature constant evaluation.
