This commit improves the RISC-V backend's handling of bit manipulation operations by combining zero-extended word-sized bit masks with 64-bit values using Zbs instructions. It introduces new patterns for `bset`, `binv`, and `bclr` that directly match canonical complemented forms with Zbs alone. This approach optimizes the generation of code involving bitmasks, potentially leading to more efficient bit manipulation operations on the target architecture.
