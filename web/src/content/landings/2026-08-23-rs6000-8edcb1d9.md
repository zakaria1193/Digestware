This commit resolves an Internal Compiler Error (ICE) that occurred when using `__int128` vector built-in functions with the `-mno-vsx` flag on POWER architectures. The built-ins have been moved to the VSX-specific stanza, ensuring they are only enabled when VSX is supported, and providing a proper diagnostic instead of crashing the compiler.
