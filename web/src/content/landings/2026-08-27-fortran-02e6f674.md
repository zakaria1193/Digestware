A bug in Fortran's code generation for structure constructors has been fixed. When copying an allocatable character array into an explicit-length allocatable character array component, the previous implementation used a bitwise copy which failed when source and destination element lengths differed. This change replaces the bitwise copy with an element-by-element string copy, ensuring correct padding or truncation.
