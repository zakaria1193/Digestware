This commit addresses an issue where Ada finalization was not correctly performed for descendants of mutably tagged types that had controlled components. It also prevents the generation of unnecessary finalization boilerplate code for class-wide objects of regular tagged types. Additional fixes improve `Might_Have_Tasks` and `Find_Type_Name`.
