GCC generated incorrect debug information for Ada bit-packed array types when they used a reverse storage order. These types are internally represented as modular integer types, and the debug info lacked accurate information about their storage arrangement. This commit introduces a `reverse_storage_order` field to the `array_descr_info` structure and ensures it is correctly populated by the Ada front-end, fixing the debug info inaccuracies.
