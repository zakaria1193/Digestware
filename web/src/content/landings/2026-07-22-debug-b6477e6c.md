This commit resolves an issue where debug information was not correctly attached to function wrappers generated by IPA ICF (Interprocedural Analysis, Identical Code Folding). When ICF replaces a function's body with a wrapper, the original function's debug info could be lost. The fix preserves the `DECL_IGNORED_P` flag across forced GIMPLE thunk expansion, allowing the wrapper's address to be correctly associated with its corresponding debug subprogram DIE. A new test case verifies this fix.
