This patch introduces support in GCC's interprocedural analysis (IPA) predicates for handling situations where a conditional expression involves an aggregate parameter with an unknown memory offset. When the parameter points to a string constant, the analysis can now inspect the string to infer information, similar to how it handles specific characters. This is a foundational step towards better analysis of such cases, with further work on PHI nodes and jump functions planned.
