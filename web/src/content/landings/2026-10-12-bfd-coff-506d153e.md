- term: r_symndx
  definition: The field in a COFF relocation entry that holds the index of the target
    symbol in the object's symbol table. Linkers use it to look up the symbol a relocation
    refers to. In malformed files it can be negative or past the end of the table.
- term: obj_raw_syment_count
  definition: A BFD macro giving the number of raw symbol-table entries declared in
    a COFF file header. Auxiliary entries count as entries. Parallel arrays such as
    sym_hashes are sized from it.
- term: sym_hashes
  definition: An array of linker hash-table entries, parallel to a COFF object's symbol

    buffer.

    shorter forms and examines relocations and symbols to do so.

    failure instead of continuing with corrupt state.

Several COFF backends used a relocation's r_symndx to index symbol tables without checking it against the table size. A crafted object with a negative or oversized index could trigger out-of-bounds heap reads in the linker or other BFD consumers. The patch adds a shared coff_symndx_in_range macro in libcoff-in.h (mirrored in libcoff.h). It checks that the index is non-negative and below obj_raw_syment_count, and the SH, ARM, AArch64, MCore, cofflink and xcofflink code now use it. Loops that can safely ignore a bad entry skip it. Functions that can't return a partial result set bfd_error_bad_value and fail. Absolute relocations that use the -1 sentinel are skipped without diagnostics. A new SH COFF linker test covers the malformed cases.
