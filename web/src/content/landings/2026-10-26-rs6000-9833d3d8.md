This commit introduces new instruction patterns for the POWER10 architecture to enable fusion of `addis` and `addi` instruction pairs. On POWER10, these pairs can be fused for performance, but the scheduler previously broke them apart. The new 'fake' instructions represent the fused pair as a single pattern, preventing the scheduler from reordering them while still generating the correct two-instruction sequence. This preserves the fusion benefit without altering the generated code.
