This commit renames two AArch64 predicates in GCC's machine description files to better reflect their usage. The `aarch64_imm3` predicate, which previously had a limited range and was used for shift amounts in extended register operations, is renamed to `aarch64_shift_imm3`. Concurrently, `aarch64_lane_imm3` is renamed to `aarch64_imm3` to represent a more general immediate value suitable for lane selection. These changes improve the readability and maintainability of the AArch64 target configuration.
