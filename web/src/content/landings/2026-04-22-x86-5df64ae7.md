The x86 common subexpression elimination (CSE) pass was previously configured to only remove redundant thread-local storage (TLS) calls when SSE2 was enabled. This commit removes the SSE2 check, allowing the pass to remove redundant TLS calls even when SSE is disabled. This can improve performance in code that uses TLS but doesn't rely on SSE instructions.
