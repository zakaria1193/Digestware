A long-standing, unused, and buggy pattern in the RISC-V backend for testing if a value is greater than or equal to 1 has been removed. The pattern incorrectly allowed a register as the last argument when a constant was required, which would have caused assembler errors if it had ever been used. This change cleans up dead code and prevents potential future issues.
