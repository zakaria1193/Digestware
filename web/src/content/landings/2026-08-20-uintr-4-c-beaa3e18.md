A test case (`uintr-4.c`) for handling instructions within exception service routines on x86 has been updated. Previously, the test expected a specific error message related to SSE instructions. However, when AVX or AVX512 are enabled by default, the compiler generates different, more specific error messages. This change modifies the test to accept any of these expected error messages (SSE, AVX, or AVX512), ensuring the test remains valid across different compiler configurations.
