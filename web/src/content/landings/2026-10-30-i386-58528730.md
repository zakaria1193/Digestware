This commit introduces a new tuning option for Intel targets to improve performance on CPUs since Sandy Bridge. It avoids using the `xchg reg,reg` instruction for register swaps, as newer Intel microarchitectures process this instruction inefficiently. Instead, the compiler now uses a three-move sequence through a scratch register, which prevents unnecessary delays caused by false dependencies.
