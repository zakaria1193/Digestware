This commit modifies `libgfortran`'s coarray collective subroutines to correctly report terminated images during collective operations. Previously, if an image in a team terminated, collective subroutines would report a runtime error and terminate remaining images, even if a `STAT` argument was present. Now, in compliance with the F2023 standard, it assigns `STAT_STOPPED_IMAGE` or `STAT_FAILED_IMAGE` to the `STAT` argument when an image terminates, allowing other images to continue if `STAT` is provided.
