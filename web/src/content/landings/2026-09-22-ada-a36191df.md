This commit aims to unify the error messages generated for failed static accessibility checks in Ada. The messages now consistently use phrases like "accessibility level of X is too deep" or "X has deeper accessibility level than". Additionally, these messages are augmented with references to the relevant rules in the Ada Reference Manual, prioritizing the latest version (Ada 2022 with Amendment 1). The exception is for illegal 'Access attribute references, which retain their original 'nonlocal access vs local object' viewpoint.
