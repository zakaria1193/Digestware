The s390 assembler now supports twelve new .insn pseudo-mnemonics, from vri_a to vri_l. These mnemonics represent different versions of the VRI (Vector Register Immediate) instruction format, introduced in IBM z13, z14, and z17 processors. The changes include opcode definitions, test suite additions, and documentation updates.
