The GCC compiler now supports the `VMAL` instruction on s390 architecture, enabling vector multiply-and-add operations for integer vector modes and TI mode. This feature, available on processors with VXE3/z17 extensions, significantly accelerates computations involving parallel multiplication and addition. The implementation includes adding the instruction pattern, adjusting RTX costs for constants, and providing new test cases.

This brings performance improvements for scientific and data-processing workloads on s390 by leveraging new hardware capabilities.
