This commit modifies the RISC-V ELF linker to ignore attributes when merging data from empty input files or sections like .note.gnu.build-id. Previously, these sections could cause linker test failures related to diagnostics, garbage collection, and symbol definitions. The change ensures these sections do not interfere with attribute merging, resolving multiple failing tests.
