An internal compiler error (ICE) was triggered on RISC-V when using very large `BITINT_TYPE` types in the SCCVN (Scalar Constant Class Value Numbering) pass. The issue was that `vn_reference_lookup_3` was using `build_nonstandard_integer_type` instead of `build_bitint_type` for types larger than `MAX_FIXED_MODE_SIZE`. This commit corrects the type creation, resolving the ICE. A new test case is added to verify the fix.
