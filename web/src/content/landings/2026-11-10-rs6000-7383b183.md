This commit enhances vector splat code generation for single-precision floating-point (SFmode) values on Power7 and Power8 processors. It replaces the previous load, conversion, and splat sequence with more efficient instructions: `lfiwzx` and `xxspltw` on Power7, and `lxsiwzx` and `xxspltw` on Power8, when loading from memory. The change also broadens support for SFmode splat inputs to all VSX targets and uses `vsx_splat_v4sf` for vector initialization.
