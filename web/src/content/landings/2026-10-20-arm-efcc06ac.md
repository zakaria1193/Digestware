This commit addresses issues in the ARM backend related to minipool placement and memory management. A previous change in pool placement calculations was not fully accounted for when inserting forced barriers, potentially leading to incorrect barrier placement. Additionally, a small memory leak in the pool dumping code, where subpools were not properly destructed, has been resolved. The changes ensure more accurate barrier placement by considering pool alignment and fix off-by-one issues, and clean up resources in the minipool dumping routine.
