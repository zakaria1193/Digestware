Test failures in gcc.target/i386/xop-pcmov3.c occurred because the `avx512vl_vternlogv4si_all` pattern was being enabled, leading to unexpected `vpcmov` instructions in the assembly output. This commit modifies the test case to disable AVX512F using `-mno-avx512f` when `TARGET_PREFER_AVX256` is not enabled by default, thus resolving the assembler scan failures.
