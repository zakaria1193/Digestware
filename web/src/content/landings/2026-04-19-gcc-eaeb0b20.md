This commit fixes a link failure that occurred when building GNAT tools on Windows hosts. The Makefile was overriding adjustments made to the LIBS variable, causing the linker to miss necessary libraries. The fix involves moving the definitions of TGT_LIB, LIBBACKTRACE, LIBIBERTY, LIBGNAT, and LIBS, and using $(LIBS) for TOOLS_LIBS.
