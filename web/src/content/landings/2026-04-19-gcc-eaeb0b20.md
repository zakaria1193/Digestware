This commit fixes a link failure that occurred when building GNAT tools on Windows hosts. The Makefile was incorrectly overriding adjustments made to the LIBS variable, leading to missing libraries during linking. The fix involves rearranging the Makefile to ensure LIBS is used correctly for linking the tools.
