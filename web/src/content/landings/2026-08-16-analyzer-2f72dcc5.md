The GCC static analyzer has been enhanced to understand C++ `dynamic_cast` operations, resolving a limitation where results of failed casts were treated as opaque. This new functionality allows the analyzer to statically evaluate `dynamic_cast` calls, similar to the frontend's `cxx_eval_dynamic_cast`, enabling it to detect bugs such as dereferencing a null pointer resulting from a failed cast. It works by traversing BINFOs and calculating offsets without directly using frontend trees.
