GCC's vectorizer has been enhanced to record permutation information, crucial for accurately costing complex vector operations. New data structures (`vect_permute_data`, `vect_call_data`) store permutation constants as trees, allowing the codegen phase to reuse them. This enables targets to query permutes associated with SLP nodes for more precise cost estimations, improving the effectiveness of vectorization, especially for operations like byte swaps.
