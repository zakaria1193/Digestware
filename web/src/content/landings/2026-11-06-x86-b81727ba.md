The x86 assembler's logic for inserting `lfence` instructions via the -mlfence-after-load option has been extended. This update adds support for instructions like LLDT, VERR, VERW, BT{,C,R,S}, SHLD/SHRD, ARPL, CMPXCHG, VMXON, VMCLEAR, VMPTRST, and VMREAD, which can affect EFLAGS or subsequent memory reads. The commit also refactors internal checks for instruction opcodes and VEX prefixes to simplify the code and improve accuracy.
