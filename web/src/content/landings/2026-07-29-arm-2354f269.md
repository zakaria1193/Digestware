This commit enhances the ARM Neon backend's handling of `vec_dup` operations on 128-bit vectors. It allows core registers to be used as source operands without needing to copy the entire vector to VFP/SIMD registers. The implementation now efficiently extracts the required lane to the lower bits of a scratch core register, or uses the core register directly if no shift is needed, simplifying code generation and potentially improving performance.
