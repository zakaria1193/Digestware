This commit syncs a change from binutils-gdb to address a configuration check failure. The mmap check would previously trigger memory leak reports from sanitizers. By introducing GCC_AC_FUNC_MMAP and disabling leak detection for the check, the build process now completes without errors when sanitizers are enabled.
