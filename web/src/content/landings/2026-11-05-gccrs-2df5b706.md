This commit optimizes method probing in gccrs by reusing the self type of an implementation block. Previously, the self type was resolved repeatedly for each probe, even when generics and bounds were involved, leading to excessive memory consumption that could cause the checker to run out of memory on large projects. By returning the already-resolved type from the context, this change significantly improves performance and reduces memory pressure.
