GCC's libstdc++ configure script had a persistent issue incorrectly parsing warnings from the GNU linker (`ld`) related to `--gc-sections`. This commit adjusts the `grep` pattern used in `acinclude.m4` to correctly match the linker's output, which now uses 'W' (uppercase) instead of 'w' (lowercase) for warnings, and ensures consistent matching across different locales by setting `LC_ALL=C`. This fixes PR126452.
