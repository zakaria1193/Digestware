This commit allows GCC's Instruction Realocation (IRA) pass to allocate Floating-Point Registers (FPRs) for values that are primarily used in integer modes on RISC-V architectures. This is particularly beneficial for bit-level operations on floating-point variables, preventing the creation of redundant `fmv.d.x` instructions. By enabling this flexibility, the compiler can better manage register allocation and reduce instruction overhead.
