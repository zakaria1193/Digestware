The constant propagation pass (`cprop`) has been optimized to improve performance when bypassing conditional jumps. Previously, it would repeatedly substitute the source of a `SETCC` instruction into jump conditions for each incoming edge, leading to unnecessary RTL allocations and performance degradation. This change modifies `bypass_block` to perform the substitution only once per block before iterating over edges, significantly reducing memory allocation and compile time for code with many conditional jumps.
