This commit improves the aarch64 backend by allowing the negated 64-bit comparison instruction (`aarch64_cm<optab>di`) to accept a zero operand directly in general-purpose registers. Previously, comparing against zero required moving the value through a vector register, which was less efficient. This change optimizes code like `-(long) (x == 0)` by using a general register comparison, reducing cross-register-file moves and improving performance.
