This commit addresses an oversight in GCC's Ada compiler where illegal uses of access-to-subprogram parameters were not always caught at compile time. Specifically, it now correctly rejects cases where such parameters are reused as named access-to-subprogram values, enforcing Ada Reference Manual rules regarding accessibility levels. New test cases have been added to verify this fix.
