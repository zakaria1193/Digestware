This commit fixes an issue in the Fortran compiler (gfortran) where scalar `CHARACTER(c_char)` dummy arguments with the `VALUE` attribute were not always passed by value as required by the BIND(C) interface. The fix ensures that for such dummy arguments, only the first character is passed by value, which is the correct behavior for C interoperability. A new test case has been added to verify this correction.
