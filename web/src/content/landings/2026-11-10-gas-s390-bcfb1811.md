This commit modifies the GNU assembler (GAS) for s390 to make the M3 mask operand optional in the `.insn` pseudo-mnemonic for the VRX instruction format. This change aligns the assembler's pseudo-mnemonic with the actual VRX instruction format, which includes an optional M3 field. Documentation and test cases have been updated accordingly.
