This commit updates several floating-point-related torture tests within the GCC testsuite to explicitly link against the math library (`libm`). This is necessary for the `hppa64-hp-hpux11.11` target, where these tests require `libm` for their execution. The changes involve adding `-lm` to `dg-additional-options` or `dg-options` in the respective test files.
