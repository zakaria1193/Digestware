The `<numeric>` header in libstdc++ has been updated to use the `__cpp_lib_parallel_algorithm` feature test macro. Previously, it relied on more general macros like `__cplusplus` and `_GLIBCXX_HOSTED`. This change provides more precise feature detection for parallel algorithms.
