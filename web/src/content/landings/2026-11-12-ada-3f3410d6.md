This Ada compiler change streamlines the computation of the lower bound for dynamic concatenation. It removes redundant checks when the result may be null and the array type originates from an unconstrained definition. By introducing a local constant for the result's first subtype and adjusting guarding conditions, the generated code for these concatenations is significantly simplified, especially in cases involving unconstrained arrays and slices.
