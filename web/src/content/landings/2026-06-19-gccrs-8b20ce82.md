- term: unit tail expression

GCC's Rust compiler now correctly emits drop calls for unit tail expressions within functions. This ensures that any resources held by variables in scope are properly cleaned up before the function returns, particularly when the function's last expression implicitly returns a unit type. This fix addresses a gap in resource management for such cases.
