GCC generalizes the LDPREINCREMENT macro-fusion recognition for RISC-V. The update allows matching non-word ADDI-type in-place address updates followed by scalar loads, supporting register-plus-offset and LO_SUM addresses, as well as self-moves. It also refactors common pre/post-index load/store constraints into a helper function, with specific checks for stores to prevent data register overlap. The changes enhance the compiler's ability to fuse address calculation with memory loads.
