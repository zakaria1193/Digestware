The gccrs compiler's `ExpandVisitor` now handles a wider range of attributes by leveraging functionality from `PointerVisitor`. This change streamlines attribute processing within various visitor methods, including those for struct fields and tuple fields. The update aims to fix issues encountered during the compilation of core Rust libraries.
