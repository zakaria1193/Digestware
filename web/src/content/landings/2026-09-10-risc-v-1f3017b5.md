This commit fixes an internal compiler error (ICE) in the RISC-V backend related to widening vector instructions. The error occurred when the destination and source operands of a widening instruction used the same number of registers (nregs). The compiler's `riscv_v_widen_constraint_ok` function had an incorrect assertion that `nregs` must be 1 in such cases. This patch modifies the function to return `false` instead of asserting when `nregs` is equal but greater than 1, preventing the ICE and allowing correct code generation for valid widening operations.
