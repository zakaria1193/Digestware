This commit removes the definitions for Control and Status Registers (CSRs) associated with the RISC-V 'N' extension. These CSRs were deprecated in privileged spec 1.12 and are no longer valid with the current standard (1.13). The assembler will now report them as unknown, and the disassembler will continue to show their numerical values.
