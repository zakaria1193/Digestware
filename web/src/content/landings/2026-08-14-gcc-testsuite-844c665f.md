A fix for Darwin's linker default behavior, which requires all symbols to be defined, resolves failures in several Link-Time Optimization (LTO) tests. Previously, these tests produced dynamically loaded objects with undefined symbols, causing them to fail on Darwin. The changes allow undefined symbols in these specific test cases, enabling the tests to run correctly.
