A new script, `gdb/contrib/pre-commit.py`, has been introduced to enforce the use of stable, released versions for pre-commit hooks. This prevents accidental updates to pre-release versions of tools like `isort`, which previously led to broken configurations. The script checks revisions and errors out on pre-release tags, and `isort` has been reverted to its last stable release (8.0.1) to comply.
