This commit fixes a bug in DWARF generation where bit extraction shifts were calculated incorrectly. The issue stemmed from mixing the address size in bytes with bit offsets. The fix converts the address size to bits before calculating the shift counts in `dwarf2out.cc`, ensuring accurate debug information. A new test case is added to verify the fix.
