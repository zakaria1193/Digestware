This commit adds support for eleven new .insn pseudo-mnemonics (vrr_a through vrr_k) to the s390 assembler. These mnemonics cover various versions of the VRR (Vector Register Register) instruction format, introduced across multiple IBM processor generations from z13 to z17. Test cases and documentation are updated accordingly.
