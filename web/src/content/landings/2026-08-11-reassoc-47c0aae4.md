This commit enhances the reassociation pass in GCC to keep chains of conditional comparisons linear when appropriate, particularly benefiting the AArch64 architecture. Previously, reassociation would aggressively rebalance these chains into trees, which is inefficient for comparisons that depend on previously set flags. The change ensures that linear chains are maintained when operands are scalar comparisons within the same block and at least one comparison can be folded into flags, leading to more efficient instruction sequences, such as single `ccmp` sequences on AArch64.
