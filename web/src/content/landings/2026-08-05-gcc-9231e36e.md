This commit introduces a new pure virtual function, `contains_zero_p()`, to the GCC compiler's value range analysis hierarchy. This predicate clearly indicates whether a given range includes the value zero. It serves as a more explicit replacement for the previously used `nonzero_p()` function, which had ambiguous behavior. The new function is implemented for various range types, improving the clarity and precision of range analysis.
