This commit corrects a bug in GCC's `combine_comparisons` function where `COMPCODE_FALSE` and `COMPCODE_TRUE` were erroneously treated as trapping operations when floating-point trapping was enabled. This led to the elimination of necessary IEEE exceptions. The fix modifies the condition that determines if a comparison traps, ensuring that these boolean outcomes do not trigger the trapping logic, thereby preserving correct floating-point exception behavior.
