This change prepares the linker's stub BFDs to be correctly used as dynamic objects. It adjusts how sections are identified (using `SEC_LINKER_CREATED` instead of relying on section names or stub status) and ensures the `EI_CLASS` is set appropriately for ELF linking, improving compatibility with targets like Arm and AArch64.
