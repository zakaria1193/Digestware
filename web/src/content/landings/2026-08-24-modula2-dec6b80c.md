The Modula-2 library build process (`libgm2`) has been updated to accurately detect the Python version. It now uses a new `ax_python_interpreter.m4` macro to ensure Python 3.0 or later is present, which is required for the `mktargetsrc.py` script. If an older Python version is found, certain library functionalities are reduced.
