This commit resolves a regression in the s390 libgcc build that occurred when configured with `--disable-decimal-float`. The build failed because conversion routines for `_Float16` to decimal float were unconditionally added, requiring decimal float support. This change ensures these routines are only included when decimal float is enabled, fixing the build issue introduced by a previous patch adding HF mode support.
