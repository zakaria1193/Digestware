This change adds missing checks in the `ipa-prop` pass to ensure that bit offsets align to byte boundaries when calculating aggregate constants. Previously, the pass could incorrectly return a constant value even if the requested offset was not on a byte boundary, leading to potential issues in constant propagation. The fix includes adding these checks to `ipcp_get_aggregate_const` and a bounds check.
