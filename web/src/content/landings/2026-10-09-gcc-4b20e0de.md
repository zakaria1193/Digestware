This commit removes obsolete header checks from GCC's build configuration, specifically for <limits.h>, <locale.h>, and <stdlib.h>, as these are guaranteed by the C89 standard. The changes involve regenerating configuration files and updating acinclude.m4 and configure.ac to reflect that these headers are always available.
