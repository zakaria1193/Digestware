This commit refactors the Algol68 compiler's static property (sprops) handling by consolidating the initialization of origin properties into a new `make_origin` function. This function takes a parse node and initializes the properties of a new origin. The `sprops_for_*` functions are updated to call `make_origin`, removing redundant code and improving maintainability within the `a68-parser-sprops.cc` file.
