The `REGNO_REG_CLASS` macro for the Xtensa target has been revised to accurately map each hardware register number to its minimal register class. This is achieved by generating a mapping within `xtensa_conditional_register_usage` that references a new global array, `xtensa_regno_to_class`. This ensures that the compiler always selects the most specific register class for a given register, as recommended by GCC's internal documentation.
