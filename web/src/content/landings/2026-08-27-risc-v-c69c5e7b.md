The RISC-V vector extension (RVV) has been updated to allow register group overlap for the vwmacc.vx and vwmaccu.vx instructions. This change enables more flexible register allocation and potentially better performance by allowing these instructions to use registers that might otherwise be considered overlapping.

New test cases have been added to verify this functionality across various data types and vector sizes, ensuring correct behavior and preventing regressions.
