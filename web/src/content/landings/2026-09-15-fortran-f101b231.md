Several functions related to Fortran array descriptor initialization have been refactored to improve code organization. Specific initialization logic for scalars and coarray descriptors has been moved into new, dedicated functions within `trans-descriptor.cc` and `trans-types.cc`. This change aims to make the code more modular and easier to understand.
