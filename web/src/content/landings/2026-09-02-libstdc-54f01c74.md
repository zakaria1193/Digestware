A bug in libstdc++'s `unordered_map` heterogeneous insertion has been fixed, preventing unnecessary copying of the key when an insertion does not actually happen. The issue involved `try_emplace` calling an incorrect helper function for new usage cases, which went undetected by tests. This patch corrects `try_emplace` and other heterogeneous insertion methods (`at`, `insert_or_replace`) to call the right helpers and ensures tests verify that keys are not copied when elements are not inserted.
