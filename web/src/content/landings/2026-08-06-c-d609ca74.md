This commit implements the C++29 feature for designated initializers applied to base classes, based on the P2287R6 proposal. It modifies parsing to correctly handle sequences of non-designated and designated initializers, particularly for base class members. The implementation also refines lookup rules and ensures correct initialization when designators refer to members of base classes.
