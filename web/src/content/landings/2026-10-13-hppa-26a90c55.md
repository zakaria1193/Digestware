This commit corrects an issue in the hppa backend's pa.cc file by removing checks for constant pool addresses. These checks were causing compilation errors because constant pool addresses are handled as special SYMBOL_REF references. The change simplifies the code by removing redundant checks in `pa_emit_sequence`, `pa_legitimate_constant_p`, and `pa_legitimate_address_p` functions.
