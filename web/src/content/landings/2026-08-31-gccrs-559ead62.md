primer_glossary:
- term: Associated Type
  definition: In Rust traits, an associated type is a placeholder for a type that
    the trait implementation will define. It allows traits to be more generic. For
    example, a `Iterator` trait might have an associated type `Item` representing
    the type of element the iterator yields.
- term: Trait
  definition: A collection of method signatures and associated types that define a
    shared behavior. Other types can implement a trait to provide that behavior.
- term: Self-referential
  definition: A type or construct that refers to itself. In this context, it means
    an associated type within a trait that directly or indirectly refers back to the
    trait itself.
- term: HIR
  definition: High-level Intermediate Representation. A representation of the code
    that is closer to the source language than machine code, used by the Rust compiler
    (and gccrs) for analysis and transformations before generating lower-level code.
