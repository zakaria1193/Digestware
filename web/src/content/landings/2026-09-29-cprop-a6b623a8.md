The constant propagation pass (`cprop`) now avoids queuing dead condition code (CC) setters when bypassing jumps. In code with long chains of conditional checks, previously, the compiler would insert redundant flag-setting compare instructions, consuming significant compile time. This change ensures that setters are only copied if they are truly needed at the destination block (e.g., for side effects, exceptions, or if they set a live register not otherwise handled). This optimization dramatically reduces compile times, by up to 95% in the tested scenario.
