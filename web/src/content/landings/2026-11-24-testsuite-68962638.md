This commit resolves an issue where several aarch64 SVE2 tests were failing or marked as UNRESOLVED. When these tests were switched to `dg-do assemble` mode due to newer binutils supporting SVE2.1/SVE2.2 instructions, the assembly (`.s`) files were not being preserved. By adding the `-save-temps` flag, similar to other assemble-mode tests, the intermediate assembly files are now created, allowing the `check-function-bodies` and `scan-assembler` tools to function correctly and the tests to pass.
