The `libssp` (stack smashing protection) library now supports `_FORTIFY_SOURCE=3` by incorporating `__builtin_dynamic_object_size`. This allows for enhanced security checks, particularly for dynamic objects, when the compiler is invoked with this specific macro defined. The changes involve updating the `ssp.h.in` header to conditionally enable this support.
