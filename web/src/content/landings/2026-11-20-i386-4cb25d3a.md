This change introduces support for the `sdot_prod` optab with BF16 and FP16 inputs, utilizing existing AVX512BF16 `vdpbf16ps` and AVX10.2 `vdpphps` instructions. This enhancement allows the vectorizer to perform floating-point dot products on these smaller data types. The implementation requires the `flag_unsafe_math_optimizations` due to the behavior of `vdpbf16ps` with denormal inputs and result flushing. New test cases are added to cover these functionalities.
