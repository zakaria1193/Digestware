This commit removes several definitions related to RISC-V privileged specification classes and associated CSRs from various components including BFD, gas, and GDB. The changes reflect the standardization on privileged spec 1.13, making older spec versions and their corresponding CSRs obsolete. The assembler and disassembler are updated to handle this change, no longer recognizing or processing deprecated spec versions or attributes.
