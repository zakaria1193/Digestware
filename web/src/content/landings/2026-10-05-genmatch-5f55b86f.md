This change optimizes the generated code in genmatch by sharing transform copies for non-delayable for-iterators. Previously, even when the result trees were structurally identical, distinct pointers were created, leading to duplicated code generation. By guarding the copy operation and checking for iterator references, identical results are now shared, reducing the generated GIMPLE and GENERIC matcher size. A fix for `contains_id` ensures correct tracking of captures in C expressions.
