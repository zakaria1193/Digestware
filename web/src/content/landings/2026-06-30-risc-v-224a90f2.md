A bug in GCC's RISC-V multilib configuration has been fixed, resolving issues where the architecture string (`arch_str`) could be left empty on native builds. Previously, the parsing logic incorrectly compared the full multilib path string against a minimal delimiter, leading to a failure in identifying the correct architecture and ABI. This commit modifies the logic to use the correctly truncated path, ensuring that native multilib configurations are properly recognized and processed.
