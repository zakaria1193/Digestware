This commit significantly enhances GCC's ability to recognize various patterns equivalent to the C++20 spaceship operator (`<=>`) for integer types. Previously, only simple `a == b ? 0 : (a > b) ? 1 : -1` forms were recognized. This update extends recognition to more complex conditional structures like `a <= b ? -(a < b) : 1` and `a >= b ? (a > b) : -1`. By identifying these patterns, GCC can now emit the dedicated spaceship operation on targets that support it, leading to more efficient and compact code.
