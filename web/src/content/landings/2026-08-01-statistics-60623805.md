This commit fixes an issue where GCC's detailed memory statistics gathering (`--enable-gather-detailed-mem-stats`) caused tests involving Precompiled Headers (PCH) to fail. The problem occurred because the statistics infrastructure did not recognize GGC'd objects loaded after a PCH restore, leading to errors in `mem_alloc_description::release_object_overhead`. The fix ensures these unknown objects are ignored, preventing test failures.
