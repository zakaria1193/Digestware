This commit modifies vectorizer patterns to guarantee that signed arguments are converted to unsigned types before being passed to internal functions `.CLZ`, `.CTZ`, and `.POPCOUNT`. Previously, some patterns could incorrectly pass signed arguments, leading to potential issues. The changes ensure type correctness by introducing explicit conversions, maintaining the bitwise integrity of the operations. This work complements GIMPLE verifier changes that reject signed arguments for these intrinsics.
