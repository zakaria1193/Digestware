This Ada compiler patch resolves a memory leak that occurred when using the 'Old attribute on finalizable types within conditionally evaluated post-conditions. Previously, temporaries holding the old value were incorrectly allocated on the heap instead of the secondary stack, leading to leaks. The fix redirects these allocations to the secondary stack.
