This commit ports the NEON SM3 and SM4 intrinsics, which are part of the FEAT_SM4 feature set, to GCC's pragma-based framework for the aarch64 architecture. It involves adding new function declarations and bases for these intrinsics, removing older builtin function definitions, and including new assembly tests to verify their functionality. This change standardizes the handling of these cryptographic intrinsics within GCC.
