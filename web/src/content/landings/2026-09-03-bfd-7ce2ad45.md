This commit fixes a bug in the BFD linker that caused failures for the tic6x target (PR34550). The issue stemmed from an optimization that moved the check for `dynamic_sections_created` too early in the linking process. This check needs to occur after the hash table type is verified. The fix ensures this check is performed at the appropriate stage, allowing `bfd_elf_link_create_dynamic_sections` to run, which correctly handles early exits if dynamic sections are already present.
