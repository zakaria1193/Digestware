Several local functions within the DOM (Dominator Tree) analysis pass have been converted into methods of the `dom_opt_dom_walker` class. This refactoring reduces the need to pass extensive state between functions, making the code cleaner and easier to maintain. The changes were tested on a stage1 bootstrap compilation, showing no alteration in the generated assembly output.
