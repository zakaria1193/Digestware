The libstdc++ library now uses an error_code overload of `filesystem::canonical` to ignore errors when resolving the `/etc/localtime` path. Previously, this could lead to exceptions being thrown, while other error-handling mechanisms for similar paths returned an empty string. This change ensures consistent error handling across different path resolution methods, preventing unexpected program termination.
