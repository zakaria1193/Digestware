The assembler was incorrectly converting register symbols to constants when processing equates, leading to incorrect symbol table entries. This commit ensures that register symbols are properly handled in equates by cloning expressions before modification. This prevents local absolute symbols from appearing in the symbol table when they should be register symbols.
