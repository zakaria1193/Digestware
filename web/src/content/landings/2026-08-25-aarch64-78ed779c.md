This commit ports the NEON square-root intrinsics (`vsqrt`, `vsqrtq`) for floating-point types to the pragma-based framework on aarch64. By moving these intrinsics into this unified system, GCC can manage their lowering and optimization more consistently. The direct function definitions in `arm_neon.h` are removed, and new function bases and definition groups are added in `aarch64-neon-builtins-base.cc` and `.def`. A new test case is included to verify the correct functioning of these ported square-root operations.
