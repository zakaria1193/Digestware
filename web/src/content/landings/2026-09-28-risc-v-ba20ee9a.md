This commit introduces a suite of new test cases for the RISC-V Vector (RVV) extension, specifically targeting register group overlap scenarios for the `vfwmul.vf` instruction. The tests cover various data types (f16, f32) and vector lengths (m1, m2, m4, mf2, mf4), ensuring correct handling of register resources during wide floating-point multiplication operations.
