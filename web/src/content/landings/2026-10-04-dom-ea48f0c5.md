The Dominator analysis (DOM) pass in GCC has been updated to replace its internal `test_for_singularity` function with the more powerful `simplify_using_ranges`.
This change leverages existing range-based simplification capabilities to achieve the same goal, leading to slightly smarter code analysis. The update is part of an ongoing effort to refactor and improve the DOM pass.
