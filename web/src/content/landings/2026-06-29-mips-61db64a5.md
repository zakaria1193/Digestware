A safety issue on MIPS architectures has been fixed by strengthening the frame barrier mechanism.
Previously, stack pointer modifications could be reordered by the compiler, leading to code that accessed stack memory improperly, especially in interrupt handling scenarios.
This change ensures that stack pointer changes are strictly ordered, preventing such unsafe reordering and improving code robustness.
