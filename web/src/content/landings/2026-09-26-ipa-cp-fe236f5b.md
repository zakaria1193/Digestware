The ipa-cp pass in GCC now passes `widest_int` parameters by const reference to `set_to_constant`, `meet_with`, and `meet_with_1` functions. `widest_int` is a large inline-buffer type, and these functions only read its values. This change avoids unnecessary copying of this large type, leading to a potential performance improvement without altering functionality.
