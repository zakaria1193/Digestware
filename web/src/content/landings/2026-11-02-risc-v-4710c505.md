This commit introduces new test cases to ensure the `vfwredosum.vs` RISC-V vector instruction correctly handles register allocation. It focuses on preventing the destination register (`vs1`) from overlapping with the source register group (`vs2`), which is a requirement of the RISC-V vector specification for operations involving different element widths. The tests cover various data types and modes to ensure robust code generation.
