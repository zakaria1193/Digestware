The RISC-V assembler has been updated to account for potential code shifts caused by RVC (RISC-V Compressed) instruction relaxation. When relaxation is enabled and RVC code precedes a region requiring alignment, the assembler now reserves up to two bytes to prevent alignment gaps from becoming too small. This ensures correct alignment in scenarios where relaxed RVC instructions might alter code placement.
