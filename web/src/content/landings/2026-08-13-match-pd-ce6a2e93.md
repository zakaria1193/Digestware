A new simplification rule has been added to `match.pd` to handle expressions of the form `(t * u) % u`. When the multiplication `t * u` is guaranteed to not overflow, the result of the modulo operation will always be zero. This rule applies to various modulo codes (TRUNC_MOD_EXPR, MODULO, mod) and extends the existing fold for `(t * u) / u` to its remainder counterpart, improving code efficiency by eliminating redundant operations.
