The GCC AVR backend has gained support for the new target option `-mprune-vectab`. This option serves as a frontend for a corresponding linker feature (`--prune-vectab`) that aims to optimize by removing unused entries from vector tables. The compiler option is active only when the linker supports the feature, which is verified during configuration.
