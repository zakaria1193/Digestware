This commit resolves a heap overflow issue in GCC's Fortran compiler when assigning a CLASS array to an allocatable array of a specific TYPE. The problem occurred because the reallocation for the target array incorrectly used the size of the CLASS container instead of the declared TYPE's element size. This led to overflows for larger types or incorrect sizing for smaller ones. The fix ensures that the element size is correctly taken from the declared type of the CLASS expression during assignment.
