The s390 assembler's instruction format RRF_FE0FF, where the first operand is in bits 16-19, has been renamed to RRD_FE0FF. This change separates it from the general RRF format starting with the IBM z196 architecture. The 'myr' instruction is updated to use the new RRD_FE0FF format designation.
