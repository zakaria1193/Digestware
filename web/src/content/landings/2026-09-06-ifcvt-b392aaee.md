This commit updates a comment for `MAX_CONDITIONAL_EXECUTE` in the GCC ifcvt pass to clarify its usage. While the name suggests a limit on conditional execution, it also governs the number of instructions that branchless paths can speculate. The comment now explains that this limit is tested in `noce_process_if_block` and `check_cond_move_block`, and notes that the default configuration implies an unpredictable branch cost. This is a documentation-only change.
