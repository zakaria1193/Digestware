This commit addresses multiple issues in the Fortran frontend related to parameterized derived types (PDTs) and strings. It ensures that PDT arrays with explicit array specifications are correctly handled, marks allocatable components with deferred types, and skips string length checks for PDT types. Additionally, it refines array referencing and memory allocation for PDT strings and arrays, and scalarizes PDT string arrays in the `TRANSFER` statement.
