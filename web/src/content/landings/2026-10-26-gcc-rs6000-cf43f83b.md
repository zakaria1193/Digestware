GCC now supports new PowerPC vector load and store instructions designed for a future architecture revision. Unlike current instructions that require the byte count in the most significant bits of a register, these new variants expect it in the least significant bits. This change simplifies code generation by avoiding bit shifts and is enabled with the `-mcpu=future` flag. It also corrects an issue where these instructions were incorrectly generated for 32-bit systems.
