This commit fixes an issue in the V850 compiler port where the length calculation for conditional branch instructions was incorrect for older V850 variants. Newer V850 variants (E3V5 and later) have extended the range of conditional branches. The code update to accommodate this extension incorrectly assumed the longer branch forms were always available, leading to incorrect instruction lengths being calculated for older targets. The fix ensures that the correct length is computed based on whether the extended conditional branch features are available.
