This commit fixes a bug in the Fortran compiler where the type of a CLASS associate name with an inferred type was being incorrectly resolved. When the associate name's selector was a function not yet parsed, `resolve_variable` would call `gfc_fix_class_refs`, which erroneously added a `_data` reference to polymorphic array component references. This made the expression non-polymorphic and caused `SAME_TYPE_AS` to be folded to `.false.` at compile time. The fix prevents `gfc_fix_class_refs` from being called on inferred-type references that `gfc_fixup_inferred_type_refs` has already processed.
