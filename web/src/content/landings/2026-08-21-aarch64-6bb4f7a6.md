This commit removes a duplicate mode attribute in the AArch64 configuration files. The saturating narrowing optab names were given a new lowercase `vnarrowq` attribute, but `Vnarrowq` already mapped to the same three modes. This redundancy is resolved by dropping the newly added attribute, simplifying the configuration and preventing potential naming conflicts.
