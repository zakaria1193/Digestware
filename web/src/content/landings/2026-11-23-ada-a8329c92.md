This commit fixes a categorization issue in GCC's Ada front-end where a `pragma Pure` on a library package or subprogram was not always correctly recognized if the subprogram had limited parameters. The `Get_Categorization` routine in `sem_cat.adb` has been updated to ensure the `Is_Pure` flag is set when a `pragma Pure` is present, resolving this corner case for pure library procedures.
