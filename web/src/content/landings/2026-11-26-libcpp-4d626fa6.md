The scripts `gen-printable-chars.py` and `gen-combining-chars.py` have been rewritten to parse `UnicodeData.txt` directly, rather than relying on Python's `unicodedata` module. This change ensures that the character tables used by `libcpp` are regenerated based on the latest Unicode standard (18.0), mitigating potential staleness issues with older Python library versions. The patch includes updated README information and regenerated `.inc` files.
