A bug in the Fortran frontend caused parenthesized scalar CLASS variables passed as actual arguments to be aliased instead of copied. This led to a segfault when such variables were passed to TYPE dummies with allocatable components, as the components were incorrectly copied and freed. The fix ensures these arguments are properly copied, with the copy's lifetime managed correctly to avoid issues with its components.
