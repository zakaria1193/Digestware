This commit addresses an issue in the Ada compiler's semantic resolution for membership tests. Specifically, it corrects the special handling for expressions of universal numeric types. The previous implementation incorrectly applied a rule meant for universal_integer types to universal_real types. This change restricts the special resolution to universal_integer, as the range check failure it aims to prevent is not applicable to real types, ensuring correct behavior according to the Ada Reference Manual.
