This commit refactors the expand pass to improve how values are extracted from tuple types, particularly in the context of vector operations. New functions are introduced to handle multi-vector-register to vector conversion and vector-element extraction, simplifying the target's responsibility. This change resolves a regression on aarch64 concerning `struct_3_256.c` and improves code generation by preventing unnecessary spills to memory when extracting bit fields from vector types.
