This commit resolves an internal compiler error (ICE) on the AArch64 target that occurred during TImode comparisons involving SUBREGs. The issue stemmed from the `aarch64_gen_compare_reg` function incorrectly using `operand_subword` when operands were SUBREGs, leading to NULL_RTX returns. The fix replaces `operand_subword` with `force_lowpart_subreg` and `force_highpart_subreg`, which correctly handle nested SUBREGs and prevent the ICE.
