The ASSERT_PRINT_EQ macro, used in JSON selftests, has been renamed to ASSERT_JSON_PRINT_EQ and moved to json.h. This change consolidates repeated assertions into a single, more specific macro, reducing code duplication. No functional changes are intended; this is purely an internal refactoring for maintainability.
