This commit fixes a bug in the live lane extraction dominance check within the vectorization pass, specifically when dealing with PHI (Промежуточная Инструкция) nodes. Previously, the compiler did not correctly verify the dominance of the vector definition with the scalar use in cases involving PHI uses. The fix ensures that the respective PHI edge source can reach the definition, thereby correctly establishing dominance. This resolves PR tree-optimization/126862 and improves the accuracy of vectorization by ensuring scalar uses of PHI nodes are properly dominated by their vector definitions.
