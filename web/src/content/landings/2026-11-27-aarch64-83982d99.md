A recent change on AArch64 incorrectly replaced `gimple_build_call_internal` with `build_ifn_call` for the `IFN_STORE_LANES` intrinsic. Since `IFN_STORE_LANES` returns void, this led to a type mismatch when the compiler attempted to assign its return value, causing an Internal Compiler Error (ICE). This patch reverts the change specifically for this call site.
