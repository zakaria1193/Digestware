This commit improves the `cond_if_else_store_replacement_limited` optimization in GCC's `cselim` pass. It now supports skipping the replacement when a store operation exists on either side of the conditional branch, provided these stores do not interfere with other operations. This change was motivated by code generation for `std::optional::reset` and adds new test cases.
