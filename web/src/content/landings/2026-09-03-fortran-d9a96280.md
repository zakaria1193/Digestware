GCC's Fortran front-end has fixed an issue related to how inherited parameter namespaces are handled for derived types, specifically addressing PR104750. The fix ensures that when modules containing derived types with parameters are read, the correct symbol information and references are loaded. This prevents namespace conflicts and ensures that parameter namespaces are properly transferred or managed, especially for locally declared parameters within derived types.
