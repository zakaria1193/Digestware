The Cobol compiler's parser has been updated to allow the REDEFINES clause to be used with OCCURS at the 01 level. Previously, this was disallowed by overly strict assertions in the parser, hindering certain valid data structure definitions. This change removes those assertions, enabling more flexible data redefinition capabilities in Cobol programs without affecting code generation.
