This commit fixes a regression in OpenMP C++ target offloading where lambda objects used as subobjects of aggregates were no longer correctly mapped. The C++ front-end failed to recognize lambda bases wrapped in location wrappers (VIEW_CONVERT_EXPR). The fix involves stripping these location wrappers when searching for the lambda object's base, thereby re-enabling correct offloading for such constructs and un-XFAILing related test cases.
