The texi2pod.pl script has been updated to support the '@table @option' syntax. This change ensures consistent handling of '@option' when it's used as an indicator within '@table' directives, aligning with existing support for '@option{text}'. Although this specific syntax is not currently used in GCC's documentation, the update benefits projects like binutils-gdb that use a modified version of the script.
