The linker previously used a uint16_t for source_files_count, which counts all source file references across modules. This could wrap around if there were more than 65535 references, leading to an incorrectly sized buffer for the source-info substream and subsequent buffer overflows. This change widens the count to uint32_t to accommodate larger numbers of source files.
