This commit addresses an issue on aarch64 where the `combinez` patterns for scalar and partial vector FP16 types incorrectly used the FMOV instruction even when the `fp16` extension was not available. This led to assembly failures. The fix specializes these patterns for `HF` and `BF` modes and uses the `INS` instruction as a fallback, resolving the bug reported in PR126983.
