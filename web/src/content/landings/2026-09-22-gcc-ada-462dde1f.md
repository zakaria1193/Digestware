This commit corrects an issue where `pragma Pure` was ignored when an Ada expression function was frozen, leading to incomplete freezing of standalone objects. The compiler's freezing machinery in `freeze.adb` has been updated to also freeze standalone objects referenced within the same scope, ensuring correct behavior.
