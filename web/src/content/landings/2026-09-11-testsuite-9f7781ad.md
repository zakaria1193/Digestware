This commit resolves failing tests on i686-linux by adding the `-Wno-psabi` flag to specific `vperm` test cases. These tests were failing due to warnings about SSE vector returns and arguments changing the Application Binary Interface (ABI) when SSE was not explicitly enabled during compilation.
