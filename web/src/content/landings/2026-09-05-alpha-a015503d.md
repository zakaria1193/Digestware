This commit addresses a bug in the Alpha ELF backend where newly allocated GOT (Global Offset Table) entries were not fully initialized, leading to potential reads of uninitialized memory. The `get_got_entry` function previously used `bfd_alloc`, leaving fields like `flags` uninitialized. This was particularly problematic for GOT entries created for TLS relocations. The fix changes the allocation to `bfd_zalloc`, which zeroes out the memory, and subsequently only assigns fields that require non-zero initial values, ensuring all fields are properly initialized.
