This commit refactors the GCC analyzer's symbol consolidation mechanism by replacing `hash_map` with `std::map`. The author found `hash_map` usage to be error-prone and the associated hash calculations to be a performance concern in profiling. By switching to `std::map`, the goal is to simplify the code, improve debuggability, and reduce the overhead from hashing, without introducing any functional changes to the analyzer's behavior.
