primer_glossary:
- term: LRA
  definition: Local Register Allocation. A compiler optimization pass responsible
    for assigning program variables to physical machine registers within a function
    or basic block. It aims to minimize memory accesses by keeping frequently used
    values in registers.
- term: Spill Candidate
  definition: A variable or temporary value that the register allocator decides cannot
    be held in a physical register at a certain point. It must be 'spilled' to memory
    to free up the register for other uses.
- term: Live Range
  definition: The portion of a program's execution during which a variable or temporary
    value holds a meaningful value and might be accessed. The register allocator considers
    live ranges when deciding where registers can be reused.
- term: Pseudos
  definition: Virtual registers used by the compiler during register allocation. They
    represent program variables or temporaries that may or may not be assigned to
    a physical register.
- term: Reload Pseudos
  definition: Virtual registers that require a load from memory before use and potentially
    a store to memory after modification, as they could not be permanently assigned
    to a physical register.

The Local Register Allocation (LRA) pass has been optimized to speed up the process of evaluating spill candidates. By reducing redundant traversals of live ranges and limiting the collection of reload pseudos, compile times for certain complex functions on x86_64 have been reduced from 17.8 seconds to just 0.9 seconds.
