In gccrs, several functions within the `Rust::Compile::handlers::inner` namespace have been declared as `static`. This change aims for code consistency and a minor optimization by allowing the linker to potentially eliminate unreferenced functions and improve symbol visibility. The forward declaration for the inner namespace in `rust-intrinsic-handlers.h` was also removed as it is no longer necessary.
