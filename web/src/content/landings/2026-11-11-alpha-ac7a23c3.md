The Alpha architecture now supports the `-mlra` option and enables the new register allocator (LRA) by default on BWX (Byte, Word, and eXtreme) targets. This change aligns with the planned removal of the older 'reload' mechanism. LRA is gated on `TARGET_BWX` because non-BWX targets have known issues with LRA handling of spilled QImode or HImode pseudos. The default behavior, controlled by `alpha_option_override`, dynamically tracks CPU types like `ev56` (BWX) which enables LRA, while older CPUs like `ev4` (non-BWX) continue to use reload.
