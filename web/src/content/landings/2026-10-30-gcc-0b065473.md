This commit updates `set_bitmask` to handle pointers directly, eliminating special cases in the CCP (Constant Code Propagation) pass. Previously, CCP had specific logic for pointers that limited information to alignment. By processing pointers within `set_bitmask`, this information is handled more generally, simplifying the CCP implementation.
