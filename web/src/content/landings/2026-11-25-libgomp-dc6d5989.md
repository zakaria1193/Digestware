This commit introduces OpenMP 6.1's omp_cgroup_mem_space, initially aliasing it to omp_low_lat_mem_space. It also updates memory space assignments for other allocators and rectifies issues in the OMP_ALLOCATOR environment variable parsing, ensuring support for ompx_gnu_managed_mem_space and handling of pinned and managed memory allocations.
