The GCC `MAINTAINERS` file has been updated to include a list of inactive email addresses for existing contributors. These addresses, gathered from Git history and previous `MAINTAINERS` file versions, serve as an archive to help match past contributions, particularly for users with Sourceware Forge accounts. Active email addresses are not duplicated, and these archived addresses are not actively used for routing or assignment.
