This commit enables GCC to recognize a specific pattern for unsigned saturating addition on AArch64: `X + MIN(~X, Y)`. This pattern is mathematically equivalent to `X + Y` with saturation. The optimization transforms a sequence of four instructions into two, improving code density and performance. A test case ensures the pattern is correctly applied only when the `MIN` operation has a single use.
