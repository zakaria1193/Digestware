This commit updates the configuration scripts across various GCC components to replace the obsolete `AC_CONFIG_HEADER` macro with its modern equivalent, `AC_CONFIG_HEADERS`. This change is a maintenance update to align with current Autoconf practices and does not alter the behavior or the output of the generated configuration files. It addresses bug report PR bootstrap/103459.
