Gprofng has been updated to correctly handle `DW_AT_decl_file` with a value of 0 in DWARF 5. Previously, this was rejected, causing functions declared in the primary source file to be erroneously associated with a header file. This change ensures that declarations within the primary source file are now accurately reported.
