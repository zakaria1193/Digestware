A test case for vectorized complex fused multiply-add operations (`complex/fast-math-complex-mls-outofplace-float.c`) has been updated to remove its ARM-specific expected-fail status. Recent changes in how the COMPLEX_FMS pattern is formed in the ARM backend now allow this test to pass correctly. Verification on an ARM target confirmed the generated code produces correct results.
