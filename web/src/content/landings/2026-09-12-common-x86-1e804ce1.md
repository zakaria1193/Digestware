GCC's common x86 configuration on Darwin now queries the kernel for AVX512 support, as the operating system enables this state lazily. Reading XCR0 directly is unreliable in this context because the state may not be initialized when needed by constructors. This change ensures accurate detection of AVX512 capabilities.
