This commit introduces vectorization for the roundeven math function on x86 architectures. It leverages SSE and AVX instructions, specifically (v)roundp[sd] and vrndscalep[hsd], to efficiently perform this operation on multiple data points simultaneously. The change includes new machine descriptions and test cases for various SSE and AVX instruction sets.
