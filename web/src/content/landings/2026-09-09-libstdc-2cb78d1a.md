GCC's libstdc++ has consolidated configuration defines related to piecewise distributions in the C++ standard library. Previously, separate macros `_GLIBCXX_USE_OLD_PIECEWISE_DISTRIBUTIONS` and `_GLIBCXX_USE_RESULT_TYPE_FOR_PIECEWISE_DENSITIES` were used, leading to non-orthogonal behavior where one could override the other. This change introduces a single macro, `_GLIBCXX_USE_NEW_PIECEWISE_DISTRIBUTIONS`, to manage this configuration, simplifying the code and better reflecting the intended behavior of these distribution types.
