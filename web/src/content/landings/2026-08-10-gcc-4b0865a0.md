GCC's `callback_only` attribute handler has been updated to explicitly reject variadic functions. Previously, the handler and attribute implementation implicitly assumed non-variadic functions, which could lead to undefined behavior. This change adds necessary checks and updates documentation to reflect this restriction, ensuring correct usage of the attribute.
