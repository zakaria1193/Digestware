The `vmul` family of NEON intrinsics for AArch64 has been ported to GCC's pragma-based framework, accompanied by new assembly tests for all variants. This commit also refactors the `gimple_arith` internal function into a template `gimple_arith_base` for better code reuse. Obsolete function definitions in `arm_neon.h` have been removed.
