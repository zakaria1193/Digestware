Several comments in GCC's ifcvt.h header file have been corrected to accurately reflect the code they document. These include clarifying the purpose of fields in `noce_multiple_sets_info` and `noce_if_info`, and correcting the meaning of `need_cmov`. Additionally, a field `and_and_p` was re-typed to a boolean, matching its usage. These are purely documentation and type corrections.
