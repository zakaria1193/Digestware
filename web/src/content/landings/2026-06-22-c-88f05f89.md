The Undefined Behavior Sanitizer (UBSan) in GCC failed to correctly instrument virtual pointer table (vptr) accesses when the vptr was located in an inherited base subobject. Previously, the instrumentation logic for `cp_ubsan_instrument_vptr` attempted to open-code the vfield access but didn't look into the base subobject. This update resolves the issue by utilizing the existing `build_vfield_ref` function, ensuring accurate vptr instrumentation for all inheritance scenarios.
