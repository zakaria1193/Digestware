This commit corrects two bugs in GCC's RISC-V bit manipulation patterns. The first fix ensures that a pattern rewriting 'and+bclr+addiw' to 'bclr+ior' properly preserves the sign extension from 32-bit to 64-bit integers. The second fix addresses a pattern that transforms 'slli+zext+shNadd' into 'slli+shNadd.uw', preventing the generation of negative shift counts, which could occur if costs for certain shifts were reduced in the future.
