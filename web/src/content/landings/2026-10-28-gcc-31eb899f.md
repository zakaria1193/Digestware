This commit resolves multiple minor bugs in the RISC-V backend, identified with the aid of an LLM review. Issues fixed include undefined behavior from shifts by object size, an off-by-one error in rotate synthesis, incorrect instruction generation for AND operations under specific feature combinations, and a design flaw where output could be written before inputs were consumed in overflow and division/modulo expanders. These fixes improve code generation correctness and robustness for RISC-V targets.
