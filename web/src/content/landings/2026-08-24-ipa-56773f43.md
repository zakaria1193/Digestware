This commit addresses an ICE (Internal Compiler Error) in GCC's target clone pass that occurred due to incorrect reference creation. When redirecting edges, the pass failed to associate references with their corresponding call statements. This patch modifies `create_dispatcher_calls` in `multiple_target.cc` to use the call statement variant of `create_reference`, ensuring that references are properly linked. A new test case `pr127023.c` is added to cover this specific scenario.
