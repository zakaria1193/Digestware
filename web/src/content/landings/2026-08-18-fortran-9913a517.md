This commit corrects an error in the Fortran compiler's `resolve_assoc_var` function that incorrectly handled expressions enclosed in parentheses when initializing an associate-name descriptor. The problematic code was removed, allowing the `trans-stmt` function to correctly process these parenthesized expressions, resolving a bug that caused incorrect program behavior.
