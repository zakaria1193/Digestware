This commit significantly expands the test suite for the RISC-V vector instruction `vwmulsu.vx` by adding many new test cases. These tests specifically target scenarios involving register group overlap, ensuring the compiler correctly handles these complex cases for various data types and vector lengths. This aims to improve the robustness of vector code generation.
