The `readelf` utility now folds its 32-bit and 64-bit specific functions for parsing section and program headers into generic routines. This change, addressing PR binutils/34356, reduces code duplication by allowing the same code to handle different integer types. A new `readelf-nn.c` file is introduced to house these generic functions, while `readelf.c` is refactored to use them, improving maintainability.
