This commit refactors several machine-specific backends (arm, cris, frv, loongarch, riscv, stormy16) to use the `add_reg_note` function instead of manually constructing instruction notes. This promotes code consistency and leverages the internal `add_reg_note`'s handling of RTL structures. The changes primarily affect functions related to multi-register operations and epilogue emission, ensuring that register-related metadata is managed uniformly.
