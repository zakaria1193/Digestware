This commit enhances the `factor_out_conditional_load` optimization pass in GCC by adding support for `TARGET_MEM_REF`, which represents memory references with target-specific constraints. Previously, this optimization could not handle `TARGET_MEM_REF` instances, leading to less optimal code generation. The update allows the pass to factor out loads that use `TARGET_MEM_REF` under specific conditions, improving generated code quality and achieving comparable performance to LLVM for certain benchmarks.
