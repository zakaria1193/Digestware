GCC's `mul_ladder_sum1` pattern has been refactored to use the declarative match syntax instead of manually traversing SSA (Static Single Assignment) names. The previous implementation involved checking the GIMPLE statement and its right-hand side code. The new pattern `(mult@mul_hilo1 @2 @3)` achieves the same goal more readably and potentially leverages the pattern-matching infrastructure more effectively, including its valueizer if available.
