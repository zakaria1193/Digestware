A new DEEP_COPY mode has been added to the `gfc_conv_subref_array_arg` function in GCC's Fortran front-end. This mode, defaulting to false, allows temporary array arguments to have their own distinct allocatable components, rather than sharing them with the original argument. This change, which does not affect existing callers, ensures proper memory management for allocatable components by deallocating them after the call, and also fixes two latent issues in the pass_optional path related to descriptor assignment and string length handling.
