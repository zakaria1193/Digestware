This commit enhances GCC's `match.pd` pattern matching to improve vectorization of conditional expressions. Previously, it could sink conversions and unary operations into `VEC_COND_EXPR` if both arms folded, but it did not handle `FLOAT_EXPR` or `FIX_TRUNC_EXPR`. The change extends this sinking capability to these conversion types, allowing vector code like `!(a[i] >= b[i])` to be vectorized more efficiently by selecting float constants directly, rather than integer constants followed by a conversion.
