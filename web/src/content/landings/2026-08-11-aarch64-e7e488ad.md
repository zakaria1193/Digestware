This commit optimizes floating-point comparisons on AArch64 by using a single condition mode (`CCFPmode`) when exceptions like NaN-related invalid operations are unobservable, such as with `-ffinite-math-only`. Previously, both ordered and equality comparisons might emit separate instructions even when the exception difference was irrelevant. This change consolidates the instruction selection, potentially improving code density and performance. It also updates existing assembly scans and adds new tests.
