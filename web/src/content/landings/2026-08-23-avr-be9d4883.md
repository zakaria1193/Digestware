This patch introduces `.gnu_attribute` tags to AVR object files, specifically indicating the bit sizes used for `double` (8 bits) and `long double` (12 bits). This tagging is performed by new mini-passes that scan the code and varpool for the presence of these types. This information helps manage shared multilibs and ensures correct linking when different floating-point precisions are involved.
