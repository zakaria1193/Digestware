This commit addresses compiler warnings related to deprecated `std::unexpected()` and its handler functions within libstdc++. Specifically, for ARM targets with unwinders enabled, the code in `libstdc++-v3/libsupc++/eh_call.cc` was triggering these deprecated warnings, which were treated as errors due to the `--enable-werror` build flag. The change selectively mutes these warnings for the relevant code block.
