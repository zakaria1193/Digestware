The test case avx2-shiftqihi-constant-1.c previously failed due to unexpected instruction generation when AVX2 was enabled by default. This commit modifies the test to explicitly use the -mno-gfni flag, preventing the generation of vgf2p8affineqb instructions and resolving the test failures.
