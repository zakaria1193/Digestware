libcc1 has updated its `configure.ac` file to use the `AC_CONFIG_HEADERS` macro instead of the now-obsolete `AC_CONFIG_HEADER`. This change ensures that the build system's autoregeneration scripts function correctly, preventing missed header regenerations that previously caused issues.
