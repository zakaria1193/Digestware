This commit addresses two issues in GCC's Cobol implementation. First, the `__gg__char_national` function was not exported correctly; it is now added to the export map and its result is assigned to an alphanumeric type instead of a numeric one. Second, the `UNSTRING` function no longer improperly modifies invalid POINTER arguments, preserving their original value while still setting the OVERFLOW flag when appropriate.
