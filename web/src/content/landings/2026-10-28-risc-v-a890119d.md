GCC reverts changes that allowed register overlap for the RISC-V vector widening unsigned multiply-add instruction (vwmaccus.vx), which uses a scalar register. This ensures compliance with the vector specification's prohibition on a single register serving operands with disparate Effective Element Widths. Test cases and instruction definitions are updated.
