The test case for the RISC-V `march-help.l` in `gas/testsuite` has been updated to reflect the `smpmpmt` extension as version `1.0`. Previously, it was incorrectly listed as `0.6`. This ensures that the assembler's `--march=help` output accurately displays the version number for this RISC-V extension, preventing potential confusion for developers using the command-line help feature.
