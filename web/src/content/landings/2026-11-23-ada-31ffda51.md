This commit corrects an issue in GCC's Ada front-end where dynamic allocations for mutably tagged types were using the size of the root type instead of the maximum size specified by the `Size'Class` aspect. The `Expand_Allocator_Expression` and `Expand_N_Allocator` routines have been updated to allocate the correct, larger size when the designated type is mutably tagged, ensuring proper memory management for these types.
