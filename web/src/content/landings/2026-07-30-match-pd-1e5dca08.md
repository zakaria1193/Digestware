This commit enhances the `match.pd` pattern matching to correctly optimize the parity of bit-reversed values. Previously, certain bit-reversal operations, particularly for generic `_BitInt` types and all bit-reverse builtins, were not recognized. This update allows the compiler to simplify expressions like `parity(bitreverse(x))` more effectively, similar to how it handles `parity(bswap(x))`.
