The gccrs compiler now supports the `assert_uninit_valid<T>` intrinsic and refactors the handling of related assertion intrinsics. The changes consolidate `assert_zero_valid`, `assert_uninit_valid`, and `assert_inhabited` into a single handler, mirroring the implementation strategy of the Rust compiler (`rustc`). This consolidation is necessary because these intrinsics share significant verification logic. New test cases are included for `assert_uninit_valid` and `assert_zero_valid`.
