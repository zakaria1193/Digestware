This commit renames several configuration variables within the libgm2 library, including GLIBCXX to GLIBGM2, and libcxx/libstdcxx to libgm2. These changes were made to improve consistency and reduce confusion, as the configuration process was partially imported from libstdc++.

The affected files include various Makefiles, acinclude.m4, configure.ac, and source files, all regenerated after the variable renaming.
