This commit corrects mode mismatches in the RISC-V bitmanip.md file, addressing issues found by an LLM review. Two patterns incorrectly used narrower modes for operands when the operation required a wider mode. The fix involves using the full DI (Double Integer) mode for shift counts, ensuring correct masking of bits and resolving testsuite regressions.
