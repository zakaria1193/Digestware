The RISC-V toolchain now supports the Zibi extension, which introduces two new branch instructions: `beqi` and `bnei`. These instructions compare a register with a small immediate value and provide the same branch range as register-based branches. The immediate value must be -1 or between 1 and 31, with -1 encoded as 0. This extension is currently at version 0.9.
