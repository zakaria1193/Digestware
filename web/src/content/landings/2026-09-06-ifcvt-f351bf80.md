This commit addresses several small cleanup issues within the GCC ifcvt pass. It removes a redundant store operation in `cond_exec_find_if_block`, simplifies pointer comparisons against NULL_RTX, adopts range-based for loops for better readability, and corrects a type mismatch in an argument. These changes improve code style and maintainability without affecting functionality.
