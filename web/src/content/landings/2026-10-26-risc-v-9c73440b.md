This commit expands the test suite for the RISC-V Vector extension by adding new test cases for the `vfw{macc,msac}.vv` instructions. These tests specifically target scenarios involving register overlap, ensuring correct behavior when the destination and source registers for these vector operations might overlap. The tests are designed to be used when the `csrr` instruction is not part of the assembly check and overlap is enabled.
