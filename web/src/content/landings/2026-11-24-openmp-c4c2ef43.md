This change fixes an issue in OpenMP's Fortran support where the mapping of allocatable components within global variables was incorrect. The `scan_sharing_clauses` function has been reordered to properly handle the deep mapping required for these Fortran constructs. Previously, global variables returned too early, preventing the `flex_array_ptr` boolean from being set correctly, which is necessary for this deep mapping.
