Several Python scripts in GCC's `contrib` directory have undergone cleanup to adhere to better coding practices and to resolve potential warnings from newer Python versions. This includes removing C-style semicolons, unused imports, and incorrect `None` comparisons. Additionally, regular expression strings were converted to raw strings to prevent misinterpretation of backslashes, and unreachable code was removed from a script. These changes aim to improve code quality and maintainability without altering script functionality.
