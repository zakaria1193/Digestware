This commit modifies the Alpha linker to emit the R_ALPHA_IRELATIVE relocation type when handling PIC (Position Independent Code) links that involve IFUNCs (Indirect Functions). Previously, the linker would emit R_ALPHA_RELATIVE, which would resolve to the IFUNC's resolver rather than the actual function selected by the resolver. This change ensures that the correct relocation is used, improving the correctness of PIC linking for IFUNCs on Alpha.
