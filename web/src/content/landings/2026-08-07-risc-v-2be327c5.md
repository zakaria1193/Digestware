This change allows the RISC-V vector instructions vwmacc.vv and vwmaccu.vv to utilize register group overlap. Similar to other vector instructions like vwadd.vv and vwmul.vv, this relaxation in register constraints provides the compiler with more flexibility in scheduling and register allocation, potentially leading to improved performance by enabling more efficient use of the vector register file.
