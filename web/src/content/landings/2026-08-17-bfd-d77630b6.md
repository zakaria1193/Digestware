This change introduces a new function, ``compatible_format``, in ``elflink.c`` to consolidate various checks that determine if an input object file is compatible with the linker's output. This function is then used in several places, including ``_bfd_elf_link_create_dynstrtab`` and ``_bfd_elf_link_iterate_on_relocs``, to ensure consistency and reduce code duplication.
