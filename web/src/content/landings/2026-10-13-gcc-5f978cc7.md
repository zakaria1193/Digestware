- term: prange
  definition: Pointer range. A representation within GCC's analysis passes that tracks
    information about pointer values, including potential aliasing and points-to sets.
- term: points-to set
  definition: The set of memory locations that a pointer might possibly point to,
    as determined by alias analysis.
- term: points-away
  definition: A state in pointer analysis indicating that two pointers are known not
    to alias each other, or that a pointer cannot be resolved to a specific memory
    location.
- term: IPA
  definition: Interprocedural Analysis. Compiler analysis that considers the entire
    program, including all functions, rather than just one function at a time.
- term: alias analysis
  definition: Compiler analysis to determine whether different memory references might
    refer to the same location.

GCC's range comparison operators (`==` and `!=`) for pointer information have been updated to correctly produce a 'points-away' result when the objects are not equal and one has a defined points-to field. Additionally, `ipa_record_return_value_range_1` now bails out early if a 'points-away' field is present, improving the robustness of alias analysis.
