The ``crontab`` file and ``git_update_version.py`` script were updated to reflect the development of GCC 17.  The build infrastructure now creates snapshots from the trunk for GCC 17, and adds GCC 16 snapshots from the release branch. This ensures that both the current development version and the previous release branch have up-to-date snapshots available.
