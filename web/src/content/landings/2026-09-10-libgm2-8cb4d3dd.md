This commit provides a fallback mechanism in libgm2 for the GetTimeRealtime function. If the clock_getttime function is not available on a system, the library will now attempt to use getttimeofday instead, mirroring the approach taken by libstdc++.

This change ensures that time-related functionality remains available on a wider range of systems by providing a compatible alternative when the preferred POSIX API is missing.
