GCC's COBOL front-end now supports a new warning option, `-Wdynamic-call`. This option flags `CALL` statements where the target is not a constant symbol, meaning the call will be resolved at runtime. This provides developers with better visibility into dynamic call behavior, which can be important for performance and debugging. Constant targets are exported as symbols for standard linker resolution.
