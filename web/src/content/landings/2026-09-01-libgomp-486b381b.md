Libgomp, the OpenMP runtime library, now offers control over Unified Shared Memory (USM) through the `GOMP_RUNTIME_USM` environment variable. This allows developers to explicitly enable, disable, or set USM to 'auto' mode, where it's conditionally used for integrated GPUs. The change includes parsing logic for the environment variable, integration into the runtime initialization, and documentation updates. Verbose environment output also now reflects USM settings.
