This commit modifies gccrs to return an empty file name when the lexer is processing input from a non-file source, such as an inline string. Previously, attempting to access a file name in such a scenario would cause the compiler to crash. Returning an empty string instead provides a safe fallback, ensuring stability when handling string-based input.
