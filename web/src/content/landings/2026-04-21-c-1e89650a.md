GCC now recognizes the `[[gnu::trivial_abi]]` attribute (and its Clang-compatible spelling `[[clang::trivial_abi]]`), which forces types to be treated as trivial for ABI purposes, enabling them to be passed in registers instead of by invisible reference.  This fixes ABI compatibility issues when linking GCC-compiled code with Clang-compiled code that uses `trivial_abi` types.  This ensures consistent call conventions across compilers.
