GCC now recognizes the ``[[gnu::trivial_abi]]`` attribute, which allows types to be treated as trivial for ABI purposes, enabling them to be passed in registers instead of by invisible references.  This fixes call convention mismatches when linking GCC-compiled code with Clang-compiled object files that use ``trivial_abi`` types. The attribute can be specified as  ``__attribute__((trivial_abi))`` or ``[[clang::trivial_abi]]``.
