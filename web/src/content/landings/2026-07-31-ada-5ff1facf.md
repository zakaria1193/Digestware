This change corrects an error in the Ada compiler's validity checking mechanism when the '-gnatVa' flag is used. Specifically, it addresses an issue where a bogus error was reported for function calls that return a value and also involve an 'In Out' or 'Out' parameter. The fix ensures the copy-out statement for these parameters is inserted correctly.
