This change modifies the linker's LTO plugin to set the symbol resolution to `LDPR_PREVAILING_DEF` for common symbols encountered in regular objects when processing an undefined or common symbol from an IR object. This addresses a bug where an incorrect resolution (`LDPR_RESOLVED_EXEC`) was used, potentially leading to issues when common symbols' sizes or alignments are overridden. New test cases are added to verify the fix.
