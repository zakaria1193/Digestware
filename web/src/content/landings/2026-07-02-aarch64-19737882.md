The MLBI instruction and its corresponding system register aliases have been removed from the `sys-rt-alias.d` and `sys-rt-alias.s` test files in the aarch64 assembler's test suite. This change aligns with the previous reversion of MLBI support, ensuring test cases reflect the current state of architectural feature support.
