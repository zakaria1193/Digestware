This commit enhances the pattern matching capabilities for modulo operations, specifically for expressions like `X % Y < Y` and `X % Y >= Y`. Previously, these patterns were only optimized under specific conditions (e.g., non-negative inputs). The update generalizes these rules to cover all input values, enabling the compiler to perform more aggressive and correct optimizations for a wider range of modulo-related code.
