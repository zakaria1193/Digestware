The GCC MATCH (Machine Architecture Tree Transformation) system has gained new patterns to simplify bitwise operations on values that have undergone both zero and sign extensions. Specifically, it now folds `(zero_extend & sign_extend)` to yield the `zero_extend` result, and `(zero_extend | sign_extend)` to yield the `sign_extend` result. This optimization flattens redundant operations, potentially leading to more efficient machine code and has been validated with a new test case for PR122848.
