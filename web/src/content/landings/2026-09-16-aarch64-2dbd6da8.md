This commit addresses an issue with macro management for AArch64 Scalable Matrix Extension (SME) builtins. It ensures that all macros defined within a `.def` file are properly undefined at the end of the file's inclusion. This prevents macro leakage and potential conflicts when subsequent `.def` files are processed. Specifically, the `DEF_SME_FUNCTION_GS` macro was missing its corresponding `undef` directive.
