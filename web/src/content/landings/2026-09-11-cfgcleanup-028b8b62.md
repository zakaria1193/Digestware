This change modifies the `cfgcleanup` pass to prevent tail merging for the predecessors of computed gotos. Previously, these tails were merged unconditionally, which interfered with the `pass_duplicate_computed_gotos` pass. By gating tail merging on the same condition as tail duplication (`!optimize_function_for_size_p && flag_expensive_optimizations`), this commit ensures that tail duplication can occur when beneficial. This results in smaller code size for certain computations and enables better optimization in specific scenarios, as demonstrated by aarch64 code size reductions.
