This change addresses a bug where Fortran's alignment calculations for components did not always account for the minimum required alignment of the component's type. For example, the i386 ABI aligns `real(8)` to 4 bytes, leading to incorrect spacing calculations. The fix compares element length against `min_align_of_type` instead of just the alignment, improving accuracy for structures with non-standard component alignments. New test cases are included.
