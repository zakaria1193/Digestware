This commit addresses data corruption issues in the Fortran compiler (gfortran) that occurred when assigning derived type expressions to class components or derived type components. It ensures that allocatable components are properly copied during such assignments. Additionally, it handles the case of assigning a class expression to a scalar class component by correctly allocating the component and using vptr copy, thus preventing data corruption.
