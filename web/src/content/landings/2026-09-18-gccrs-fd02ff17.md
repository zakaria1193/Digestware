gccrs has been fixed to correctly handle substitutions involving nested generics, resolving Rust-GCC/gccrs#4884. The changes in `rust-type-util.cc`, `rust-typecheck-context.cc`, and `rust-tyty-subst.cc` ensure that substitutions account for already used arguments in nested generic structures like `GenericSplitN< Split <T,P>>`. This improves the accuracy of generic type resolution.
