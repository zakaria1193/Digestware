This commit ports the `v{ld,st}{2,3,4}` families of NEON interleaving load/store intrinsics on AArch64 to GCC's pragma-based framework. The change introduces new structs and functions for handling tuple loads/stores and updates the machine description to use these new mechanisms. This migration removes obsolete built-in function declarations and cleans up the intrinsic handling logic.
