This change modifies the Rust compiler frontend to correctly evaluate non-unit tail expressions before any local variable drops occur within a function body. Previously, a non-unit tail call could execute after local drops, potentially leading to incorrect program state. The fix involves storing the result of the tail expression before emitting the drops and then returning the stored value, ensuring proper execution order.
