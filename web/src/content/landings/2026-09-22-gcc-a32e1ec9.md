primer_glossary:
- term: loop vectorization
  definition: An optimization technique that transforms a loop to operate on multiple
    data elements simultaneously using wide vector registers, significantly improving
    performance for data-parallel computations.
- term: live lane extraction
  definition: A specific operation during vectorization where data from a vector register
    is selectively extracted to form a scalar value or to be used in a subsequent
    operation. This often occurs when a loop's body can only be partially vectorized.
- term: costing
  definition: In compiler optimization, costing refers to the process of estimating
    the performance impact (e.g., execution time, instruction count) of various operations
    or code transformations. This guides the optimizer's choices.
- term: vect_body
  definition: Refers to the main part of the loop body that is being considered for
    vectorization.
- term: vect_epilog
  definition: The part of the loop that handles remaining iterations after the main
    vectorized loop has completed. This is often needed when the number of iterations
    is not a multiple of the vector width.

This change enables the cost model to account for 'live lane extraction' operations, which are part of vectorization. It ensures that these costs are consistently applied whether vectorization occurs within the main loop body or in a loop epilog, leading to more accurate cost estimations and potentially better vectorization decisions.
