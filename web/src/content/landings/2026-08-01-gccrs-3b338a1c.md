This commit addresses an issue in gccrs where the compiler erroneously removed unused assignments more than once for the same identifier, as reported in Rust-GCC/gccrs#4674. The fix modifies the `UnusedContext::remove_assign` function to ensure that each unused assignment is removed only a single time. A new test case is included to specifically verify this correction.
