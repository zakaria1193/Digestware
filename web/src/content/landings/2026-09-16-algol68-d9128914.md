This commit enhances the Algol68 compiler's ability to track source code locations. It introduces a `location_t` structure to precisely capture the span of text associated with a parsed node, with the caret pointing to the start of that text. This improves the accuracy of error reporting and debugging information by providing more precise references to the original source code.
