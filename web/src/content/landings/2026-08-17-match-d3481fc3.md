The GCC `match` system now allows a C variable to define the result code or operation within `simplify` expressions. This change significantly reduces the size of generated code by eliminating redundant `for` loops, achieving up to a six-fold reduction in some cases. This is particularly beneficial for enabling ARM builds with the `-O0` optimization level, which previously encountered issues due to excessive code size. The new syntax uses an optional `with` clause to define a C identifier for the result code.
