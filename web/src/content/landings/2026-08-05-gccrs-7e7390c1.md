This commit partially enables support for slice patterns with bound rest patterns (e.g., `x@..`) in GCC's Rust front-end. While full type checking and GENERIC compilation for these patterns are still pending, the compiler now handles them in various stages, including borrow checking and HIR lowering, preventing premature errors.
