This patch refactors the Ada legality check for tagged and untagged types, which previously had separate implementations with distinct error messages. By factorizing these checks into a single rule as defined by the Ada reference manual (7.3), the compiler maintains better consistency and provides a unified error reporting mechanism for this legality rule.
