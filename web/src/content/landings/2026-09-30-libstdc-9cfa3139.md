This commit prevents libstdc++ from corrupting single-architecture builds on AIX by skipping an unnecessary archive repackaging step. GNU binutils' `ar` command has issues merging 32-bit and 64-bit archives, which interfered with single-architecture builds. The change modifies the AIX configuration to avoid this repackaging when only one architecture is targeted.
