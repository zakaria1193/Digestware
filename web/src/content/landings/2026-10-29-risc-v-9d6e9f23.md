This commit addresses register group overlap issues in RISC-V vector instructions vwabda[u].vv. The instructions, which widen absolute differences and accumulate, previously had encodings where source registers could overlap with the destination register group. This commit disables such overlaps by using early clobber constraints and adds comprehensive test cases to verify correct register allocation and prevent incorrect instruction generation.
