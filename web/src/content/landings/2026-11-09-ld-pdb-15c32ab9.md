The linker's PDB handling function `handle_debugs_section` incorrectly assumed a fixed symbol entry size when processing COFF symbol tables. This commit updates it to use `bfd_coff_symesz` to correctly determine the symbol entry size, accommodating the larger 20-byte entries found in bigobj files, thus preventing incorrect parsing of debug information.
