This patch corrects an issue in RISC-V vector operations where variable-indexed element accesses were being mishandled. Previously, gen_lowpart incorrectly reinterpreted sub-Pmode indices, leading to wrong slide amounts in vslideup/vslidedown instructions. The fix uses convert_to_mode to zero-extend these indices, ensuring correct code generation.
