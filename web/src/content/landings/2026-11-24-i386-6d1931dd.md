This commit refactors the mechanism for generating `-Wpsabi` warnings about ABI changes on i386. It introduces a reusable infrastructure, replacing the previous specific handling for zero-width bit-fields. The new system uses a `classify_state` structure to track applied ABI changes and re-classifies types based on old behaviors. This allows for more generalized reporting of ABI deviations whenever a type's classification actually changes, making the warning mechanism more robust and extensible.
