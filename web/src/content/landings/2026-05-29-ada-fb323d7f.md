This commit resolves a dangling reference problem that occurred when using `Bounded_Indefinite_Holders` with `Empty_Holder` objects. The problem arose because the finalization of an empty container failed to deallocate its subpool, which previously resulted in a lingering reference from the global pool. The fix modifies the `Clear` procedure in `libgnat/a-cbinho.adb` to ensure the subpool is always deallocated, even if the container is empty, thereby preventing the dangling reference.
