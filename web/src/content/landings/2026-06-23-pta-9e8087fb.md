This commit adjusts a code comment in `gimple-ssa-pta-constraints.cc` related to the `handle_call_arg` function. The previous comment incorrectly suggested the function was only called in non-Interprocedural Analysis (IPA) mode. The updated comment clarifies that `handle_call_arg` can also be invoked when IPA is active, providing more accurate documentation for developers.
