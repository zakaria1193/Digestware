The stack-checking feature (-fstack-check) on i386 Windows platforms now has an increased protection range. This ensures proper recovery from stack overflow conditions, specifically on some configurations of Windows Server 2025. The change defines STACK_CHECK_PROTECT in config/i386/cygming.h.
