The `STACK_CHECK_PROTECT` value has been increased for 64-bit Windows configurations. This adjustment is necessary for `-fstack-check` to reliably recover from stack overflow conditions, particularly on certain configurations of Windows Server 2025. Users of `-fstack-check` on these platforms should see improved stability in the face of stack overflows.
