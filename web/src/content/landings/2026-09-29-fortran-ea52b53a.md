This commit addresses a bug in the Fortran compiler where type parameter inquiries, such as `s%len` or `s%kind`, were mistakenly treated as variables. This caused associate names to incorrectly point to the string length of `s`, leading to failures in certain test cases like `associate_90.f90`. The fix ensures these inquiries are correctly identified and not treated as variables, resolving the issue.
