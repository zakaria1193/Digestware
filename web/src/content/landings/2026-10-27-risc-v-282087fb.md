This commit optimizes the RISC-V Zbs extension by eliminating redundant masks in bit clear (bclr) instructions. The bclr instruction inherently uses only the necessary lower bits of its index. The compiler now recognizes rotate forms with explicit masks and directly emits the bclr instruction, avoiding unnecessary masking operations on RV32 and RV64 architectures. This simplifies generated code and potentially improves performance.
