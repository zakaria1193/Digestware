This commit adjusts GCC's test suite for C++ coroutines by disabling the '-Winvalid-specialization' warning flag for specific test cases. These tests define specializations for `std::coroutine_handle`, which have been marked with `[[_Clang::__no_specializations]]` in recent revisions, causing the warning to be incorrectly triggered.
