GCC's `ranger_cache::range_from_dom` function has been updated to track abnormal edges during the entire dominator search. Previously, inferred ranges were not added if the predecessor was an abnormal edge. This change enhances the analysis by correctly handling abnormal control flow paths, leading to more accurate range inferences.
