New test cases have been added for the RISC-V vector multiply-accumulate instructions, specifically vwmacc.vv and vwmaccu.vv. These tests cover scenarios including register group overlap, ensuring correct behavior for signed and unsigned operations across various data types and modes. Additionally, specific checks are included for the 'csrr not asm' condition when overlap is enabled.
