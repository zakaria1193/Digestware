This commit addresses an Internal Compiler Error (ICE) and improves diagnostic messages related to return value checks within C++ expansion statements. Previously, the compiler would ICE when attempting to instantiate expansion statements with dependent return values. The fix defers the full evaluation of `check_return_expr` until the final instantiation of the expansion statement, preventing the ICE. It also ensures that diagnostics accurately reflect the situation when return values are dependent or when specializations are involved.
