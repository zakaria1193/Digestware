This commit introduces the foundational logic within GCC's call graph (`cgraph`) to create 'internal callback edges'. These edges are designed for calls to outlined functions, such as `IFN_ASSUME` bodies, which are not typically represented in the main call graph. Unlike regular callback edges, internal ones do not initially have a 'callback-carrying edge', and this patch lays the groundwork for their creation, with the actual edge creation logic deferred to a later patch.
