This commit adds a Neon expander for the `negv2di2` operation on ARM architectures. While ARM's Neon instruction set has a `VSUB.i64` instruction that can perform negation, it lacks a dedicated `VNEG` instruction for this mode. This forces scalarization, which can be inefficient. The new expander utilizes `VSUB.i64` to perform the negation directly using Neon, improving performance.
