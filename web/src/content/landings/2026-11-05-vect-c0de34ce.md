The vectorization pass in GCC has been updated to correctly handle partial vectorization scenarios. Previously, the `vect_do_peeling` function would set the iteration count range to `[0, VF]` even for partial vectorization, which is too conservative. This could lead to incorrect loop unrolling or peeling. The fix ensures that this range is only set when not performing partial vectorization, allowing for more accurate optimization.
