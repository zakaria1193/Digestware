This commit updates RISC-V scan-assembler tests to allow the use of 't' registers, which were previously excluded. The change broadens testing coverage by ensuring that assembly directives and register aliases are correctly handled across different RISC-V core configurations, particularly on the K1 design. This addresses a potential oversight in register alias handling that could lead to test failures.
