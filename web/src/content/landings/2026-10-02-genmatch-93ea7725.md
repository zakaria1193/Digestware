This commit enhances the error handling in GCC's `genmatch` pass. Previously, if a GIMPLE transform required a sequence for a `COND_EXPR` substitution and none was available, the entire matching process would fail. The change modifies the code to jump to the failure label of the current pattern instead, allowing matching to continue with subsequent patterns. This prevents a local failure from causing a global skip of all remaining patterns.
