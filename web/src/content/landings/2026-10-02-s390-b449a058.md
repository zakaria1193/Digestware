The hardware transactional memory (htm) extension is no longer a requirement for using the perform processor assist (ppa) instruction on IBM z15 (arch13) and later architectures. This change reflects that 'ppa' can be used for purposes unrelated to htm, specifically with constrained transactional-execution facilities. The update includes modifications to opcode definitions and test suites to accommodate this.
