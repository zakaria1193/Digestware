The linker's ELF backend now correctly handles errors during garbage collection of input sections. Previously, the `bfd_gc_sections` function could return false on invalid input without the linker reporting a fatal error. This change ensures that if `gc_mark_extra_sections` returns an error, `bfd_gc_sections` also returns false, and `lang_gc_sections` checks this return value to report a fatal error, preventing incorrect linking.
