This commit resolves an issue in the Fortran compiler where class container types were incorrectly used as the element type for array descriptors. This led to erroneous initialization of the element length, impacting runtime behavior such as the `ASSOCIATED` intrinsic. The fix detects class containers and unwraps them before creating array descriptor types, ensuring correct element length calculation and accurate program execution.
