On Darwin (macOS) systems, compiler-generated constants for C++ source code locations are now made linker-visible. This ensures that these symbolic names, which are distinct from regular code symbols, can be correctly resolved by the linker, potentially improving debugging and symbol resolution for C++ programs compiled on this platform.
