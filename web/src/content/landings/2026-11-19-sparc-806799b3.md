This commit resolves an assertion failure in the SPARC backend's `function_arg_record_value` routine. The issue stemmed from incorrect argument slot calculation for structures containing a single float element when passed as the seventh argument. The fix redirects these cases to the `BLKmode` path, ensuring correct stack-based passing on Linux and adding a new test case.
