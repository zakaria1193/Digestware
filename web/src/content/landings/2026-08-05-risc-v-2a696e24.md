This commit enables register overlap for the RISC-V Vector (RVV) `vwmulsu.vv` instruction. By leveraging the `Wvr` constraint in the machine description, this change allows `vwmulsu.vv` to reuse registers in a manner consistent with other widening vector instructions like `vwadd.vv` and `vwsub.vv`. This enhancement is expected to improve code density and potentially performance by enabling more efficient register utilization.
