This commit cleans up the GCC codebase by removing several instances of verbose conditional expressions. It replaces patterns like `condition ? true : false` with the `condition` itself, and `condition ? false : true` with the negation of the condition (`!condition`). This simplification improves code readability and maintainability across various internal compiler files, including `ipa-polymorphic-call.cc`, `tree-ssa-loop-im.cc`, `match.pd`, and Fortran-specific files.
