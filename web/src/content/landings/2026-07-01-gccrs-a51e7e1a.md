The `Identifier` class in gccrs has been moved from `rust-ast.h` to a new file, `rust-ast-identifier.h`. This change allows the `Identifier` class to be included independently of the entire AST definition, making it more convenient to use in various parts of the compiler without pulling in unnecessary code.
