The BPF assembler in binutils previously failed to assemble kernel BPF selftests when using the addr_space_cast instruction with hex-formatted address spaces. This change modifies the assembler to accept various spellings of these address spaces by parsing them as numbers. This ensures compatibility with newer GCC versions that support addr_space_cast and resolves assembly errors that occurred due to literal string matching.
