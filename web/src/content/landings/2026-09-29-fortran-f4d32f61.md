The Fortran compiler's translation process incorrectly created the 'span' variable for a dummy array within a contained procedure, rather than its owning function. This led to an internal compiler error (ICE) when the dummy array was first referenced from the contained procedure. The fix ensures the span variable is correctly associated with the host function, resolving the ICE and enabling proper handling of these array declarations.
