This commit addresses an ICE in the D frontend that occurred in `gimplify_var_or_parm_decl` when handling assertions. The fix ensures that the result type of `assert()` is consistent with its inferred expression type (`void` or `noreturn`). It also refactors the pattern of calling `BUILT_IN_TRAP` into a separate function `build_trap_call` to reduce code duplication.
