This commit addresses an issue in GCC's Algol 68 compiler where the `find_operator` function did not correctly handle standard 'pow' operators and other cross-term operators. The Revised Report specifies abbreviated notations for these, implying type coercions. The compiler now correctly inlines these coercions, such as converting an `int` to `real` when a `real` and `int` operand are used with a power operator, rather than requiring explicit operator definitions for every type combination.
