This commit overhauls how gccrs handles intrinsic compilation by introducing a new `Intrinsic` wrapper class. This class manages the setup of the function block, including parameters and type parameters, allowing lower-level lambdas to focus solely on compiling the function body. This change significantly reduces code duplication, cutting down the `rust-intrinsic-handlers.cc` file by nearly 1000 lines.
