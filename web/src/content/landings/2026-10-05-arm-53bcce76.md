The Arm minipool code has been significantly refactored to manage pools as sets of subpools, each handling constants with common alignment requirements. This resolves subtle bugs that arose from earlier attempts to accommodate 64-bit alignment. The new design also improves the handling of backward references by checking for existing reachable constants before inserting duplicates. Additionally, the code now prioritizes using existing constants in their current pool locations over adding new ones, further optimizing constant usage.
