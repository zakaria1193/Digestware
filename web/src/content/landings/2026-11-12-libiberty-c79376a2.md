The `libiberty` directory within the Binutils project has been synchronized with a recent GCC commit. This update brings changes to the `configure` script, `configure.ac`, and documentation files (`functions.texi`, `strtoll.c`). Notably, it simplifies finding `libiberty_topdir` and replaces an obsolete macro in `configury`, ensuring consistency between the two projects' shared libraries.
