This change updates the PE/COFF object file writer in BFD to correctly encode the alignment of thread-local storage (TLS) variables into the `Characteristics` field of the `_tls_used` directory. This aligns with modern Windows SDKs (starting Windows 8.1) and compilers like Clang and MSVC, ensuring proper runtime alignment for over-aligned thread-local variables.
