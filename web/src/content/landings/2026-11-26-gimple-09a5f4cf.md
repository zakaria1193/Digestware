This commit refactors GIMPLE (GCC's intermediate representation) to access use-operand information through a common base class. Previously, different statement types accessed this information through distinct, non-aliasing records, which could lead to reordering bugs detected by type sanitizers. Using `gimple_statement_with_ops_base` ensures consistent and safe access across all relevant statement types.
