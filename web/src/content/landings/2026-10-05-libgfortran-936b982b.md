This commit resolves a shared memory object leak in libgfortran's `caf_shmem` component. Previously, if the supervisor process terminated due to a signal (like Ctrl+C or a timeout), it would exit without unlinking the shared memory object, leaving it behind. The fix ensures the shared memory object is properly unlinked after its descriptor is passed to child processes, preventing resource leaks and excluding the mapping from core dumps.
