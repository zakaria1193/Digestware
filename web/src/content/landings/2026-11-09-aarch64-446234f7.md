- term: AArch64
  definition: The 64-bit ARM architecture. GCC supports generating code for this architecture.
- term: AdvSIMD
  definition: An extension to the ARM architecture that provides Single Instruction,
    Multiple Data (SIMD) capabilities, similar to SSE on x86. It's used for accelerating
    multimedia and signal processing.
- term: SVE
  definition: Scalable Vector Extension, an advanced SIMD instruction set for ARM
    architecture that allows vector registers to be of variable length, adapting to
    the hardware.

- term: FP16

    to FP32.

    FP32 but less precision.

    code.
- term: machine patterns

    specific machine instructions for a target architecture.

This commit introduces support for several new Advanced SIMD and Scalable Vector Extension (SVE) features on AArch64, specifically related to half-precision (FP16) and bfloat16 (BF16) matrix multiplication. It adds intrinsics for `vmmlaq_f16` and `vmmlaq_f32_f16` in AdvSIMD, and `svmmla_f16` and `svmmla_bf16` in SVE, including overloaded aliases. The changes involve updating C++ front-end builtins, backend patterns, and test suite configurations to recognize and utilize these new hardware capabilities.
