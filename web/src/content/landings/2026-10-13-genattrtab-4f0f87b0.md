This commit modifies `genattrtab` to ensure attribute simplification is performed independently for each instruction code. It introduces a mechanism to clear all simplification marks before processing each instruction, removing the need for a previous `clear_struct_flag` call. This change prevents simplifications from one instruction from incorrectly influencing others, potentially leading to more optimized attribute values and a faster `genattrtab` execution.
