GCC's contrib, libcpp, and libstdc++ components have been updated to align with the Unicode 18.0.0 standard, released on September 16, 2026. This update includes changes to various Unicode data files and regenerates necessary header files. The libstdc++ inline namespace and version code have also been bumped. Testcases have been enhanced to cover new characters and ranges introduced in this Unicode version.
