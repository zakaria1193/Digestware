Two defects related to the `TEAM_NUMBER` intrinsic in Fortran coarrays have been fixed, stemming from work on PR126777. First, when using `-fcoarray=single`, `conv_intrinsic_team_number` incorrectly returned the team handle instead of -1 for the initial team; this is now corrected to always return -1 in this mode. Second, when using `-fcoarray=lib` with `-lcaf_single`, the `_gfortran_caf_team_number` function would dereference a null team handle, causing a segfault; this is now fixed to handle null handles correctly, treating them as the current team. Documentation and a new test case are also updated.
