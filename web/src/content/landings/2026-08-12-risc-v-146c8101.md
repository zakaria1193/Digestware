primer_glossary:
- term: macro-fusion
  definition: A compiler optimization technique where multiple independent machine
    instructions are combined into a single, more complex instruction. This can improve
    performance by reducing instruction fetch, decode, and execution overhead.
- term: RISC-V
  definition: An open-standard Instruction Set Architecture (ISA) based on Reduced
    Instruction Set Computer principles. GCC supports various RISC-V profiles and
    extensions.
- term: load/store pair
  definition: Consecutive load or store instructions that operate on adjacent memory
    locations and can potentially be fused into a single instruction, especially when
    they share a base address and have regular offsets.
- term: post-indexed
  definition: A memory addressing mode where the base address is used for the memory
    access, and then the base address is updated (e.g., incremented or decremented)
    after the access.
- term: pre-indexed
  definition: A memory addressing mode where the base address is updated first (e.g.,
    incremented or decremented), and then the updated address is used for the memory
    access.
- term: RTL

    GCC. It describes operations on registers and memory at a level suitable for instruction
    scheduling and optimization.

GCC introduces several new macro-fusion capabilities for the RISC-V architecture. These enhancements allow the compiler to combine adjacent floating-point and integer load/store pairs, as well as post-indexed load/store operations, into single instructions. The changes also generalize the recognition of pre-indexed load operations. While these fusions are disabled by default and have their checks XFAILed, they pave the way for future performance improvements by enabling the processor to execute more work per instruction.
