The GCC Analyzer's internal representation of simulated memory has been significantly rewritten to address issues with type handling, low-level memory manipulation, and unclear semantics. The new implementation tracks memory content on a per-bit basis, representing memory regions as symbolic ranges with bit offsets and sizes. Instead of storing symbolic values directly, it now uses `symbolic::bit_vectors`, improving the model's robustness and making it easier to fix bugs, especially for C++ and complex memory operations.
