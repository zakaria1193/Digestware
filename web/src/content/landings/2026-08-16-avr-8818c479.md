This commit introduces support for .gnu_attribute 4 (Tag_GNU_AVR_VTABLE_AS) for AVR targets. This allows C++ virtual tables to be placed in specific address spaces, which is crucial for upcoming support in G++ for ISO/IEC TR 18037 'Embedded C' named address spaces. The new attribute helps detect ABI violations by tagging object files with information about the vtable address space used.
