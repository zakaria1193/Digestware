This commit replaces manual instruction type checks with `dyn_cast` across numerous GCC source files. `dyn_cast` is a C++ feature that safely checks and converts pointers between class hierarchies. Using `dyn_cast` instead of predicates like `CALL_P` makes the code more robust by ensuring type safety and reducing the risk of runtime errors, while also simplifying the codebase.
