The RISC-V linker's `riscv_elf_check_relocs` function now consolidates the handling of different Thread-Local Storage (TLS) relocation types. This unification simplifies the code by allowing common checks for relocations that map to GOT_TLS_IE or GOT_TLS_LE, improving maintainability.
