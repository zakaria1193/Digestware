This commit introduces support for new pairwise intrinsic operations on the AArch64 architecture, specifically for SVE2p3 and SME2p3. The new intrinsics include `svaddqp`, `svaddsubp`, and `svsubp`, enhancing the vector processing capabilities for ARM processors. The changes involve defining and declaring these functions, updating machine descriptions, and adding a comprehensive set of new test cases.
