The Rust front-end for GCC (gccrs) has refactored its `Drop` implementation by moving existing helper functions into new, dedicated files named `rust-compile-drop.cc` and `rust-compile-drop.h`. This consolidates all Drop-related logic into a single location, improving code organization and making it easier to maintain and understand. Consequently, the `CompileBlock` and `CompilePatternLet` visitors now utilize these centralized `CompileDrop` functions for emitting scope drop calls and checking Drop trait implementations.
