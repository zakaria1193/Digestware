This commit enhances the vectorizer's ability to match complex multiplication patterns by enabling it to try all eight possible orderings of operands and multiplication variants. Previously, only a limited set of operand permutations were considered. This broader matching, combined with existing checks like `compatible_complex_nodes_p` and data flow analysis, ensures that more valid complex multiplication code can be vectorized without accepting incorrect combinations. This change is a prerequisite for correctly applying the signed zero handling fix on AArch64.
