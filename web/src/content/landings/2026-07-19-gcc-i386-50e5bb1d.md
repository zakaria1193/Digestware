This commit introduces AVX10/v2 intrinsics for converting FP32 (single-precision float) to FP8 (BF8/HF8) formats, specifically supporting Single-Source Round-To-Odd (RTO) behavior. It adds support for 128, 256, and 512-bit vectors, including masked operations. New intrinsic definitions, built-in descriptions, and machine code patterns are included, along with test cases, to enable these specialized conversions for AI and HPC workloads on compatible x86 hardware.
