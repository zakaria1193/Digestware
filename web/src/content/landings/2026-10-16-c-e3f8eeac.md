This commit addresses an alignment problem in C++ where virtual bases with stricter alignment requirements than the containing class could lead to misaligned memory accesses. Previously, the compiler assumed full alignment for all subobjects, causing issues like the SLP vectorizer using `movaps` instructions that would fault. The fix ensures that references to potential base subobjects use the correct, potentially lower, alignment.
