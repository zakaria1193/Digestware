This commit addresses several issues in the Fortran frontend and the OpenMP runtime. It includes janitorial fixes for parameterized derived types in Fortran I/O, corrects checks for `safelen >= simdlen` in OpenMP clauses, and silences failing C++ test cases for OpenMP `declare variant` by adding an xfail directive. These changes improve compiler correctness and test stability.
