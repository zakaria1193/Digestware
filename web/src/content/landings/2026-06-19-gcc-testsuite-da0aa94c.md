  only valid test results are reported.

The GCC test suite now extends its skipping of `-g3` debug information tests to Darwin 23 and later operating systems. This change addresses an incompatibility where the `dyld`-based linker on these newer Darwin versions does not function correctly with the output generated by GCC at the `-g3` debug level. The affected tests, `dwarf2-macro.c` and `dwarf2-macro2.c`, will bypass this configuration to prevent failures.
