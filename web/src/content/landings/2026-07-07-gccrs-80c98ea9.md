GCC's Rust compiler now uses EH_ELSE_EXPR to manage block-scope drop cleanups within TRY_FINALLY_EXPR. This change ensures that Drop implementations are correctly invoked during normal control flow exits, even before full stack unwinding support is integrated into the compiler. The normal cleanup path now uses the Drop cleanup, while the exceptional path uses an empty statement.
