This commit resolves an issue in GCC where explicit settings for certain i386 target options were not being preserved correctly when function-specific target attributes were applied. Options like `-mstack-protector-guard` and `-mbranch-cost` were previously saved only by value, not by their 'explicit-set' status. This caused functions with target attributes to revert to default options unexpectedly. By using the `Save` directive instead of manual copying, both the value and the explicit-set bit are now preserved, ensuring consistent behavior across LTO streaming and function attributes.
