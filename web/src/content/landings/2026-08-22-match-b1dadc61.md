This commit removes several unused result captures from widening multiply matches in the `match.pd` file. By reducing the amount of data stored in result operands, these changes offer a slight improvement in compiler speed. The affected patterns include `mul_carry_low_sum`, `mul_low_accum`, and several `mul_ladder_sum` variations.
