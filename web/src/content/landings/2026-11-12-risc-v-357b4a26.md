This commit addresses a register overlap issue in the RISC-V `vwsub[u].wv` instruction. The instruction's specification requires that `vs1` (with EEW = SEW) must not fall within the register group of `vs2` (which uses EEW = 2 * SEW). This commit enforces this rule by applying the Wn4 constraint to the `vs2` operand, similar to how it's handled for `vfwsub.wv`, thus preventing incorrect assembly when `vs1` is allocated from the `vs2` register group.
