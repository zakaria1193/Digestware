The JIT (Just-In-Time compilation) support, `libgccjit`, is now enabled by default for Cygwin targets, similar to MinGW. Previously, it was disabled unless `--enable-host-shared` was specified. This change aligns the configuration and allows JIT compilation to be used on Cygwin without special flags.
