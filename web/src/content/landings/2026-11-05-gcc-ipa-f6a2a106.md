Inter-procedural analysis (IPA) previously had duplicate code for handling function-local addresses within pointer ranges. This commit centralizes this logic into a new method `prange::clear_function_local_addr` and moves its invocation to `ipa_get_value_range`. This refactoring removes special-case code from other IPA functions, simplifying the analysis and ensuring consistent treatment of local addresses.
