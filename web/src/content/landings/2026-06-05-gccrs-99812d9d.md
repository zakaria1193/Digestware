This commit resolves a use-after-move bug within the `Lexer::parse_decimal_int_or_float` function in the GCC Rust compiler. Previously, a `str` variable was used after it had been moved, leading to an undefined state where the prefix of a numerical literal might be incorrectly identified as empty on some platforms. The fix prevents this erroneous behavior, ensuring accurate parsing of decimal integers and float literals.
