This commit addresses a failure in the `spaceship_mixed_variants.c` test on ILP32 targets for the C++20 spaceship operator (`<=>`). The original test failed because these targets lack a `DI` mode spaceship optab, preventing the optimization from occurring. To resolve this, tests using `long long` as an input argument to the spaceship operator have been moved to a new file, `spaceship_mixed_variants_ll.c`, which now includes appropriate target-specific checks to prevent failures on unsupported architectures.
