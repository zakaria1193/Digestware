This commit renames the SVE `UNSPEC_COND_FRINTN` pattern in the GCC AArch64 backend to `roundeven`, aligning it with the standard terminology and the existing Advanced SIMD implementation. Previously, the mismatch prevented `roundeven` operations from being vectorized using SVE, forcing them to fall back to Advanced SIMD. This change ensures that `roundeven` can now be correctly implemented by SVE, improving performance for relevant floating-point operations.
