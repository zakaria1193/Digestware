The AMDGCN backend has been refactored to natively support vector memory loads and stores using the `(mem (reg:<vecmode>))` construct. This replaces less efficient gather/scatter operations, allowing for more conventional representation of vector memory accesses. While masked loads still require a workaround due to potential reloads, this change improves the representation of unconditional vector loads and stores.
