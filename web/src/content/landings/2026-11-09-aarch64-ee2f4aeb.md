This commit introduces support for carry-less multiplication (clmul) and its widening variant (clmul_widen) on AArch64, utilizing the PMULL instruction. It adds specific optabs for clmuldi3, clmul_widendi3 (when TARGET_AES is available), and clmul_widenqi3 (for TARGET_SIMD). These implementations leverage AArch64's PMULL capabilities to provide efficient carry-less multiplication, replacing slower software sequences. The changes include examples showing significant instruction count reductions for these operations, particularly when the necessary hardware features like FEAT_PMULL are present.
