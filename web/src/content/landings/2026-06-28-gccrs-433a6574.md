This commit refactors gccrs by introducing `ForeverStackBase` as a base class for `ForeverStack`. The `Node` structure and related members, such as `Link`, `LinkCmp`, `is_root`, `is_prelude`, `is_leaf`, and `insert_child`, are moved to `ForeverStackBase`. This allows `ForeverStack` instances to share the same underlying node objects, reducing memory overhead and simplifying the management of nodes across different namespaces. This change is a precursor to unifying node trees across multiple `ForeverStack` instances.
