The documentation for the x86 assembler option -mlfence-after-load has been improved. It now clarifies that the option primarily targets hardware affected by Intel SA-00334 and does not cover all load instructions. Additionally, the documentation specifies that not all load instructions are covered, focusing on those that alter registers used in subsequent memory access calculations.
