This change addresses memory management issues within the RISC-V target attribute parser. It ensures that the old subset pointer is cleared before a new one is parsed, preventing a double-free when an XLEN mismatch occurs. Additionally, a destructor was added to release any remaining subset list on parser destruction, fixing potential memory leaks.
