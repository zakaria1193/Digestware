This commit introduces support for the BSR0 register, part of the ACEv1 ISA. It treats BSR registers similarly to TMM registers, allocating space for future extensions and enabling register allocation. Changes include updates to register class maps, debugger register maps, conditional register usage, and machine description files, ensuring the BSR0 register is recognized and managed by the compiler.
