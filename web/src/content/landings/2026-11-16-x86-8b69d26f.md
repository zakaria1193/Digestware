This commit restores the generic ELF section field copying logic for non-Solaris x86 binaries. A previous change had incorrectly short-circuited this generic handling for such binaries, leading to issues like `SHT_SECONDARY_RELOC` sections having zeroed `sh_link` and `sh_info` fields. This fix ensures these fields are correctly populated, resolving a bug in the BFD library.
