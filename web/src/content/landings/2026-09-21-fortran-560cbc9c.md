This commit corrects an issue in the Fortran compiler where span-addressed character arrays were not always dereferenced, leading to type mismatches. The exception that omitted dereferencing when the pointer target type had the string flag set has been removed. This ensures that span-based pointer arithmetic accesses consistently result in the expected data type, preventing regressions when switching between different array access methods.
