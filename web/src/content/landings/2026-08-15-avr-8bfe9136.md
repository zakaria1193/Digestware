This commit improves the readability and maintainability of the AVR backend's fixed-point instruction definitions. It replaces hardcoded "magic numbers" in the `avr-fixed.md` file with symbolic constants, such as `REG_24`. This change makes the code easier to understand and less prone to errors caused by unclear numerical values.
