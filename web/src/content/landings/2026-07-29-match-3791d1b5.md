This commit introduces a new simplification rule in `match.pd` that folds expressions of the form `(x + y) - MIN(x, y)` into `MAX(x, y)`. This algebraic identity holds for both integers and floating-point numbers (under certain conditions like reassociation). The optimization simplifies code by reducing the number of operations required, as demonstrated by an example reducing four instructions to one on AArch64.
