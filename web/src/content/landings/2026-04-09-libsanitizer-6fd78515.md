The commit fixes the availability of `struct sock_fprog` for libsanitizer on Linux systems. The structure is provided by the Linux kernel headers (`<linux/filter.h>`), which are not always included by default in all C library implementations (e.g. musl). This commit adds the missing include to make it available on all Linux systems.
