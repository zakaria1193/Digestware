This commit refactors `libstdc++`'s chrono time formatting to improve efficiency when dealing with time points that have integer second precision. For such cases, locale-dependent formatting is unnecessary, so the code now conditionally skips the locale argument. This change eliminates a specific locale overload and simplifies initialization, while also including a minor inlining optimization for a helper function.
