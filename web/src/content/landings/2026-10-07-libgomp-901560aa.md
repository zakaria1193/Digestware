This patch parallelizes the initialization of thread-local data within libgomp's parallel region setup, aiming to reduce overhead when using a large number of threads. Previously, each thread's local values for task, team number, function pointers, and data were initialized sequentially by the primary thread. This change distributes this initialization work among the threads, significantly speeding up the setup process, especially when reusing thread teams.
