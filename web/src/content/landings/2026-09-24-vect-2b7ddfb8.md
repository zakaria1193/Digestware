This commit resolves an internal compiler error (ICE) in GCC's vectorizer related to emulated vector operations. When SIMD instructions are unavailable (e.g., with `-mgeneral-regs`), the vectorizer attempts to emulate them. A recent transition in the costing logic caused it to incorrectly use an old interface, leading to a null pointer dereference. This fix updates the costing code to use the correct SLP node, resolving the ICE and a related test case.
