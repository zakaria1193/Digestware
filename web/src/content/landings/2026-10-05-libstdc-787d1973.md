The libstdc++ library now conditionally applies the gnu_printf attribute for C++11 and later. This change prevents pedantic warnings in C++98 code that would arise from using %zu format specifiers in internal error message formatting functions. The attribute is now only enabled when the C++ language dialect supports it, simplifying the code and avoiding unnecessary warnings.
