This commit refactors the `genemit` tool to use a helper function, `note_split`, for emitting dump messages related to split operations. Previously, each of the thousands of `define_split` and `define_peephole2` generators included repetitive code to print a dump message. By centralizing this logic into `note_split` in `emit-rtl.cc`, the generated code size for `insn-emit-*.cc` files is reduced, and compilation time decreases. The dump output remains unchanged, preserving the integrity of regression tests that rely on it.
