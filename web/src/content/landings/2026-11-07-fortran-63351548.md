This commit significantly enhances GCC's Fortran compiler's handling of parameterized derived types (PDTs), addressing errors related to their usage, particularly in function arguments and allocations. It introduces a mechanism to use 'hidden arguments' for PDTs that require them, ensuring correct parameter passing and type checking. New functions and data structures are added to manage this, along with checks for parameter consistency and runtime error reporting for mismatches. This resolves issues with PDTs in various calling and allocation contexts.
