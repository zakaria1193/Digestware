The reassociation pass in GCC has been updated to use a target-specific policy hook for ordering conditional comparisons. This addresses issues where generic reassociation might not respect target constraints, leading to suboptimal code. The new hook allows targets like AArch64 to specify preferences, such as preferring constants or floating-point zeros in comparisons, resulting in more efficient instruction selection. The generic pass also ensures that trapping comparisons are handled correctly.
