A new field, `inverted_mapping`, has been added to the `callback_info` structure. This field provides a reverse mapping, allowing developers to find the index of a callback's parameter given an argument's index. This is particularly useful for interprocedural analysis (IPA) pass, such as IPA-SRA, to associate argument flows with a callee's parameters.
