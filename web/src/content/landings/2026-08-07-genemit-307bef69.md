This commit refactors `genemit` to distribute the definitions of overloaded names more evenly across output files. Previously, a single file received all definitions for `add_clobbers`, `added_clobbers_hard_reg_p`, and `code_for_`/`gen_` pairs. This led to a significant size imbalance, with one file being 70% larger than others, slowing down parallel compilation. By assigning an output file per overloaded name, the file sizes are now balanced within a 3% spread, improving overall build times.
