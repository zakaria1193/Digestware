This commit fixes an Integer Compiler Error (ICE) in Fortran related to structure constructors involving class pointer components. When a class pointer component is associated with a non-class target, this change ensures that the correct data, vptr, and length are set, resolving issues for both scalar and array scenarios. New test cases are included.
