The deprecated `-frust-c-style-string-literals` flag has been removed from gccrs. Its functionality is now managed by the `-frust-compat-version=<1.64>` flag, which controls compatibility with Rust version 1.64. This change simplifies flag management and aligns string literal parsing behavior with specific Rust language versions.
