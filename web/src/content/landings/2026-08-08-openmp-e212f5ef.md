This change updates OpenMP's SIMD function cloning to use VOID_TYPE_P for checking void return types. Previously, functions with void return types defined via typedefs could cause an Internal Compiler Error (ICE) during compilation. The fix ensures these cases are handled correctly, and a new test case has been added to verify the fix.
