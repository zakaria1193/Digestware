This commit resolves an issue where narrow CLMUL (carry-less multiplication) results on AArch64 were not correctly extended when stored in promoted registers, leading to incorrect values being read by later operations. By using `convert_move` for promoted SUBREG targets, the fix ensures correct sign extension and passes libstdc++ tests.
