Adds a new linkage kind, `lk_module`, to the C++ compiler to represent entities that are part of a module but not exported.  Previously, such entities were identified by checking `lk_external && DECL_MODULE_ATTACH_P && !DECL_MODULE_EXPORT_P`. The new `lk_module` enumeration simplifies this check and allows for further cleanups in the code. This change clarifies the representation of module linkage within the compiler.
