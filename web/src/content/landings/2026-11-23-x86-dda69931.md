The x86 linker now correctly handles IFUNC (indirect function) symbol references found in non-allocatable sections, such as debugging information. Previously, these references could cause the linker to abort, especially when only such sections referred to an IFUNC symbol. This change ensures that these references are processed as STT_FUNC, allowing the linker to resolve them to the IFUNC's resolver function and preventing build failures.
