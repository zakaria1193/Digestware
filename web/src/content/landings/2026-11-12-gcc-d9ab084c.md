This commit ensures that the `ADAC` environment variable is passed correctly to sub-configures (like `gnattools`) during the GCC build process. Previously, `ADAC` was not consistently passed, leading sub-configures to use the default `CC` for testing and incorrectly report `have_gnat=no`. This change improves user experience by preventing confusion and ensuring accurate build configurations.
