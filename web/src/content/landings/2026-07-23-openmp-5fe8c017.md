This commit simplifies the OpenMP compiler's handling of the `device_type(nohost)` clause when targeting offload devices. It refactors the code generation logic in `gimplify.cc` to use helper functions like `build_string_literal` and `build_int_cst` for constructing error messages and values. This change also adjusts related test cases for accuracy, making the code cleaner and easier to maintain.
