This commit significantly increases the use of `rtx_insn *` pointers within various scheduler components. Functions across multiple scheduling files and target-specific code now accept or store `rtx_insn *` arguments. This allows the scheduler to more precisely track dependencies and relationships between individual instructions, potentially improving instruction scheduling and reordering for better performance.
