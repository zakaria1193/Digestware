The C++ standard forbids applying `views::iota` twice in a row (e.g. `views::iota(views::iota(0))`), and the library now enforces this.  The change modifies the return type deduction of `_Iota::operator()` to explicitly exclude `iota_view<decay_t<_Tp>>` when `_Tp` is itself an `iota_view`. This prevents the creation of ill-formed types and resolves LWG4096.
