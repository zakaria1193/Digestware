This commit addresses significant regex performance regressions introduced previously by making the executor's traversal mode (DFS vs. BFS) a template parameter instead of a runtime member. This allows the compiler to eliminate dead code paths for the unused mode at compile time, reducing dynamic instructions and mispredicted branches. This optimization restores and surpasses the performance of GCC 15 for email, URI, and IPv4 regex matching.
