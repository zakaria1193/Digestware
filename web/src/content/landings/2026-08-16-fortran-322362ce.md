An issue in the Fortran compiler caused array constants from `ISO_FORTRAN_ENV` to be uninitialized when used within procedures. Although these constants were marked `TREE_STATIC` for inlining, their static initializers were only generated for main programs or modules. This fix ensures that initializers are emitted regardless of the enclosing scope, correctly initializing these array constants within procedures.
