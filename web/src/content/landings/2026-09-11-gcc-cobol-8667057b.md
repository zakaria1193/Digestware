This commit changes how COBOL-WORDS overrides are applied. Instead of the scanner handling them directly, the generated scanner now retrieves tokens, and the COBOL-WORDS overrides are applied afterward. This revision allows for more flexibility, though not all keywords can be modified successfully with the current implementation.
