This commit fixes an Internal Compiler Error (ICE) in GCC's Fortran front-end related to dummy functions that return a CHARACTER type with a length dependent on a function argument. The issue occurred because `gfc_trans_deferred_vars` incorrectly set up the result length, similar to how it handles CHARACTER dummy variables. Since the argument is not declared in the caller, this led to an assertion failure. The fix modifies the function to skip this setup for dummy functions, preventing the crash.
