This commit replaces the direct use of `XVECEXP` for accessing elements within RTX sequences with more robust and safer accessor functions. This change improves code maintainability and reduces the potential for errors by abstracting away the low-level details of RTX sequence manipulation. The affected areas include various target backends and internal compiler passes dealing with instruction sequences.
