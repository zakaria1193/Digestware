This commit removes expected failures for `csrr` assembly checks in several RISC-V test cases. The register overlap support for `vwmulsu.vx` has been improved, which means `csrr` instructions are no longer expected in the assembly output for these specific tests. This change aligns the tests with the current compiler's behavior.
