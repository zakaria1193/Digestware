This commit optimizes RISC-V bit manipulation instructions by folding redundant count masks in inverted bit extraction. Using `define_split`, the compiler can now generate more efficient code for these operations. Performance testing on RV64 microkernels showed significant reductions in instruction counts and cycles, with improvements up to 14.31%.
