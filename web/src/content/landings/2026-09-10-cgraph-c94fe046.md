A new `assume_function` field has been added to the `cgraph_node` structure to store information that was previously only available in the `struct function`. This is particularly important for Link-Time Optimization (LTO) where `struct function` might not always be present. The Intelligent Code Grouping (ICF) pass has been updated to consider this new field, preventing merging of functions with differing `assume_function` values.
