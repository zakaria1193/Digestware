This commit addresses issues in GCC's Fortran front-end concerning parameterized derived types (PDTs). When recursing into PDT components, the compiler now correctly verifies that all components of the parameter list are explicit before allocating parameterized components. If they are not explicit, the components' own parameter lists are used to replace assumed expressions, resolving errors reported in PR82173.
