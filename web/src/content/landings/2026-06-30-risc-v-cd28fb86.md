This commit corrects an issue with the disassembly of RISC-V vector instructions, specifically related to the zvdota extension's alternative format. The fix ensures that alternative format names (altfmt) for vtype are only displayed when the necessary extensions are advertised or when all extensions are enabled. This prevents incorrect disassembly output for instructions that use these specialized vector types.
