Binutils now supports new linker options `-z zicfilp=` and `-z zicfiss=` for RISC-V Control Flow Integrity (CFI) features, aligning with lld's functionality. These options control the inclusion and reporting of CFI-related properties in the output binary. The default behavior is 'implicit,' meaning the property is set only if all inputs have it. Options like 'unlabeled' and 'always' explicitly set the property, while 'never' clears it. Separate 'report' options control diagnostic messages.
