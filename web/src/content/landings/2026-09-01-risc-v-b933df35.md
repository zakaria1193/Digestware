This change enables register overlap for the RISC-V vector instruction `vwmaccus.vx`, similar to other widen ternary vx instructions. By leveraging the `Wvr` constraint in the machine description, the compiler can now allow these registers to overlap, which previously caused related test cases to fail. This allows for more flexible register allocation and simplifies testing.
