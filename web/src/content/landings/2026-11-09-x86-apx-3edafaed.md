The GNU Assembler (GAS) now optimizes certain forms of the AND instruction on the x86/APX architecture when a small immediate value is used. This change allows instructions like `AND $imm8` to be encoded more compactly using byte operations, leveraging EVEX.ND encodings. The optimization is applied to preserve code size and efficiency.
