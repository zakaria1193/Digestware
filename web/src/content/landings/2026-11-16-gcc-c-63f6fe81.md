A temporary workaround has been implemented in the GCC C++ front-end to bypass an assertion that checked for address-space qualification. This prevents compiler internal errors (ICEs) in rare cases related to C++ named address spaces, which are not yet fully supported. The change ensures that compilation can proceed until full support for these address spaces is merged, at which point the original type qualification checks can be reinstated.
