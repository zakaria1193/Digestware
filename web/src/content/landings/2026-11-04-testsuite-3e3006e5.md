A GCC test case (`pr128409-1.c`) was being silently skipped because its target selector was too restrictive. The selector "*-*-linux" did not match common Linux triplets like "x86_64-pc-linux-gnu". This change updates the selector to "*-*-linux*", aligning it with a similar test case and ensuring it is executed on the intended target systems.
