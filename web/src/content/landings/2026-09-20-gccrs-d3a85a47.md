gccrs has implemented an initial version of hotpatching for `rustc-lib`, a component that provides Rust library functionality within GCC. This is achieved by backporting specific patches from the Rust core library, including functionality for CStr parsing (`core/ffi/c-str.for-rfl-patch`) and `Vec::extract_if` (`alloc/vec-extract-if.for-rfl-patch`). A Python script is included to apply these patches to `rustc-lib`, along with a README file explaining the process.
