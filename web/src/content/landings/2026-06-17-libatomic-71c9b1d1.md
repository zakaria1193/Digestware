This commit updates `libatomic`'s AArch64 assembly code to emit modern AArch64 build attributes for Branch Target Identification (BTI), Pointer Authentication Codes (PAC), and Guarded Control Stack (GCS) features. These attributes are used when the `__ARM_BUILDATTR64_FV` macro is available, indicating compiler and assembler support for this new signaling method. For toolchains that do not support the new attribute form, `libatomic` maintains backward compatibility by falling back to emitting the existing GNU property notes.
