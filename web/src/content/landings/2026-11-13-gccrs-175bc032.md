The GCC Rust frontend (gccrs) has added missing entries for `ATOMIC_CXCHG*_FAIL*` intrinsics, which are used for atomic compare-and-exchange operations. This enables the compiler to correctly handle these operations, improving support for concurrent programming in Rust.
