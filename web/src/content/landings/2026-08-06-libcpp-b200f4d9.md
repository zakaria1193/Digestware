This commit updates libcpp to implement the C++29 standard's changes to identifier rules based on new Unicode recommendations (P3658R1). It introduces a distinction between characters that are valid for C++ identifiers (XID_Start/XID_Continue) and those valid for C compatibility (ID_Compat_Math_Start/ID_Compat_Math_Continue). For C++98 through C++26, both sets are accepted. However, for C++23 and C++2Y, the compatibile characters are only accepted in non-pedantic modes, ensuring stricter adherence to evolving standards.
