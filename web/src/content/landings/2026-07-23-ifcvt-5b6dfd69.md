A redundant check for the `else_bb` pointer has been removed from the `noce_process_if_block` function within GCC's ifcvt optimization pass. The test was located within a code block that was already guaranteed to have a non-null `else_bb` due to prior conditions. This change simplifies the code without affecting its behavior.
