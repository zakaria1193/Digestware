This commit refactors gccrs to use `DefId` (Definition IDs) instead of AST (Abstract Syntax Tree) node IDs for indexing, which is crucial for resolving trait implementations and other associated items. By introducing a new indexing pass after HIR lowering, the compiler can map AST nodes to `DefId`s, enabling more robust and efficient resolution in components like the method resolver and path probe expressions.
