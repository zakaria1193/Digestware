The C++ compiler now suppresses -Walloc-size warnings for memory allocations resulting from new expressions. The compiler's lowering of new expressions already ensures correct allocation sizes or handles overflows, making the warning redundant and potentially misleading for these cases. This change prevents unnecessary noise in compilation output for standard C++ memory allocation.
