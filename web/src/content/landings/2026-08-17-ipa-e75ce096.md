A redundant `if` statement has been removed from the `ipa_compute_jump_functions_for_edge` function in GCC's IPA (Inter-Procedural Analysis) pass. This check was intended to handle internal calls, but since internal functions and their calls are not represented in the call graph used by this pass, the condition was never true. Removing this dead code simplifies the implementation and avoids potential confusion.
