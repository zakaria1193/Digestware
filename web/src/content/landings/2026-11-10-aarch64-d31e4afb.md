This commit optimizes the handling of ARM C Language Extension (ACLE) function attributes for NEON and SVE pragmas by sharing attribute lists. Instead of generating these lists repeatedly for each function declaration, GCC now builds distinct lists once, caches them, and reuses them. This significantly reduces compiler runtime, particularly for files including both ARM NEON and SVE headers.
