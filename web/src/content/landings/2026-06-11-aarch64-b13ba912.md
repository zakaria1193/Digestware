A new tuning option, `AVOID_MOVIMM_Z`, has been added for AArch64 targets. This tune allows the compiler to choose between using a zeroing SVE move immediate instruction or a merging variant after zeroing the destination. The optimization is enabled on cores where the zeroing variant has been measured to be slightly faster, potentially improving performance for SVE operations. The change involves modifications to header files, machine description files, and tuning flag definitions.
