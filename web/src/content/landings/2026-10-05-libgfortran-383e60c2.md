Previously, if a Fortran coarray ALLOCATE or FORM TEAM operation exceeded libgfortran's shared memory pool, it would incorrectly return a success status (STAT=0). This led to the allocator returning a pointer beyond the pool's bounds, resulting in a segfault on first access. This change modifies the allocator to return a null pointer upon exhaustion, allowing ALLOCATE and FORM TEAM to report the error via STAT= or terminate gracefully, and other allocations to terminate the image with an informative message.
