This commit modifies three x86 test files (`vect-pack-trunc-1.c`, `vect-perm-even-1.c`, `vect-perm-odd-1.c`) to be compiled with `-mno-avx512vbmi` and `-mtune=generic`. This addresses test failures caused by AVX512VBMI instruction set usage and differing tuning options, ensuring test stability.
