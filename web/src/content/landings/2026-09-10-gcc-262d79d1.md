Two new functions, `stream_vector_out` and `stream_vector_in`, have been added to `callback-info.cc`. These functions abstract the process of streaming `auto_vec<int>` data to and from LTO (Link-Time Optimization) object files. This change tidies up the code and prepares for the addition of another vector field in `callback_info`.
