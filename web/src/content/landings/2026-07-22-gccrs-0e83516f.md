primer_glossary:
- term: DST
  definition: Dynamically Sized Type. A type whose size is not known at compile time,
    such as a slice `[T]` or a trait object `dyn Trait`. DSTs can only be used behind
    pointers like `&` or `Box`.
- term: ADT
  definition: Algebraic Data Type. A composite type formed by combining other types.
    In Rust, this typically refers to structs and enums.
- term: fat pointer
  definition: A pointer that contains not only the memory address of the data but
    also additional metadata. For slices, this is the length; for trait objects, this
    is a vtable pointer.
- term: unsize coercion
  definition: A conversion in Rust that allows a sized type to be coerced into a DST
    behind a pointer. For example, `&[T; N]` can be coerced into `&[T]`.

The gccrs compiler's backend has gained support for Dynamically Sized Types (DSTs) within Algebraic Data Types (ADTs). Previously, DST fields were embedded directly, but now the compiler correctly identifies unsized ADTs, preserves their layout, and generates fat pointers for references. This enables correct handling of unsized ADTs that follow unsize coercion rules.
