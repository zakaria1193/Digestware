This commit fixes an internal compiler error (ICE) that occurred when mangling empty anonymous unions or structs used as non-static data members. Previously, the mangling process failed because it expected a name for these constructs. The fix introduces a new mangling scheme, using an index instead of a name, similar to how unnamed bitfields are handled. This ensures correct name mangling for these C++ constructs, resolving bug PR125541.
