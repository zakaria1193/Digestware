GCC now correctly handles conflicts between a class `using` declaration and a subsequent class definition. Previously, the compiler treated these as a redefinition rather than a conflict between distinct declaration types. This fix ensures that name lookup accurately identifies these as separate kinds of declarations, resolving issues reported in PR115806 and improving diagnostic messages for related test cases.
