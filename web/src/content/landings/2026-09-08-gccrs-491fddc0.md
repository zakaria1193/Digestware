GCC Rust now filters out method selection candidates when the 'self' type is incompatible. This prevents erroneous matches, such as those involving double references (e.g., `&&A`) when only a single reference is expected or compatible, as seen with `PartialOrd` for `&i8`. This fix ensures that method resolution considers the precise nature of the receiver type.
