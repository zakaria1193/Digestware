GCC Rust (gccrs) has been enhanced to better support `llvm_asm` (inline assembly). This update refines how GCC Rust handles various LLVM-specific constraints, such as `=*m`, and adapts to changes in template string usage, moving from multiple strings to a single one. The changes aim to safely handle or reject most usages of LLVM inline assembly, minimizing future compatibility issues.
