primer_expert: For assumed-shape dummy arrays passed by reference, the span (which
  includes bounds and data pointer) is accessed via the dummy's descriptor. This commit
  ensures that the span is loaded into a local variable (`GFC_DECL_SPAN`) on procedure
  entry, alongside the bounds, to avoid re-accessing the descriptor within the procedure
  body, especially in outlined regions. This resolves a bug where the span was reloaded
  from a potentially inaccessible descriptor on the device.

Fortran procedures using assumed-shape dummy arguments addressed through their descriptor's span now correctly load this span into a local variable on entry. Previously, the span was reloaded from the descriptor at each element reference, causing issues within outlined regions (like OpenMP target regions) where the descriptor was not mapped, leading to dereferencing a host pointer and using garbage data.
