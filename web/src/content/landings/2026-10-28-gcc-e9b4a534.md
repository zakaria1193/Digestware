This commit simplifies code in the CRIS and FRV backends by having several split functions directly return the `end_sequence` RTL expression. This avoids unnecessary intermediate steps or variable assignments. The affected functions include those handling move operations and conditional moves, leading to slightly cleaner and potentially more efficient RTL generation.
