This commit fixes the gating of SME-LUTV2 (Scalable Matrix Extension - LookUp Table Version 2) assembly tests in the aarch64 testsuite. The tests are now configured to assemble only when the assembler supports ``sme-lutv2``, and will compile otherwise. This ensures that the tests run correctly and avoid errors on assemblers that do not support the required features.
