This commit fixes the gating of SME LUTv2 assembly tests in the AArch64 testsuite. The tests are now configured to assemble only when the assembler supports the `sme-lutv2` extension. Otherwise, they are compiled as C code. This ensures that assembly tests are only run on systems with the required hardware support.
