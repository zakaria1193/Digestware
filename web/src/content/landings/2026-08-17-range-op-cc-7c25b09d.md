This commit enhances range analysis by introducing relation effects for division and modulo operations when the operands are equal. Specifically, if `a == b`, then `a / b` is now known to result in `1`, and `a % b` is known to result in `0`. This optimization is applied earlier in the compilation process, potentially improving code generated by `-O2` and later.
