This commit addresses an issue where recent changes to the aarch64 NEON built-ins in GCC used C++17-style nested namespace definitions. This caused compilation warnings when building the compiler with C++14 standards, which GCC is still required to support. The fix modifies the namespace declarations in `aarch64-neon-builtins-base.h`, `aarch64-neon-builtins-shapes.h`, and `aarch64-neon-builtins-shapes.cc` to use the older, C++14 compatible syntax, ensuring the compiler can be built correctly.
