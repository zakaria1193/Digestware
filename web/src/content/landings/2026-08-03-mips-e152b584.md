This commit resolves an issue in the MIPS backend where built-in functions declared to take no arguments were incorrectly constructed. Specifically, for functions returning `int` or `unsigned int` with `void` arguments, the backend was creating an incorrect function type signature. This fix ensures correct argument type lists are used, preventing C++ compilation failures.
