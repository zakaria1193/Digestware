A previous fix for PR82173 introduced a regression in Fortran pointer assignment checks. The `gfc_check_pointer_assign` function now correctly verifies that an rvalue is not only `expr_NULL` but also does not have a symbol tree (which can arise from an interface). This ensures that pointer assignments involving interfaces are handled properly, resolving the regression and passing a new test case.
