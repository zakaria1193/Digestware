The C++ parser defers parsing of initializer lists (`{}`) when they appear in a complete class context. Previously, the parser incorrectly assumed that only 'this' usage and name lookup could necessitate deferred parsing in such scenarios. This change corrects that assumption, resolving a bug where init-lists caused parsing issues.
