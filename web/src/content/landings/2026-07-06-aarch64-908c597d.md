This commit improves the speed of GCC's bootstrap process on AArch64 systems by limiting performance counter probes for Arm Scalable Performance Monitoring Events (SPE). Previously, the autoprofile script would scan all available `perf` events, which could be slow on systems with many event types. By using `perf list pmu`, the probes now focus only on Performance Monitoring Unit (PMU) events, which include Arm SPE. This change reduces bootstrap time and ensures that the probe remains efficient without excluding relevant SPE events.
