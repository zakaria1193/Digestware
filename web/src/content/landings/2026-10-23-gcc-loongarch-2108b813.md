The LoongArch backend in GCC has been updated to improve optimization for bit manipulation instructions. The changes address a regression where the compiler favored `+` over `ior` in certain bitwise operations, leading to less efficient code generation for patterns like `bytepick.w`. Rewriting these patterns allows the compiler to adapt to these upstream changes and select more optimal instruction sequences.
