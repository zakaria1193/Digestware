This commit removes the `vaddd_s64` and `vaddd_u64` function definitions from `arm_neon.h` for the aarch64 architecture. Since these functions are now implemented directly within the compiler, the definitions in the header file are no longer necessary and have been deleted. This resolves a compiler error that occurred when the header was included within an `extern "C" {}` block in C++ code.
