Gprofng has been updated to correctly resolve DWARF 5's default indexed string (`DW_FORM_strx*`) and address (`DW_FORM_addrx*`) forms. Previously, these indices were misinterpreted, leading to incorrect compilation unit names, directories, and program counter ranges, causing display issues. This change ensures accurate resolution by using `.debug_str_offsets` and `.debug_addr` sections.
