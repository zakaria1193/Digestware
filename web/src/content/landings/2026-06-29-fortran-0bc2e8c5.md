A bug in GCC's Fortran compiler (gfortran) that affected access to components of `CLASS` declared type variables has been fixed.
Previously, the compiler incorrectly used the data component itself instead of its derived type when checking for coarray components.
This led to errors in specific scenarios, now resolved with a corrected logic and a new test case to verify the fix.
