Following the removal of CXX2A contracts, the C++ front-end has refactored how function contract specifiers are handled. Previously, attribute lists were used to maintain compatibility, but now that these contracts are gone, the code has been simplified by replacing these lists with `tree-vec`. This change removes unnecessary obfuscation and streamlines the internal representation.
