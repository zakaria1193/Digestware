primer_general: When you write a program that uses OpenMP, a set of compiler directives
  and API routines, it can leverage specialized hardware like GPUs (Graphics Processing
  Units) to speed up certain calculations. This is called 'offloading.' The `libgomp`
  library is the part of GCC that handles these OpenMP runtime features. This commit
  is a code organization improvement within `libgomp`. It takes some declarations
  (which tell the compiler about functions and variables) that were previously copy-pasted
  into multiple files and moves them into a single, shared header file called `target-indirect.h`.
  This makes the code cleaner, easier to read, and simpler for developers to maintain,
  as changes only need to be made in one place instead of many. This improves the
  overall quality of the `libgomp` codebase without changing how your OpenMP programs
  behave.

This commit refactors the libgomp codebase by moving the prototypes for `GOMP_INDIRECT_ADDR_MAP` and `GOMP_INDIRECT_ADDR_HMAP` from being repeatedly declared in accelerator-specific `team.c` files into a single, dedicated header file, `config/accel/target-indirect.h`. This change improves code organization and reduces redundancy, making the code easier to maintain and ensuring consistent declarations across different accelerator targets.
