The `expand_divmod` function maintained a cache of the constant divisor from the last division it processed, intending to optimize subsequent modulo operations with the same constant. However, this cache was a function-scope static variable that was never reset, causing its state to persist across function boundaries. This commit resets the cache at the start of each function expansion, ensuring that a function's optimization is determined solely by its own code and not influenced by previously compiled functions in the same translation unit. This change makes the heuristic deterministic and can lead to code size improvements.
