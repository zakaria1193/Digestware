This change removes specialized pointer handling from `ipcp_update_vr` in the interprocedural analysis (IPA) pass. With pointers now having global ranges that store alignment information in bitmasks, the special alignment copying logic becomes unnecessary. This simplifies the analysis and reduces code complexity.
