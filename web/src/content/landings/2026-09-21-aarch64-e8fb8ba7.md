An optimized expander for `__builtin_isnormal` has been added to the AArch64 backend, supporting `float`, `_Float16`, and `__bf16` types. This new implementation uses integer arithmetic instead of floating-point comparisons, which can be faster and crucially avoids generating spurious exceptions on signaling NaNs. This change addresses a part of PR66462 by improving the robustness and performance of the `isnormal` intrinsic.
