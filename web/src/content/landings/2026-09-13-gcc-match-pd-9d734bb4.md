This commit enhances GCC's pattern matching capabilities by completing the folding of branchless minimum and maximum operations. New patterns handle cases like `Y + MIN (X - Y, 0)` and `MIN (X + Y, Y) - Y`, which can reduce instruction counts significantly, as seen in the x264 median-of-three predictor example.
