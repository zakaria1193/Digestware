The gccrs compiler's High-Level Intermediate Representation (HIR) map is being made more manageable by extracting crate-related mappings into a dedicated class. This change reorganizes internal data structures to improve clarity and maintainability within the Rust frontend. Numerous backend and checking components now utilize this more organized structure.
