The binutils linker now correctly handles linking XCOFF object files with incompatible architectures. Previously, when a mismatch occurred, the linker would continue processing and attempt to dereference null pointers for magic sections, leading to a segmentation fault. This change adds checks to ensure these sections are not null before accessing their size, preventing the crash.
