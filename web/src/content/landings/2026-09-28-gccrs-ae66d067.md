GCC's Rust frontend (gccrs) now includes implementations for several fast floating-point arithmetic intrinsics: `fadd_fast`, `fsub_fast`, `fmul_fast`, `fdiv_fast`, and `frem_fast`. While these intrinsics are now recognized and handled, the current implementation performs standard, non-optimized operations. The change notes that GCC does not support enabling 'fast' mode for individual operations, only program-wide.
