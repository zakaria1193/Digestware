This change addresses memory leaks in Fortran's handling of polymorphic types. Previously, the deallocation of objects with LEN-dependent components in PDTs was incomplete, leaving memory unreleased. Additionally, polymorphic assignments from structure constructors caused leaks in their temporary components. The fix ensures these components are finalized and deallocated, resolving issues with memory management for complex polymorphic assignments and structure constructors.
