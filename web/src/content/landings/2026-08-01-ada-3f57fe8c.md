This patch resolves a crash in the Ada compiler related to `Unchecked_Union` components when the `-gnateV` flag is used. The issue stems from incorrect validation of fields within an `Unchecked_Union` type. The fix involves modifying the `Validate_Field` procedure in `exp_attr.adb` to do nothing if the field belongs to an `Unchecked_Union` type, preventing the crash. A new test case is added to cover this scenario.
