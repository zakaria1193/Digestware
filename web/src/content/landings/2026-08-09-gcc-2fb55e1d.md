This commit corrects an issue in `match.pd` where the transformation of `0.0 - x` to `-x` incorrectly handled signed zeros, violating IEEE 754 standards. The fix ensures that when signed zeros are honored, `+0.0 - +0.0` correctly results in `+0.0`, and it also addresses cases where `x` is NaN. New test cases are added to verify the correct behavior.
