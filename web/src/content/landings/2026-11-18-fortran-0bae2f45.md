This commit corrects the behavior of the Fortran intrinsic function `IS_CONTIGUOUS`. Previously, it incorrectly returned `.true.` for array sections that used a vector subscript (e.g., `A([1,3])`). This was because the runtime check examined a temporary array built for such sections, which happened to be contiguous. However, the Fortran 2023 standard specifies that sections with vector subscripts are not contiguous. The fix ensures `IS_CONTIGUOUS` now returns `.false.` in these cases, aligning with the standard.
