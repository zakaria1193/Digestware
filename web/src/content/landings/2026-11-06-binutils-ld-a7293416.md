The linker's PDB handling for debug sections now correctly initializes the `sectlist` array using `xcalloc`. Previously, if an object file contained malformed debug information, the linker could read uninitialized memory when processing relocations against symbols not associated with a valid section. This fix prevents such reads and ensures robustness when linking files with malformed PDB debug sections.
