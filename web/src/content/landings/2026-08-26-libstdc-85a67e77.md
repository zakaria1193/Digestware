GCC has backported implementations of `std::optional` and `std::expected` from the C++ standard library, making them available for C++14 development. The `std::optional` implementation was largely automated, while `std::expected` underwent significant restructuring. These backported features aim to provide modern C++ functionalities to users working with older standards, passing respective test suites.
