Several test cases for the `aarch64` architecture have been updated to require support for indirect functions (ifuncs). This change gates the execution of these tests, ensuring they are only run on platforms that provide `ifunc` capabilities. This prevents test suite failures on `aarch64` targets where `ifunc` support is not present or not enabled, improving the reliability of the test suite.
