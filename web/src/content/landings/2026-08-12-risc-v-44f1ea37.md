This commit enables specific macro-fusion operations for the RISC-V xt-c9501fdvt tuning, including ascending and descending integer load/store pairs. Floating-point load/store pairs remain disabled for this particular tuning. The changes introduce new test cases and modify existing ones to exercise the enabled fusion matchers across various scenarios, such as RV32 Zilsd overlap and independent cases for load pairs, ADD_ST, PREINDEX_ST, and POSTINDEX_ST. This aims to improve instruction scheduling and code density for this specific RISC-V configuration.
