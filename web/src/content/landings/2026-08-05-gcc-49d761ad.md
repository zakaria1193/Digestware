The gfortran test cases `default_format_2.f90` and `default_format_denormal_2.f90` are now marked as expected to fail (XFAIL) on the `hppa*-*-hpux*` platform. This is due to a limitation in the `snprintf` function on this platform, which only provides 33 digits of decimal precision for `long double` values. This precision is insufficient to uniquely represent `long double` values, causing the tests to fail.
