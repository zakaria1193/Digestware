GCC's AArch64 backend now leverages SVE2's `SQSHRNB` and `UQSHRNB` instructions for saturating narrowing right shifts. This allows the compiler to fuse a constant right shift with a saturating truncation into a single instruction, where previously these were separate operations. The changes extend vector mode matching to cover relevant SVE modes and update machine description files to recognize these fused operations, improving performance for code involving saturating shifts and truncations on SVE2-capable hardware. This resolves PR126629.
