The AVR-specific `avr_pass_casesi` optimization pass is now controlled by a new command-line option, `-mdemote-switch`. This option is enabled by default when optimizations are active, mirroring the previous behavior of the pass's gate function. This change provides explicit control over the `casesi` pass for AVR targets.
