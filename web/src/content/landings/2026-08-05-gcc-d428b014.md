This commit updates several parts of the GCC compiler to use `!contains_zero_p` instead of the `nonzero_p` function for checks related to ranges that exclude zero. The `nonzero_p` function was not always precise, as it returned false for ranges like `[1, 5]`, which do not contain zero but also do not represent all non-zero values. Using `!contains_zero_p` provides a more accurate and direct representation of the intended condition.
