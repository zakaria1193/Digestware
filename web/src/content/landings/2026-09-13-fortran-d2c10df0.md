This commit simplifies the initialization of KIND components within Parameterized Derived Type (PDT) templates in the Fortran compiler. It enforces that KIND components must be integer constants and ensures any remaining component initializers are simplified for parameter substitution if necessary. A new test case is added to verify these changes.
