This commit addresses an Internal Compiler Error (ICE) in C++ reflection when processing a call to `identifier_of` within a generic lambda. The issue occurred because `eval_identifier_of` would call `build_special_member_call`, which in a template context creates a `COMPONENT_REF` that could not be evaluated by `cxx_eval_constant_expression`. The fix enforces a non-template context during `process_metafunction` when such calls are encountered, ensuring that the generated expression is evaluable as a constant expression and preventing the ICE.
