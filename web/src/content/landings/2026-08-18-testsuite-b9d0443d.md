This commit enhances the Fortran test suite by employing generic assembly checkers for hidden symbol directives. Previously, tests relied on object-format-specific representations of 'hidden' visibility, causing failures on platforms like Darwin where the defaults differed. By using generic matchers, the tests now correctly verify the presence or absence of hidden symbols across various object formats, ensuring consistent and reliable testing.
