This commit adjusts a test case to only scan the vpinsrw instruction for 64-bit targets. Previous changes to the instruction count for this test caused a mismatch on 32-bit targets. Given that AVX-512BW is common on processors supporting AVX-512, the change limits the test's scope to avoid this specific issue.
