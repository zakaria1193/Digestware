The libiberty library is updated to match the latest version in GCC. This synchronization brings in several changes, including updates to the Makefile dependencies, fixes for sanitizer configure checks, removal of obsolete C functionality tests, replacement of autoconf macros, and handling of long options by spilling them to a response file. It also ensures proper handling of dylibs on Darwin and addresses a signed integer overflow in d_compact_number.
