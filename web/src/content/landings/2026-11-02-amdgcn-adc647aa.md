This commit addresses an integer overflow vulnerability in stack size and offset calculations for AMD GCN targets. By using 64-bit integers for these calculations, GCC now safely handles larger stack requirements. The fix impacts the libgomp plugin's kernel creation, the kernel prologue's stack pointer initialization, and Newlib's reent struct location, preventing potential crashes or incorrect behavior due to exceeding UINT_MAX.
