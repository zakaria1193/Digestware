This commit ensures that the Cobol compiler sets the correct source code location for numeric literals used with the BY REFERENCE clause. Previously, location data could be missing or invalid for such literals, leading to unhelpful diagnostics. This fix improves error reporting by accurately pinpointing the location of BY REFERENCE numeric literals.
