GCC now supports a set of new absolute difference accumulation intrinsics for the AArch64 architecture, specifically for SVE/SME2.3. These intrinsics, such as `svabal_s16` and `svabal_u64`, allow for efficient computation of accumulated absolute differences on vector data.
