This patch resolves an issue on i386 targets that do not support SSE2, where initializing a V4SF vector with zeros for its upper V2SF half would fail. The old implementation used a raw `SET` instruction, bypassing fallbacks that would correctly materialize the zero using integer modes when `movv2sf` was unavailable. By switching to `emit_move_insn`, the zero is now correctly materialized as a DImode move, resolving the problem and generating expected code sequences.
