The Cobol compiler now enforces that the `ADD CORRESPONDING` statement must take exactly two operands. This change, which addresses bug RT 3665, provides a more specific error message for incorrect operand counts. Additionally, a related fix prevents an internal compiler error (ICE) that could occur when attempting to use the `WRITE` statement in syntax-only mode.
