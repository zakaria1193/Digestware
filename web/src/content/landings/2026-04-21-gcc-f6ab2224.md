This commit merges changes from the upstream D compiler, DMD, and its runtime library, druntime. It imports bug fixes from the v2.113.0 release branch of DMD and druntime.  The changes include a fix in `expr.cc` to avoid generating a `STRING_CST` for mutable array types.
