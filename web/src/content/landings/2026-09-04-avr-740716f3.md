The AVR-specific `avr_pass_2moves` optimization pass has been modified to correctly handle debug instructions. Previously, transformations within this pass could be affected by the presence or absence of debug insns, leading to failures when the `-fcompare-debug` flag was used. The changes ensure that instruction traversal and register use chain analysis correctly ignore debug insns, resolving regressions in specific test cases.
