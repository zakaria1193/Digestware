This change fixes an issue in Ada where the `Has_Constrained_Partial_View` flag was not correctly inherited when deriving constrained private types that had defaulted discriminants. The fix ensures that both the partial and full views of derived types correctly inherit this flag from their parent types, maintaining correct type behavior.
