This commit introduces a set of new test cases for the RISC-V Vector (RVV) extension, focusing on register group overlap when using the `vfwsub.vf` instruction. These tests, covering various data types (f16, f32) and vector lengths (m1, m2, m4, mf2, mf4), aim to ensure the compiler correctly handles register allocation for wide floating-point subtraction operations.
