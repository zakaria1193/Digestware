The AArch64 `sqxtun` and related instructions are now represented using a simpler RTL structure: an unsigned truncate of a signed maximum against zero. This change allows the vectorizer to directly match these patterns, eliminating intermediate instructions and improving code generation efficiency for SIMD operations involving saturation and narrowing.
