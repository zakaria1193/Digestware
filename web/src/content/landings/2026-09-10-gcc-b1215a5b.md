This commit refactors the management of `recog_data`, a global variable used by the instruction extraction process. Instead of copying the large `recog_data_d` structure, it is now accessed via a macro that dereferences a pointer. This allows saving and restoring its state by simply swapping pointers, significantly reducing overhead. The change also converts several backends (reload, i386, sh) to use a new RAII class `recog_state_saver` for managing this state, improving efficiency and code robustness.
