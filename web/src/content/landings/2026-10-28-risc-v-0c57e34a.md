GCC reverts changes that permitted register overlap for the RISC-V vector widening signed-unsigned multiply-add instruction (vwmaccsu.vv). This aligns with the vector specification's restriction against using a single register for different Effective Element Widths simultaneously. The fix impacts test cases and instruction definitions.
