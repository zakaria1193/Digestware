The AArch64 backend has been updated to correctly expand bitwise OR and XOR operations (aop<mode>3) to IOR or ADD instructions, rather than defaulting to PLUS. This change is necessary because the AArch64 architecture does not define a specific instruction for this operation, and the previous default caused issues with floating-point conversions and bitfield operations. The fix ensures more accurate code generation, resolving regressions in specific C code patterns.
