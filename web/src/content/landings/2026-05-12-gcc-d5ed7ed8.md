GCC's cost model for vector instructions now utilizes the recorded vector composition type when calculating costs, particularly for multi-lane `VMAT_STRIDED_SLP` operations. Previously, the compiler over-costed vector constructions due to a lack of precise information about the actual vector composition. By incorporating this newly available information, the costing becomes more accurate, leading to better optimization decisions and potentially more performant generated code.
