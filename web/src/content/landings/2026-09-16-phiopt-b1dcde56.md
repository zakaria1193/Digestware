The PHIOPT pass in GCC now uses improved heuristics for commoning loads before the vectorizer runs. Previously, many common loads were rejected due to simple heuristics. This change allows loads from other loads to be factored out earlier, potentially enabling more code to be vectorized. Two test cases are now factored out in phiopt2, and one case was adjusted to preserve vectorization.
