This commit refines the constraints for the split pattern of the RISC-V `slliw` instruction when dealing with shifted bitfields. It ensures the pattern only matches bitfields starting at bit 0 and that the upper bits of the operand correctly reflect the sign-extended result of the `slliw` operation.
