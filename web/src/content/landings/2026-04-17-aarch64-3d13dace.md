This commit modifies the `aarch64_sme_write_zt` instruction pattern in `aarch64-sme.md`. It adds the use of `ZTO_REGNUM` and `SME_STATE_REGNUM` to the `movt` instruction, which is used to write to the ZA tile zero register. Additionally, it replaces `unspec_volatile` with `unspec`, allowing dead code elimination if the dependencies are correct. A new test case, `zt0_state_8.c`, is added.
