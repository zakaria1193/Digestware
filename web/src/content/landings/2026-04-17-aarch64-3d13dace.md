This change ensures the compiler properly utilizes ZTO_REGNUM and SME_STATE_REGNUM when dealing with movt instructions related to the Scalable Matrix Extension (SME) in AArch64. The volatile qualifier was removed from an unspec, as it's no longer needed with correct dependencies, which could allow for better code optimization.
