This commit completes the cleanup of legacy 'ternlog' patterns from the `sse.md` file for the i386 architecture. Obsolete patterns and mode iterators have been removed. Surviving 'ternlog' patterns now consistently use decimal immediate operands instead of hexadecimal, and corresponding test cases have been updated to align with this change.
