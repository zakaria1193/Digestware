Test cases for SVE (Scalable Vector Extension) division instructions on aarch64 were failing due to changes in instruction scheduling that altered the output order. The tests originally expected a precise instruction sequence. This commit loosens the tests to only match the predicated `sdiv` or `udiv` instructions, making them resilient to minor reordering while still verifying the core functionality.
