This commit introduces a conceptual 'TMM' register within GCC's i386 backend to prepare for future register allocation in ACE ISAs. While full register allocation is not yet implemented due to spill management complexities, this 'fake' register allows the compiler to understand instruction dependencies better than using inline assembly. It ensures that users can pass TMM register numbers, enabling user-driven allocation which is suitable as TMM acts as an accumulation unit.
