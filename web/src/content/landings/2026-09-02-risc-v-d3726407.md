RISC-V functions using standard calling convention variants will now correctly mangle their names with ABI tags as specified by the psABI. This change ensures that variants like the fixed-length vector calling convention append the appropriate tag, for example, appending 'riscv_vls_cc_<ABI_VLEN>' to the mangled name. This improves ABI compliance and mangling accuracy for RISC-V.
