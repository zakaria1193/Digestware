This commit corrects a bug in the GCC x86 backend's LCP stall peepholing optimization. Previously, the compiler allowed any register type as the previous scratch register, but this change enforces the use of a general-purpose register. This ensures correct code generation and avoids unexpected performance issues related to micro-architectural stalls.
