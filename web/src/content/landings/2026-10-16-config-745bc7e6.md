  was a macro used for defining commands to be executed during the configuration process,

- term: autoconf
  definition: A tool that automatically configures source code packages to adapt to
    nearly any Unix-like operating system. It generates shell scripts that check for

- term: multilib
  definition: A system that allows a compiler to produce libraries and executables
    for multiple architectures or ABIs from a single build of the compiler. This is
    common for supporting both 32-bit and 64-bit targets, or different floating-point
    ABI variants.
- term: AC_OUTPUT_COMMANDS
  definition: An Autoconf macro that was used to define commands to be written into
    generated Makefiles or other configuration files. It has been deprecated.
- term: AC_CONFIG_COMMANDS
  definition: The current Autoconf macro for defining commands to be written into
    generated configuration files, replacing AC_OUTPUT_COMMANDS.
