This commit introduces support for the RISC-V Zvbdota family of extensions, which perform batched dot products. These extensions extend the existing Zvdota functionality by computing up to eight dot products concurrently, using scaled vector register groups and immediate values. The changes include adding assembler and disassembler support for the new operand constraints and instructions across various RISC-V extensions.
