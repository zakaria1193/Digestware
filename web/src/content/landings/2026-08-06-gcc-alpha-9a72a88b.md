A bug in GCC's Alpha backend caused the assembler to reject code by leaving behind an `ldah` instruction while removing its paired `lda` instruction. This happened because the `exception_receiver` and `builtin_setjmp_receiver` used different instruction types, making one deletable by dead code elimination while the other was not. This commit modifies the second instruction of the pair to use a new `UNSPECV_LDGP2` volatile type, ensuring both are treated as a unit and preventing the assembler error.
