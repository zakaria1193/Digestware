This commit enhances GCC's instruction generation mechanism by adding `gen_insn_<name>` wrapper functions. These wrappers, created using `make_*_insn_raw`, generate uninserted instructions directly from named patterns. This change affects various parts of the compiler, including RTL emission, code generation, and specific target backend implementations.
