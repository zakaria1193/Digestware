This commit introduces support for converting between FP8 (8-bit floating-point) and FP6 (6-bit floating-point) formats using new AVX10/v2 intrinsics. It adds numerous intrinsic functions for various conversion scenarios, including masked and unmasked operations, across different vector sizes (128, 256, and 512 bits). New test cases are included to verify the functionality of these conversions.
