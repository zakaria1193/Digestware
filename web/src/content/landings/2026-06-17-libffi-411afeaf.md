This commit updates the `LOCAL_PATCHES` file within GCC's bundled `libffi`, incorporating an upstream change that enhances how AArch64 security features are marked. Specifically, it includes a backport that enables `libffi` to emit AArch64 feature build attributes for Branch Target Identification (BTI) and Pointer Authentication Codes (PAC) when assembler support is available. This ensures that binaries compiled with `libffi` more accurately reflect their security capabilities, using a modern attribute mechanism over older GNU property notes.
