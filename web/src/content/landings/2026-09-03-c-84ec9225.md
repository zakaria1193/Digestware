This commit addresses an issue where `constexpr` structured bindings used as conditions in C++ code were incorrectly rejected by GCC. The compiler mistakenly flagged access to internal variables as out-of-lifetime during constant evaluation. The fix involves changing the internal representation from `TARGET_EXPR` to `get_temp_regvar` with `pushdecl`, which properly differentiates temporary variables from structured binding base variables.
