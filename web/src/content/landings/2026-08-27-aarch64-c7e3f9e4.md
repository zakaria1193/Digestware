primer_expert: This commit introduces the use of SVE2's `SADALP` and `UADALP` instructions
  within the AArch64 backend's expanders for `reduc_widen_ssum` and `reduc_widen_usum`.
  Previously, these widening sums were expanded using two instructions (`SADDWB`/`SADDWT`
  or `UADDWB`/`UADDWT`), which added one half of a narrow vector to the accumulator.

- term: SVE2

The compiler now utilizes the SVE2 SADALP and UADALP instructions for widening sums on AArch64, replacing the less efficient sequence of SADDWB/SADDWT or UADDWB/UADDWT. This change is applicable to scenarios like the FLAC encoder's residual sum calculation, where 32-bit values are accumulated into a 64-bit sum. The new instructions perform the pairwise widening accumulation in a single step, improving performance.
