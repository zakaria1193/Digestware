This commit introduces a new pattern for the i386 architecture that modifies the sign of floating-point numbers directly in memory. Instead of loading the value into an SSE register, performing a bitwise operation, and storing it back, the compiler now uses instructions like `btr` (bit test and reset) or `bts` (bit test and set) to flip the sign bit in memory. This is more efficient as it avoids unnecessary memory accesses and register usage, especially for operations like `fabs(*p)` or `x = -x` when applied to memory locations. It also preserves the behavior for signaling NaNs when using x87 math, unlike previous SSE-based operations.
