GCC's ifcvt pass has factored out the logic for decoding reversed conditions into a new function, noce_reversed_cond. Previously, this decoding was implemented inline in multiple matcher functions. The new function simplifies the code by handling both the condition and its associated code, reducing duplication and improving maintainability.
