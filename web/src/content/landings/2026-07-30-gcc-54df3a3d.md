GCC now centralizes common attribute handling logic into a new file, `attr-handlers.cc`. This change moves functions previously duplicated in both libgccjit and c-family compilers to a shared location. This consolidation aims to reduce code duplication and improve maintainability across different parts of the compiler infrastructure.
