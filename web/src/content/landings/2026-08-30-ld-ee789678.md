The tic6x linker's behavior for `--shared` linking was fixed. Previously, it would not create dynamic sections unless an input object contained relocations. This patch relaxes the input object suitability test, aligning it with other targets and resolving a failure in a recently added test case. It also updates testsuite entries for tic6x.
