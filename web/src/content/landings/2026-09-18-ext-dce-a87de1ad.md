The extended dead code elimination (ext-dce) pass now correctly marks all spanned hard registers as live when references involve multiple registers. This fixes a bug where `ext-dce` failed to account for all registers in multi-register references, leading to the incorrect elimination of valid code, as reported in PR127367.
