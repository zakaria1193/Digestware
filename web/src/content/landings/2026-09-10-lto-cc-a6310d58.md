This commit addresses issues with OpenMP's `declare target` directive when used with global variables in link clauses, specifically within the LTO (Link-Time Optimization) process. It prevents redundant creation of device-side pointer variables (`...$linkptr`) by checking for existing `VALUE_EXPR`s and ensures that host and device symbols are correctly finalized and outputted by calling `varpool_node::finalize_decl` and using `force_output`.
