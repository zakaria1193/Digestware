This commit enhances the initialization of V16QI vectors on x86 SSE by employing more efficient instruction sequences. The improvements aim to reduce the number of instructions generated, particularly for common initialization patterns involving byte assignments. Examples show a significant reduction in code size and complexity compared to previous GCC versions.
