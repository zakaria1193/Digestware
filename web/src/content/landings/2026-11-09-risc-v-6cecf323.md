This commit addresses a memory leak identified in the `vector_permconst` pass for RISC-V targets. The fix involves changing the `vector_permconst_table` from a dynamically managed structure to an automatic variable, ensuring its memory is properly reclaimed. Additionally, the `const_vector_hasher` struct now derives from `free_ptr_hash`, further contributing to memory management correctness. These changes prevent memory from being leaked during the execution of this optimization pass.
