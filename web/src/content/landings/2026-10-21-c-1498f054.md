This commit corrects the C++ frontend's handling of the `CPTK_STRUCTURED_BINDING_SIZE` trait, particularly for non-class types and arrays. Previously, the compiler might reject valid code if the type wasn't already instantiated. The fix involves calling `check_trait_type` appropriately and simplifying trait expression handling, resolving a bug reported in PR127766.
