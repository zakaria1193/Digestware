This commit resolves an internal compiler error (ICE) that occurred during Link-Time Optimization (LTO) when processing enumeration types (`ENUMERAL_TYPE`) that use large or huge `_BitInt` as their underlying type. The `gimple_get_alias_set` function, which was trying to determine the type size, failed for these large bit-integers, leading to the ICE. The fix ensures that the alias set is correctly determined by using the underlying `_BitInt` type directly.
