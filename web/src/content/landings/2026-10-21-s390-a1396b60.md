This commit corrects a bug in the s390 function profiler that caused a duplicated call to `__fentry__`. The issue arose from an incorrect rewrite of the `TARGET_64BIT` `else` branch during the removal of the `-m31` option. The fix reorganizes the conditional logic so that the handling for `-mnop-mcount` and the default case correctly falls under an `else` branch of the `flag_fentry` check, ensuring only a single `__fentry__` call is emitted when profiling is enabled.
