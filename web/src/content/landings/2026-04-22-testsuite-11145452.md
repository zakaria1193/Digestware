This commit marks several dg-error tests in the AArch64 SME (Streaming SIMD Extensions) test suite as expected failures (XFAILs). It also adds two xfailed dg-bogus tests. This allows downgrading the related PR to P2 and delaying the resolution of the issues to GCC 17.
