This commit updates the testsuite to mark specific tests related to AArch64's Scalable Matrix Extension (SME) as expected failures (XFAILs). This allows the issues to be addressed in a later GCC release without blocking the current release. The affected tests include `streaming_mode_1.c` and `za_state_[12].c`.
