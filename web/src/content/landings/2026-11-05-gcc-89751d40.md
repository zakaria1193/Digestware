Following the removal of `ptr_info_def`, the function `duplicate_ssa_name_ptr_info` has been renamed to `duplicate_ssa_name_pt_solution`. This change enhances clarity by aligning the function name with the remaining terminology in the SSA (Static Single Assignment) form related to pointer analysis solutions. Several internal routines that utilize this function have been updated to call the renamed version.
