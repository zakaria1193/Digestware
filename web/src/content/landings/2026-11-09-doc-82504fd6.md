The documentation for GCC's machine description (`md.texi`) has been updated to include details on the `clmul` and `clmul_widen` optabs. These operations, which are related to the `__builtin_clmul` intrinsic, were previously undocumented, lacking information on operand order, semantics, and potential failure conditions.
