This commit addresses an issue where IPA predicates incorrectly matched bit-field conditions against byte offsets. The predicate conditions were stored as bit offsets, while jump function values used byte offsets. The existing logic divided bit offsets by 8, losing sub-byte position information and leading to incorrect matching. This caused a test case to misinterpret a bit-field, resulting in unreachable code elimination and a fall-through into `_start`. The fix ensures that lookups are skipped for non-byte-aligned conditions, resolving PR 126153.
