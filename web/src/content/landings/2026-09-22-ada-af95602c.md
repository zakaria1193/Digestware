This commit further cleans up the implementation of freezing for Ada expression functions, bringing it closer to the semantic model. It eliminates obsolete code exposed by previous refactoring and corrects how aspect expressions are resolved, ensuring both component prefixes and subcomponent prefixes are handled correctly. Selector names in expanded names are also now resolved as direct names, fixing a previous inaccuracy.
