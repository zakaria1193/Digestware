Fixes a C++ modules issue where pointer-to-member constants were not always marked as used during module import. This could lead to the compiler neglecting to emit the member definition, causing linking to fail. The fix ensures that `TREE_USED` is set on `PTRMEM_CST_MEMBER` during stream-in, guaranteeing that the member is emitted.
