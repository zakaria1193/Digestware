This commit enhances the RISC-V backend by generalizing cost modeling for word packing instructions, specifically with the Zbkb extension. It extends the cost calculations for `packh` to also cover `pack` operations, enabling the `combine` pass to select these instructions when Zba is enabled. Performance improvements were observed in microbenchmarks and benchmarks like the SQLite varint decoder.
