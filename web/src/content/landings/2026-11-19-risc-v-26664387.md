The RISC-V psABI mandates that 2*XLEN scalar arguments and return values be ordered by significance, irrespective of endianness. On big-endian targets, this significance-based ordering differs from the typical memory layout ordering. This commit implements the correct significance-based ordering for named 2*XLEN scalar register pairs. Anonymous variadic arguments, aggregates, and floating-point reals maintain their existing memory-layout ordering to ensure compatibility with existing conventions.
