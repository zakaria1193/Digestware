gccrs has implemented proper handling for match arm guards, which were previously not type checked or compiled. An arm with a guard would incorrectly be taken solely based on pattern matching. This change ensures that guards are type checked as boolean expressions and evaluated after the arm's bindings. If a guard evaluates to false, compilation proceeds to the next arm. The implementation extends to unsafe, const, and pattern checkers, addressing Rust-GCC/gccrs#4957.
