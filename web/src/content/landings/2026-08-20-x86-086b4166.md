The x86 backend now allows direct loading of minus ones into MASK registers and standard constants into SSE registers. This change replaces memory loads with more efficient register operations, such as using `kxnor %k0, %k0, %k0` to load -1 into a mask register, which can improve performance for certain instruction sequences. Several test cases have been added to verify this functionality.
