Aligned memory allocation functions in libstdc++ could return a pointer to memory smaller than requested due to size_t overflow during size rounding. This commit introduces checks for such overflows in various aligned allocation implementations, including fallback mechanisms and platform-specific functions like _aligned_malloc on Windows. This prevents the allocation of undersized buffers, enhancing memory safety.
