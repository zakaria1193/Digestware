A recent optimization for widening multiplies caused a minor testsuite regression on the arc port. The compiler now generates component SI multiplies instead of a full 'muldi' instruction as expected by the test. To resolve this without altering the optimization's design, the testsuite has been updated to disable expensive optimizations, effectively restoring the older code generation behavior for this specific test.
