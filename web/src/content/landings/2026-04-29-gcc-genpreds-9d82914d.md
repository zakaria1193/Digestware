This commit introduces foundational support for dependent, dynamic register filters within GCC's `genpreds` tool. Unlike traditional register filters that are static, these new filters can depend on or refer to other operands in an instruction, requiring runtime evaluation. The `genpreds` tool now generates the necessary evaluation functions and infrastructure, enabling more sophisticated and flexible register constraint checking during instruction recognition and selection.
