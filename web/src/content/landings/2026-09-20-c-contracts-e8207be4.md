This commit addresses an issue in C++26 contract handling where the return value of a function could be destroyed twice, or an internal compiler error (ICE) could occur. The problem arose from creating an artificial block for contract assertions which duplicated cleanup code. The fix involves overriding the return value sentinel management within this artificial block to ensure proper cleanup.
