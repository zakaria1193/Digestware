A new flag has been added to gccrs to unify the behavior of 'expect never' during type coercion. This change affects multiple functions within `rust-coercion.cc` and `rust-unify.cc`, introducing a consistent way to handle scenarios where a type is expected to be `never`. This aims to resolve issues related to type coercion and unification, as indicated by the fix for Rust-GCC/gccrs#4918.
