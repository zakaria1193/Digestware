This patch enhances the RTL expansion for `bitreverse` and `store_fixed_bitfield` operations by introducing a new `aop_optab`. This `aop_optab` allows target backends to precisely choose between bitwise OR, XOR, or addition instructions, leading to better code generation on various architectures like x86, RISC-V, and AVR. Previously, the expansion relied on a generic `PLUS` or `IOR` that might not be optimal. This change provides finer control, yielding more efficient code, as demonstrated by an improved `x86_64` expansion for a struct assignment.
