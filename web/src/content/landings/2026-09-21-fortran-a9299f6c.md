This change addresses a bug in Fortran pointer assignments where the span of an array pointer was not correctly copied from its target descriptor. By marking the _data field of array pointer class containers with GFC_DECL_PTR_ARRAY_P, the compiler now ensures that the span is copied from the target descriptor, even for polymorphic arrays. This corrects issues related to derived types and ensures accurate array behavior.
