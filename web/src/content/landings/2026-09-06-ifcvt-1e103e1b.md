The GCC ifcvt pass now factors the scan for instruction sequences that clobber the non-canonicalized condition code into a new function, `noce_seq_clobbers_cc_cmp_p`. Previously, `noce_convert_multiple_sets_1` performed this scan twice for candidate sequences, once with and once without a specific instruction. This refactoring consolidates the logic, improving code efficiency and maintainability without functional changes.
