This commit introduces a comprehensive set of test cases for the RISC-V Vector extension, specifically targeting the `vwmaccsu.vv` instruction concerning register group overlap. These tests aim to ensure correct behavior when vector registers are reused or overlap during the execution of this instruction, covering various data types and vector lengths.
