GCC's middle-end can now perform constant folding for various CRC (Cyclic Redundancy Check) built-in functions. This change computes CRC values at compile time when all arguments are compile-time constants, replacing runtime table-based computations with a simpler loop calculation. This optimization avoids runtime overhead for CRC operations, especially beneficial in performance-sensitive code. Future work will include architecture-specific CRC folding.
