This commit addresses an issue in gccrs where merging name resolution contexts for extern crates did not correctly merge usage bindings. Previously, only name declarations were merged, leading to problems such as return types within functions not being recognized. By ensuring usage bindings are also merged, the compiler can now correctly resolve these types.
