Previously, BF16 absolute value tests used `__builtin_fabsf16`, which after a compiler change, caused the vectorizer to reject them due to an unnecessary intermediate conversion. This commit switches the tests to use `__builtin_fabsf`, which correctly handles BF16 input by promoting it to a float. This allows the vectorizer to process the loops again, yielding the same runtime results but improving code generation efficiency.
