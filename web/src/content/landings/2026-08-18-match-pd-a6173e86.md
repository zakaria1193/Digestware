This change modifies the MIN/MAX narrowing in match.pd to use MIN/MAX followed by a convert operation. Previously, the narrowing was limited to single uses of the result, failing to support scenarios with explicit vector type conversions like converting between v2si and v2di. The new approach generates more efficient assembly by first performing the minmax on the wider type and then converting to the narrower type, resolving issues with PR middle-end/126906.
