This commit enhances the x86 backend's handling of local variables passed as register arguments. It now correctly identifies and processes cases where an SSA_NAME is spilled into argument-linked memory, specifically when that memory is used to store a local variable. Previously, the compiler might incorrectly return true in such scenarios, preventing proper optimization. The change, motivated by PR target/126450, ensures more accurate register allocation and spilling by properly recognizing the usage of argument-linked memory for local variables.
