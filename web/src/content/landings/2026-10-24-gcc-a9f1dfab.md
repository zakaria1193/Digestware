This commit refactors code generation in multiple GCC backends, including arc, arm, epiphany, msp430, nds32, and sh, by separating instruction patterns from the actual RTL instructions they generate. This change improves the clarity and maintainability of the code emission logic, particularly for complex instruction sequences like stack manipulations or register saving/restoring. By treating patterns and emitted instructions distinctly, the compiler can manage intermediate code representations more effectively.
