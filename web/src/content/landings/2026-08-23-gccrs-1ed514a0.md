This commit lays the groundwork for integrating LLVM builtins into gccrs by implementing initial adapter functions. Currently, it supports specific x86 builtins such as `rdrand`, `rdseed`, `addcarry`, and `subborrow` for various data sizes. These adapters translate LLVM's intrinsic calls into equivalent GCC `__builtin_ia32_` calls, allowing Rust code using these functions to compile correctly.
