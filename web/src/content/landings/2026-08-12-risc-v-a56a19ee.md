This commit introduces support for descending floating-point load/store pair fusion on RISC-V architectures. It reuses the existing pair matcher logic to add capability for pairs that access memory addresses in descending order. The change includes a new test case (`fusion-fldfst-pair-dec.c`) to verify this functionality. While the fusion capability is added, it is currently marked as XFAIL (expected to fail) in the test suite, as the selected tuning for the tests disables this specific capability, ensuring that the new code path is correctly integrated and can be tested once enabled.
