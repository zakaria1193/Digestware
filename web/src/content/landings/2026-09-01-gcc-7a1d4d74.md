This commit addresses failures in two test cases, `pr123109-vector.c` and `pr123109-scalar.c`. The vector test now correctly uses `SImode` elements for its `v4si` and `v4usi` types, resolving shift count overflow warnings. The scalar test was modified to use 32-bit integer types, fixing similar shift count overflow issues and pattern matching failures related to integer size assumptions.
