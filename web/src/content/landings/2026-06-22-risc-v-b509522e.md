Binutils now includes minimal support for the new RISC-V supervisor extension, Svrsw60t59b. This update primarily involves integrating the extension into the Binary File Descriptor (BFD) library and the GNU Assembler (GAS), allowing these tools to recognize and handle code compiled with this extension. This prepares the toolchain for future software and hardware that leverage this new supervisor-level functionality.
