The `gcc_AC_C_ENUM_BF_UNSIGNED` macro, which was used to determine if enum bitfields were unsigned by default, has been removed. This macro was no longer necessary because it was not used within GCC itself since a previous cleanup, and a subsequent change further deprecated its underlying functionality. This commit cleans up the build configuration by removing dead code.
