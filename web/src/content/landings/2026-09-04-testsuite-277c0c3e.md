GCC's testsuite for the analyzer on Darwin now correctly handles older operating system versions that do not define the `O_CLOEXEC` flag. The tests `mkostemp-1.c` and `mkostemps-1.c` have been updated to provide a dummy definition for `O_CLOEXEC` when it's missing, ensuring compatibility back to Darwin 9.
