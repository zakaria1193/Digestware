This commit entirely removes the ARI (Automated Review Interface) system from GDB. While ARI reporting was disabled some time ago, its associated code remained in the debugger. The system, originally intended to enforce GDB coding standards, was ultimately deemed more of a hindrance than a help. Its removal cleans up the codebase and streamlines GDB's development process.
