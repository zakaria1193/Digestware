This commit adjusts the expected outputs for a number of RISC-V test cases in the GCC test suite. A recent generic change in the compiler subtly altered the generated assembly code for various tests. After reviewing these changes and confirming their validity from a code generation perspective, the expected outputs in the test suite have been updated to match the new behavior, ensuring the test suite remains accurate.
