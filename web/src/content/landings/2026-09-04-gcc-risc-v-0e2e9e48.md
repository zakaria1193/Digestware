This patch introduces a scalar `memset` implementation for RISC-V, improving code generation when vector `memset` expansion is not possible or efficient. It adds a test mode for expanders to check for support without emitting code and a new scalar `memset` expander for non-zero values and known lengths, preventing unnecessary libcalls.
