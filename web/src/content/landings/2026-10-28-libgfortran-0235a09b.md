This commit introduces robust overflow checking for coarray size calculations within libgfortran's shared memory implementation. Previously, multiplying the per-image size by the number of images could result in an integer overflow, leading to an incorrectly small allocated size and potential data corruption. The fix saturates size arithmetic at `SIZE_MAX` and rejects requests for sizes that cannot be rounded up to a power of two, ensuring that such operations fail gracefully with appropriate error reporting.
