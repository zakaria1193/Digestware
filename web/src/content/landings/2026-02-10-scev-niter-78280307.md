The loop iteration analysis logic in GCC's scalar evolution (SCEV) component now relies on the `INTEGRAL_NB_TYPE_P` macro instead of directly comparing types to `INTEGER_TYPE`.  This change makes the code more robust in identifying integer types, specifically including boolean types, which were previously missed. This improves the accuracy of loop analysis.
