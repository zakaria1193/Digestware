This commit refactors the `compute_exit_dependencies` function within GCC's path solver. It extracts the logic for closing dependencies into new, separate methods (`close_dependencies` and `add_dependencies_of`). This restructuring does not change the existing functionality but prepares the code for a subsequent commit that will allow closing a set of names for dependency analysis, improving maintainability and enabling future optimizations.
