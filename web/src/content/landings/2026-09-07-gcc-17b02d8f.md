This change integrates the conversion of `_BitInt` types to and from various floating-point types into GCC's existing optab (operator table) infrastructure. This allows for more efficient handling and potential caching of these conversions, especially when multiple conversions occur. Previously, these conversions were often generated manually, leading to less optimized code and difficulties in overriding specific library function names. The new approach uses dedicated optabs for these conversions, improving consistency and maintainability.
