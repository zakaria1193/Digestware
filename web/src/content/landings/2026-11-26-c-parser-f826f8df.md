This commit addresses a spurious warning from GCC's `-Wshift-count-negative` option that was incorrectly triggered for the `__builtin_stdc_bit_floor` and `__builtin_stdc_bit_ceil` functions. These built-ins are lowered by the C parser into shift operations. In certain edge cases, such as when the input argument is 0 or 1, the generated shift operation is part of dead code. However, due to intermediate folding by `c_fully_fold`, the shift count could be evaluated to a negative value, triggering the warning. The fix suppresses the warning specifically for these shift expressions generated by the built-ins and also ensures that the warning is not emitted if it has already been suppressed, preventing the bogus warning from appearing.
