To address discrepancies between gccrs's default target Rust version (1.49) and newer requirements, a new command-line option `frust-compat-version` has been added. This allows users to specify a target Rust compatibility version, enabling gccrs to account for backward-incompatible language or library changes between Rust versions. This is particularly useful for compiling older codebases, like `libcore` for Rust Linux, without needing to explicitly enable post-1.49 features.
