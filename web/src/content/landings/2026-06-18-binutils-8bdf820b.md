The `check-whitespace-pre-commit.py` script, used in GDB's development process, now performs comprehensive whitespace checks on almost all files. Instead of an `allow` list, the script now uses a `todo_list` to exclude files that are not yet whitespace-clean. This change improves code quality by enforcing consistent whitespace conventions across most of the codebase.
