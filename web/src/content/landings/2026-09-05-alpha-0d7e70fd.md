This commit introduces support for the `R_ALPHA_IRELATIVE` dynamic relocation type on the Alpha architecture. This relocation is used by the dynamic linker (or static executable startup code) to execute an IFUNC's resolver and store the returned address. The commit assigns the next available number (42) to this relocation and adds its definition to the BFD reloc map and the Alpha ELF header, preparing for its use in linking.
