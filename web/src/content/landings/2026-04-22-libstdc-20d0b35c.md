The ``mdspan`` deduction guide in libstdc++ now accepts ``data_handle_type`` by value, ensuring consistency with the corresponding constructor. This change resolves LWG4511, and a new test case validates the corrected behavior.  This allows more flexible usage of ``mdspan`` with different data handle types.
