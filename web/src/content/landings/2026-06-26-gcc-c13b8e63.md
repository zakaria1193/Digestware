This commit significantly improves the GDB Python script used for pretty-printing GCC's internal Real-Time eXpressions (RTX) data structures. It enhances the output for various RTX types, including adding specific details for register nodes and instruction codes, making it easier for developers to inspect compiler internals during debugging.
