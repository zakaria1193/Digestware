This commit refactors the `operator_abs::fold_range` function within GCC's range analysis to operate on sub-ranges independently. Previously, taking the absolute value of a range could collapse distinct sub-ranges if they spanned across zero. Now, the absolute value is applied to each sub-range, and the results are unioned, preserving gaps and more accurately representing the range's properties.
