The Rust compiler's backend has been updated to use `build_int_cst(integer_type_node, cst)` instead of `build_int_cst(NULL_TREE, cst)`. This change standardizes the creation of integer constants, with the goal of removing the `build_int_cst_type` function in the future and improving code maintainability.
