The gccrs compiler now supports the 'dispatch_from_dyn' language item specifically for the 'Box' type. This enables correct dynamic dispatch for Boxed values. While other smart pointers could also use this feature, they are not yet fully supported. This change includes updates to the expression compiler, type checker, and language item registration.
