The libgfortran library on Darwin has been updated to disable its shared memory coarray implementation on macOS versions prior to 10.7 (Darwin 11). This is because the implementation relies on `PTHREAD_PROCESS_SHARED`, which is not supported on these older systems. This change prevents the shared memory coarray features from causing testsuite noise on unsupported platforms.
