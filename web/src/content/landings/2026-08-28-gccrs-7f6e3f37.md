This commit enhances gccrs's borrow checker by preventing multiple moves from the same product-type expression (like structs or tuples). It achieves this by passing the expression's HIR ID through the BIR, allowing the analysis to identify and reject attempts to move from the same source multiple times. A new test case validates this behavior.
