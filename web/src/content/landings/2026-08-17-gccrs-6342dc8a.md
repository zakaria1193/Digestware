Compile times in gccrs are improved by refactoring debug output calls into a do-while wrapper. This change ensures that arguments to debug functions are only evaluated when debugging is actually enabled, preventing unnecessary computation and speeding up compilation when debug output is turned off. The changes affect `rust-diagnostics.cc` and `rust-diagnostics.h`.
