A new helper function called `lookup_annotation` has been added to the C++ frontend. This function simplifies the process of looking up annotations associated with program entities. The new helper is used in several places in the compiler, including `grokfndecl`, `grokdeclarator`, `push_local_extern_decl_alias`, `cp_parser_decomposition_declaration`, and `eval_annotations_of`.
