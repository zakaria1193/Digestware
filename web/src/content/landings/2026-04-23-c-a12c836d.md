Introduces a new helper function, `lookup_annotation`, to centralize and simplify the process of looking up annotations within the C++ compiler. This function is now used in several places, including `grokfndecl`, `grokdeclarator`, `push_local_extern_decl_alias`, `cp_parser_decomposition_declaration`, `eval_annotations_of`. This change aims to improve code readability and maintainability by providing a single, well-defined way to access annotations.
