This commit introduces a new helper function called ``lookup_annotation`` to simplify the process of looking up annotations within the compiler's internal representation. This helper is used in multiple places, including ``grokfndecl``, ``grokdeclarator``, ``push_local_extern_decl_alias``, ``cp_parser_decomposition_declaration``, and ``eval_annotations_of``. By centralizing the annotation lookup logic into a single function, this change improves code readability and maintainability.
