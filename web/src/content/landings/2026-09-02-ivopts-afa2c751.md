This patch fixes a bug in the induction variable (IV) elimination optimization when the loop exit condition involves a less-than comparison. The previous implementation could unsoundly compute loop bounds, leading to incorrect pointer arithmetic or even out-of-bounds memory access, particularly when loops execute zero times or when offsets are large and wrap around the address space. The fix recomputes the bound more robustly and enforces conditions for safe unsigned comparisons.
