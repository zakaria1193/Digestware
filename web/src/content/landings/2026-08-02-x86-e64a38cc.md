Several test cases for x86 vector initialization were using the incorrect flag `-mno-sse4.1`. This commit replaces it with `-mno-sse3` to accurately reflect the desired test conditions. The change ensures that tests dependent on SSE3 features do not accidentally pass due to broader SSE4.1 disabling.
