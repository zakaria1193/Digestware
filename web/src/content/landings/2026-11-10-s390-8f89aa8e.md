The s390 assembler now supports the `.insn` pseudo-mnemonics rx_a and rx_b, which represent specific variations of the RX instruction format. This change adds these mnemonics to the opcode definitions and includes new test cases for z/Architecture. The assembler does not enforce architecture or CPU level requirements for these pseudo-mnemonics.
