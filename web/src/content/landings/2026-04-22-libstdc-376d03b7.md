The `__cpp_impl_reflection` and `__cpp_lib_reflection` feature test macros were increased to `202603L` to indicate the implementation of P3795R2, a C++ reflection proposal.  The implementation is complete except for the `is_applicable_type`, `is_nothrow_applicable_type` and `apply_result` metafunctions; code should test `__cpp_lib_reflection >= 202603L && __cpp_lib_apply >= 202603L` to check for those.
