Binutils' BFD library has been updated to recognize the 32-bit core file format used in AIX 7.3. Previously, GDB would report these files as unrecognized, preventing analysis. This change adds support for the specific `CORE_DUMPXX_VERSION_AIX73` identifier, enabling proper core dump handling.
