This commit addresses a bootstrapping problem on MinGW targets with `bootstrap-lto-lean` and `--enable-plugin`. The issue arose because plugin libraries were incorrectly configured to export all symbols, leading to symbol table overflow and LTO symbol export failures. The fix modifies the MinGW host makefile to prevent exporting internal symbols from specific frontends (gnat1, f951, lto1, etc.) and adjusts LTO object handling for `cc1`/`cc1plus` to ensure successful linking. `libgccjit`'s public import library is preserved.
