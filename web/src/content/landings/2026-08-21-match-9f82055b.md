The match-tree-optimization code in GCC has been updated to use `wi::to_wide` instead of `tree_to_uhwi` in the `mul_hi` and `mul_lo` patterns. This change is a small compile-time optimization, as `wi::to_wide` is expected to have minimal overhead in this context, potentially leading to slightly faster compilation.
