The Ada toolchain's build system incorrectly handled the `GNATMAKE_FOR_BUILD` Makefile variable. Instead of passing it directly to sub-makes, it was exported for sub-configures, leading to incorrect build behavior. This change modifies the Makefiles to ensure `GNATMAKE_FOR_BUILD` is passed directly as intended, resolving build issues related to this variable.
