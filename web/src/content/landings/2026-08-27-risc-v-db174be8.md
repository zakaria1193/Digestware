This commit introduces new test cases for the RISC-V vector instructions `vwmacc.vx` and `vwmaccu.vx`. These tests cover scenarios involving CSRR (Control and Status Register) checks when overlap is enabled, aiming to improve the robustness of the compiler's support for these vector operations.
