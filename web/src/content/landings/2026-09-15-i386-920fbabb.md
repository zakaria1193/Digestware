An internal compiler error (ICE) in `split_double_mode` on the i386 architecture has been fixed. The issue occurred when attempting to split a paradoxical subregister in a double-precision mode. The compiler now correctly handles these cases by assigning a zero value to the high half of the split register, preventing the ICE and ensuring correct code generation.
