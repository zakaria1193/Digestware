This commit allows register overlap for the RISC-V vector instruction `vwmulsu.vx`. Similar to other widening vector multiplication instructions, this change enables the reuse of vector registers, which can lead to more efficient code generation. The change modifies the vector constraint in the GCC target configuration for RISC-V.
