GCC introduces support for the AVX10_V2_AUX instruction set extensions. This enables new single-source runtime-selected (RTNE) conversions between FP32 and FP8 floating-point formats. The changes include updates to CPU feature detection, intrinsic functions, and machine-level code generation for the x86 architecture.
