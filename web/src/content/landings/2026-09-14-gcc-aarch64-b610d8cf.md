This commit introduces support for several new AArch64 Scalable Matrix Extension (SME) version 2.1 structured sparsity outer product intrinsics. These intrinsics, requiring the `+sme-tmop` and various `+sme-f*` or `+sme-b*` architecture options, enable specialized matrix operations for sparse data. The changes include adding new intrinsic shapes, register constraints, and predicates to the compiler, along with associated tests and documentation updates.
