The gccrs compiler's High-Level Intermediate Representation (HIR) map has been refactored to improve organization by regrouping all proc macro-related operations into a specialized subclass. This change consolidates functionality, making the HIR map more manageable and easier to navigate for developers working on the Rust frontend. Affected components include macro expansion, name resolution, and session management.
