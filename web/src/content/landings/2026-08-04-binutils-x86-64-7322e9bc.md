This change prevents a segmentation fault in the x86-64 linker when processing non-ELF input. Previously, `elf_x86_64_common_definition` would crash if the input file was not in ELF format. The fix ensures that the linker returns `SHN_COMMON` for non-ELF input, leading to an assertion failure in `bfd/coffgen.c` instead of a crash, thereby improving stability.
