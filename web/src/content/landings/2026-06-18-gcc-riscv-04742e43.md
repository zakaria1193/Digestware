This commit improves code generation for RISC-V by introducing a new splitter for equality comparisons of the form `X eq C`, specifically when `C` is a small constant. Since RISC-V lacks a direct `setCC` style instruction for comparing a register against a constant, GCC previously generated a multi-instruction sequence. The new splitter rewrites these comparisons into a more efficient two-instruction sequence, leading to slightly smaller and faster code.
