The `genmatch` tool, which generates decision trees for pattern matching, previously mishandled overlapping sets of delayed operators, leading to duplicate case labels in generated code. This change partitions expression and function nodes into connected groups that share concrete switch cases, emitting each group's cases only once and guarding matchers for partial overlaps. This resolves duplicate labels and slightly increases generated source size.
