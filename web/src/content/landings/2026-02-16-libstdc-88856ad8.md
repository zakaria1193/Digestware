GCC's libstdc++ now supports creating and manipulating symbolic links on Windows. This change introduces new functions for symlink operations, ensuring they are available only on Windows versions that support this feature. It also handles potential differences in path resolution and addresses an issue with creating unprivileged symlinks by retrying the operation without the flag if an error occurs.
