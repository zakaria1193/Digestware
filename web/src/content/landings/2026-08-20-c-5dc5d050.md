In the C++ frontend, the `lookup_destructor` function now correctly passes the `complain` flag down to the `lookup_member` function. While this change does not fix any existing issues, it improves the handling of SFINAE (Substitution Failure Is Not An Error) diagnostics by ensuring that error reporting is consistently propagated during member lookups.
