A bug in path instrumentation for `gcov` has been fixed by changing how prime paths are inserted into SCCs. The previous use of `insert` instead of `insert_with_suffix` could lead to non-maximal paths being preserved, resulting in incorrect path counts reported by `gcov`. Using `insert_with_suffix` ensures all path suffixes are correctly processed, even if it incurs a slight compile-time overhead.
