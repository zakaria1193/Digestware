This commit addresses an issue in the lowering of large and huge `_BitInt` type PHI nodes. Previously, copies for incoming edges were processed sequentially, leading to race conditions where one copy could overwrite a value needed by a subsequent copy on the same edge. The fix processes these copies edge by edge as a parallel operation, using temporaries to safeguard values if necessary, thus preventing incorrect results and ensuring the integrity of `_BitInt` computations.
