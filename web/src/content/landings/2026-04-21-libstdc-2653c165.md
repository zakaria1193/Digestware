The ``__integral_constant_like`` concept, which checks if a type behaves like an integral constant, is now implemented in terms of ``__constexpr_wrapper_like``. This change, implementing LWG4486, eliminates code duplication and makes the library easier to maintain. ``__constexpr_wrapper_like`` has been moved from ``bits/simd_details.h`` to ``std/concepts``.
