This commit addresses a bug in Fortran's handling of class allocations where virtual pointers (vptrs) were not being correctly initialized. Changes in `trans-array.cc` and `trans-stmt.cc` ensure proper array descriptor usage and assignment for class sources. A new test case, `allocate_class_5.f90`, is added to verify the fix.
