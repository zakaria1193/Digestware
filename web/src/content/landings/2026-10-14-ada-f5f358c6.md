This commit fixes an assertion failure in the Ada compiler's contract processing. The `Make_Class_Precondition_Subps` function was incorrectly called for primitive wrapper subprograms, which are not intended to have class preconditions. The fix modifies the function to accept these wrapper subprograms, thereby preventing the assertion failure and ensuring correct handling of Ada contracts.
