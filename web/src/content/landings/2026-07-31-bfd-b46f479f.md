This commit corrects an issue in the AIX RS/6000 core file handler (`rs6000-core.c`) where build-time checks for BFD64 were incorrectly applied. These checks, intended for differentiating 32-bit and 64-bit builds, were found to be bogus and potentially broke the reading of older core files. The commit removes these erroneous conditional compilation blocks and initializes a missing field in a non-CORE_NEW code path.
