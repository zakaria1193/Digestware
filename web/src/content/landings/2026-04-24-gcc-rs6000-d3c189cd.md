GCC would crash (ICE) during C++ template parsing on rs6000 due to premature folding of expressions with non-dependent types.  This commit delays folding operations until after template instantiation by using non-folding equivalents like `convert` and `build2` instead of `fold_convert` and `fold_build2` during the initial parsing, which avoids the crash.  This fix specifically targets C++ code and does not affect C code.
