This commit resolves an Internal Compiler Error (ICE) occurring in the C front-end when `__builtin_has_attribute` is used with a variable and the `pure` attribute. The issue arises because `DECL_PURE_P` incorrectly accepts `FUNCTION_DECL` when a `VAR_DECL` is passed. The fix ensures that the function correctly checks for `FUNCTION_DECL` when `TREE_CODE` is evaluated.
