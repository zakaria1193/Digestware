The RISC-V vector cost model now differentiates the cost of permute instructions based on the LMUL (vector length multiplier). Previously, a single `permute_cost` was used, but this commit changes it to an array indexed by LMUL (1, 2, 4, 8). This allows for more accurate cost estimation, particularly modeling non-linear scaling, and defaults to quadratic scaling for generic cores. This change has caused regressions in tests where generic segment costs were previously too cheap, and specific instructions like `bswap16` were miscosted.
