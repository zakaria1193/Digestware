A new pattern has been added to `match.pd` to recognize and fold a specific idiom for calculating a rounded-up average: `((x >> 1) + (y >> 1)) + ((x | y) & 1)`. This idiom is mathematically equivalent to `(x | y) - ((x ^ y) >> 1)`, which is a more optimized form. This change is particularly relevant for targets with averaging instructions and for vector types, where it reduces the number of instructions generated for motion-compensation averages in media codecs.
