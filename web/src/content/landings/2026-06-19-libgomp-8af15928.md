OpenMP now provides a new routine, `omp_get_device_distances`, allowing applications to determine the spatial proximity between the executing thread and available GPU devices. This function is particularly beneficial on systems with multiple devices and NUMA architectures, where minimizing data transfer latency by selecting a geographically closer GPU can significantly improve performance. The API permits developers to optimize device selection based on hardware topology, enhancing performance for offloaded computations.
