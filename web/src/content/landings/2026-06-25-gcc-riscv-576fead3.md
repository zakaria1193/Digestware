  can complicate simple bit operations. This commit improves the compiler's ability
  to recognize these patterns and generate the faster `Zbs` instructions, making programs

This commit enhances the RISC-V backend's ability to generate Zbs bit manipulation instructions, addressing PR123884. The compiler frequently struggled to produce optimal `bset`, `bclr`, or `binv` instructions for single bit manipulations, especially with sub-word objects that get promoted to word size. This update improves code generation efficiency for common bitwise operations.
