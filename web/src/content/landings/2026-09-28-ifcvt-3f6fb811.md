The if-conversion pass's `find_cond_trap` function has been updated to prevent it from overwriting a live condition-code register. Previously, on SPARC, this could lead to incorrect program behavior when a condition code set earlier in the code was needed by a later branch, causing miscompilations, particularly for switch statements with unreachable default cases. The fix reuses an existing check (`noce_clobbers_live_cc_p`) to ensure condition codes are not clobbered, resolving issues on SPARC64.
