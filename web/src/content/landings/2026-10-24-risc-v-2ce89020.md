GCC now includes a framework to manage hardware errata for specific RISC-V cores. A new `riscv-errata.def` file lists errata, each with a corresponding `-mfix-NAME` option. CPU cores in `riscv-cores.def` can be associated with specific errata. The `--with-errata` configuration option enables errata workarounds by default for cores or specified errata lists. Additionally, functions with different errata are now prevented from being inlined into each other, preserving correct behavior.
