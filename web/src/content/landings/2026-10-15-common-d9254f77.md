The `-fduplicate-switch-dispatch` optimization, which improves dispatch speed at the cost of code size, is now enabled by default for `-O2` builds. This option complements the existing computed-goto unfactoring and has shown significant performance improvements on benchmarks like `mawk` and `QuickJS-ng` on AArch64 systems. It remains disabled for size-optimized builds (`-Os`, `-Oz`) and size-optimized functions.
