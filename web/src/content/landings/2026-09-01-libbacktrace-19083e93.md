This change updates several functions within `libbacktrace` that handle symbol information for PE/COFF and XCOFF object file formats. Instead of hardcoding the value `3` for `BACKTRACE_MOREDATA_VERSION`, it now uses the defined constant. This ensures consistency and makes the code more robust against future changes in the MOREDATA versioning scheme.
