GCC now supports generating vectorized math function calls to the HYGON Vector Math Library (HVML) through the new option `-mveclibabi=hvml`. This complements existing support for Intel SVML and AMD ACML/AOCL. The implementation maps 39 scalar math function families, including C23 trigonometric functions, to HVML's naming conventions. It requires a 64-bit target and unsafe math optimizations, and test cases have been added to verify its functionality and constraints.
