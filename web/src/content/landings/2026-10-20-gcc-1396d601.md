This change modifies the `single_use` tracking in `match.pd` to monitor if all uses of an expression occur within a single statement, rather than just a single actual use. This correction is necessary for correctly handling complex vector permutation expressions where a subexpression might be used multiple times within the same statement, ensuring that optimizations like `VEC_PERM_EXPR` are applied as expected.
