The i386 backend now uses the MODE_SIZE attribute in several places, replacing direct calls to GET_MODE_SIZE. This change simplifies double-word checks in 'cstore<mode>4' by using MODE_SIZE > UNITS_PER_WORD and bt_comparison_operator, eliminating explicit mode tests and code comparisons. No functional changes result from this simplification.
