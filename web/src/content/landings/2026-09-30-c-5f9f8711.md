This commit addresses an Internal Compiler Error (ICE) that occurred when the `-Wsubobject-linkage` warning was enabled for code involving function types or pointers to data members. The compiler crashed when attempting to access `TYPE_MAIN_DECL` of a function type, which lacks such a declaration. The fix adds a check for `OVERLOAD_TYPE_P` before calling `decl_anon_ns_mem_p`, preventing the invalid access.
