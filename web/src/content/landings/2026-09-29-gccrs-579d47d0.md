gccrs has corrected the implementation of the remainder operation for single-precision (f32) and double-precision (f64) floating-point types. Previously, attempting to use a generic binary operation resulted in an Internal Compiler Error (ICE) because GCC's later passes do not support this operation for these types. The fix involves calling the appropriate `remainder{,f,l}` builtins and storing their results.
