Several branchless matchers in GCC's ifcvt pass shared identical code for winding up, validating, and emitting the transformed sequence. This commit extracts this common logic into a new function, `noce_commit_sequence`. This reduces code duplication and improves maintainability without altering the optimization's behavior.
