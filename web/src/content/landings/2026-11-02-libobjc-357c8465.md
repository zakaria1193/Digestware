The build system for libobjc has been updated to replace the deprecated `AC_LIBTOOL_WIN32_DLL` macro with the modern approach of passing `win32-dll` directly to `LT_INIT`. This change ensures compatibility with newer versions of libtool and maintains correct build configuration for Windows DLLs. No functional changes are expected as the macro was called before `LT_INIT`.
