GCC is changing how it represents type qualifiers. Previously, `int` was used as a bitmask for qualifiers like `const` and `volatile`. However, with the introduction of address space qualifiers, this approach leads to incorrect bitwise operations when merging qualifier sets. This commit modifies the internal representation to correctly handle the combination of standard qualifiers and address spaces, preventing subtle bugs, particularly in C++ named address space support.
