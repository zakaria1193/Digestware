The `libgcobol` library has corrected the `CBL_GET_PROGRAM_INFO` function to align with its documented return values and buffer handling. Previously, the function did not consistently honor the specified return codes or exhibit the expected behavior for `return-buf` and `return-buf-len` parameters. This update ensures greater adherence to the function's specification.
