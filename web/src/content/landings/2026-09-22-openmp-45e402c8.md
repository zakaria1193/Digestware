This patch implements the 'local' clause for the OpenMP `declare target` directive. This new clause allows variables to have non-associated versions on the host and device, preventing them from being automatically managed by the offloading machinery. When a 'local' variable is modified on the GPU, `omp target update` will not work as expected, confirming its local scope. This feature is integrated by extending the existing `declare target` attribute handling in the front-ends.
