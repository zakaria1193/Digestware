This commit introduces a workaround in gccrs for Rust's `#[rustc_legacy_const_generics]` attribute, which is necessary for compiling certain parts of `stdarch`. This attribute is a legacy feature used to enable const generics in older Rust code. The implemented shim provides a starting point for handling these constructs, although it doesn't fully implement the attribute's behavior. The change adjusts type cast rules and adds related attributes.
