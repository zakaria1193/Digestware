The s390 assembler now supports .insn pseudo-mnemonics for the RRF-a, RRF-b, RRF-c, RRF-d, and RRF-e instruction variants. These variants, which include optional operands and can predate specific architecture levels, are now correctly documented and tested. The changes also fix existing tests for the RRF instruction.
