The AArch64 backend in GCC previously did not set reservation information for Scalable Vector Extension (SVE) instructions, leading to a large number of 'nothing' entries in the Data Flow Analysis (DFA) for instruction scheduling. This commit rectifies this by treating all SVE instructions as basic NEON instructions. This change ensures that the DFA can more accurately schedule SVE instructions alongside NEON instructions, improving overall instruction scheduling performance and correctness.
