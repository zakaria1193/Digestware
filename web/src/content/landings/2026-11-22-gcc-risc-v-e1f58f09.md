This commit addresses an issue in RISC-V vector code generation related to narrowing shifts by fixing the 'even-odd' pattern matching. Previously, the compiler could miss opportunities to use efficient narrowing shift instructions due to an unnecessary check on register natural size and a missing clobber for temporary destinations. The fix removes the redundant check and adds necessary clobbers, ensuring all applicable cases for narrowing shifts are correctly handled.
