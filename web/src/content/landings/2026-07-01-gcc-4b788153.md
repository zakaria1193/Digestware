This commit refactors the definition of register class constraints in GCC's RTL (Register Transfer Language) by replacing several macros (BASE_REG_CLASS, MODE_BASE_REG_CLASS, etc.) with a single, unified target hook `TARGET_BASE_REG_CLASS`. This change simplifies the target definition interface and prepares for future extensions, such as adding support for memory operands.
