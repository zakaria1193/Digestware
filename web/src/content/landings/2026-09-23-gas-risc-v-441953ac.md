The RISC-V `tail` pseudo-instruction now supports an optional register argument, similar to the `jump` instruction. This allows compilers to emit software-guarded tail calls using a scratch register, ensuring compatibility with systems that may not have the Zicfilp extension enabled, by using an `auipc` hint encoding.
