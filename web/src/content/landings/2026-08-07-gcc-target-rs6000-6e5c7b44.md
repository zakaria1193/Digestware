This change enables the use of vector pair load and store instructions for optimizing memory and string built-in functions, such as `memcpy`, when the `-mcpu=future` flag is used on PowerPC. It also introduces and documents the `-mblock-ops-vector-pair` option, which controls this behavior and can be set by specific `-mcpu` values. A new test case is added to verify this functionality.
