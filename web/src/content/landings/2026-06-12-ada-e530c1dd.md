This commit addresses two issues affecting membership tests for Ada's tagged types. The first fix implements a special case from the Ada Reference Manual, which previously caused valid code to be incorrectly rejected. The second corrects the dynamic semantic rules for membership tests when both the tested expression and type are specific tagged types, preventing incorrect runtime outcomes. These changes involved adjusting how designated types are retrieved and how tag checks are performed in various contexts, including an unexpected interaction with anonymous access return types.
