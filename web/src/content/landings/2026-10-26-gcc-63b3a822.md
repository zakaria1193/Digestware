This commit corrects the order of operations in GCC's value-range construction. It ensures that pt_set_unknown is called only after the m_kind field is properly set. This prevents potential issues by guaranteeing all necessary data is available before this function is invoked, addressing a bug reported in PR tree-optimization/128177.
