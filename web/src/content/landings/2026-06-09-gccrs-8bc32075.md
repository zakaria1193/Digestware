The Rust front-end for GCC (gccrs) can now generate `Drop` calls for values that are implicitly returned at the end of function bodies. This ensures that resources held by these values are properly released when they go out of scope. The change modifies `HIRCompileBase::compile_function_body` to insert these calls, bringing gccrs closer to full Rust `Drop` compliance for function-scoped items, although explicit `return` statements are not yet supported by this mechanism.
