This commit enhances GCC's configuration process by allowing separate partition counts for the machine description generators (genemit, genrecog, genattrtab). It introduces `--with-md-generator-partitions` and deprecates the old `--with-insnemit-partitions`. The AArch64 target is now configured with a default of 6:6:1 partitions for these generators to balance compile times and performance. The changes also improve Makefile dependency handling and cleanup of generated sources.
