A recent change intended to optimize x86 ELF handling inadvertently disabled the generic copying of special section fields for non-Solaris binaries. This led to incorrect `sh_link` and `sh_info` values in `SHT_SECONDARY_RELOC` sections. This commit reverts that optimization for non-Solaris targets, restoring the generic copying mechanism to ensure these fields are set correctly, resolving a bug in relocation processing.
