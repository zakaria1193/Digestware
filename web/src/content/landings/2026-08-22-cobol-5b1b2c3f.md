The Cobol compiler has been updated to accept device names, such as 'SYSIN', as valid filenames in SELECT statements, following IBM's interpretation where it's not a reserved word. Additionally, the lexer now permits carriage return (CR) characters within string constants, expanding the accepted character set beyond newline and null characters for string literals.
