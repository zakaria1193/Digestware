This commit simplifies several test cases in the OpenMP test suite related to constructors and destructors for static aggregates with the `declare target` directive. Previously, tests for AMD and NVIDIA GPU offloading duplicated identical logic for scanning offload tree dumps. This change consolidates that logic, reducing redundancy and making the test suite more maintainable without affecting test coverage or correctness.
