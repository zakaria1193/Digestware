This change extends the MIN/MAX narrowing optimization in `match.pd` to handle vector types. It enables folding comparisons on wide vector types, like `v2di`, directly into MIN/MAX operations on narrower vector types, like `v2si`, after a `__builtin_convertvector` cast. This optimization requires that the wide vector MIN or MAX operation has only one use to avoid introducing redundant operations, significantly simplifying code for operations involving type conversions and MIN/MAX.
