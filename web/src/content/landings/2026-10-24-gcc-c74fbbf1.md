This commit updates the `add_function_usage_to` function in GCC's `emit-rtl.cc` and `rtl.h` to accept an `rtx_insn *` as a parameter. This change clarifies that the function operates in the context of a specific machine instruction, improving type safety and maintainability within the RTL emission code. It ensures that the function is used appropriately when tracking function call information related to a particular instruction.
