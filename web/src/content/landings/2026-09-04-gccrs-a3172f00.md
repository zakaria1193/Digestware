This commit refactors gccrs's feature gating mechanism by introducing a `GateResult` enum. The `FeatureGate::gate` function now returns this enum, indicating whether a feature was successfully gated or encountered an issue. This change improves error reporting and makes the gating status more accessible to other compiler passes, as the `gate` function is now public.
