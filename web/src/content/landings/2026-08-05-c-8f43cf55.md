This commit adjusts the C++ parser to correctly interpret OpenMP and OpenACC array sections, such as `[:n]` or `[idx:]`, when compiled with C++26 or later standards. C++26 introduced new splicing tokens (`CPP_OPEN_SPLICE`, `CPP_CLOSE_SPLICE`) that conflicted with the existing syntax for array sections. This change ensures that these array sections are parsed as intended, maintaining compatibility with OpenMP/OpenACC array slicing despite the new C++26 parsing rules.
