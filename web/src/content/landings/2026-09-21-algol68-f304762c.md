The Algol68 compiler frontend used a parse node attribute called `SYMBOL_COMPLEX`, which has become redundant and is no longer used. This commit removes the attribute and associated parsing logic, simplifying the codebase. The functionality is effectively covered by the `SYMBOL_COMPL` attribute.
