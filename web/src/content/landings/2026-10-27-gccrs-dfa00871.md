The GCC Rust front-end now supports the `nontemporal_store` intrinsic. This intrinsic provides a hint to the compiler that a memory write operation should be performed in a non-temporal manner, which can improve performance by avoiding unnecessary caching.  While the intrinsic is added, GCC currently lacks a mechanism to fully express the non-temporal aspect, so it behaves like a regular write operation.
