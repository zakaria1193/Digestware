This commit refines the `write_name` function in GCC's C++ frontend by changing the type of its `ignore_local_scope` parameter from `int` to `bool`. It also defaults this parameter to `false`, simplifying calls for most users. Only one specific call site, which previously passed `1`, now explicitly passes `true`. This change enhances code readability and reduces minor boilerplate in the name mangling logic.
