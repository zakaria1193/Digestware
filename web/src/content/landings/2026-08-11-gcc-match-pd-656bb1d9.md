This commit expands the `match.pd` patterns to unconditionally simplify more conditional bitwise OR operations. It introduces new patterns to handle cases where a bit is checked and then set if not present, or where a bitmask is tested against itself. These simplifications apply when the bit is derived from a left shift (e.g., `1 << val`) or when a full bitmask is involved, allowing the compiler to replace conditional logic with direct bitwise OR operations, thereby improving code efficiency.
