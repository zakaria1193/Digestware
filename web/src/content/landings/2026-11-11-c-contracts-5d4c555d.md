This commit refactors how C++ contracts are handled during `constexpr` evaluation. Instead of always diagnosing contract violations at the outermost constant expression level, diagnostics now occur during evaluation if active. This change ensures that diagnostics have better context, stop evaluation at the point of violation if terminating, and correctly handle situations where an assertion failure occurs within an otherwise constant initialization. It also improves diagnostic reporting by using the predicate's location and providing clearer explanations.
