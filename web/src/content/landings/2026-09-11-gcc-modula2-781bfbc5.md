This change enables the complex arc sine, cosine, and tangent functions for the Modula-2 ISO libraries by ensuring proper testing and use of GCC's built-in trig functions. It addresses an incomplete set of builtin tests and filters these functions based on `LONGREAL` support, improving the completeness of the Modula-2 math library.
