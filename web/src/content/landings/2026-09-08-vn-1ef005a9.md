A fix has been implemented for infinite recursion in the `insert_predicates_for_cond` function within the Value Numbering (VN) optimization pass. The issue occurred when handling comparisons like `a != 0` where the comparison itself was not canonicalized before testing for recursion. This change adds canonicalization before the recursive check, resolving the infinite loop and preventing related issues, particularly for PR127261.
