This patch prevents crashes in the vectorizer when a loop uses partial vectorization with masked SIMD clones, and the target lacks a suitable vector mask type for scalar integer masks. Previously, a NULL tree could be passed to `vect_record_loop_mask`, causing a crash. The fix now checks for a valid mask type and disables partial vectors if none is found, ensuring stability. It also adds an assertion to catch such issues earlier.
