A bug in the GCC COBOL compiler's handling of the `SET <named-conditional> {TRUE|FALSE}` statement for string types has been corrected. The issue involved an off-by-one error when calculating string lengths, which has now been fixed in both the `genapi.cc` and `libgcobol.cc` components. This ensures correct length processing for named conditionals applied to strings.
