The Fortran runtime library had a bug in the `FINDLOC` intrinsic function where it did not correctly advance through the `MASK` array when both `MASK` and `DIM` arguments were provided. This led to incorrect results or potential issues during array traversal. This commit regenerates the runtime library templates for `FINDLOC` after fixing the logic in the `ifindloc1.m4` macro to ensure proper handling of the `MASK` argument in all relevant cases.
