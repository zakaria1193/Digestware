This commit resolves compiler warnings about unused parameters in the `std::experimental::filesystem::v1` implementation for Windows targets. When compiling with `[[maybe_unused]]` attribute support and `-Werror`, the `create_directory_symlink` and `create_symlink` functions generated unused parameter warnings. The fix annotates these parameters to silence the warnings and prevent build failures.
