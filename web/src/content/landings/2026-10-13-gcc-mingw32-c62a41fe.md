A recent change to `HOST_EXTRA_OBJS_SYMBOL` in GCC's MinGW32 configuration inadvertently turned it into a declaration instead of a definition. This caused the symbol to be undefined, breaking functionality. This commit resolves the issue by adding an explicit initializer (set to zero), ensuring the symbol is correctly defined.
