The `text-art` library's `array2::set` method previously only accepted `const` references, preventing move assignments even when an rvalue was provided. This change introduces an overload that accepts an rvalue element (`element_t &&`), allowing `std::move` operations to take effect. This is beneficial for element types that manage their own resources, such as `styled_unichar` which contains a `std::vector`, enabling more efficient assignments in contexts like `canvas::paint`.
