This commit optimizes the GCC build process by allowing the `configure-gcc` script to start as soon as the GMP library's configuration is complete, rather than waiting for all GMP, MPFR, MPC, and ISL libraries to be fully built. This change significantly shortens bootstrap build times, with reported improvements of up to 7% on specific architectures and configurations. The `configure-gcc` script has minimal dependencies on these libraries during its own configuration phase.
