The `switchlower` pass in GCC incorrectly handled large `BITINT_TYPE` values in switch statements, leading to incorrect conditional logic for determining if a value was within a cluster's range. This commit corrects the logic by ensuring that values are cast to their unsigned equivalent before subtraction and comparison when `!TYPE_UNSIGNED` is true, rather than relying on `!TYPE_OVERFLOW_WRAPS`. A new test case verifies this fix.
