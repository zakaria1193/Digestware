This commit tidies up the GCC AVR backend's instruction patterns for rounding operations. It replaces separate mode iterators (`ALL1Q`, `ALL2QA`) with a combined iterator (`ALL12QA`) for 1- and 2-byte modes, simplifying the machine description and potentially improving maintainability.
