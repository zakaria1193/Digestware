This commit resolves a build error in the z80 assembler (`tc-z80.c`) that occurs with newer versions of GCC and glibc. The issue stems from `bsearch()` and other functions propagating `const`-correctness, which conflicted with a non-`const` pointer used in the assembler's internal tables. Adding the `const` qualifier to the pointer fixes the build without affecting functionality, as the pointer is never written to.
