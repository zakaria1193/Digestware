This change prevents `objcopy` and `strip` from adding a `PT_RISCV_ATTRIBUTES` program header to RISC-V ELF files when the linker (LLD) version is older than 17. Older LLD versions do not create this header, and attempting to add it later can corrupt binaries by failing to reserve space for program headers.
