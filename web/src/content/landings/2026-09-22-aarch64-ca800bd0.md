The generic `atomic_store<mode>` pattern in the AArch64 backend used `general_operand`, which prevented common subexpression elimination (CSE) when the store value was an immediate. This commit replaces `general_operand` with `aarch64_reg_or_zero`, a more specific operand that allows CSE to function correctly, potentially leading to more optimized code.
