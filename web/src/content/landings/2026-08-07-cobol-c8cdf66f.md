This commit refactors the way variables are created in the COBOL front-end. Many specialized helper functions for defining variables (e.g., `gg_define_int`, `gg_define_char_star`) have been removed. Instead, code now directly calls the more general `gg_define_variable` function with the appropriate GCC tree type, simplifying the codebase and reducing redundancy.
