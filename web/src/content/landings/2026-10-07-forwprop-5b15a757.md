This change corrects an issue in forward propagation where table-based zero counts for types larger than `int` were being truncated. The `simplify_count_zeroes` function previously computed zero values using `int` semantics, leading to incorrect results when the actual table entry exceeded `int`'s range. The fix ensures that these entries are correctly selected after conversion to the table's actual type, resolving miscalculations for CLZ/CTZ operations and improving accuracy for `long long` types.
