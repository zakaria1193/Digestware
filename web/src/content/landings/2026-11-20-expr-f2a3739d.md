This commit corrects how GCC handles bit-fields within unions during constructor element categorization. It replaces the use of TYPE_SIZE with DECL_SIZE for more accurate size comparisons, ensuring that padding bits are correctly accounted for. This change also leads to more efficient code generation by properly initializing entire unions when needed.
