This commit refactors the test suite for the x86 `truncsfbf` (truncate single-precision float to BFloat16) instruction. It consolidates duplicated code by moving common checks into a new header file, `truncsfbf-check.h`. This improves maintainability and reduces redundancy in test cases like `truncsfbf-2.c`, `truncsfbf-5.c`, and `truncsfbf-6.c`. The changes also ensure the tests correctly check for runtime support of SSE2 and add necessary scan directives for the `vcvtneps2bf16` instruction.
