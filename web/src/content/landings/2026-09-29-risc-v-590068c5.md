This commit introduces a new test case for the RISC-V vfwsub.wv instruction. The test specifically targets scenarios where the `csrr` (Control and Status Register) is not handled via assembly, and vector register overlap is enabled. This aims to catch potential issues related to register allocation and instruction execution under these specific conditions.
