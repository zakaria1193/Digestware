The configuration script for RISC-V now uses the older `%` string formatting instead of Python 3.6's f-string syntax. This change ensures that the build process remains compatible with a wider range of Python 3 versions, as f-strings were only introduced in Python 3.6. It reverts a previous assumption that any Python 3 version would be sufficient.
