This commit refactors GCC's testsuite to correctly handle errors and return values from the `scan-symbol-common` function. It addresses issues where arguments were incorrectly concatenated and where early exits lacked return values, leading to inaccurate test results or failures. The changes ensure that tool failures and skipped tests are reported consistently, improving the reliability of test execution.
