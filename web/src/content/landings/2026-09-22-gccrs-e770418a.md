The gccrs test suite for core Rust functionality has been updated. Previously, tests verified code only up to the lowering stage; now, they will proceed further, verifying correctness up to the type-checking stage. This change expands the scope of testing for the Rust frontend, aiming to catch more issues earlier in the compilation pipeline.
