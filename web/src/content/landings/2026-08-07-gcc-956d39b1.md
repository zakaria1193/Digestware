GCC now leverages new Power10 instructions to simplify the process of zero-extending values from memory into VSX registers. Previously, this involved multiple steps, including extending to a general-purpose register pair and then moving to a VSX register. The new `lxvrdx` (and similar) instructions can directly load and zero-extend data into VSX registers, eliminating intermediate steps and resulting in more efficient code for operations involving `__uint128_t`.
