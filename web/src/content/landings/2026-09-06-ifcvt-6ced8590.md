The ifcvt pass now uses a new helper function, noce_representable_diff_p, to check if the difference between two constant values in a conditional branch is representable and to truncate it to the correct mode. This logic was previously duplicated in noce_try_store_flag_constants and noce_try_cmove. The change improves code maintainability without altering optimization behavior.
