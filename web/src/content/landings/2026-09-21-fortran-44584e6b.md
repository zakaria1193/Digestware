The Fortran compiler has refactored the `span_addressed_array` function to return a boolean value, clarifying its purpose as a predicate. Previously, it could return either `NULL_TREE` or its argument, leading to ambiguity in boolean contexts. This change separates the predicate logic from the value selection, improving code clarity and making the function's intent more explicit, especially in `gfc_get_dataptr_offset`.
