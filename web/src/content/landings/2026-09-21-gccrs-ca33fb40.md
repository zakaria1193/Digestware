GCC's Rust frontend (gccrs) previously only diagnosed arithmetic overflow for signed integers during constant evaluation, allowing unsigned integers to wrap around silently. This commit enhances the constant evaluation process to detect and report overflow for both signed and unsigned types, aligning with Rust's language specification (E0080 error). The change involves modifying how arithmetic expressions are built and checked, ensuring proper location information is available for error reporting.
