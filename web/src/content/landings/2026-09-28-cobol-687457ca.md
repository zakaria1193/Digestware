A new compiler option, -Wvalue-clause, has been introduced for cobol. This option permits trailing blanks in VALUE clauses that exceed the defined space of the data item. Previously, the ISO standard dictated that such trailing blanks would be deemed an error, but this change allows them to be treated as harmless.
