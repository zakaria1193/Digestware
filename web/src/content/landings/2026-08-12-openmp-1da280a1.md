The OpenMP runtime library's OMPT (OpenMP Tooling Interface) tracing options have been consolidated. Previously, separate flags -fopenmp-ompt and -fopenmp-ompt-detailed controlled different levels of tracing detail. This change unifies them into a single flag, -fopenmp-ompt, which accepts an optional argument to specify the tracing level: minimal, basic, or extended. This change clarifies the relationship between the levels and improves user experience by providing a more intuitive interface for controlling trace verbosity.
