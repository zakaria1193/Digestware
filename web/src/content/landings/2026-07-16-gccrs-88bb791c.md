This patch ensures that block cleanup code is executed for unlabeled `break` and `continue` statements in GCC's Rust front-end. Unlabeled `break` statements now return their translated tree, consistent with `continue`, and tail-position control flow expressions are emitted as statements to ensure they remain within the `TRY_FINALLY_EXPR` body.
