GCC's range analysis has been updated to no longer restrict itself from analyzing SSA names that occur within abnormal PHI nodes. Previously, this restriction was in place due to a misunderstanding of the 'abnormal' marker, which pertains to transformation constraints rather than analysis limitations. The range analysis can now correctly determine value ranges even when PHIs are involved in abnormal control flow paths, as the core semantics of PHI and copy operations still hold. This change aims to improve the accuracy and completeness of range analysis.
