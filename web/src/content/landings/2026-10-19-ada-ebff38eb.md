This commit standardizes the internal checking for whether a procedure is an initialization procedure within the GCC Ada front-end. It replaces all calls to `Sem_Util.Within_Init_Proc` with `Exp_Util.Inside_Init_Proc`. Both functions perform the same check, so this change consolidates the functionality into a single, consistent location (`Exp_Util`), simplifying maintenance and reducing potential inconsistencies. The commit affects several files related to Ada's expression and semantic analysis.
