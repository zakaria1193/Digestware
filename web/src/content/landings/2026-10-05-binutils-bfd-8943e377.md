This commit introduces initial support for the BPF Type Format (BTF) into the BFD library. It includes the necessary data structure definitions and helper functions to decode BTF information. The new include/btf.h file, derived from GCC's version and based on Linux kernel definitions, ensures synchronization with related tools.
