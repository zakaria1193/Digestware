A test case in `vec-msumc.c` for the rs6000 target failed on big-endian 32-bit multilib configurations. This commit resolves the issue by adding an `int128` effective-target check. This correctly marks the test as unsupported for the `-m32` option on big-endian systems, ensuring test suite integrity.
