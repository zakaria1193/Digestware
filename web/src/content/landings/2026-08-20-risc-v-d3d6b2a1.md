GCC's RISC-V backend now includes the `MVENDORID`, `MARCHID`, and `MIMPID` identification registers for six specific RISC-V cores. This enhancement supports the automatic detection of CPU types for tuning and optimization purposes, enabling features like `-mtune=native`.
