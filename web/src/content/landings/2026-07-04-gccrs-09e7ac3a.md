This commit updates gccrs to allow type parameter bounds to correctly reference forward-declared generic parameters. Previously, the compiler might have incorrectly disallowed this usage, potentially hindering the definition of complex generic structures. The change ensures that bounds within a type parameter can properly refer to other generic parameters that have been declared but not yet fully defined.
