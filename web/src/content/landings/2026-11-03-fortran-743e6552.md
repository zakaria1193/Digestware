In the Fortran frontend, the `trans_scalar_class_assign` function previously created tree nodes that were not utilized if an early return path was taken. This commit optimizes the function by delaying the creation of these nodes until they are actually needed. This change avoids unnecessary computation and memory allocation when the early exit condition is met, improving the efficiency of the Fortran compiler's expression translation.
