This commit updates libgm2's source files to include declarations for malloc and free from the standard C library header `stdlib.h` (or `cstdlib` in C++). Previously, these functions were declared using `malloc.h`, which is not part of the C standard and can lead to portability issues.

By using `stdlib.h`, the code becomes more compliant with C standards and more likely to compile correctly across different platforms and C library implementations.
