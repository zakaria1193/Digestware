This commit updates AArch64 SVE assembly tests for `dup_lane` operations involving lane 0. Due to common subexpression elimination (CSE) simplifying duplicated vectors of lane 0 into a `mov` instruction, the expected assembly output has changed. The tests are modified to reflect this, ensuring they pass while still verifying correct SVE functionality.
