This commit refactors several `DEF_` macros used for defining index enums in the aarch64 backend. By employing variadic arguments (`...`), these macros now ignore all arguments except the first (the name). This simplifies the macro definitions and usage, particularly for enums like `vector_type_index` and `mode_suffix_index` where only the name is relevant.
