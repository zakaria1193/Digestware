GCC's Rust compiler now issues a warning when a trait object is declared with a `Drop` bound. Since trait objects themselves are not dropped and values behind them are dropped automatically, the `Drop` bound on a trait object has no effect. This new lint helps developers by identifying and flagging these redundant, no-op bounds.
