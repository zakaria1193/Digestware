This commit prevents the C++ compiler from caching function calls during constant evaluation if those calls involve exception handling mechanisms like `rethrow`, `__builtin_uncaught_exceptions`, or `__builtin_current_exception`. Caching such calls could lead to incorrect results if the execution context's exception state changes. By marking these operations as non-cacheable, the compiler ensures more reliable constant evaluation in the presence of exceptions.
