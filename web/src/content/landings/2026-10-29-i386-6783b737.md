This commit introduces a new lowering path for the `bitreverse` operation on i386 architectures, leveraging the `vbitrevb` instruction from the AVX512-BMM extension when AVX512VL is also present. This provides a more efficient implementation compared to the previous fallback using GFNI instructions. The change includes updates to the machine description files and adds test cases to verify both the new AVX512-BMM path and the GFNI fallback.
