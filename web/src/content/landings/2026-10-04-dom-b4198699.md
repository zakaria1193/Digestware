The DOM (Dominator Tree) analysis pass no longer includes a special case for optimizing conditional statements based on boolean variable ranges. Previously, `optimize_stmt` would transform conditions like `if (b == 5)` into `if (0 == 5)` when `b` was known to be in the range `[0, 1]`. This transformation is now redundant as the `simplify_stmt` pass already handles such cases effectively. This change simplifies the DOM pass and includes a new test case.
