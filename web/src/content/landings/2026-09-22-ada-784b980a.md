This commit refines the handling of freezing record types in the Ada compiler, specifically for types derived from untagged controlled private types. An early return in `Expand_Freeze_Record_Type` was found to be too late, preventing the proper completion of primitive operations for these derived types. The fix involves moving this early return to an earlier point in the function to ensure correct code generation.
