This commit ensures that vector extract forms utilizing AVX512VL or AVX512DQ are not emitted unless the corresponding ISA extensions are enabled. It adjusts the machine description to use 256-bit source forms with AVX512VL and 64x2 forms with AVX512DQ, and introduces new tests to verify this behavior. This prevents incorrect code generation when targeting processors with a subset of AVX-512 features.
