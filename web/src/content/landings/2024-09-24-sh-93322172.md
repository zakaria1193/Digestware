This commit improves the handling of Super Function (sfunc) patterns on the SH architecture by introducing new predicates to pin input arguments to hard registers. Previously, LRA did not correctly process clobber patterns in some sfuncs that used hard registers as input. By rewriting these patterns using `match_operand` and `match_dup` with the new predicates, the compiler ensures better compatibility with LRA.
