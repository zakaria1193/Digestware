This commit fixes an internal compiler error (ICE) in gccrs's handling of path pattern refutability. Previously, `PathPattern::is_refutable` looked up paths using only the last segment's HIR ID, which did not correctly identify the item. This caused `let` bindings and function parameters to hit a `rust_unreachable` error. The fix now resolves paths through name resolution, correctly identifying constants as refutable and falling back to the scrutinee type for others.
