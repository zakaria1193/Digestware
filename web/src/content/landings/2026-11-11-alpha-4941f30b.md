The Alpha EV6 processor features two execution clusters, and values passed between them incur a one-cycle delay. This commit refines the instruction scheduling model to accurately reflect this cross-cluster latency for dependencies between the MVI (Move Immediate) unit and the multiplier. Previously, a less accurate model duplicated reservations, overestimating latencies. The updated model introduces specific bypass paths to account for the delay only when necessary, improving code generation for performance-sensitive chains involving these operations.
