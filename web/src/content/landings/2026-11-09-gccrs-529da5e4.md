A new test suite has been added to gccrs to compare the diagnostics generated during the compilation of the Rust core library against a known-good expected output. This test runs the type checker and diffs the output, ensuring that any regressions or unexpected changes in diagnostics are caught early in the development process, particularly during pull requests. The test is configured for 64-bit targets and excludes backtraces from ICE lines.
