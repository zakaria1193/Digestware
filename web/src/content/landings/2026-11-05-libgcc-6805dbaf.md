The libgcc configure script has been refactored to simplify how it determines the `libgcc_topdir`. Previously, it used multiple variables to deduce this path, but since libgcc is only built for the target and the source directory is always suffixed with `/libgcc`, this logic could be safely removed. The change also removes an unnecessary Autoconf directory search. This results in cleaner and more straightforward configuration for libgcc.
