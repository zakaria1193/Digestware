This patch resolves an Internal Compiler Error (ICE) occurring during conversions between Modula-2's REAL32 and REAL64 types. It introduces a new helper function, `IsRealGCC`, to correctly identify GCC's supported real types, differentiating them from strict ISO Modula-2 types. This change ensures accurate type handling during these conversions.
