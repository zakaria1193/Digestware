This commit standardizes the use of Algol 68's internal type representations (`a68_*_type`) throughout the compiler's Algol 68 front-end. Previously, the code sometimes used native C types instead of the Algol 68 specific type nodes. By enforcing the use of `a68_*_type` for internal operations, the compiler ensures type consistency and correctness, except when interacting with external entities like libcalls that require C types. This change affects numerous lowering functions in the `a68` subsystem.
