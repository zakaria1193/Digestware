This commit introduces several minor C++ style and correctness improvements to the GCC ifcvt pass's `noce` path. It corrects `noce_can_force_operand` to return a boolean instead of an `insn_code` by comparing against `CODE_FOR_nothing`. It removes unnecessary braces around single-statement conditional blocks in `bbs_ok_for_cmove_arith` and value-initializes `if_info` in `noce_find_if_block` to avoid a later `memset`. These are C++ idiomatic improvements and do not change functionality.
