This patch introduces a new helper function, `get_niter_type_bound`, to GCC's loop iteration analysis. This function simplifies the computation of type bounds, which are crucial for understanding loop behavior and potential overflows. The new helper is immediately used in existing functions like `loop_exits_before_overflow` and `derive_simple_iv_with_niters`, and is intended for reuse in upcoming patches related to non-wrapping bounds.
