This commit introduces new `m2-debug` and `check-m2-debug` rules to the Modula-2 build system. These rules enable building the Modula-2 front end (`cc1gm2`) using a whole-program compilation approach (`-fm2-whole-program`) with optimization disabled (`-O0`) and debugging symbols enabled (`-g`). This is intended to facilitate bug hunting and debugging during the early stages of issue triage.
