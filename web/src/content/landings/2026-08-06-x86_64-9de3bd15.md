This commit updates two x86_64 test cases to account for changes introduced by Common Subexpression Elimination (CSE). The `pr81501-9b.c` test now checks for components of `check-function-bodies` in any order, as explicit ordering was removed. The `pr124407-1.c` test, which previously failed due to over-constrained scan-rtl-dump regexs, has been updated to scan for a specific `movabsq` instruction, accommodating an equivalent representation resulting from the CSE changes.
