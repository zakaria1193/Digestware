Two RISC-V vector test cases have been updated to include stricter platform Vector Length (VLEN) checks. These tests previously ran code compiled for a 256-bit VLEN (`rv64gcv_zvl256b`) but only required the base `riscv_v` extension, causing them to fail on platforms with smaller VLENs. The tests now explicitly require specific VLEN configurations to pass, ensuring their correctness across different RISC-V vector implementations.
