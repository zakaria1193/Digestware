This commit restores the intended behavior of the `--param=riscv-autovec-mode` option for the RISC-V architecture. A recent change had regressions that incorrectly altered the autovectorization mode. The fix ensures that the autovect mode is only overridden if it matches one of the available modes, preventing unintended modifications and regressions in RISC-V code generation.
