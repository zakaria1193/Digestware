GCC now fully supports the OpenMP `uses_allocators` clause, enhancing how memory is managed for accelerated targets. This implementation introduces a new map kind for libgomp, ensuring allocator initialization happens on the host rather than the target, which bypasses many initialization problems. The change also enforces strict compatibility of allocator data formats between host and accelerator and adds necessary runtime checks.
