This commit cleans up the Dominator (DOM) optimization pass by removing code that handled cases where a constant was the first operand of a binary operation (like PLUS_EXPR or EQ_EXPR). GIMPLE canonicalization ensures constants appear on the right side for these operations, rendering these code paths unreachable. Similarly, code for handling constants as the first operand in conditional expressions was removed as it's also made obsolete by canonicalization.
