This patch introduces bounds for POLY_INT indeterminate constants on AArch64, specifically for Scalable Vector Extension (SVE) operations. This allows GCC to recognize that certain vector length calculations, like `svcntb()` and `svcntw()`, always produce results within known ranges. Consequently, comparisons involving these values can be folded away, simplifying code and improving optimization.
