This change adds support for the `.gnu_attribute` tags `Tag_GNU_AVR_BITS_DOUBLE` and `Tag_GNU_AVR_BITS_LONG_DOUBLE` in the AVR toolchain. This allows the linker to detect and report errors when attempting to link object files compiled with different sizes for `double` or `long double`, ensuring ABI compatibility.
