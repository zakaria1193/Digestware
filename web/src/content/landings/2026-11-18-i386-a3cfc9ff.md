The register stack conversion pass, previously a generic pass, has been moved to `config/i386/i386-reg-stack.cc`. This change reflects that the pass is only utilized by the x86 architecture due to its reliance on x87 floating-point registers. The pass order is preserved for i386 by integrating it into the i386-specific pass definition file. This is a code organization change with no functional impact.
