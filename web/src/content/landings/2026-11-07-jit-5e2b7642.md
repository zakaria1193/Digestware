Libgccjit has been extended with new functionality to support computed gotos and block addresses, under ABI version LIBGCCJIT_ABI_39. This enhancement introduces `gcc_jit_block_get_address` and `gcc_jit_block_end_with_indirect_jump`, exposing GNU C's labels-as-values and indirect jump capabilities. This is particularly beneficial for JIT-compiled interpreters, allowing them to implement direct-threaded code tables for dispatch loops and state machines, potentially improving performance and flexibility.
