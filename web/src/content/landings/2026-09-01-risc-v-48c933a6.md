This commit adds support for the XAndesVSIntH extension to the RISC-V toolchain. The changes include updates to BFD for ELF compatibility, GAS for assembler directives and tests, and the opcode library for instruction recognition. This enables the use of new vector integer instructions for enhanced performance on compatible hardware.
