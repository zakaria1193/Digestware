This commit introduces the necessary linker-internal definitions for RISC-V Zcmt table-jump (JVT) relocations. It adds a new relocation type `R_RISCV_TABLE_JUMP`, a base symbol `RISCV_TABLE_JUMP_BASE_SYMBOL`, and a section name `TABLE_JUMP_SEC_NAME` to `include/elf/riscv.h`. Additionally, it defines Zcmt constants related to table jumps and alterations in `include/opcode/riscv.h`. This lays the groundwork for linker optimizations involving table jumps.
