This commit removes the clearing of the LOOP_C_INFINITE flag within the `vect_do_peeling` function. The flag has not been set since a prior commit (r12-2004-g88ada5c051c49a), making its clearing in this function unnecessary. This is a minor cleanup that removes dead code.
