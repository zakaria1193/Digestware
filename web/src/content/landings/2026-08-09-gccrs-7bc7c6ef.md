gccrs now accurately tracks the initialization state of local variables across control-flow branches in the BIR, specifically addressing conditional moves. This allows the compiler to correctly classify `Drop` statements as conditional when a local is moved on only some execution paths. New tests validate this behavior for static, dead, and conditional drops.
