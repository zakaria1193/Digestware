This commit addresses a build issue in the Modula-2 compiler (cc1gm2) where `make install` could trigger unnecessary recompilation of generated sources. The build rules have been rewritten to use order-only dependencies for generated files. This ensures that if header files change, the compiler is rebuilt, but simply rebuilding headers does not cause the generated sources themselves to be regenerated unnecessarily. This resolves PR126847.
