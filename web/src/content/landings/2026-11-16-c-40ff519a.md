This change corrects how GCC handles nested functions, specifically when determining if they require a static chain for proper execution. Previously, the check for `DECL_STATIC_CHAIN` was performed too late, after the function body was parsed, which could lead to incorrect assumptions about static initialization of variables pointing to these functions. The fix ensures that `DECL_STATIC_CHAIN` is set earlier, conservatively assuming a static chain is needed until the function is fully parsed. This aligns with PR128760 and PR128518, improving the correctness of nested function handling and associated static initializations.
