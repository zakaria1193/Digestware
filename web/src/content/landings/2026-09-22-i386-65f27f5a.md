This commit addresses an issue in GCC's Control-flow Enforcement Technology (CET) pass where duplicate `ENDBR` (End Branch) instructions were being inserted. This occurred when different switch tables pointed to the same case block, or when dispatches shared a table. The fix ensures that an `ENDBR` is reused if one already exists after the destination label, preventing unnecessary instructions and potential overhead.
