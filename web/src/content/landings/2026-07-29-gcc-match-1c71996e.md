This commit enhances the `match.pd` component to fold certain comparisons involving masked values and arithmetic operations. It transforms expressions like `((X + C1) & LOWMASK) ==/!= C2` into simpler forms, reducing the number of instructions generated. This optimization is particularly beneficial for code generation on architectures like AArch64, as demonstrated by a significant reduction in instruction count for a sample function. New tests are added to cover these folding rules.
