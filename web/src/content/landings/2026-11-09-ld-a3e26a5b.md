The linker's VxWorks emulation incorrectly accessed ELF-specific hash table members without first verifying the hash table's type. This could lead to a heap-based buffer overflow when a generic ELF output format was selected via a linker script. This change adds a check for `is_elf_hash_table` to prevent this out-of-bounds read, resolving AddressSanitizer reports.
