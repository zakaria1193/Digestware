This commit fixes a bug in the Fortran compiler where statement labels were not correctly preserved in programs containing a `CONTAINS` section. The issue arose because a new namespace was created after the `CONTAINS` block, causing labels to be associated with the wrong scope. The fix ensures that statement labels are correctly assigned to the containing namespace and that labelled `RETURN` statements are properly handled.
