This commit corrects a comment in libgomp regarding the handling of global static variables within 'target' structured blocks when Uniform Memory Access (USM) is enabled. The previous comment incorrectly stated that these variables would be address-translated, potentially causing issues. The compiler actually optimizes this by directly accessing the host variable, avoiding address translation. A new testcase verifies this correct behavior, addressing PR 127186.
