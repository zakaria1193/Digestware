The inter-procedural analysis (IPA-CP) pass in GCC incorrectly redirected calls to specialized clones when polymorphic contexts were not considered. This could lead to the execution of wrong virtual methods if a clone was specialized for one dynamic type but a later clone assumed a different one. A new function, `cgraph_edge_brings_all_contexts_for_node`, is introduced to check these polymorphic contexts, ensuring that calls are only redirected to clones for which the context is compatible, thus preventing runtime errors.
