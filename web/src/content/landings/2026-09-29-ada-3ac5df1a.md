This commit addresses an issue where the `Compile_Time_Known_Aggregate` flag was incorrectly set for Ada array aggregates. This occurred when all elements were static, but the array's subtype was dynamic due to its component subtype being dynamic. The compiler now prevents setting this flag in such cases, ensuring these aggregates are handled correctly by the backend.
