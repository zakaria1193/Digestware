For s390, byte-swapping operations on halfwords will now be implemented using a rotate instruction instead of a `vperm` instruction. This change avoids the overhead of loading a permutation vector from the constant pool and allocating an unused vector register, leading to more efficient code generation, especially when vector extensions are not fully utilized.
