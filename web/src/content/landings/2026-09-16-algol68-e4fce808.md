This change integrates `location_t` into the `LINE_T` structure within the Algol68 compiler, replacing separate fields for filename and line number. This allows for more robust tracking of source code positions, including the associated file name via the linemap. Various parts of the Algol68 compiler, particularly those dealing with low-level code generation and parsing, have been updated to use this new structure and associated macros for accessing line information.
