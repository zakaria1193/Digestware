This commit corrects a bug in a libstdc++ test suite helper procedure. The `v3_check_preprocessor_condition` was mistakenly passing a literal string 'name' instead of the intended filename variable to another function, `v3_try_preprocess`. This change ensures tests correctly use the specified source file for preprocessor condition checks.
