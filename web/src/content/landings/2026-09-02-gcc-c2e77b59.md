The compiler now supports nesting `#pragma GCC suppress_coverage` directives. Previously, nested directives triggered a warning, but this has been removed to accommodate legitimate use cases such as custom assert macros within code that is already suppressed for coverage. This change allows for more flexible control over which code regions are excluded from coverage reporting.
