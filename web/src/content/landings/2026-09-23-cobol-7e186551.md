This commit refactors how GCC's COBOL runtime searches for dynamically linked shared objects (.so files). It updates the search policies to better honor the `>>CALL-CONVENTION` clause and ensures consistency in locating functions. Documentation and runtime logic in `libgcobol.cc` have been modified accordingly.
