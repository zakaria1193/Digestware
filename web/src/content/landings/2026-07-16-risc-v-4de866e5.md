This commit introduces support for the XuanTie xxtvarith vendor vector extension on RISC-V architectures. It enables intrinsic functions and auto-vectorization for instructions like `xt.vile` and `xt.vilo`, which are useful for vector permutation operations. These can benefit workloads such as video processing (e.g., x264) and are compatible with other vector extensions like Zvzip.
