The GCC testsuite's `sync-4.C` test case, which previously failed on Darwin platforms, has had its expected failure (xfail) narrowed down. While it consistently failed on older powerpc-darwin9, a more recent unwind library on Darwin10 caused failures on x86 as well. With the unwinder now fixed, this test passes on modern Darwin, so the xfail is now restricted only to the few remaining problematic versions.
