The aarch64 testsuite has been updated to verify that non-default mcmodel settings are correctly supported by the target. Previously, simply setting an mcmodel would cause tests to fail rather than be flagged as unsupported, obscuring target capabilities. This change ensures tests accurately reflect target support for various memory models.
