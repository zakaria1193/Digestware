A freezing issue causing missing names for the `Image` attribute of enumeration types has been resolved. This problem arose from an undesirable coupling between assertions and Ghost mode. The fix involves restoring separate processing paths for these two mechanisms, sacrificing a warning for disabled non-static assertions to prevent more severe freezing issues.
