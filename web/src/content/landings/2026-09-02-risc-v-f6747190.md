This patch introduces support for the XuanTie vendor-specific XXTVarith and XXTVcoder extensions for the RISC-V architecture. These extensions include new vector instructions for arithmetic operations, Galois-field multiply-xor, and fast CRC folding, along with instructions similar to Zvabd.
