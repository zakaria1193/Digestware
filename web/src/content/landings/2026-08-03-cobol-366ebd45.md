This commit updates the COBOL compiler's lexer to correctly handle comments within string literals. Previously, the lexer would incorrectly interpret the sequence '*>' as an inline comment even if it appeared inside a quoted string. The fix introduces a new function, `skip_quoted_literal`, to properly recognize string constants and ensures that inline comments are only processed when they appear outside of these strings. This prevents erroneous parsing of COBOL source code.
