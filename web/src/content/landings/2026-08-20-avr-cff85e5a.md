This patch introduces a new command-line option, `-m[no-]fuse-ifelse`, for the AVR target. This option provides finer control over the `avr-ifelse` optimization pass, allowing developers to enable or disable it as needed. The change modifies the pass's gate function to respect the new option, providing greater flexibility in controlling optimizations.
