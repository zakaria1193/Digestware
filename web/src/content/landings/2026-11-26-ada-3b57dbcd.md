A regression in the Ada front-end caused global names within the expression of an iterated component association in an aggregate to be resolved incorrectly when used in a generic unit instance. This fix ensures that these expressions are correctly resolved by making a copy of the expression tree using `New_Copy_Tree` during the resolution process. A new test case has been added to verify the fix.
