This commit enhances the `combine` pass on aarch64 to treat `PREFETCH` instruction addresses with the same simplification logic as `MEM` addresses. Previously, address computations rewritten by `combine` for `MEM` accesses were not applied to `PREFETCH`, causing issues with 32-bit indices. This fix ensures that address calculations, such as zero-extends on 32-bit values, are correctly preserved for `PREFETCH`, leading to more efficient code generation and saving dynamic instructions, particularly for functions like `__builtin_prefetch`.
