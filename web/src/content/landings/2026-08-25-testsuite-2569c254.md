A test case in GCC's testsuite, `vec-mask-zero-1.c`, has been updated to require the `vect128` capability. This is necessary because the test checks optimized GIMPLE for 128-bit vector types, and on some targets like SPARC, vector lowering splits these operations due to limited vector mode support. Requiring `vect128` ensures the test's final checks are performed only on targets that support the tested vector size, preventing spurious failures.
