This commit introduces a new helper function, `fold_contiguous_load`, to the AArch64 backend of GCC. This function is designed to encapsulate and simplify the logic for processing contiguous memory load operations. It serves as a foundational element for an upcoming refactoring effort focused on AArch64 loads, particularly for supporting SVE features.
