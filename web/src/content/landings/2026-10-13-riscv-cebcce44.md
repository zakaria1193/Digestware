GCC has added new patterns and splitters for the RISC-V czero instruction, enhancing its ability to recognize and optimize conditional move operations. This update specifically targets cases where czero is formed using logical operations, including those involving negated values and bitwise operations, leading to more efficient code generation for RISC-V architectures.
