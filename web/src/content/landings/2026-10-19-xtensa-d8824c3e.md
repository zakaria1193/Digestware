This commit fixes an internal compiler error (ICE) on the Xtensa architecture that occurred when using double-precision floating-point constants with the -mauto-litpools option. The issue was caused by an incorrect condition in the instruction selection logic, which has been corrected by using `satisfies_constraint_Gz` instead of `CONSTANT_P`.
