This commit addresses a bug in the fallback expansions of several GCC atomic builtins. When the operand involved in a `TER` operation is a `MEM` (or contains one) that could alias with the memory being atomically updated, incorrect code was generated. This patch forces the `val` operand into a pseudo register in such cases, resolving issues where the updated value was incorrectly used instead of the original value. It also fixes a problem where `val` could be read twice in compare-and-exchange loops.
