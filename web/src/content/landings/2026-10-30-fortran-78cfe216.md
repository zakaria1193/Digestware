The Fortran compiler's 'simply contiguous' predicate has been corrected to accurately handle polymorphic arrays. Previously, it incorrectly evaluated the predicate for a polymorphic contiguous array because it relied on the last component of a class container's data reference, which lacks the contiguous attribute. The fix ensures that the predicate properly tracks type information and accesses the correct attributes, distinguishing between polymorphic and non-polymorphic references, and correctly identifying contiguous polymorphic arrays.
