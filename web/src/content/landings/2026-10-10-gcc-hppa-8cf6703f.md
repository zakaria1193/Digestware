This commit resolves several secondary reload issues encountered by the HPPA backend's Local Register Allocation (LRA), which emerged after a previous fix for reload problems. It addresses incorrect handling of SImode/SFmode type punning, preventing SIGSEGV crashes by blocking cross-class type punning for modes fitting in a single float register. The changes also improve the handling of secondary reloads for REG+D addresses and fix issues with symbolic and constant loads for SFmode and DFmode by splitting out address calculations.
