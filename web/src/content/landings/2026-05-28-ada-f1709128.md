This commit addresses a formatting issue in the Ada compiler's diagnostic messages. Previously, messages that were meant to be continuations of a preceding diagnostic used the incorrect `|` character instead of the standard `\` for continuations. This change updates the `Process_Restriction_Synonyms` and `Analyze_Pragma` routines to use the correct continuation character, ensuring that multiline diagnostic messages are presented clearly and coherently to the developer.
