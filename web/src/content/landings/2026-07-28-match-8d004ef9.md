This commit optimizes the negation of unsigned integers cast to signed types, specifically targeting expressions like `(int)-(unsigned)a`. It introduces checks to remove redundant casts when signed integer overflow occurs, aligning with the behavior of `-fwrapv`. The optimization is achieved by refining pattern matching rules to recognize and simplify these expressions, including handling cases where the result of the negation might be `INT_MIN`. New test cases are provided.
