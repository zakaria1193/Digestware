This commit extends the BFD x86-64 COFF backend to support the `R_AMD64_ABS` relocation type. This type is equivalent to the `R_X86_64_NONE` relocation in the ELF format and is also recognized in the Windows world as `IMAGE_REL_AMD64_ABSOLUTE`. By adding support for this relocation type, the backend becomes more compliant and can handle a wider range of object files.
