The C++ compiler and standard library now fully implement P3795R2, except for a few reflection metafunctions. To advertise this, ``__cpp_impl_reflection`` and ``__cpp_lib_reflection`` were bumped to 202603L.  Code relying on reflection features can now use these feature test macros to check for availability.
