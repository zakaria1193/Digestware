This commit resolves an ICE (Internal Compiler Error) in GCC's C++ frontend that occurred during the explanation of failed __has_unique_object_representation checks. The issue stemmed from incorrectly trying to get the source location of a type, which led to a crash. The fix involves using the `location_of` utility to correctly retrieve location information, preventing the ICE and ensuring accurate error reporting.
