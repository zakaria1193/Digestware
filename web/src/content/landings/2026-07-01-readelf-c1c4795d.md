The readelf utility now avoids "may be used uninitialized" warnings from GCC 14. This is achieved by ensuring that `rel_entsz` and `entsz_name` are initialized before returning from `process_relocs` in error cases. Additionally, the handling of unknown relocation types has been adjusted to use the default case, which GCC 14 was previously unable to correctly identify as the sole unhandled enum value.
