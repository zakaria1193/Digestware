GCC now recognizes and fuses ADD, ADDW, or ADD.UW instructions with a subsequent undisplaced scalar integer store operation on RISC-V when the store uses the add result as its memory address. This optimization aims to streamline address calculation and store operations. The fusion logic carefully checks for overlapping registers between the ADD result and the store data to prevent incorrect behavior. This new fusion capability is disabled by default and is verified with new test cases.
