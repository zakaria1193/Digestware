This commit fixes a bug in the loop invariant code motion pass (`ivopts`) that miscalculated loop bounds when the loop counter wraps around during its first increment. Previously, the calculation assumed non-wrapping behavior, leading to incorrect iteration counts and potentially premature loop termination. The fix adjusts the bound calculation to consider `a + 1` and `b + 1` instead of `a` and `b`, ensuring correct behavior even when the counter reaches its maximum value and wraps to zero.
