This commit introduces the `-m128bit-atomic` compiler option, allowing the generation of inline 128-bit atomic loads and stores. This avoids the overhead of calling into the `libatomic` library for platforms that support these operations. The option is now enabled by default in 64-bit mode for processors supporting x86-64-v3 or later, or AVX-capable processors from major vendors, simplifying the use of efficient atomic operations for developers targeting compatible hardware.
