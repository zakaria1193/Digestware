The GCC Rust frontend now handles Rust 1.55's "active" features, which can be "incomplete" and use a `__status_to_bool` mechanism. Additionally, it fully supports the `#[used]` attribute, including the `#[used(linker)]` variant, ensuring static variables are not unexpectedly removed by the compiler or linker, similar to C's `used` and `retain` attributes.
