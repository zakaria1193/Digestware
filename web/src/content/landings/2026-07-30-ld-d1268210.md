The linker (ld) will no longer define special symbols like __start, __stop, .startof., and .sizeof. for sections marked with the ELF SHF_EXCLUDE flag, unless the output is relocatable or the flag is cleared. This change addresses PR ld/34448 by ensuring these symbols are only created when relevant, preventing potential issues with excluded section content.
