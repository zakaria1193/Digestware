The COBOL front end has been updated to correctly recognize and accept all intrinsic function tokens within the `REPOSITORY` paragraph. Previously, some intrinsic names might have been rejected as invalid syntax, hindering program compilation. Additionally, the commit improves the error message generated when a COBOL program fails to end with a sentence, providing more actionable feedback to developers. This resolves PR 40 and RT 3574.
