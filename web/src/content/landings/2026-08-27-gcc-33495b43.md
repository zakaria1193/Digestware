The GCC compiler has removed the `-ftree-loop-if-convert` option, which previously allowed standalone loop if-conversion. This change simplifies the compiler by tying if-conversion directly to the vectorizer's loop vectorization pass, as other if-conversion mechanisms (`phiopt` and `cselimg`) are considered more general. This aims to improve integration with the vectorizer and eliminate under-tested functionality.
