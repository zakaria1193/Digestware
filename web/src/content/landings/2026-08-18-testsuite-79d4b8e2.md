Several test cases involving NaN (Not-a-Number) and infinity values fail on Alpha because the architecture only guarantees IEEE-compliant floating-point behavior when the `-mieee` option is enabled. Without it, Alpha uses different comparison instructions and traps non-finite operands. This commit uses `dg-add-options ieee` to ensure these tests are run with `-mieee` on Alpha and SH, aligning the compiler's behavior with the test expectations and avoiding test failures.
