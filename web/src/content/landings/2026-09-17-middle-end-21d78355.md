This commit addresses a compiler crash (ICE) in the dataflow analysis pass when zeroing call-used registers on return paths that also contain sibling calls. The issue arose because zeroing registers updated the exit block's use set, invalidating previously recorded clobber information for sibling calls. The fix ensures a rescan of call-related dataflow information after register zeroing, preventing the ICE.
