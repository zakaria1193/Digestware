This commit changes the COBOL compiler's intermediate representation to call a library routine, `__gg__move()`, for moving intermediate values. Previously, the compiler generated many individual statements with conditional tests for such moves, leading to poor middle-end performance. Routing these operations through a dedicated library function significantly improves behavior, mitigating performance issues observed with thousands of such statements.
