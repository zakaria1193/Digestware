primer_glossary:
- term: -mno-relax
  definition: A compiler or assembler flag that disables code relaxation. Relaxation
    is an optimization where fixed-size instructions can be replaced by smaller, variable-size
    instructions (like RVC on RISC-V) to reduce code size. Disabling it means the
    generated code uses fixed-size instructions, simplifying address calculations.
- term: fixup
  definition: A placeholder or instruction in assembled code that needs to be resolved
    later by the linker. For branches and jumps, this involves calculating the correct
    offset to the target label.
- term: relocation
  definition: Information embedded in an object file that instructs the linker how
    to modify addresses in the code or data sections to correctly reference symbols
    (functions or variables) that are defined elsewhere, potentially in different
    object files or shared libraries.
- term: PCREL_HI20
  definition: A RISC-V relocation type used for PC-relative addressing, typically
    for the upper 20 bits of an immediate offset. It's often used in conjunction with
    another relocation (like PCREL_LO12_I) to form a full 32-bit offset for branches
    and loads.

This commit corrects an issue in the RISC-V assembler where, with `-mno-relax` enabled, branch and jump fixups to labels in other sections were incorrectly resolved. This led to wrong offsets and the omission of necessary relocations. The assembler now correctly handles these cross-section branch fixups only when the symbol resides in the same section, aligning its behavior with existing PCREL_HI20 relocation handling.
