Test cases `zero-scratch-regs-29.c` and `zero-scratch-regs-30.c` were failing because the `TARGET_USE_FFREEP` option, which enables the `ffreep` instruction as a replacement for `fstp`, was enabled by default. This led to assembler scan failures as the tests expected `fstp`. This commit modifies the test cases to disable this optimization using `-mtune-ctrl=^use_ffreep`, resolving the failures.
