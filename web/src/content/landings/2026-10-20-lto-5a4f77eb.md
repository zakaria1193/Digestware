- term: Link-Time Optimization (LTO)

This commit resolves an issue in Link-Time Optimization (LTO) where signed and unsigned `_BitInt` types of the same precision were not guaranteed to have the same alias set. This could lead to incorrect aliasing analysis. The fix is applied during canonical type merging, ensuring that these types are treated consistently, unlike the previous approach that relied on `c_common_get_alias_set` which is complicated by LTO's streaming mechanism. A new test case validates this correction.
