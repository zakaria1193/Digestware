This patch enhances the i386 backend's ability to implement vector permutations for V4SI and V4SF types by leveraging the SSE 4.1 `insertps` instruction. Previously, such operations resulted in multiple instructions; now, they can be consolidated into a single `insertps` instruction, significantly reducing code size and improving performance. This also aids in optimizing zero-extension operations for SSE registers.
