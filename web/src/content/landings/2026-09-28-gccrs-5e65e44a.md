The gccrs test suite has been updated to extend the testing of Rust allocation code. Previously, tests for allocation-related code in `rust/alloc/alloc.exp` only ran up to the name resolution phase. This commit changes the test configuration to run these tests all the way through the type checking phase, providing more comprehensive verification of allocation functionality.
