This commit corrects an issue in the Cobol compiler where group attributes were not being inherited properly. Specifically, the `numeric_group_attrs` function in `symbols.cc` was modified to ensure that group attributes correctly inherit only from `FldGroup`, resolving an inheritance bug and improving the accuracy of Cobol data type handling.
