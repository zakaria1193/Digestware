This commit centralizes the implementation of Ada's rule 3.10.2(9.1) concerning the accessibility level of conditional expressions. Previously scattered and limited to specific contexts and anonymous access types, the new implementation handles both static and dynamic levels uniformly. This resolves issues with anonymous access discriminants and streamlines the accessibility checking process within the compiler.
