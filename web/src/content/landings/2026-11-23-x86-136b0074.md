This commit prevents the x86 backend from enabling stack realignment for leaf functions that have a zero frame size. Such functions, when performing over-aligned stack accesses through user-casted pointers, could incorrectly trigger stack realignment. This led to an assertion failure in the function epilogue. The fix ensures that stack realignment is only disabled in such cases, aligning with the absence of stack slots.
