GCC's `ranger` pass, responsible for determining value ranges, previously could not handle loads from constant arrays of floating-point numbers. While constant propagation (`cprop`) could optimize loads from double arrays, `ranger` lacked this capability. This commit extends `ranger` to correctly determine the range of values loaded from constant tables containing floats, enabling further optimizations that rely on value range information, especially in conditional code.
