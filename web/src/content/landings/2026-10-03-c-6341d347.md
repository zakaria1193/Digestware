This commit fixes an Internal Compiler Error (ICE) during name mangling for calls to `__builtin_bswapg` and `__builtin_bitreverseg`. These built-in functions, which have return types dependent on their argument types, were treated as internal function calls (IFN_BSWAP, IFN_BITREVERSE). The compiler previously crashed when trying to mangle these calls. The fix ensures they are mangled similarly to type-generic built-ins with fixed return types, resolving the ICE.
