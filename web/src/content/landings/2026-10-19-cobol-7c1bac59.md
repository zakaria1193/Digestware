This commit adjusts the default behavior of the COBOL compiler regarding `SEQUENTIAL` files, setting `ADVANCING` to 'AFTER 1 LINE' by default in `parse.y`. Additionally, it introduces a new public function `__gg__file_io_funcs` in `libgcobol/gfileio.cc`, which is part of the effort to support an I/O plug mechanism. This change enhances flexibility in handling file I/O operations.
