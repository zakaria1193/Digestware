The C++ LTO (Link-Time Optimization) test cases for Darwin 8 and 9 in GCC's testsuite have been updated. These tests manually craft link lines, and on these older Darwin versions, a specific crt (C runtime) component is required to correctly build shared libraries. This change adds the necessary `-dylib0.o` flag to the link line for these tests.
