This commit adds new test cases to the GCC C++ testsuite to verify the compiler's handling of floating-point overflow, specifically in line with C++29 P3899R3. The tests, derived from the paper itself, confirm that GCC already implements the specified behavior for floating-point operations where results exceed the representable range. This ensures that the compiler's output aligns with the upcoming C++ standard for such critical numerical computations, particularly for extended floating-point types.
