This commit resolves an issue where GCC's vectorizer incorrectly generated unsupported reduction recurrences when using if-conversion. The problem arises when a reduction is conditionally updated within an `if-cvt` transformation, hiding the true recurrence from the vectorizer. The fix involves restructuring the generated code to float out the conditional expression, preventing the vectorizer from misinterpreting the control flow and failing to vectorize the loop, as reported in PR126551.
