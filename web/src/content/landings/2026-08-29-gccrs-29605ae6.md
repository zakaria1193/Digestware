gccrs implements 1-to-1 adapters to translate LLVM builtin function signatures into GCC builtin signatures. This commit specifically handles cases involving `FORWARD_ARGUMENTS`, enabling functions like `llvm.addcarryx.u32` and `llvm.addcarryx.u64` to be compiled by mapping them to their `__builtin_ia32_` equivalents. Adapters for SIMD-related builtins are included but currently unused as gccrs does not yet support SIMD types.
