This commit addresses two issues in the RISC-V backend. First, it corrects the template for a branch-on-bit pattern in `config/riscv/andes.md` to use the correct forward label syntax ('1f') for long branch sequences, resolving an incorrect 'f' append. Second, it refines a peephole optimization in `config/riscv/peephole.md` to ensure that the `REGNO` instruction is only applied when its operands are actual registers, not subregisters, preventing potential issues with SUBREG objects.
