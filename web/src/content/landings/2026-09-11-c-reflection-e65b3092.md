This commit resolves an Internal Compiler Error (ICE) occurring in C++ reflection when using namespace splice scopes within a namespace alias. The compiler previously crashed because it expected a type but received a namespace declaration due to an incorrect handling of SPLICE_EXPR. The fix involves constructing a SPLICE_SCOPE type when processing dependent namespaces, ensuring correct type handling.
