A pattern in the `match.pd` file used for matching conditional vector expressions has been simplified. The inner comparison within the `VCE` (Vector Conditional Expression) construct was found to be redundant for the purpose of `VEC_COND` matching and has been removed. This change may lead to slightly more optimized generated code by `genmatch` and could potentially improve matching for certain bitwise operations.
