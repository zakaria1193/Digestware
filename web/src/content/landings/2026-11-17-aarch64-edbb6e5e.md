This change enables the AArch64 backend to recognize bit-field insert (BFI) instructions that are formed using bitwise OR (IOR) or addition (PLUS) operations, especially when operands have disjoint non-zero bits. Previously, the compiler would generate multiple AND, AND, and ORR/ADD instructions, leading to inefficient code. By using `any_or_plus` in pattern matching and updating the cost model, these operations are now correctly identified and emitted as a single BFI instruction, resolving performance regressions and test failures.
