Dead tests for a null TARGET have been removed from `noce_try_cond_arith` within the `ifcvt` pass. After a subregister fallback mechanism, all paths in this function are guaranteed to have a conditional move, making subsequent checks for a null TARGET redundant. One of these redundant tests incorrectly suggested that both candidates could fail, which has also been corrected by stating the invariant with an assertion. This change is a code cleanup with no functional impact.
