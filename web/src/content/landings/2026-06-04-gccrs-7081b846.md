This commit introduces a workaround for a regression on AArch64 systems, specifically affecting the `utf8_identifiers` test case in GCC Rust. A recent change related to literal suffix validation inadvertently caused an invalid error on AArch64. To unblock builds, the test case has been modified to use a more conventional float value, thereby sidestepping the parsing issue until a proper fix is implemented via Issue #4575.
