This commit adds the missing `:c` specifier to the `gt` (greater than) comparison in the `mul_carry_low_sum` and `mul_carry_cross_sum` patterns within GCC's `match` component. This correction ensures that the order of operands in these patterns can be swapped, preventing incorrect optimizations when operand order is significant. A new test case is introduced to verify this fix.
