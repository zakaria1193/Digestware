This change enhances the RISC-V backend by tightening operand predicates for atomic memory operations. This exposes the address computation to optimization passes like CSE, allowing them to better identify and fold redundant address calculations. Previously, an issue with instruction predicates prevented these optimizations, leading to suboptimal code generation for static memory accesses.
