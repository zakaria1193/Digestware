The compiler's handling of flexible array members in structs has been refactored to improve ABI diagnostics. Previously, a function-local static flag controlled a warning about the ABI change (introduced in GCC 4.4). This patch moves the flexible array member check into a helper function and uses the `psabi_new_behavior_p` flag, deferring the note to `inform_psabi_change`. This eliminates redundant static flags and consolidates diagnostic reporting.
