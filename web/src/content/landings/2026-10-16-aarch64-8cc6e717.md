This commit addresses issues with the AArch64 SVE (Scalable Vector Extension) implementation by adding missing `sve_type` definitions for several instructions. Previously, the absence of these types led to compile time increases for certain benchmarks and caused test case failures due to instruction scheduling discrepancies. The fix includes adding the necessary `sve_type` and adjusting test cases with `-fno-schedule-insns2` to mitigate instruction reordering issues affecting assembly checks.
