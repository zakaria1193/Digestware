The `prange::pt_invariant_p` and `prange::pt_invariant_away_p` functions in `value-range.h` now return a boolean `true` or `false` directly. Previously, these functions returned a `TREE` object which was then implicitly converted to a boolean. This change simplifies the API by providing explicit boolean results, aligning with modern coding practices and improving readability.
