Philip Herron corrected the derive macro for the `Ord` trait in `gccrs` to use `Self` instead of a raw type name.
This change ensures that the generic type parameters of an implementation are correctly captured when deriving `Ord`.
This resolves an issue with how trait implementations are handled in generic contexts, specifically fixing Rust-GCC/gccrs#4879.
