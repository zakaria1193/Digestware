This commit addresses a bug in the Fortran compiler's handling of parameterized derived types (PDTs) by fixing an issue in the `gfc_trans_deferred_vars` function. It ensures that the PDT component allocation function (`gfc_allocate_pdt_comp`) is only called when the symbol associated with the component has a valid parameter list. This prevents erroneous calls and subsequent miscompilations for certain PDT instantiations.
