GCC's libstdc++ now more broadly applies Lemire's algorithm for generating random numbers within power-of-two ranges. Previously, this efficient algorithm was primarily used for 32-bit (`__UINT32_TYPE__`) and 64-bit (`__UINT64_TYPE__`) unsigned integers. This update allows it to work with targets that lack these specific types, by masking the result of integer conversions to the required bit width. The core logic for Lemire's algorithm and the necessary type definitions are now consolidated in `uniform_int_dist.h` for better organization and portability.
