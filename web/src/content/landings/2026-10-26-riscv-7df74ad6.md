This commit refines RISC-V patterns for masked comparisons against zero, simplifying the emitted RTL and improving efficiency. By replacing `ANYI` iterators with `X` iterators, the patterns now more directly handle the masking operations, avoiding unnecessary subregister operations. This change simplifies the generated code for equality comparisons involving masked registers, potentially leading to more optimal instruction sequences.
