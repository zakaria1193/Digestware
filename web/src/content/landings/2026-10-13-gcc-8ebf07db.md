This commit addresses a regression in RISC-V code generation where certain address calculations, particularly those involving offsets in the range [2048..4095], were not optimally synthesized. The changes ensure that the `riscv_add_offset` function now correctly utilizes `synthesize_add` when possible, leading to more efficient RTL generation for memory references. This resolves an issue where naive code generation was falling back for these offsets, impacting the ability to combine subsequent instructions.
