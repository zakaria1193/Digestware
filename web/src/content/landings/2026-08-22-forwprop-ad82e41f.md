The hilo{0,1,2} components within the long_mul_summand structure in forwprop have been converted into an array. This change streamlines the code, particularly for range-based for loops, by eliminating the need for a local array copy. The update also replaces direct hilo[n] access with array indexing and modifies the copy location to use a loop.
