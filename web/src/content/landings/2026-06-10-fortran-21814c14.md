This commit resolves an Integer Compiler Error (ICE) encountered when passing a NULL() actual argument to an allocatable dummy argument in Fortran. The change ensures that NULL() is handled correctly for non-class, non-character allocatable dummies, similar to how it's handled for derived-type dummies. A new test case is added to confirm the fix.
