A bug in the aarch64 target driver has been fixed that affected the handling of `-march=native` when the `-mtune` option was also specified. Previously, changes to `ARCH_IDENT` values caused lookups to fail, leading to incorrect CPU feature detection. This commit adjusts string offsets to ensure proper matching of identifiers, resolving the issue and restoring correct behavior.
