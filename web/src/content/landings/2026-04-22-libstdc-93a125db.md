The C++ standard library now mandates that the alignment parameter passed to `std::is_sufficiently_aligned` must be a power of two. This change implements LWG4290, which adds missing mandates clauses to the function's specification. A new test case, `testsuite/20_util/is_sufficiently_aligned/2_neg.cc`, has been added to verify the correct behavior.
