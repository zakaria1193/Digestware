This commit optimizes a specific bitwise operation pattern in GCC's RTL (Register Transfer Language) to generate more efficient code for RISC-V processors. It transforms `(and (xor A 1) B)` into `(and not A B)` when `B` is a 0 or 1 value. This change is particularly beneficial for RISC-V's limited instruction set, reducing instruction count by approximately 160 million in benchmarks like x264 by utilizing the `andn` instruction.
