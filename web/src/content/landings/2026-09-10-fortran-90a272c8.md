This commit explicitly passes `false` as the `formal_ptr` argument to `gfc_conv_subref_array_arg` in various Fortran translation routines. This change reflects the understanding that copy-in/copy-out operations for argument association are used in contexts where dummy arguments cannot have the pointer attribute. By making this explicit, the code simplifies reasoning about argument types and avoids potential issues related to pointer semantics in these specific cases.
