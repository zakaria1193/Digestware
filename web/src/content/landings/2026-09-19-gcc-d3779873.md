This commit fixes an alignment issue in GCC where arguments passed partially through registers and partially on the stack were not correctly aligned. The `assign_parm_find_stack_rtl` function previously used the full argument boundary for alignment, even when only part of the argument was on the stack. This led to incorrect memory accesses, such as misaligned loads/stores on RISC-V. The fix clamps the alignment to the actual size of the portion on the stack, ensuring correct memory referencing and resolving issues with specific RISC-V instructions.
