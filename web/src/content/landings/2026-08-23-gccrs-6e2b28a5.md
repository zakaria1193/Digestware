The GCC Rust frontend now indexes implementation trait blocks and stores them in the trait map. This allows for more efficient filtering during trait probing, preventing the compiler from needing to scan the entire crate. By directly mapping trait implementations, the compiler can quickly locate relevant trait information, speeding up compilation for projects with extensive trait usage.
