The Cobol compiler's parser will now continue processing even if the lexer encounters errors, allowing for more comprehensive error reporting. Additionally, the compiler now permits moving a literal value to a numeric-edited data item, aligning with COBOL's preference for late-binding and ensuring MOVE operations always succeed, with potential issues arising only when using the results.
