This commit refactors the COBOL COMPUTE statement to use Reverse Polish Notation (RPN) for expression evaluation. Previously, complex expressions like 'z = a * b + c * d' would generate numerous temporary variables. The new RPN-based approach utilizes a stack, which is processed by the libgcobol library, leading to more efficient computation and a reduced burden on the GCC middle end.
