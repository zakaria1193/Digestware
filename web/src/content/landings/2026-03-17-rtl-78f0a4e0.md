This patch introduces the necessary middle-end adjustments in GCC's RTL to allow memory operands that are vectors of addresses. A new flag, `MEM_INDEPENDENT_P`, is introduced to indicate that vector addresses can be treated independently, which is crucial for certain backends like GCN. While existing targets are unlikely to be affected due to not yet reporting vector modes as legitimate, this lays the groundwork for future backend support for vector memory operations.
