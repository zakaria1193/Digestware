This commit updates several PowerPC test cases for Future VSX arithmetic built-ins. Previously, these tests used inline assembly to force specific operands into floating-point registers (FPRs), thereby controlling which instructions the compiler would generate. The update removes this forcing mechanism, allowing the tests to instead evaluate the compiler's default instruction selection. This change enables the tests to catch regressions or improvements in how the compiler automatically chooses instructions for VSX operations, making the test suite more robust against future changes.
