This commit enhances the COBOL parser's ability to maintain lexer state when processing Compiler-Directing Facilities (CDF) lookahead tokens. Previously, if a CDF token was not a lookahead token, it was reprocessed, sometimes leading to incorrect NAME recognition. The changes ensure that the lexer state is correctly managed, fixing an issue where a CDF directive could prevent the recognition of an implicit PICTURE clause. Debug messages and internal logic have also been tidied.
