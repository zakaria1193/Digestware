This commit simplifies libstdc++'s error handling by removing unnecessary preprocessor checks for the `EPERM` macro. These checks were present in headers for MinGW and MinGW-w64 targets, but `EPERM` is consistently defined across Windows and POSIX-like systems. By removing these checks, the code now unconditionally uses `EPERM`, simplifying the headers and aligning with existing code that assumes its presence.
