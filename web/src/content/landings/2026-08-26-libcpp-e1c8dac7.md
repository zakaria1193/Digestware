A bug in libcpp's header unit handling caused a closed file descriptor to be recorded as zero instead of the intended -1 sentinel. This led to incorrect behavior where subsequent textual includes could mistakenly reopen and read from stdin. This fix ensures that valid descriptors are closed and the sentinel is correctly set to -1, resolving the issue and preventing incorrect file reading.
