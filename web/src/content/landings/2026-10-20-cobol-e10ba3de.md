This change modifies the default configuration for libgcobol to disable embedded RUNPATH information in COBOL executables. Previously, RUNPATH was enabled by default. Users can explicitly enable it using `--enable-libgcobol-rpath`. Additionally, a spurious message during `make check-cobol` has been resolved.
