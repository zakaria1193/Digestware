GCC's Ada front end previously used a two-pronged approach for static accessibility checks during type conversions in instance bodies. This change removes the separate implementation for these checks, instead directly inserting raise statements for failures, aligning it with how these checks are handled in other contexts. The old approach was difficult to maintain and less consistent than the new unified method.
