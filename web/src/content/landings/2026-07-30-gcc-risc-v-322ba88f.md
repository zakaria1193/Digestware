This commit enables register group overlap for several RISC-V Vector extension instructions: `vwadd.vv`, `vwsub.vv`, `vwmul.vv`, and their unsigned variants. This change allows these dual-widen vector instructions to leverage register overlap, similar to how `vwadd[u].wv` already does, potentially improving code density and performance.
