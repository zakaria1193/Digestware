Tests for the `builtin copysign` function were failing because the compiler generated `andps` instructions when `pand` was expected, due to a specific optimization flag `TARGET_SSE_PACKED_SINGLE_INSN_OPTIMAL` being enabled by default. This commit disables this optimization for the affected tests using `-mtune-ctrl=^sse_packed_single_insn_optimal`, resolving the instruction mismatches.
