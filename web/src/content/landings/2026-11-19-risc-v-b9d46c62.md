The RISC-V architecture can now leverage the Zbkb extension for logical operations with complemented constants. This change optimizes mask operations, such as `~0xf000UL`, by using a single `lui` instruction combined with an `andn` operation, reducing instruction count and improving efficiency. The compiler now handles these inverted logical operations for Zbkb, aligning with the cost model of the Zbb extension.
