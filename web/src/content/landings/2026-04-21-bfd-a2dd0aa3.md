  a fixed timestamp for builds, often set by build tools. Now, programs using `libbfd`

  contents.

The ar utility now uses the SOURCE_DATE_EPOCH environment variable to determine the timestamp of the archive. If the BFD_DETERMINISTIC_OUTPUT flag is set on the archive and SOURCE_DATE_EPOCH is present, the date stamp will be set to the value of the variable, otherwise it defaults to 0.
