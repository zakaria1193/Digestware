GCC's Rust frontend now includes const getter overloads for fields within HIR pattern nodes. These are necessary for the type-aware refutability checks, enabling access to pattern fields through const references, as required by commit b44ed1c5e770490c0d73c648a741263c12be6328 which addresses Rust-GCC#2082.
