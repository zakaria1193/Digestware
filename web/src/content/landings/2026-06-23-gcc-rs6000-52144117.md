This commit introduces infrastructure support for `future-altivec` as a builtin-stanza predicate for PowerPC. This framework allows for the definition of specialized AltiVec-specific builtins that are enabled only when both `-mcpu=future` and `-maltivec` compiler options are specified. This ensures that future PowerPC ISA extensions, particularly those leveraging AltiVec, can be properly supported and utilized by the compiler.
