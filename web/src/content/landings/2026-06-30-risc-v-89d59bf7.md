This commit introduces support for additional RISC-V Zvdota extension classes and their alternative format specifiers. It enhances the assembler and disassembler to recognize instructions like `Zvfqwdota8f` and to handle the `vtype` alternative format bit, which is crucial for selecting specific vector element formats. The changes include updates to internal data structures, new constants for `vsetvli`/`vsetivli` instructions, and additions to the test suite to cover these new features.
