The gccrs compiler now centralizes the checking of attributes in a single location during the lowering phase, improving error reporting by explicitly mentioning which attribute is unknown. This change removes redundant attribute checking code from `get_lang_item_attr` and consolidates it within `ASTLoweringBase::handle_outer_attributes`.
