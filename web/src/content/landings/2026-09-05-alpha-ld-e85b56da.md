    executables and allows libraries to be shared among multiple programs.

This commit enables the indirect function (IFUNC) tests for the alpha target by removing it from the skip list in `ifunc.exp`. It also updates the `ld/NEWS` file to reflect that the alpha target supports IFUNCs using the new `R_ALPHA_IRELATIVE` relocation, though a matching C library is still required for runtime execution. Static linking of IFUNC addresses is noted as unsupported.
