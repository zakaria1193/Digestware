GCC now leverages SVE2 SQXTNB and UQXTNB instructions on aarch64 for saturating truncation operations, enhancing vectorization. Previously, these operations were emulated less efficiently using minimum and maximum instructions followed by a truncating store. This change improves performance by directly using hardware support for these operations, making code generation more efficient for saturated truncation patterns.
