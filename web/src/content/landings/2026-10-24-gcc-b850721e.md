Several functions in GCC's exception handling (EH) subsystem now accept a const rtx_insn* instead of a non-const pointer. This change enhances type safety by preventing accidental modification of instruction representations during exception analysis. It allows the compiler to more accurately reason about code paths and potential exceptions.
