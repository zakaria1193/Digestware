primer_glossary:
- term: Dominator Optimization
  definition: A compiler optimization pass that analyzes the control flow graph of
    a program to determine dominance relationships between basic blocks. This information
    is used for various optimizations, including dead code elimination and constant
    propagation.
- term: SSA
  definition: Static Single Assignment form. A representation of intermediate code
    where every variable is assigned a value exactly once. This simplifies many compiler
    analyses and optimizations.
- term: Equivalence
  definition: In this context, it refers to a relationship where one SSA name can
    be substituted by another, often because they have been determined to hold the
    same value at a certain point in the program.
- term: Basic Block
  definition: A sequence of instructions with a single entry point and a single exit
    point. Control flow enters at the beginning and proceeds without halt or possibility
    of diversion until the end.
- term: PHI node
  definition: In SSA form, a PHI node is an instruction that merges values from different
    control flow paths. It indicates which version of a variable to use based on which
    predecessor block was executed.

The dominator optimization pass (`tree-ssa-dom`) has been optimized to prevent redundant walks in `back_propagate_equivalences`. Previously, the pass repeatedly traversed uses of SSA names, leading to performance issues in code with many equivalences. This change caches information about names that do not yield useful equivalences, drastically reducing compilation time and instruction count for affected programs.
