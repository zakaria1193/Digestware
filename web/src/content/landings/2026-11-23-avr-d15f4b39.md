This change adds a definition for `INCLUDE_ALGORITHM` in the AVR target's configuration. This is necessary because while `<algorithm>` might be transitively included when using GCC's libstdc++, it is not guaranteed in all build configurations, particularly when using alternative C++ standard libraries like LLVM's libc++. Defining `INCLUDE_ALGORITHM` ensures that standard algorithms like `std::min` are correctly available, preventing compilation failures.
