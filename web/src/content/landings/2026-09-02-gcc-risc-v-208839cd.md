This patch introduces a scalar `memmove` implementation for RISC-V, which previously only had a vector version. It adds a new dispatcher `riscv_expand_block_move` and an overlap parameter to the block move routines. While overlap is handled for straight copies, loop-based moves currently assume no overlap, limiting optimized expansion to known lengths of 96 bytes.
