This commit refactors the existing logic for redirecting callback edges by moving it into a new, standalone function called `callback_redirect_edge`. This function encapsulates the redirection behavior, making the code cleaner and preparing it for reuse with internal callback edges in a future patch. The direct usage of this new function is demonstrated in `cgraph_edge::redirect_call_stmt_to_callee`.
