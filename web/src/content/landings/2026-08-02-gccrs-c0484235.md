    means the `Drop` implementation for the moved value does not need to be called

gccrs now integrates its Basic Intermediate Representation (BIR) drop analysis into the backend cleanup phase. This optimization allows the compiler to skip generating cleanup code for `Drop` operations on locals that have been moved, as they are no longer valid. Unaffected locals continue to use existing cleanup logic.
