This commit adds a new `define_insn_and_split` pattern for `seq_sne_qi` in the RISC-V backend to address suboptimal code generation for single-byte integer (QI) comparisons, resolving PR124019. While such comparisons are rare in common benchmarks, the dedicated pattern ensures correct and efficient code generation for these edge cases, preventing bootstrap failures that were observed in earlier GCC versions.
