When instantiating nested class templates, the compiler needs to look up members in the enclosing scope when processing base class clauses. A recent change removed scope handling around base clause substitution, which broke lookups for using-declarations. This commit restores the correct scope handling to ensure members from the enclosing class are properly brought into scope during nested class instantiation, fixing PR 82613.
