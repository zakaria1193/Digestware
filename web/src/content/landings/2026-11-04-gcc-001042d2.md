The internal 'prange' points-to analysis API has been reworked to adopt an address-centric naming convention. Functions and data structures previously using 'pt_' prefixes (e.g., `pt_solution`) are now prefixed with 'addr_' (e.g., `addr_base`, `addr_offset`). This change aims to reduce confusion with other points-to (`pt`) related concepts and improve the clarity of the API, ensuring that range-based pointer analysis uses terms that directly relate to memory addresses.
