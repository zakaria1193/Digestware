This change corrects the handling of Fortran VALUE dummy arguments, particularly for derived types with allocatable components and CLASS actual arguments. According to the Fortran 2023 standard, VALUE arguments are passed by copy. Previously, gfortran incorrectly shared data for derived types with allocatable components and handled CLASS dummies improperly. This patch ensures that derived types with allocatable components are passed by reference to a copy, allowing the callee to deallocate components. It also ensures that CLASS dummies receive a copy of the data through the vtable, handling intrinsic actual arguments correctly.
