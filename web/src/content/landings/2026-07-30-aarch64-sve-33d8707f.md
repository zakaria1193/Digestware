primer_expert: The `aarch64_expand_sve_const_vector` function was inefficiently generating
  constant SVE vectors, especially those with trailing zeros, by using predicate masks
  and `SEL` instructions. This commit introduces a new function that detects when
  the second element of patterns is always zero. If so, it generates a non-scalable
  vector from the first elements or directly uses a scalar constant if only one pattern
  exists. This optimizes cases like `{1,2,1,2,1,2,0,0}` which previously involved
  unnecessary operations, aligning performance with loop-generated code.

This change optimizes the generation of constant SVE vectors on AArch64, particularly for cases with trailing zeros. It replaces inefficient sequence of predicate masks and conditional selects with direct loads or scalar constructions, bringing its efficiency closer to that of loop vectorization.
