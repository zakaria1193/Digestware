This commit resolves a bootstrap failure in the Cobol frontend that occurred due to the use of `-Werror=format-diag`. The error stemmed from an unquoted '-dialect ibm' option within a format string in `parse.y`. The fix replaces the unquoted option with a properly quoted `%<-dialect ibm%>`, ensuring that the format string is parsed correctly and allowing the Cobol frontend to build successfully.
