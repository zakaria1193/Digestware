This change updates the libgomp NVIDIA GPU plugin to require a minimum driver version of 340 or newer. This version was released a decade ago, ensuring compatibility with a reasonably modern NVIDIA driver stack for GPU offloading. The change affects the plugin's CUDA library definitions and source code.
