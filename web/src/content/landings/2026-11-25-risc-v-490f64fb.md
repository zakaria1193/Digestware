The RISC-V assembler now correctly emits `R_RISCV_ALIGN` relocations for code sections where relaxation is disabled but preceded by relaxable code. Previously, when relaxation was off, the assembler used fixed NOPs for padding. However, if relaxable instructions altered the code's layout, the linker might still adjust alignment points. This change ensures that alignment directives are respected by emitting the necessary relocation information, preventing potential alignment issues.
