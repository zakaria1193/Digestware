This patch introduces support for synthesizing certain 64-bit constants on RISC-V using the `shNadd.uw` instruction, which performs a shift and add operation. Previously, creating such constants involved multiple instructions. The compiler now identifies opportunities to use `shNadd.uw` for specific constant values that fit the pattern `u * (2^N + 1) - 2^32`, leading to more compact code. A new test case verifies this optimization, and the logic for handling fused multiply-add (FMA) with `use_uw` is adjusted for correctness.
