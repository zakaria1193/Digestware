An Internal Compiler Error (ICE) occurred in the GIMPLE parser when processing `_Literal` expressions involving Variable Length Array (VLA) types, such as `svuint8_t` from `<arm_sve.h>`. This commit replaces a problematic call to `TYPE_VECTOR_SUBPARTS(type).to_constant()` with `constant_lower_bound()`, which correctly determines the number of elements for VLAs, thus fixing the ICE and adding new test cases.
