The `get_scalar_to_descriptor_type` function in the Fortran front-end has been modified to accept the scalar's type directly as an argument, rather than accessing it via `TREE_TYPE()`. This change shifts the responsibility of extracting the type to the calling functions (`gfc_conv_scalar_to_descriptor`, `gfc_conv_derived_to_class`, `gfc_conv_class_to_class`), simplifying the `get_scalar_to_descriptor_type` function itself and addressing PR122521.
