This commit prevents BFD from attempting to process relocations in ELF object files that have an empty symbol table section. Such files can cause confusion because the linking process relies on a valid symbol table, particularly for the `STN_UNDEF` symbol. BFD now treats empty symbol tables similarly to missing ones, reporting an error and avoiding incorrect processing, which resolves several PRs related to malformed object files.
