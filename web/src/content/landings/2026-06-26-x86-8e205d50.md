This commit introduces new runtime tests to GCC's x86 backend for the `memmove` built-in function. These tests specifically target scenarios where the source and destination memory regions for the `memmove` operation overlap and are inlined with various bounds. Adding these tests helps ensure the compiler's optimization of `memmove` consistently produces correct results under these challenging conditions, preventing potential data corruption.
