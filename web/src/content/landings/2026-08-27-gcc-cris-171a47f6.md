This commit enhances the CRIS backend by adding support for several variants of the SWAP instruction found in version 8 of the CRIS architecture. These new patterns allow GCC to efficiently implement operations like 32-bit rotates by 16 bits and bit reversal, significantly reducing code size and improving performance compared to previous manual implementations.
