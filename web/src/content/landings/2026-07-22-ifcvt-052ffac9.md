Three functions in GCC's ifcvt pass (noce_process_if_block, noce_convert_multiple_sets, and cond_move_process_if_block) duplicated code for modifying the Control Flow Graph (CFG) after a successful conversion. This change factors this common logic into a new helper function, `noce_finish_if_conversion`, reducing redundancy and improving code maintainability.
