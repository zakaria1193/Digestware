This commit removes the dedicated metadata export visitor in gccrs, opting instead to directly dump the Abstract Syntax Tree (AST) into metadata files. This change is made because the existing metadata format is incomplete and does not support trait implementations, which are expected to change soon. While this approach is slower, it is considered more complete and correct for the current state of metadata handling in the compiler.
