This commit resolves an issue in GCC's Ada front-end where valid calls to asymmetric inequality operators ('/=') using prefix notation were incorrectly rejected when one operand was a tagged type. The fix redirects the handling of asymmetric inequality operators for tagged types to the common processing path, ensuring correctness and also addresses an inheritance glitch for derived types.
