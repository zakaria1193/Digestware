This commit resolves an internal compiler error (ICE) and related incorrect behavior in GCC's Fortran front-end when handling type-bound procedure calls through an inferred `ASSOCIATE` name. Previously, such calls, especially those involving components or procedure pointers, would fail due to incorrect type lookups and missing fix-ups. The fix ensures proper reference resolution and type checking for these complex call scenarios, also addressing issues with array references following `CLASS` components.
