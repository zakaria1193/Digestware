This commit corrects the `cpp_check_xid_property` function, which is used by the Rust frontend for identifier validation. The function previously misapplied Unicode character properties, incorrectly classifying characters with only the XID_Continue property as valid starting characters for identifiers. The fix ensures that only characters with the XID_Start property are accepted as initial identifier characters, aligning with Unicode standards and preventing potential issues in languages like Rust that rely on these precise checks.
