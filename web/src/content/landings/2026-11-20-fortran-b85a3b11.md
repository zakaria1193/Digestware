This commit addresses a regression in the Fortran compiler's handling of parameterized derived types (PDTs), resolving issues related to parameter access. It updates symbol attribute access from `CLASS_DATA (sym)->attr.pointer` to `CLASS_DATA (sym)->attr.class_pointer` and removes unnecessary `pointer` attributes for dummies. This ensures correct internal representation and handling of PDTs, preventing compilation errors.
