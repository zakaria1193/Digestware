This commit simplifies the Ada compiler's code generation for record aggregates by removing outdated finalization handling logic. The `Generate_Finalization_Actions` procedure, which was tied to an old implementation, has been removed. Instead, the `Initialize` primitive for controlled types is now called directly at the appropriate point in `Build_Record_Aggr_Code` for extension aggregates.
