RISC-V vector shuffle slide patterns incorrectly accepted non-monotonic masks, leading to incorrect code generation at -O0. This change verifies that the sequence endpoints match expected positions for OP0 and OP1, rejecting invalid patterns. A new test case has been added to cover this fix.
