GCC improves code generation for __builtin_bitreverse{8,16,32,64} on RISC-V when the ZBKB extension is enabled. It now utilizes specific brev8 or rev8 instructions for better performance. The change also adjusts the condition for using the bswaphi2 instruction to include the ZBKB extension.
