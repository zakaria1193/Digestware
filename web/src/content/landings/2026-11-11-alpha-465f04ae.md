The input_operand predicate on the alpha architecture has been fixed to correctly test for the lra_in_progress flag. Previously, it used reload_in_progress, which is never set by the Late Register Allocator (LRA). This led to LRA incorrectly rejecting constants that require splitting, and in some cases, caused a crash due to an unrecognized instruction being emitted. The fix ensures that constants are split properly when LRA is active, resolving these issues.
