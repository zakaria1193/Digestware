primer_glossary:
- term: RISC-V vector extension
  definition: An extension to the RISC-V instruction set architecture that adds support
    for single instruction, multiple data (SIMD) operations, allowing a single instruction
    to process multiple data elements in parallel.
- term: vwredsum.vs / vwredsumu.vs
  definition: RISC-V vector instructions for widening reduction (summation). `.vs`
    indicates that the destination register group is specified by the `vd` register
    and the source register groups are `vs1` and `vs2`.
- term: SEW
  definition: Standard Element Width. Refers to the width of individual data elements
    within a vector register (e.g., 8-bit, 16-bit, 32-bit).
- term: EEW
  definition: Effective Element Width. The width of the elements being processed by
    a vector operation, which can be different from the SEW, especially in widening
    operations.
- term: Register group
  definition: A contiguous block of vector registers used by a single instruction.
    The size of the group depends on the operation's element width and the vector
    length.

New test cases ensure that the scalar operand `vs1` for the RISC-V widening reduction instruction `vwredsumu.vs` does not overlap with the `vs2` register group. This addresses potential register allocation issues and maintains correct program execution.
