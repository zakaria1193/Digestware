This commit optimizes the `genattrtab` tool by modifying how instruction entries are removed from attribute values. By adding a 'prev' pointer to `insn_ent`, entries can now be removed in constant time, avoiding a quadratic cost that previously dominated processing for large attribute lists on targets like AArch64 and RISC-V. This change significantly reduces `genattrtab`'s execution time.
