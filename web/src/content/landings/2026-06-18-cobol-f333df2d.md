The GCC COBOL front end improves the performance of `MOVE` operations by implementing a faster routine for converting numeric-display numerical strings to binary values. It also enhances the conversion of binary values to big-endian COMP-4 values. This change refactors the `copy_little_endian_into_place` function into `move.cc` and allows it to handle both little-endian and big-endian targets, including taking the absolute value of signed inputs when the target is unsigned, which provides more robust and efficient data movement.
