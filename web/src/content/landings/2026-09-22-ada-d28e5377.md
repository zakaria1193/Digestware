The Ada compiler's DWARF 5 support, when enabled, creates a mapped stream for the `.debug_line_str` section. The `Close` procedure for DWARF contexts was not properly closing this stream, leading to leaked memory allocations. This commit modifies `Close` to ensure the line-string stream is properly closed before the object file is finalized, preventing resource leaks.
