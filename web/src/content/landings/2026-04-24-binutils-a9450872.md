The x86 and x86_64 disassemblers now accept the command line option `-M annotate-immediates`.  This option displays the symbol associated with immediate values, if one exists.  This enhancement helps in debugging and reverse engineering by providing more context for immediate values in disassembled code. It currently works only on executable binaries and shared libraries, not static object files.
