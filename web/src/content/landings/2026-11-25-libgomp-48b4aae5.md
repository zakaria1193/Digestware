This change corrects an issue in libgomp where the OMP_TARGET_OFFLOAD=mandatory setting did not properly initialize the default device ICV when encountering nested environment configurations. The fix ensures that the default device is correctly determined, whether it's an offload device or an invalid one, even within nested ICVs, preventing potential misconfigurations in target offloading scenarios. New test cases have been added to verify this behavior.
