primer_glossary:
- term: macro-fusion
  definition: An optimization technique where the compiler combines two or more adjacent
    instructions into a single, more efficient instruction or sequence, provided specific
    conditions (like register dependencies) are met.
- term: RTL
  definition: Register Transfer Language, an intermediate representation used by GCC
    to describe hardware operations before they are translated into machine code.
- term: producer-consumer relationship
  definition: A dependency where one instruction (producer) generates a result that
    is used as an input by another instruction (consumer).
- term: pre-allocation destination overmatching
  definition: A compiler optimization where the destination register of an instruction
    is speculated to be reused by a later instruction, even before exact register
    allocation is finalized. This allows for earlier instruction scheduling and potential
    fusion.
- term: subregister
  definition: A portion of a larger register, treated as a distinct unit for certain
    operations.
- term: parameterized classifiers
  definition: Helper functions or logic within the compiler that can identify instruction
    types based on various parameters, allowing for more flexible and reusable recognition
    rules.
- term: microarchitecture-specific constraints
  definition: Rules and limitations imposed by the specific design of a processor's
    execution pipeline and functional units, which influence instruction scheduling
    and optimization.
- term: RISC-V
  definition: An open-standard instruction set architecture (ISA) based on modularity,
    extensibility, and simplicity, gaining traction in embedded systems and high-performance
    computing.

GCC's RISC-V backend has undergone a significant refactoring of its macro-fusion helper functions. This change factors out common RTL parsing logic, improving code reuse and maintainability. It enhances the accuracy of destination matching by considering subregister bit positions and preserves pre-allocation destination overmatching while validating real producer-consumer dependencies. The introduction of parameterized classifiers allows later fusion recognizers to share structural matching logic without duplicating microarchitecture-specific constraints, leading to a more robust and extensible fusion framework.
