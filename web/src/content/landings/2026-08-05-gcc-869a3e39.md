The gfortran test case `PR100914.f90` is now skipped on `hppa*-*-hpux*` platforms. This is because the target environment on these systems does not provide the standard `complex.h` header file, which is required for the test to execute correctly. This change prevents testsuite failures on this specific platform due to the missing header.
