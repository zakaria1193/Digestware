This commit optimizes AArch64 ADD instructions where the immediate value becomes zero after relocation, as recommended by the ARM architecture specification. It replaces ADD x0, x1, 0 with MOV x0, x1 and ADD x2, x2, 0 with NOP, while handling register 31 (SP) and --no-relax appropriately. This improves code density and performance.
