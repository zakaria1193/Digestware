This commit adds the emission of modules into the metadata export files generated by gccrs. Previously, modules were not included, which prevented them from being correctly resolved when another crate imported the current one. New functions in `rust-export-metadata.cc` now handle emitting the module preamble and suffix, ensuring module structure is preserved in the metadata.
