This commit revises the implementation of CLZ (count-leading-zeros) and CTZ (count-trailing-zeros) for the s390 architecture. For scalar CTZ, the input is now manipulated to ensure a consistent output range for zero inputs, aligning with vector instructions. The target hooks for CLZ/CTZ defined-at-zero values are updated to handle vector modes. Additionally, CLZ/CTZ for the TI mode are implemented using vector patterns, requiring specific handling for TI mode results expected in GPRs.
