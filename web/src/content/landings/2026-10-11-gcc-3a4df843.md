Recent changes to Count Trailing Zeros (CTZ) and Count Leading Zeros (CLZ) instructions caused build failures on the VAX architecture. This commit applies a fix similar to one made for the pru-elf target, ensuring VAX builds can proceed by correctly defining CTZ_DEFINED_AT_ZERO using GET_MODE_UNIT_BITSIZE. VAX builds have been verified.
