This commit addresses two issues in Fortran's array constructor handling of character length expressions. The first fixes a problem with `trans-array.cc` by adding a check for `INTEGER_CST`. The second, more extensive fix, improves how character lengths (`charlens`) are tracked during parsing to prevent them from being left dangling, ensuring proper cleanup and avoiding memory issues.
