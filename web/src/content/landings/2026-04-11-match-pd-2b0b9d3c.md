GCC's pattern matching now transforms expressions of the form ``x != -CST ? x + CST : 0`` into ``x + CST``.  This simplification occurs when CST1 is equal to the negation of CST2. This optimization can improve code generation, particularly in scenarios involving operations like 'rtrim', which removes trailing whitespace from a string.
