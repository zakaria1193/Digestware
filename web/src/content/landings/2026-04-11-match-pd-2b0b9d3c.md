The compiler now simplifies expressions matching the pattern `x != CST1 ? x + CST2 : 0` into `x + CST2` if `CST1` equals `-CST2`. This optimization is particularly useful in scenarios like 'rtrim'-style operations, potentially improving code efficiency by removing a conditional branch.
