The gccrs compiler now distinguishes 'tool attributes' from other attributes, ensuring that tool-specific attributes are ignored by the compiler and can be handled by external tools. This is achieved by modifying the `is_known` API to return an enum indicating attribute knowledge and updating attribute handling in the AST lowering and name resolution phases.
