primer_glossary:
- term: MD generator
  definition: Machine Description generator. GCC uses machine description files (MD
    files) to describe the instruction set architecture of a target processor. The
    MD generator processes these files to create internal tables and code used by
    the compiler.
- term: partitions
  definition: In this context, partitions refer to how the MD generator divides its
    work into separate compilation units. A higher number of partitions can increase
    parallelism but also incurs overhead from repeated setup and teardown.
- term: bootstrap compile times
  definition: The time it takes to compile the compiler itself. Optimizing bootstrap
    times is crucial for development iteration speed, especially in large projects
    like GCC.
- term: i386

    the basis of the x86 architecture. GCC supports a wide range of i386-compatible
    processors.
- term: SGPR

    state or parameters.
- term: VGPR
  definition: Vector General Purpose Register. VGPRs are typically used to hold data
    for vector operations, allowing multiple data elements to be processed in parallel.

GCC's i386 machine description (MD) generator now defaults to 6:6:1 partitions for its internal processing. This change, aimed at optimizing bootstrap compile times, rebalances the workload across compilation units related to instruction matching and recognition. The new default significantly reduces the compile time for critical files like `gimple-match` and `generic-match` objects, bringing them closer to more efficient compile times previously seen with smaller partition counts.
