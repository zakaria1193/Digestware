The compiler has removed legacy logic for handling include directories in the gcobc component of the COBOL front-end. These heuristics were initially added when the copybook directory structure was not yet standardized. Current versions of cobol1.cc now correctly include necessary directories, making this old logic obsolete. This change simplifies the gcobc code by removing unnecessary heuristics.
