The NEON halving-add intrinsics vhadd and vrhadd have been ported to GCC's pragma-based framework for aarch64. This change updates test cases to expect streaming-mode diagnostics instead of inlining failures and removes the always_inline attribute from these functions in arm_neon.h, requiring alternative intrinsics like vqtbl in some tests.
