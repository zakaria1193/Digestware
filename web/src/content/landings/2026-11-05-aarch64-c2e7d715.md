This commit introduces the foundational elements within GCC's aarch64 backend for handling NEON shift intrinsics using the new pragma-based framework. It defines new shape checkers for shifts, adds syntax support for parsing element types, and introduces several new GIMPLE-based classes designed to represent instructions, specifically for shifts with immediate or register operands. These building blocks are necessary for subsequent commits that will port specific NEON shift intrinsics.
