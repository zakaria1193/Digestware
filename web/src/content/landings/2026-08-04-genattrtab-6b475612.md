This commit refactors `genattrtab` to distribute its generated code across multiple files, similar to `genemit` and `genrecog`. This addresses performance bottlenecks on targets like AArch64 where `insn-attrtab.cc` became a very slow-compiling object due to large switch statements. The changes leverage the existing `--with-insnemit-partitions` mechanism and sort functions by size to improve load balancing, significantly reducing the compile time of the largest attribute object.
