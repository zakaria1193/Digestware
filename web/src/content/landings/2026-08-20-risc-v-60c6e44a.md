The RISC-V core identification table structure has been modified to include space for `MVENDORID`, `MARCHID`, and `MIMPID` registers. Initially, these fields are set to `UNKNOWN_ID` for all cores, preparing the system for later population with specific CPU identification values, which is necessary for features like `-mcpu=native`.
