A test case for OpenMP reverse offloads on NVIDIA GPUs ('libgomp.fortran/reverse-offload-5.f90') was causing deadlocks. To mitigate stalled test suite runs, the timeout for this specific test has been reduced from an unspecified duration to 10 seconds. This addresses a pragmatic issue in the test environment rather than a code defect.
