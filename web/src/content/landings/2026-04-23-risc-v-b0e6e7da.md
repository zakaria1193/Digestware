The pipeline checker in GCC was erroneously reporting 'ghost' reservations as missing, leading to incorrect pipeline configurations. This commit filters out these default reservations (specifically 'ghost') from the RISC-V pipeline description, preventing the checker from flagging them as errors and ensuring correct pipeline construction. This change improves the accuracy of the pipeline checker and simplifies the pipeline definition.
