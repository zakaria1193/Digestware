The RISC-V pipeline checker in GCC now filters out default reservations, which currently consists only of "ghost" reservations. This prevents the pipeline checker from erroneously providing reservations for ghost instructions in some pipelines, improving the accuracy of the checker's output. This change impacts the internal representation of RISC-V pipelines within GCC.
