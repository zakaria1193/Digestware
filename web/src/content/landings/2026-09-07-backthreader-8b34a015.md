primer_expert: The `backthreader::find_taken_edge_*` functions previously constructed
  a new `path_range_query` object for each candidate path. This commit modifies the
  `backthreader` to allocate a single `path_range_query` instance (`m_solver`) and
  reuse it via its `reset_path` method. This significantly reduces overhead from repeated
  `path_oracle` allocation, `ssa_lazy_cache` setup, and heap vector allocations, resulting
  in a 6.7% performance improvement for `back_threader::thread_blocks()` and a 0.08%
  improvement for the entire compile time over the tested corpus.

The backthreader pass has been optimized by reusing a single `path_range_query` object across multiple candidate paths. This eliminates redundant allocations and setup for path analysis, leading to a substantial performance improvement in the `thread_blocks` function and overall compilation time.
