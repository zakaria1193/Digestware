The C++ standard forbids unnamed bit-fields from having cv-qualified types (e.g., `const int : 4;`). This commit enforces this rule by adding a pedwarn (pedantic warning) in `grokbitfield` when such a declaration is encountered. This change aligns GCC's behavior with the standard, improving code correctness and portability.
