Implements CWG issue 2229, which prohibits unnamed bit-fields from being declared with cv-qualified types (i.e., `const` or `volatile`).  The compiler now issues a pedwarn (pedantic warning) when such a declaration is encountered.  This change enforces the C++ standard and improves code portability by preventing undefined behavior. Addresses PR123935.
