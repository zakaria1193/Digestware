This commit introduces support for the gfx1154 hardware target within the GCN (Graphics Core Next) compiler backend. Since gfx1154 is a variant belonging to the gfx11-generic family, basic support could be integrated with minimal effort. This expansion allows GCC to generate code for this specific AMD GPU architecture.
