This commit fixes an issue in the expansion of the `.MUL_OVERFLOW` built-in function when arguments do not conform to standard precision modes. Previously, the code assumed uniform precision, leading to incorrect results for types like `_BitInt`. The fix ensures proper handling of value ranges for these non-standard types, particularly when mixed with signed or unsigned values.
