This commit registers the `va_list` language item within the gccrs compiler. This involves adding a corresponding enum value for `VaListImpl` in the header file and registering it in the compiler's language item management system. This is a necessary step for gccrs to correctly handle C's variadic function arguments (`...`) when interacting with C code or when implementing similar features.
