This commit corrects an issue where GCC's `-Wrange-loop-construct` warning would trigger erroneously for C++ range-based for loops that actually perform a trivial copy. The problem stemmed from the `is_trivially_xible` check incorrectly inferring a non-trivial copy constructor. By adjusting the check to use a `const pair<int> &` reference, GCC now accurately identifies trivial copies, preventing developers from seeing misleading warnings.
