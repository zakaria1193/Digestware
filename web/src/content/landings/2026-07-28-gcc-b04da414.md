GCC's frange class gains a new set_pairs function to install a set of sub-ranges. This function sorts and fuses overlapping sub-ranges, capping the result at MAX_PAIRS. While preliminary statistics suggest two sub-ranges are sufficient for 99.6% of cases, the current implementation caps at one interval. This change is behind a switch, with no user-facing functionality altered yet.
