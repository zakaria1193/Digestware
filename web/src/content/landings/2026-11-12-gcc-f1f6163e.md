This commit renames several functions within GCC's Rust frontend responsible for handling attributes. The renaming convention prepends 'rust_' to functions like `handle_noreturn_attribute`, `handle_malloc_attribute`, and others, improving clarity and namespace management within the compiler's Rust support. This change is purely organizational and does not affect compiler behavior or generated code.
