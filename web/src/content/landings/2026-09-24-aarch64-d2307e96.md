This commit ports the NEON SHA512 intrinsics, associated with the FEAT_SHA3 feature set, to GCC's pragma-based framework for the aarch64 architecture. It adds new function declarations and bases for these cryptographic intrinsics, removes older builtin function definitions, and introduces new assembly tests to confirm their correct implementation. This change standardizes the handling of these SHA512 intrinsics within the GCC compiler.
