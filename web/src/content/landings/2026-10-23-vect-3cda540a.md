This commit removes the `vect_use_loop_latch_condition_p` function from the vectorization pass. The function had become an alias for `LOOP_VINFO_EARLY_BREAKS_VECT_PEELED` but was used inconsistently, causing confusion. By removing it, the code becomes cleaner, and uses of this logic now directly employ `LOOP_VINFO_EARLY_BREAKS_VECT_PEELED`.
