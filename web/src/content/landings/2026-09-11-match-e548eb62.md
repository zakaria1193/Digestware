This commit introduces a new optimization pattern that transforms `x + umax(x, 1)` into `umax(x * 2, 1)`, provided that `x * 2` is known not to overflow. This simplification is particularly useful for the `std::vector::push_back` implementation, as it can trade a post-`umax` addition for a pre-`umax` shift, potentially improving code generation. This pattern is seen as a special case of a more general `x + minmax(a, b)` optimization.
