This commit adds pattern matching support within GCC for unsigned scalar saturating multiplication (SAT_MUL) operations following form 13. This enables the compiler to identify and optimize these specific saturation patterns, which are crucial for performance in contexts like digital signal processing. The change specifically targets scenarios where the multiplication of two `NT` type operands, cast to a wider `WT` type, is then checked for overflow, saturating to all ones if overflow occurs.
