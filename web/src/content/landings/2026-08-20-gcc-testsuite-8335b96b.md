Vector length (zvl) checks for RISC-V's vector extension (RVV) incorrectly used a shared cache property. This could lead to unsupported tests running or supported tests being skipped because a check for one vector length (e.g., VLEN=128) might incorrectly cache results for another (e.g., VLEN=256). This change assigns a unique property to each `check_runtime` call for different zvl configurations, resolving the cache collision.
