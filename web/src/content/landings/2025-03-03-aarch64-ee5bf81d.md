This change disables the outline atomics feature on AArch64 when the `-mcmodel=large` option is used. Outline atomics are not designed to function correctly with the large code model, which affects how code addresses are generated. The compiler will now automatically turn off outline atomics if `-mcmodel=large` is active and issue a warning if the outline atomics option was explicitly enabled by the user. Documentation has been updated to reflect this change.
