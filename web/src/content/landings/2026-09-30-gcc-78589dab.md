A warning was being generated in `rs6000-builtin.cc` when attempting to store the value 2147483648 (0x80000000) into an `int` type. This commit silences the warning by ensuring the code handles this specific large value appropriately within the context of the `cpu_supports_info` function on rs6000 (powerpc) architectures.
