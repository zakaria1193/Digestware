The Rust frontend in GCC has introduced `is_refutable()` methods to its High-Level Intermediate Representation (HIR) pattern nodes. These methods distinguish between patterns whose refutability can be determined syntactically (like wildcards and literals) and those requiring type information. This enhancement is crucial for accurate pattern matching analysis and addresses issue Rust-GCC#2082.
