This commit adjusts the linker test suite for the Alpha architecture by introducing a new `alpha_ld_flags` proc to selectively apply linker options, such as `-Ttext-segment`, only where needed. It also removes a redundant check for big/little endianness within the test harness, simplifying the test execution.
