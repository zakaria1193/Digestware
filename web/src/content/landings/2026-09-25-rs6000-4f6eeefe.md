This commit refactors the `rs6000_analyze_swaps` function to accurately handle `vec_extract` operations. It ensures that special handling for swappable instructions is applied only when webs contain permuting load/store instructions, preventing unnecessary adjustments to extracted lanes and improving code generation for non-permuting loads/stores.
