GCC's Rust front-end (`gccrs`) now recognizes the `unsafe_cell` language item. This change prevents types containing `unsafe_cell` from being marked as constant, aligning with Rust's semantics for such types. This commit includes new functions for checking the presence of `unsafe_cell` and updates the compiler's language item registry, along with a new test case.
