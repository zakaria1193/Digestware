This commit corrects how Alpha unaligned load and store operations compute memory addresses. Previously, these operations directly used constants that were not resolved early enough, causing internal compiler errors when stack frame offsets exceeded 64K. The fix uses `copy_addr_to_reg` to ensure addresses are properly materialized, preventing the issue and making `-fstack-protector` more reliable by avoiding a common trigger for this bug.
