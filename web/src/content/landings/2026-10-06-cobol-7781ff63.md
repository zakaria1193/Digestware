The performance of COBOL `COMPUTE C = A <op> B` statements has been significantly improved, with execution speeds now 2-3 times faster. This optimization detects when a `COMPUTE` operation involves only two operands and can be safely performed using the more efficient underlying `ADD` or `SUBTRACT` logic, rather than the more complex `COMPUTE` machinery. The new `parser_as_two()` function identifies these opportunities.
