This patch enhances the RISC-V compiler's ability to handle complex data movements, particularly 'unsplittable' moves involving arbitrary data modes. It extends the `riscv_subpart` function to manage sub-parts of any mode and uses this capability to move spilled TFmode values in word-sized chunks. This change addresses issues with quadword splits and int128 data types, reducing the occurrence of spills in such scenarios.
