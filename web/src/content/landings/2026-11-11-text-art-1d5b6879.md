This commit addresses compiler warnings related to format strings (`-Wformat-diag`) within the `text-art` module of GCC. The changes involve modifying `pp_printf` formats to avoid leading punctuation where unnecessary and to use plain strings when no actual formatting is required. This ensures cleaner code and suppresses the warnings without impacting functionality.
