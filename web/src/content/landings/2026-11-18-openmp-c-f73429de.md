Several positive test cases related to OpenMP memory allocation handles (omp_cgroup_mem_alloc, omp_pteam_mem_alloc, and omp_thread_mem_alloc) have been disabled. The author previously forgot to disable these tests, which were found to be ill-formed. This commit rectifies the situation by disabling the problematic tests, preventing them from causing issues in the test suite.
