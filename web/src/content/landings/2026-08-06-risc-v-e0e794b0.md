This commit introduces the `riscv_reassociation_width` function and defines `TARGET_SCHED_REASSOCIATION_WIDTH` to allow per-tune reassociation widths for RISC-V targets. Specific tunes like 'generic-ooo' and 'xt-c9501fdvt' receive wider widths (2/2/1 and 3/2/1 respectively) for integer, floating-point, and vector operations, while others default to a width of one. This aims to improve instruction scheduling and performance by allowing more flexible instruction reordering.
