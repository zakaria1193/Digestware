This commit addresses an issue in libgomp's configuration where the Fortran compiler variable (FC) was not correctly set to 'no' when Fortran support was explicitly disabled via '--enable-languages=fortran'. This incorrect setting could confuse the libtool build system. The change ensures that FC is explicitly set to 'no' in this scenario, preventing build issues.
