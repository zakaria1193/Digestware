This change renames the `metafns_called` flag within GCC's C++ compiler to `state_dependent`. This renaming aims to better reflect the flag's purpose, which tracks whether constexpr evaluations are dependent on runtime state or exceptions. The associated comment is also updated to clarify its role concerning exceptions during constexpr evaluation. This is a code organization and clarity improvement.
