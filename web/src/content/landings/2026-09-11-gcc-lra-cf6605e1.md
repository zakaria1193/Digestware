This commit corrects a bug in the late-stage register allocator (LRA) where optional reloads for output operands were not being inherited. This oversight resulted in suboptimal or incorrect code generation for certain operations. The patch introduces a new function, `inheritance_pseudo_p`, and modifies `undo_optional_reloads` to ensure that optional reloads for output operands are preserved if they are inherited, thereby fixing the reported issue and improving code quality.
