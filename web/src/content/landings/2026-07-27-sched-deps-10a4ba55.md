This commit corrects a memory leak in the `sched-deps` component by ensuring that dependency cache bitmaps are properly cleared before the associated cache arrays are freed. Previously, `sched_deps_finish` reset `cache_size` prematurely, causing the cleanup loop to iterate zero times. This resulted in the cache arrays being freed without their bitmap elements being returned to the obstack. The fix moves the `cache_size` reset to after the cleanup loop, guaranteeing that all allocated memory is reclaimed.
