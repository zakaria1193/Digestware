This commit addresses an issue in the RISC-V backend where the generation of machine instruction (MI) thunks could cause an assertion failure when legalizing sibcall addresses. The problem occurred because MI thunks were generating RTL as if register allocation was complete, leading to incorrect pseudo-register creation. The fix ensures the correct register (`STATIC_CHAIN_REGNUM`) is used for post-reload thunk code, resolving PR126449.
