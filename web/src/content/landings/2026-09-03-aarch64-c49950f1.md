This patch refactors the `NEON_FUNCTION` macro in the aarch64 backend to be variadic. This change allows a single macro definition to handle multiple NEON intrinsics that share the same GIMPLE handler class and arguments, up to 10 intrinsics. By reducing redundancy in how intrinsics map to handlers, this improves code maintainability and clarity within the NEON builtins framework.
