Parallel testsuite runs previously truncated summary files before merging them, leading to data loss if the merge failed and leaving the tree with empty summaries. This commit modifies the process to merge summaries only from instances that successfully produced one, clearly warns about missing summaries, and uses temporary files for the merge. A failed merge now correctly reports an error, ensuring the integrity of test results.
