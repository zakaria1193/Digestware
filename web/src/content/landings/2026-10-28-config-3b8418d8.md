This commit synchronizes the ``pkg.m4`` configuration script from GCC, updating the ``PKG_CHECK_MODULES`` macro. It replaces the obsolete ``AC_TRY_LINK`` with the current standard ``AC_LINK_IFELSE`` macro. This change ensures better compatibility and adherence to Autoconf's recommended practices for checking linker capabilities during the build configuration phase.
