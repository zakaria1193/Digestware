The s390 assembler now allows omitting the trailing comma in .insn pseudo-mnemonics when all optional operands are omitted. This simplifies the syntax for mnemonics like `.insn INSN-FMT,OPCODE` instead of requiring `.insn INSN-FMT,OPCODE,`. This change is a prerequisite for making operands fully optional in `.insn rre` and `.insn s` to match specifications.
