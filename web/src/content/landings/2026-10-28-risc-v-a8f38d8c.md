GCC reverts changes that permitted register overlap for the RISC-V vector widening unsigned multiply-add instruction with an undefined scalar source (vwmaccu.vx undef). This aligns with the vector specification's restriction against using a single register for different Effective Element Widths. The fix impacts test cases and instruction definitions.
