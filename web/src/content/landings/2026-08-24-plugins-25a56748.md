This commit fixes an ODR (One Definition Rule) violation that occurred due to a naming conflict with the `callback_info` struct. The struct, defined in `plugin.cc`, had the same name as another struct in `plugin.cc` itself (or possibly a different file included transitively). To resolve this, the `callback_info` struct is now placed within an anonymous namespace, ensuring its uniqueness and preventing ODR issues, particularly when compiling with Link-Time Optimization (LTO).
