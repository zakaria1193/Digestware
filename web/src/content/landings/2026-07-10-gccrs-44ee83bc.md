GCC's Rust frontend has introduced a stub for the `assert_zero_valid` intrinsic. This intrinsic is intended to check if a type can be safely zero-initialized, typically by using layout engine support to detect problematic types like references or `NonNull` types. Currently, the stub always returns the unit type `()`, with full implementation deferred until layout engine capabilities are integrated.
