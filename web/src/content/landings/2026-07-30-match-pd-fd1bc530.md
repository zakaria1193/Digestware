This commit introduces a new optimization rule to GCC's pattern matching system (`match.pd`) for simplifying masked OR comparisons. It addresses the dual of an existing rule: `(X | C) == (Y | C)` now folds to `((X ^ Y) & C) == 0`. This optimization is demonstrated with an example of case-insensitive ASCII comparison, allowing for more efficient code generation on architectures like aarch64.
