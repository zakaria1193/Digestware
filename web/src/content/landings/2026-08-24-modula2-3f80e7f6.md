The Modula-2 compiler build system has removed the `GM2_FOR_TARGET_ESC` macro from `Make-lang.in`. Instead of using this redundant macro, the build now directly quotes the `$(GM2_FOR_TARGET)` variable. This change simplifies the build process for Modula-2 libraries and builtins.
