Several constant macros defining the number of general-purpose, branch, floating-point, and accumulator registers on the Xtensa target have been eliminated. Instead of using these intermediate macros, the register class predicate macros (e.g., `GP_REG_P`) now directly use the `IN_RANGE()` macro with the start and end numbers of the respective hardware registers. This change reduces code redundancy and simplifies the header files.
