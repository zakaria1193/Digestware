This commit enhances the debug string representation of the `forever_stack` in gccrs by including nodes from the extern and language preludes. Previously, the streaming of nodes started from the root and did not traverse these preludes. By incorporating them, the debug output now provides a more comprehensive view of the `forever_stack`'s contents, aiding in debugging complex compiler states.
