This commit addresses a potential issue where the `<string>` header might not be included before `system.h` in various GCC source files. By defining `INCLUDE_STRING` in these files, it ensures that `std::string` can be correctly used, resolving a problem identified in PR 128311. This prevents compilation errors related to string manipulation within these components.
