The `combine` pass in GCC now ignores `DEBUG_INSN`s when checking for intervening volatile memory accesses. Previously, a `DEBUG_INSN` could cause a non-executing memory access to be incorrectly treated as volatile, preventing valid instruction combinations. This change improves optimization opportunities by ensuring only actual volatile accesses are considered.
