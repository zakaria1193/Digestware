This patch enables trial constexpr folding for `INIT_EXPR` in the C++ front-end, mirroring existing support for `TARGET_EXPR`. This change addresses test failures in `is_constant_evaluated3{a,b}.C` by correctly handling local copy-initialization, which is represented as an `INIT_EXPR`.
