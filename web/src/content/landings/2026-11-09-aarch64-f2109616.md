This commit corrects the AArch64 vectorizer's behavior when a specific auto-vectorization mode is forced via a command-line parameter. Previously, even when a mode was explicitly set (e.g., `VNx4QI`), the vectorizer would still attempt an automatic mode selection first. If the auto-selected mode succeeded, it could prevent the desired forced mode from being used. The change ensures that when `aarch64_force_autovec_mode` is set, the candidate list is cleared and repopulated only with the forced mode, guaranteeing its selection.
