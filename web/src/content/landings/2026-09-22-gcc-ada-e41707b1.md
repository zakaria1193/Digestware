This commit resolves a regression in the Ada compiler that caused run-time crashes when dealing with imported C arrays that were declared without a size. The compiler previously added an indirect indirection for large objects intended for interfaces, which led to issues. The fix prevents this indirection for exported or imported objects, ensuring the compiler or linker will issue errors instead of crashing.
