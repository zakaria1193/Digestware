This commit refines a diagnostic message generated by the GCN (Graphics Core Next) backend. Previously, the message suggested using `-foffload-options=-mxnack=any` without quoting the option. The change adds quotes around the option, making it clearer which specific flag the user should employ, particularly when encountering issues related to offloading or specific hardware features.
