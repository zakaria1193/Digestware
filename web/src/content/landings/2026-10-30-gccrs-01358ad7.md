The gccrs compiler no longer crashes when encountering error types during type checking. Previously, failed expressions would result in null lookups, leading to crashes. This change ensures that error types are preserved in the context. Additionally, operators and array literals now properly bail out when an operand has already errored, preventing type stacking issues. Constants also retain their declared type if their initializer fails.
