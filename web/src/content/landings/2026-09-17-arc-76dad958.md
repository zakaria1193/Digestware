This commit addresses an issue in the ARC target architecture where several instructions (doloop_end, loop_end, dbnz, flag, kflag) incorrectly modified condition codes without declaring this side effect. Due to a recent change moving AArch64 CC fusion into late-combine, GCC now keeps condition codes live across these instructions, leading to wrong code generation. By adding the necessary CC clobber declarations to the instruction patterns, GCC correctly accounts for these side effects, fixing bugs like PR68185 for ARC60x and ARC700.
