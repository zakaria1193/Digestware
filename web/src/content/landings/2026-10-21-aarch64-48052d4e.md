The AArch64 backend's if-conversion profitability check previously skipped cost analysis too broadly for sequences containing increments, often leading to unnecessary conversion of complex code blocks into conditional selects. This patch refines the check to only skip the cost analysis when the sequence consists of a single increment and a conditional select that directly uses it. This ensures that longer or more complex sequences with increments are subjected to proper cost evaluation, preventing suboptimal code generation and improving performance in certain loop scenarios.
