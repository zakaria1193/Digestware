Gfortran previously ignored UTF-8 byte order marks (BOMs) but only if they appeared on the very first line of a source file. This commit fixes that behavior by ensuring the temporary line buffer is correctly extended when a BOM is present, preventing potential Valgrind errors. A new test case verifies this fix.
