This commit introduces support for new AVX10/v2 instructions related to sub-byte element extraction and symmetric-signed saturation narrowing. It adds new intrinsic functions for various vector sizes (128, 256, and 512 bits) to handle these operations, along with necessary definitions in i386-builtin-types.def, i386-builtin.def, and i386-expand.cc. New patterns in sse.md facilitate the implementation of these instructions.
