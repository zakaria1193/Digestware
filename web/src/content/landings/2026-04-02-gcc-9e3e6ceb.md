This commit fixes an incorrect length attribute for the `bswaphi2` pattern, which implements the `__builtin_bswap16` intrinsic, on the MicroBlaze architecture. The pattern generates 2 assembly instructions with a length of 8 bytes, but the length attribute was missing, causing the compiler to assume a default length of 8 bytes. This allowed the pattern to be scheduled into a delay slot of a branch instruction where only a 4-byte instruction could be placed. The patch adds `(set_attr length 8)` to the pattern.
