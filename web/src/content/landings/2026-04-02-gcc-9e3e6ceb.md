This commit fixes an incorrect length attribute for the `bswaphi2` pattern, which implements `__builtin_bswap16`, on the MicroBlaze architecture. The incorrect length could cause the instruction to be scheduled into a delay slot of a branch instruction where it doesn't fit, leading to incorrect execution. The fix sets the length attribute to 8 bytes.
