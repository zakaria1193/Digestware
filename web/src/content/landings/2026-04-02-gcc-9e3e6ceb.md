The `bswaphi` pattern, which generates code for `__builtin_bswap16`, was missing the `length` attribute, causing its length to be assumed as 8 bytes. This could lead to the pattern being incorrectly scheduled into a delay slot of a branch instruction, where only 4-byte instructions are allowed. This commit adds the `(set_attr length 8)` to the `bswaphi2` pattern in `microblaze.md` to correct this issue.
