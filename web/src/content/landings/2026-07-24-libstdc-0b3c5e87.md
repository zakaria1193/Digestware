GCC's libstdc++ has corrected the implementation of the uniqueness check for `std::ranges::stride::mapping` to align with the C++20 standard (LWG4606). The previous implementation incorrectly rejected some valid stride combinations. The fix accurately calculates the required span size for new mappings derived from existing ones, ensuring that the stride of a newly added dimension is sufficiently large. It also handles dimensions with an extent of one and zero strides more correctly.
