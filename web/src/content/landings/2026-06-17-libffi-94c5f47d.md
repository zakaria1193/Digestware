This commit updates libffi's AArch64 assembly code to use modern AArch64 feature build attributes for indicating support for Branch Target Identification (BTI) and Pointer Authentication Codes (PAC). When the `__ARM_BUILDATTR64_FV` macro is defined, signifying assembler support, these attributes are emitted, replacing the older GNU property notes. This change improves the precision and standardization of how binaries communicate their security capabilities to the runtime environment, ensuring better compatibility with contemporary AArch64 security features.
