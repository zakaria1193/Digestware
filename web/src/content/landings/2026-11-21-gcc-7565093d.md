This commit fixes a critical bug in GCC's expression equivalence checking (`exp_equiv_p`), which incorrectly treated `SUBREG` expressions with different promotion states as equivalent. This issue, latent for decades and exposed by recent RISC-V backend changes, could lead to incorrect code generation. Specifically, it caused Common Subexpression Elimination (CSE) and Global CSE (GCSE) to remove valid code, resulting in combine passes incorrectly removing zero-extension instructions, ultimately producing wrong code.
