The GCC documentation for machine descriptions has been updated to clarify that string comparison patterns like `cmpstrn` and `cmpstr` can read more than one byte at a time. This relaxation applies when a target architecture can guarantee that such wider reads will not cause faults, for instance, with aligned memory blocks. This aligns the documentation with the `memchr` pattern's existing condition.
