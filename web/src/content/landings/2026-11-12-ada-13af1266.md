This commit fixes a bug in the Ada front-end where the dynamic accessibility check for function calls or allocators in Ada 95 mode was failing incorrectly when the result was a named access type. The fix ensures that named access types are handled consistently with other language versions, restoring the correct behavior for dynamic accessibility checks.
