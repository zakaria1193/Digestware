This commit modifies the `gimple_can_merge_blocks_p` function to ignore debug statements when checking for compiler-inserted nops that mark coverage-suppression boundaries. Previously, a trailing `DEBUG_BEGIN_STMT` could hide these nops when debugging (`-g`) was enabled, incorrectly allowing blocks to merge. This change prevents debug markers from altering the Gcov Control Flow Graph (CFG) checksum, ensuring it accurately reflects the generated code even with debugging information.
