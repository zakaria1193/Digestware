This commit removes the `new_bb_cbk` callback from the `make_forwarder_block` function within `cfghooks.cc`. This callback has been unused for approximately 19 years, since r0-78960-g89f8f30f356532. Removing it simplifies the code and paves the way for future changes to the `make_forwarder_block` function.
