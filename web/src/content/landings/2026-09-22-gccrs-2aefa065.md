This commit corrects the naming of atomic store and load intrinsics within the gccrs compiler to align with older Rust versions (specifically 1.49.0). Previously, these intrinsics were using naming conventions from Rust 1.64.0, which could lead to compatibility issues. The patch adds back the required 1.49.0 namings for these critical intrinsics.
