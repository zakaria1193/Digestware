Floating-point rounding modes on Alpha are controlled by instructions, which previously defaulted to static rounding. This commit modifies the default rounding mode to dynamic when -frounding-math is enabled and no specific rounding mode is provided. This ensures that runtime rounding mode changes are respected, fixing issues in several floating-point test cases.
