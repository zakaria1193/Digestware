The C++ standard library (libstdc++) now supports Single Instruction, Multiple Data (SIMD) vectorization for `std::complex` types. This enables the compiler to perform operations on complex numbers using SIMD instructions, potentially improving performance. While bitwise operations are fully supported and trivially vectorized, division is not yet implemented due to an `static_assert`. Absolute value operations (`_M_abs`) also require additional math functions (sqrt, hypot) not yet available for SIMD complex types.
