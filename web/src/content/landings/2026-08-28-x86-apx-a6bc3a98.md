This commit integrates the handling of the EVEX.V4 bit, which relates to the register specifier, directly into the `build_evex_prefix()` function. Previously, this might have been handled by a more expensive `build_apx_evex_prefix()` call. By performing this directly, the code becomes simpler and potentially more efficient, as it avoids unnecessary steps in generating the EVEX prefix.
