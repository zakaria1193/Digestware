GCC Fortran encountered an Internal Compiler Error (ICE) when allocating a CLASS component of a structure constructor from a non-polymorphic derived-type value. The problem occurred because the allocation function was incorrectly passed the type's own symbol instead of the correct type node for sizing. This patch ensures that `gfc_typenode_for_spec` is used for derived types as well, resolving the ICE and enabling correct sizing.
