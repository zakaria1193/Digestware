This extensive commit adds support for two 16-bit floating-point formats, `_Float16` and `__bf16`, to GCC for little-endian 64-bit PowerPC architectures. It introduces new compiler flags (`-mfloat16`, `-mno-float16`) and configuration options to control this support, enabling it by default on relevant systems. The implementation details how these 16-bit values are passed and returned in registers and memory, leveraging specific PowerPC instructions.
