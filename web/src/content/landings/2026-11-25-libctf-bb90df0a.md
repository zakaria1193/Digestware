This commit hardens libctf against malformed type records that could lead to heap out-of-bounds reads and writes. A crafted FUNCTION type record with an excessively large vlen could cause `ctf_flip` to read past the end of its buffer. Similar over-reads occurred during type counting and size calculation. The changes introduce bounds checks for record headers, extensions, and variable-length data in various functions to prevent these vulnerabilities. Malformed dictionaries are now rejected with ECTF_CORRUPT.
