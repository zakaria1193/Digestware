This commit relaxes an ordering barrier in GCC's pattern matching system, specifically for pairs of GIMPLE and GENERIC code forms. Previously, the system prevented later patterns from merging with earlier ones if a specific blocking node existed between them. This was often redundant when matching GIMPLE and GENERIC forms derived from the same source construct, as they cannot match the same input simultaneously. The change makes the matching more efficient, reducing the size of generated matchers.
