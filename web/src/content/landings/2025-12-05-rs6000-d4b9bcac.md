This change improves code generation for the __builtin_parityll intrinsic on PowerPC targets. Previously, even when the popcntd instruction was available, the compiler emitted a less efficient sequence. Now, it utilizes popcntd directly when supported, reducing instruction latency and improving performance for parity checks on 64-bit integers.
