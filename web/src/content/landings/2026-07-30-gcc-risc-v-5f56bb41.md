This commit introduces a comprehensive set of test cases for the RISC-V Vector extension's `vwadd.vv` instruction, focusing on scenarios involving register group overlap. The tests cover signed integer types (8-bit, 16-bit, 32-bit) and various vector mask/multiplier configurations (m1, m2, m4, mf2, mf4, mf8), ensuring correct behavior when destination and source registers overlap.
