This commit modifies the `TYPE_OVERFLOW_SANITIZED` predicate to accept integral vector types, allowing Undefined Behavior Sanitizer (UBSan) to instrument signed integral vector arithmetic. Previously, `TYPE_OVERFLOW_SANITIZED` only accepted scalar types, preventing UBSan from detecting overflows in vector operations. This change ensures that diagnostics are generated for vector operations that can overflow, as demonstrated in a test case involving vector negation.
