This commit addresses issues with long branch sequences for Andes RISC-V extensions, which introduce new conditional branch instructions. The problem lay in inverting the condition for long branches: when a short direct branch wouldn't fit, the compiler needed to branch around a long unconditional branch. The inversion logic for the condition was missing, causing incorrect branching behavior. The fix ensures the correct condition is used for long branches in these Andes extensions.
