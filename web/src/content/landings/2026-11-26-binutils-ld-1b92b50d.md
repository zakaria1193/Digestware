This change updates the RISC-V linker test suite to correctly select the emulation for Zcmt tests. Previously, riscv32-elf systems defaulted to ELF32, causing the linker to reject RV64 objects before tests could proceed. The update enforces LP64 for most RV64 tests and adjusts byte-order handling, while also refining how sparse jump tables are inspected using objdump -z to account for endianness differences.
