This commit updates the aarch64 backend to use standardized hint values for atomic fetch-and-modify operations, aligning with recent changes in the ARM Architecture Procedure Call Standard (ACPS) / Architecture Configuration Language Element (ACLE). The `require_const_argument` for `aarch64_expand_atomic_hints_builtins_fetch` and the hint values in `atomics.md` have been adjusted to match the current ACLE state.
