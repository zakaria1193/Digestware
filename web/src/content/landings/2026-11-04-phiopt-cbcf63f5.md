This commit fixes a bug in the `phiopt` optimization pass where the removal of middle blocks in diamond or triangle control flow structures could lead to incorrect debugger output. When blocks were deleted, their associated debug binds were also removed, causing variables to retain outdated values on certain code paths. The fix ensures that debug binds of removed blocks are properly reset before the conditional logic, similar to how CFG cleanup handles forwarder blocks, thus maintaining accurate variable states for debuggers.
