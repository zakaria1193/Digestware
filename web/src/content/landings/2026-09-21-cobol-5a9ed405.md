This commit fixes a flaw in the `CBL_GET_PROGRAM_INFO` function 2 implementation within `libgcobol`. The previous logic incorrectly assumed function 2 only returned status and program name for the handle it was associated with. The documentation clarifies that function 2 must return information from the caller program and update the handle. The corrected logic now adheres to this, enabling correct retrieval of call stack information across program calls, ensuring that the handle is updated with information from the calling program in each step.
