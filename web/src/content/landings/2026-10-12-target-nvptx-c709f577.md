The nvptx backend for GCC now correctly handles vector modes when checking for defined values at zero in `CLZ_DEFINED_VALUE_AT_ZERO` and `CTZ_DEFINED_VALUE_AT_ZERO` macros. This ensures consistent behavior with other backends that were updated to look through vector modes for these checks.

This change improves the correctness and portability of vector operations on the NVPTX architecture by ensuring that vector data types are properly interpreted in these specific macro contexts.
