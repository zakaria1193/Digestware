This commit introduces support for the C++26 P3861R1 proposal, which aims for a more pragmatic approach to standard structural types. A new GCC attribute, `gnu::structural_type`, is added to override the requirement that all base classes and members of a structural type must be public. This attribute is then applied in libstdc++ to class templates like `string_view`, `span`, and `variant` that are intended to behave as structural types in C++26, ensuring their compatibility with the evolving standard.
