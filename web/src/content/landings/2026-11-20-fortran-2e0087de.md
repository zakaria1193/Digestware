A fix in the Fortran compiler addresses an invalid memory reference issue related to class PDT (parameterized derived type) intent out. The change ensures that a check for a NULL right-hand side is applied to class PDTs, similar to unlimited polymorphic expressions, thereby preventing potential crashes or incorrect behavior during assignments.
