The Darwin backend for GCC now makes all string constant labels linker-visible, a change that aligns its behavior with the aarch64 strategy and aims for greater consistency. While this may result in a slight efficiency loss for x86_64, it addresses issues related to the linker visibility of string constants, as reported in PR126723. This ensures that string literals are reliably available to the linker.
