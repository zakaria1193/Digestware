GCC's intermediate representation (RTL) optimizer can now simplify vector comparisons more effectively. The optimization `(not (eq x y))` is now correctly transformed into `(ne x y)`, even for vector types, including floating-point vectors.
This change enhances the optimizer's ability to recognize equivalent boolean logic, leading to more compact and potentially faster machine code. It includes modifications to both the middle-end RTL optimizer and the i386 backend to handle these vector operations.
