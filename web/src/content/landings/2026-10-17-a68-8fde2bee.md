The Algol68 compiler has been updated to define fixed-size modes for standard data types. This change standardizes how these types are represented and handled, particularly in the context of real number operations. The code dispatching for built-in functions like `a68_real_pow`, `a68_real_round`, and `a68_real_entier` now relies on type equality rather than just precision, leading to more robust and accurate behavior.
