This commit optimizes the `dominated_by_p_w_unex` function, which is frequently used during value elimination in the SCCVN pass. The previous implementation relied on a slow, heuristic walk across the CFG. The new approach dynamically tracks immediate dominators of the executable CFG using an array indexed by RPO number, updated via a Cooper-Harvey-Kennedy nearest-common-ancestor intersection. This significantly speeds up the dominance queries from an arbitrary limit to O(depth of the dominator tree) while removing unsafe handling of back-edges.
