primer_glossary:
- term: noexcept specifier
  definition: A specifier that indicates whether a function or, in this case, a compound
    requirement within a template, can throw exceptions. 'noexcept(true)' means it
    cannot throw, 'noexcept(false)' means it can, and 'noexcept(expression)' means
    its exception-throwing behavior depends on the evaluation of the expression.
- term: compound requirement
  definition: A type constraint in C++ templates that checks if a type satisfies certain
    properties, such as having specific member functions or types. It's part of the
    Concepts TS and later C++ standards.

    between functions with the same name but different signatures, especially in C++'s
    name-mangling scheme.

GCC now supports C++29's P3822R2 paper, enabling conditional noexcept specifiers within compound requirements. This allows more precise control over exception specifications in template metaprogramming. The implementation aligns with Clang's mangling scheme for these new specifiers.
