This commit fixes an incorrect cost estimation for the Xtensa `CONST.S` machine instruction within the `xtensa_is_insn_L32R_p()` function. Previously, `CONST.S` was mistakenly assigned the same cost as the `L32R` instruction, which is used for literal pool references. This led to incorrect instruction selection. The fix ensures that `CONST.S` (and potentially `CONST.D` in the future) is correctly distinguished from `L32R` by modifying the function to return false when these constant instructions are encountered.
