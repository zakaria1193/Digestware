A change in GCC's Fortran compiler (since r17-6306) caused the finalization wrapper of a Procedure-Derived Type (PDT) to free its LEN-dependent components prematurely. This led to use-after-free errors when these components were still in use, such as with INTENT(OUT) actual arguments. The fix ensures these components are freed only during actual deallocation, mirroring the handling of coarray components.
