This commit addresses an out-of-SSA bug occurring when the `forwprop` pass encounters vector `CONSTRUCTOR` expressions involving SSA names from abnormal PHI nodes. Previously, if a uniform vector element was an SSA name from an abnormal PHI and redefined before the `CONSTRUCTOR`, the live ranges of the two SSA versions would overlap, causing the out-of-SSA transformation to fail. The fix prevents the `simplify_vector_constructor` from 'splatting' such SSA names, thus resolving the live-range conflict and enabling optimizations like SLP vectorization on affected platforms.
