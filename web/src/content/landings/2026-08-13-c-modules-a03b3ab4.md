An internal compiler error (ICE) in GCC's C++ modules feature has been fixed. The issue occurred when a redeclaration of a variable had language-specific data allocated, but the original declaration did not. This change ensures that language-specific data is correctly allocated using `retrofit_lang_decl` for such cases, resolving the ICE and improving module handling for inline definitions.
