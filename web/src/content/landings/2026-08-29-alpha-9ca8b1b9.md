The Alpha architecture's frame structure does not support accessing caller frames directly. This change modifies `FRAME_ADDR_RTX` to return an error for nonzero counts passed to `__builtin_frame_address`. This aligns with the architecture's limitations, preventing the emission of incorrect text addresses and improving diagnostic messages.
