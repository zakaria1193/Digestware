This commit adds template instantiations for the `get_named_test_scalar` method within the `scalar_manager` class in GCC's static analyzer. Specifically, instantiations for `integer`, `concrete_bit_offset`, and `concrete_byte_offset` types are added. This change addresses a build issue (PR analyzer/128854) by ensuring that the required template specializations are available for the analyzer's symbolic scalar management.
