The RISC-V Vector extension's vfwsub.wv instruction now supports register overlap, similar to vfwadd.wv. This change allows the source operand vs1 to overlap with the destination register vd under specific conditions, while still preventing overlap with vs2's register group. This modification enhances the compiler's ability to generate efficient code by providing more flexibility in register allocation.
