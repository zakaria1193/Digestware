This commit modifies the add_reg_note function to accept an rtx_insn* argument. This change is applied across various RTL analysis and code generation functions, ensuring that instruction information is correctly passed and utilized. Specific instances in rl78 and s390 backends now correctly pass the instruction pointer, improving the accuracy of note-related operations.
