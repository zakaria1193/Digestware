GCC now utilizes the RISC-V Zvbb extension to implement byte swap (bswap) operations more efficiently. The `shuffle_bswap_pattern` has been extended to use the `vrev8` instruction, allowing it to swap bytes within larger data types (SImode and DImode) that were previously inefficiently handled. This change improves performance for bswap operations when the Zvbb extension is available.
