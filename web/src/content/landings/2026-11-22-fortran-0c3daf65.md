This change corrects how the Fortran compiler handles the `LEN` of character array components within Parameterized Derived Types (PDTs). The `gfc_simplify_len` function previously mishandled references to length parameters for such components, dropping array references and incorrect KIND values, leading to ICEs and incorrect type assignments. The fix preserves base object array references, resolves new references to scalar type parameter inquiries, and ensures correct KIND conversion, while also fixing a double-free bug in `reset_array_ref_to_scalar`.
