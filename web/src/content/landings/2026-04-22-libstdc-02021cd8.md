This commit adds `_GLIBCXX_RESOLVE_LIB_DEFECTS` comments to several libstdc++ headers, marking the resolution of Library Working Group (LWG) issues that were already implemented but not explicitly marked as resolved. These issues affect pre-C++26 features and were resolved during the 2026 Croydon meeting. The added comments improve code clarity and maintainability by explicitly linking the code to the corresponding LWG issue.
