The libstdc++ now explicitly marks several already-implemented library defect fixes with ``_GLIBCXX_RESOLVE_LIB_DEFECTS``. This commit covers issues affecting pre-C++26 features that were resolved during the 2026 Croydon meeting. This improves code maintainability by clarifying which parts of the library address specific known issues.
