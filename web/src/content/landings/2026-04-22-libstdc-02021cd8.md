The C++ standard library now includes `_GLIBCXX_RESOLVE_LIB_DEFECTS` comments for issues that were already implemented but lacked explicit references. This change covers issues affecting pre-C++26 features resolved during the 2026 Croydon meeting. Specific comments have been added to `include/bits/chrono_io.h`, `include/bits/print.h`, `include/std/condition_variable`, `include/std/format`, `include/std/mdspan`, and `include/std/optional`.
