This commit addresses linking failures on FreeBSD for Modula-2 programs that use specific math intrinsics like `csin[l]`, `ccos[l]`, and `ctan[l]`. It introduces a new tool, `mktargetsrc`, which generates target-specific Modula-2 libraries, pruning missing intrinsics at compile time rather than failing at link time. Additionally, a new `-fdump-builtins` flag is added to aid `mktargetsrc` in processing built-in functions. The changes improve the build process and error handling for Modula-2 development on various platforms.
