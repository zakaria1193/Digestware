The GCC compiler for AArch64 has gained support for exposing AdvSIMD integer multiply-add operations (FMA) through its optab system. Previously, AArch64 lacked specific optabs for integer FMA, causing sequences like `e - ey * 3` to be expanded into separate multiply and add instructions, preventing recognition of fused multiply-subtract operations. This change introduces new optabs and expands existing ones to leverage hardware FMA capabilities.

This enhancement allows the tree math pass to retain multiply-add operations, leading to more efficient code generation. For example, a specific `cbrtf` implementation in glibc sees a 1.69% reduction in instructions. Test cases cover various scenarios including signed/unsigned modes, constant/variable factors, and wraparound values.
