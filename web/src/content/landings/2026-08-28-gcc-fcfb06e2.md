This commit defines `_DARWIN_C_SOURCE` in several Darwin testsuite files. This is necessary because glibc and Darwin's libc have different interpretations of `_POSIX_SOURCE`, and defining `_DARWIN_C_SOURCE` allows access to functions outside the strict POSIX set on Darwin systems.
