This change integrates the handling of EVEX.R4 and EVEX.X4 bits directly into the `build_evex_prefix()` function. Previously, these might have been deferred to a more complex function, leading to unnecessary bit setting and clearing. By handling them directly, the code becomes more efficient and simpler, reducing the overhead associated with prefix generation.
