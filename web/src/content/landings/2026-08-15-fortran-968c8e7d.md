This commit fixes an internal compiler error (ICE) in the Fortran front-end related to the `IS_CONTIGUOUS` intrinsic function. Previously, the code incorrectly used a pointer to a descriptor directly, bypassing the necessary dereferencing. This led to the descriptor accessors receiving a pointer instead of a descriptor, causing the ICE. The fix dereferences the pointer to ensure the accessors receive the correct type, resolving the error and includes a new test case.
