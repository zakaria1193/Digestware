The GCC installation documentation (`install.texi`) has been updated to remove a note mentioning support for Windows CE targets on SuperH and MIPS architectures. This note was inaccurate, as the GCC configuration scripts no longer support these specific Windows CE targets. The removal clarifies the documentation and reflects the current state of target support.
