This commit modifies the jump function computation within the IPA pass to correctly handle internal callback edges. Previously, the logic relied on callback-carrying edges, which internal callbacks lack. The changes remap arguments for these edges and add an early return in `get_dynamic_type` to prevent issues with internal calls, ensuring IPA analysis can proceed for assume bodies.
