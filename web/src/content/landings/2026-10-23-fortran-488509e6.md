This commit fixes an invalid read vulnerability in the Fortran compiler's module loading mechanism. The issue occurred when processing `use, only:` statements with module names prefixed by double underscores ('__'). The compiler's `load_needed` function would incorrectly attempt to scan an empty name in such cases, leading to an invalid read. The fix prevents this scanning of empty names, ensuring the compiler handles these constructs safely.
