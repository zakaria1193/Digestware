This commit disables a specific folding optimization in `match.pd` when dealing with C++ frontend `COND_EXPR`s that involve bit-fields. The C++ frontend can generate `COND_EXPR`s where operands are bit-fields, which are often unpromoted. An optimization pass, `cp_fully_fold`, was incorrectly folding these expressions before type promotion occurred, leading to an invalid intermediate representation. This invalid state would later cause a compiler Internal Compiler Error (ICE) during type verification. The fix modifies `cp_fold` to promote bit-field operands within `COND_EXPR` before folding, ensuring the expression is valid before optimization passes encounter it.
