This commit implements the `no_split_stack` attribute for the D language frontend in GCC. This attribute prevents the compiler from splitting the stack for a function, which can be necessary for certain code that relies on continuous stack frames. The implementation includes a handler for `@gcc.attributes.attribute("no_split_stack")` and the UDA `@gcc.attributes.noSplitStack`. This enhancement provides compatibility with the LDC compiler.
