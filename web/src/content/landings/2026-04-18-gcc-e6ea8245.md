This commit adds support for the `@gcc.attributes.attribute("no_split_stack")` and `@gcc.attributes.noSplitStack` attributes in the D frontend. This allows D code to prevent stack splitting, which is a feature that can improve performance in some cases. This addition enhances compatibility with LDC.
