This commit adds support for the `@gcc.attributes.attribute("no_split_stack")` attribute and the `@gcc.attributes.noSplitStack` UDA in the D frontend. This functionality is added for compatibility with LDC.  The `no_split_stack` attribute prevents the compiler from splitting the stack, which can be necessary for certain code that relies on contiguous stack frames.
