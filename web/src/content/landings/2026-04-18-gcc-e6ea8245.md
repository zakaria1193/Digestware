The commit implements the `@gcc.attributes.attribute("no_split_stack")` and `@gcc.attributes.noSplitStack` attributes for the D language in GCC. This addition provides compatibility with the LDC compiler, which utilizes these attributes to control stack splitting. The implementation includes a new attribute handler and a new test case.
