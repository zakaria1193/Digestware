Manual drop emission for explicit return statements in the GCC Rust compiler has been removed. Instead, explicit returns are now handled using a try-finally cleanup mechanism, simplifying the code generation for these cases. This change removes related helper functions and modifies the expression compilation to store return statements for later processing.
