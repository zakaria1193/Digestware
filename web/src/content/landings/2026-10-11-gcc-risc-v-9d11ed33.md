This commit addresses RISC-V compiler test failures related to pack instructions, which arose after recent changes to how the compiler handles operations where inputs have no overlapping set bits (any-or-plus, or AOP). The compiler now uses a code iterator and pattern matching to correctly identify and cost these operations, ensuring that explicit OR matching RTL and prior costing mechanisms are updated for the new forms. This resolves all pack instruction failures in default test runs for RISC-V.
