The genextract tool is responsible for extracting operands from instruction patterns. Previously, it used a large switch statement where each case corresponded to an instruction, leading to excessive labels and large generated code. This commit replaces the switch statement with a data-driven approach. It uses tables to store extraction methods, operand counts, and path strings, allowing `insn_extract` to walk these paths dynamically. This change significantly reduces the size of the generated code, particularly on architectures like AArch64 and RISC-V.
