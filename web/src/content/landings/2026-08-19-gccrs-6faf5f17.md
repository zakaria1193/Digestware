This commit introduces basic Application Binary Interface (ABI) support in gccrs for the `unadjusted` and `platform-intrinsic` variants. The changes involve updating the `ABI` utility class in `rust-abi.h` and `rust-abi.cc` to recognize and handle these ABI specifiers, which are used to control how types are passed and laid out.
