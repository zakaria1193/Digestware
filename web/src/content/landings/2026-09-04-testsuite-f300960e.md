A test case in the GCC testsuite (`vect/pr36648.cc`) has been modified to ensure it does not execute when a constructor is implicitly constexpr. This is because such constructors do not generate runtime code that can be vectorized. By adding a requirement to exclude cases with implicit constexpr constructors, the test suite maintains accuracy and avoids unnecessary checks.
