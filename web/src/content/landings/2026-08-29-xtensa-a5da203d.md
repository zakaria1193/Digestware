This commit enables the Xtensa `CONST.S` instruction for loading specific single-precision floating-point constants (+0.f, 1.f, 2.f, 0.5f) into floating-point registers. It also allows the Reload/LRA pass to handle assignments of +0.f to general-purpose registers using the `MOVI` instruction. This optimization is available when floating-point instructions for division, reciprocal, or square root are configured, as `CONST.S` is then enabled in the Xtensa ISA.
