The `libcpp` initialization of its vectorized lexer (`init_vectorized_lexer`) incorrectly only checked for `HWCAP2_SVE2`. This caused issues on some virtual machines that advertise SVE2 support while disabling SVE, a nonsensical configuration that nonetheless occurs. Such systems would crash with an 'Illegal instruction' error upon lexing any input. This commit modifies the check to require both `HWCAP_SVE` and `HWCAP2_SVE2`, ensuring the vectorized lexer is only used when SVE is properly available, thereby fixing bootstrap issues on these misconfigured environments.
