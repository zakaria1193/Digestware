The PDB stream directory's block map was limited to 256 block numbers with a 1024-byte block size, restricting PDB files to about 64MB. This change increases the block size to 4096 bytes, matching MSVC's standard and raising the PDB file size limit to approximately 4GB. Larger files were previously truncated and rejected by tools like llvm-pdbutil.
