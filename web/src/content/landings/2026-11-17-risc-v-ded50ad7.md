This commit corrects an issue with RISC-V vector iterators related to Zvfh modes. Specifically, the VWEXTF and VLS SF modes were incorrectly missing the TARGET_ZVFH flag. This oversight meant these modes were not properly recognized when Zvfh was enabled. The fix involves adding the TARGET_ZVFH flag to the affected iterator definitions, ensuring correct compilation for programs utilizing these vector operations.
