This commit enhances the RISC-V support in `objdump` by enabling it to decode Zcmt table-jump (JVT) entries. It introduces new fields in the disassembler's private data structure, functions for handling JVT addresses, and updates the instruction printing logic to annotate JVT targets. This allows for more accurate disassembly of code using the Zcmt extension.
