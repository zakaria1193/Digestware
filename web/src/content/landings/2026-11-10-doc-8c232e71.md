The GCC manual's documentation for the `GCC_COLORS` environment variable contained an error in its listed default value. A colon was missing between the `invalid=` and `highlight-a=` capabilities, causing them to appear as a single malformed entry due to line continuation. This commit corrects the documentation by adding the necessary colon, ensuring the example default value is accurate.
