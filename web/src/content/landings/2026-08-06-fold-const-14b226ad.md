This commit fixes an issue in GCC's selftests related to the construction of `vec_perm_indices`. Two tests involving mixed VLA (Variable Length Array) and non-VLA types were incorrectly specifying the number of elements for `vec_perm_indices`, leading to potential errors. The fix ensures the correct element count is provided for these tests.
