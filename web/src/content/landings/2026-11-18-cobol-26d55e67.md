The COBOL compiler's UNSTRING statement handling has been corrected to properly select the longest delimiter when multiple delimiters match the input text. Previously, it could incorrectly choose the last matching delimiter in the list, leading to parsing errors. This fix ensures that UNSTRING behaves according to the COBOL standard by prioritizing the longest match.
