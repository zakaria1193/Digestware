This commit removes a redundant call to `Milliseconds_To_Timeval` in the Ada runtime library. Since `Timeval` is a public type in `System.C_Time`, it can be directly initialized using an aggregate. The removal simplifies the code and avoids an unnecessary function invocation, making the time handling more efficient.
