This commit refactors code in `match.pd` to use `wi::to_wide` more extensively, improving consistency and potentially performance. Additionally, it replaces bitwise AND operations with the modulo operator (`% 4`) for checking multiples of four, making the intent of the code clearer. These changes were verified after a bootstrap and test on x86_64-linux-gnu.
