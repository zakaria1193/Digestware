This commit updates the algol68 front-end to use TYPE_CANONICAL for type comparisons during assignment operations. Previously, it incorrectly used SET_TYPE_STRUCTURAL_EQUALITY. This change is necessary because the compiler now emits typedefs, and TYPE_CANONICAL correctly resolves type equivalence, preventing incorrect assignments and addressing PR algol68/127977.
