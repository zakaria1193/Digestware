This patch introduces new accessor functions in GCC for specialized SSA name range types, namely `ssa_name_irange_info`, `ssa_name_prange_info`, and `ssa_name_frange_info`. These accessors provide convenient shortcuts for retrieving pointers to specific range storage types. If the range is not of the expected type, the accessors return NULL, preventing potential errors and simplifying the code that utilizes these range informations.
