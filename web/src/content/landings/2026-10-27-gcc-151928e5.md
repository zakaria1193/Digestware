This commit removes the `HAVE_LONG_LONG` macro from GCC's configuration, as the project now mandates C++14, a standard that guarantees the presence of the `long long` type. This simplifies configuration and internal headers by removing a check that is no longer relevant, ensuring consistency with the project's modern C++ requirements.
