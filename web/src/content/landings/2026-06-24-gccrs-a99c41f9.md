This commit ensures that destructors are correctly emitted for all active block scopes before an explicit return statement is executed in the GCC Rust compiler. If the explicit return has a value, it is saved before drops are performed. For unit returns with an expression, that expression is evaluated and its result handled before drops and the final unit return.
