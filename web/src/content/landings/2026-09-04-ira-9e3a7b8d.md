The Integrated Register Allocator (IRA) component's decision to use the simple LRA (Local Register Allocation) now correctly excludes debug instructions. Previously, debug instructions consumed UIDs, potentially causing the threshold for simple LRA to be crossed and leading to different code generation. This change ensures the decision is based solely on the count of non-debug instructions.
