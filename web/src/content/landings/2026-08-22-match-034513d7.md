This commit removes redundant checks for `INTEGER_CST` in several widening multiply patterns within `match.pd`. These checks were found to be already handled by inner-most matches, making them unnecessary. The removal simplifies the generated code, resulting in a 0.2% reduction in code size (approximately 584 lines).
