A bug caused compilation failures when using C++ reflection features alongside sanitizers. Consteval-only variables were being processed too late, after sanitizer instrumentation had already attempted to generalize them. This led to errors, preventing constexpr functions from compiling correctly. This commit reorders operations to purge these variables before sanitizer checks, resolving the issue.
