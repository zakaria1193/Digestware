GCC now recognizes descending-address integer load/store pairs for the RISC-V architecture. This new macro-fusion capability allows the compiler to combine adjacent loads or stores where the addresses decrease with each access. The feature reuses existing pair matching logic and is currently disabled by default, with its positive dump checks failing until a CPU explicitly enables it.
