This commit refactors the implementation of `impl Trait` parameter checking in gccrs's AST lowering phase. Previously, a boolean flag was used to determine the validity of `impl Trait` parameters in function arguments. This change replaces the boolean with a more descriptive enum class, improving code clarity and maintainability. The affected AST lowering functions have been updated to use the new enum API.
