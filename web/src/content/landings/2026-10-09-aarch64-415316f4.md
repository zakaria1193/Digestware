This patch modifies AArch64's machine description (`aarch64.md`) to make bitfield instructions (bfi, bfxil, rev16) recognize RTL expressions using PLUS, IOR, or XOR. This change is necessary to address testsuite regressions that occurred after a previous patch improved the middle-end's ability to select between these operations. While the patterns are now AOP-safe, accurate cost estimates for these instructions are still pending review in a separate patch.
