The xtensa implementation of -fzero-call-used-regs has been revised to correctly handle scenarios where no address registers are cleared. Previously, this could lead to a crash. The updated code now uses register A9 to clear other non-GP registers when no address registers are available, and a new test case has been added to verify this fix.
