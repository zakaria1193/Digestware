Gfortran now correctly handles sequence association when a scalar actual argument is passed to a Fortran dummy argument that is an explicit-shape array with the VALUE attribute. Previously, this scenario led to an ICE because the compiler's handling for scalar VALUE dummies did not extend to array dummies. The fix involves creating temporary copies of array elements and managing character string lengths appropriately.
