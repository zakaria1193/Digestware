This change enables `-fasynchronous-unwind-tables` and `-funwind-tables` by default for the sparc64 Linux target. This ensures that `glibc`'s `backtrace()` function can reliably traverse the call stack using the libgcc unwinder, preventing backtraces from stopping prematurely at the first frame. This aligns sparc64 with other architectures like aarch64 and riscv that already have this behavior enabled by default.
