primer_expert: The `pep.em` template, used for PE-COFF executables (often for Windows
  targets), included a `support_old_code` static variable. This variable was intended
  to control behavior related to older ARM PE targets. However, the `pep.em` template
  does not handle ARM targets; it primarily targets x86 PE. The variable was copied
  from `pe.em` but has remained unused in `pep.em` since its introduction in 2006.
  A recent Clang build flagged it as unused-but-set. This commit removes the variable
  while retaining the functionality of the `--support-old-code` option by simply not
  using the variable.

The `support_old_code` variable in the PE-COFF (PEP) linker emulation was found to be set but never used, leading to compiler warnings. This variable was intended for ARM PE targets, which are not handled by the pep.em template. It has been removed to clean up the linker's emulation code.
