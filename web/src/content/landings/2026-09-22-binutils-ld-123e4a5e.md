This commit addresses a segmentation fault (SEGV) in the `elf_orphan_compatible` function within the GNU linker (`ld`). The issue occurred because the code did not properly check for null pointers when `SHF_LINK_ORDER` was set. The fix adds a necessary sanity check for `linked_to` before dereferencing it, preventing the crash.
