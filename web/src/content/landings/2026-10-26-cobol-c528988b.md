This commit introduces changes to the GCC COBOL compiler to support enhanced debugging capabilities in GDB. The primary goal is to make the current currency sign and field contents available to the debugger, which is crucial for inspecting program state when one COBOL program calls another or during stack frame changes. These updates improve the debugger's ability to analyze the runtime behavior of COBOL programs.
