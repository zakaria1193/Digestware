Several test cases for AVX256 unaligned load and store operations were failing because AVX512F was enabled by default, conflicting with the expected AVX instructions. This commit modifies the test suite to compile these tests with the `-mno-avx512f` flag. This ensures that the tests correctly target AVX256 behavior without interference from newer AVX512 features, resolving issues like incorrect assembler scan results.
