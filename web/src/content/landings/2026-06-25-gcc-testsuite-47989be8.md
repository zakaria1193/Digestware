This commit updates GCC's test suite to enable overriding the `CREATE_GCOV` setting using an environment variable. Previously, this setting was hardcoded, limiting flexibility when running tests. The change, implemented in `lib/profopt.exp`, provides consistency with how autoprofiled bootstraps are handled, making the test environment more configurable for developers.
