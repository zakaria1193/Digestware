The i386 PAVG builtins, which compute an unsigned average rounded up but use signed vector types, are now canonicalized to IFN_AVG_CEIL. This change involves view-converting operands to unsigned types and simplifies masked and unmasked calls. The optimization is applied when operands are equal for modes without IFN_AVG_CEIL optabs, enabling more generic simplifications.
