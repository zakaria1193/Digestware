GCC's Rust frontend (gccrs) now supports recursive algebraic data types (ADTs). This complex feature involves registering ADT types with placeholder variants during initial type checking, allowing fields to resolve back to the root ADT. Recursion guards and a new 'ActiveADT' tracking mechanism are employed to manage this during type unification and code generation, fixing multiple reported issues.
