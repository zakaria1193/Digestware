Several test cases in the GCC test suite that explicitly use the `-fpic` or `-fPIC` flags were failing on certain targets due to a missing requirement for the effective target to support Position Independent Code (PIC). This commit adds the necessary `require target fpic` directive to these tests, resolving spurious failures on platforms like pru-unknown-elf and avr.
