gccrs now supports handling Rust's trait aliases at the Abstract Syntax Tree (AST) level, up to the lowering phase. Although trait aliases are an unstable feature in current Rustc versions, they are available in older versions (pre-1.49) and were adopted by the Rust core library between versions 1.51 and 1.54. This commit adds the necessary AST nodes, visitor patterns, and parsing logic to recognize and process trait aliases.
