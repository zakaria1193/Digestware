This commit resolves an internal compiler error (ICE) in the C++ reflection implementation that occurred when processing `consteval`-only variables. The error stemmed from `mark_needed` being called with a `consteval_only_p` declaration, which violated an assertion. The fix adds necessary guards to prevent this call in `cp_finish_decl` and `setup_explicit_instantiation_definition_linkage`, ensuring correct handling of these types of variables.
