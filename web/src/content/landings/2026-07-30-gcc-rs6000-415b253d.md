This commit modifies the rs6000 backend to properly skip labels during the stmt_vinfo walk. Previously, the code generated stmt_vec_info structures for labels, which are no longer necessary. By starting the basic block walk after labels, this change ensures more accurate code generation and avoids issues with how these structures are handled.
