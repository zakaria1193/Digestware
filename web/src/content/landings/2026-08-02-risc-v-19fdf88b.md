This commit introduces a comprehensive set of new test cases for various RISC-V vector subset instructions, including `vwsub`, `vwsubu`, `vwmul`, and `vwmulu`. The tests cover scenarios with different element widths and vector lengths, ensuring the correctness of these operations, particularly concerning register overlap and specific compiler flags.
