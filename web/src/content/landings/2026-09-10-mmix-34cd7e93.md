This commit resolves compiler warnings on the MMIX target related to signedness mismatches when handling exception handling return registers. Target-independent code expects `EH_RETURN_DATA_REGNO` to return an `unsigned int`, but the MMIX backend was returning an `int`. The change makes `mmix_eh_return_data_regno` return `unsigned int` and adjusts related variables and loops to use unsigned types where appropriate, preventing sign-compare warnings and ensuring compatibility with the core exception handling code. This fix is necessary for builds with `config-list.mk`.
