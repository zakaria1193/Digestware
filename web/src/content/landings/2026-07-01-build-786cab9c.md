This commit removes the `--with-gnu-as` configure option and the associated `gas_flag` variable. Since the `HAVE_GNU_AS` macro has been removed, this option is no longer necessary. The commit also removes references to this option from documentation and contrib scripts, simplifying the configuration interface.
