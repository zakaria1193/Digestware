A bug in the little-endian expansion of vec_permx on rs6000 modified the permute control vector. This modification caused subsequent vec_permx calls using the same control vector to produce incorrect results. The fix generates the negated control vector in a new pseudo register instead of altering the input operand, and a new test case is added.
