This commit initializes the `size` variable to 0 within the `altivec_resolve_overloaded_builtin` function. This change addresses a false positive warning from the maybe-uninitialized pass, which flagged `size` as uninitialized because it was only accessed from the second loop iteration onwards. Initializing it to 0 resolves the warning without affecting the code's logic.
