gccrs has removed the `extended_key_value_attributes` feature, which was active in Rust versions 1.50-1.53. This simplifies version bumping to Rust 1.54 and beyond, as support for this feature would be removed anyway. The commit also removes all parse-time feature gating usage, though the underlying infrastructure is retained for future use.
