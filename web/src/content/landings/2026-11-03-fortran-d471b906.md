This change ensures that when a Fortran class value is copied to a temporary variable, the compiler uses polymorphic assignment. Previously, the class information could be lost, causing the assignment to fall back to non-polymorphic behavior. The fix involves saving and using the class container reference in expression metadata, allowing the compiler to correctly handle assignments involving polymorphic types and temporaries.
