This commit resolves an issue where hashing TYPENAME_TYPEs in precompiled headers was unreliable due to hashing pointer addresses. These addresses change between compile runs, leading to duplicate type creations and incorrect debug information. The fix changes the hashing mechanism to use TYPE_UID, which is preserved across precompiled header reads, ensuring consistent compilation results.
