This commit fixes a regression in the Algol-68 compiler's mode equivalence checking. The function `are_modes_equivalent` was incorrectly comparing 'INDICANTs' as strings, leading to false negatives in mode equivalence. The fix involves changing this comparison to avoid string comparisons for INDICANTs, restoring correct behavior and passing a new test case.
