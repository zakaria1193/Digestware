A recent change in GCC's genmodes intended to use wider types for `mode_unit_size` arrays. However, the definition of `MODE_UNIT_SIZE_TYPE` was emitted only when the host compiler was GCC, causing issues for other host compilers. This commit moves the definition to `insn-modes.h`, making it consistently available and resolving build failures on non-GCC hosts.
