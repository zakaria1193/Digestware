This patch enhances RISC-V code generation for conditional XOR operations with constants, addressing an inefficiency identified in PR125731. By modifying the `get_base_reg_or_constant` function to handle constants and adjust mode handling, the compiler can now generate more efficient, branchless sequences for certain conditional XOR patterns, improving performance.
