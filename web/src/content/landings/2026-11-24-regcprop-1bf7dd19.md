This commit resolves compiler internal errors (ICEs) occurring on RISC-V with higher LMULs, specifically when dealing with vector dot-product operations. The `subreg_lowpart_offset` function requires that mode sizes be ordered, but it was being called with unordered modes in certain scenarios. The fix adds a check to ensure mode sizes are ordered before calling this function, preventing the ICEs.
