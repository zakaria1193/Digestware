GCC's Rust front-end (`gccrs`) now conditionally enables the `cfg_select!` macro based on the `-frust-compat-version=1.90` compiler flag. This commit updates the macro resolution logic and test cases to reflect this gating, ensuring that the macro is only available when explicitly requested through the compatibility version setting.
