The x86 assembler's `check_Scc_OszcOperations` function didn't always restore the `input_line_pointer`, leading to `ignore_rest_of_line()` reading from an invalid memory location. This commit ensures `input_line_pointer` is properly restored. Additionally, the commit fixes an issue where the assembler would increment `input_line_pointer` before handling MRI mode hex floats.
