A new warning, -Wdeprecated-octal-literal, has been added to GCC to flag the use of octal literals that do not use the `0o` prefix. This change affects the C preprocessor (libcpp), C-family language frontends, and libstdc++. The warning is enabled by default for C++29 and can be configured for other C standards. The commit includes test cases demonstrating how to handle the warning, such as using the new `0o` prefix or conditional compilation.
