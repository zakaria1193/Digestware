The if-conversion pass incorrectly destroyed condition-code registers that were still live, causing incorrect flag values to be used by subsequent instructions. This change ensures that if-conversion respects the liveness of condition-code registers, preventing it from clobbering them and thus fixing bugs like PR126501 and PR126747.
