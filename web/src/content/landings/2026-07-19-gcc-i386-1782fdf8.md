This commit introduces a comprehensive set of AVX10/v2 intrinsic functions for converting between FP8 (8-bit floating-point) and FP32 (single-precision floating-point) formats. It adds support for various vector sizes (128, 256, and 512 bits) and includes masked operations. New intrinsic definitions, types, and test cases are provided to ensure the correct implementation of these conversions for AI and high-performance computing workloads.
