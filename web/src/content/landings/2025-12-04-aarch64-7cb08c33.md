This commit introduces support for the `+sme-mop4` extension on aarch64 by adding corresponding intrinsics and instructions. It includes definitions for various `svmop4a` variants with different data types and configurations, as well as new SVE mode suffixes and register constraints. The changes also update internal functions to handle new register classes and function shapes.
