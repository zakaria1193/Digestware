This commit hardcodes the use of Solaris v2 mapfile syntax for GCC's Solaris linker (ld). Previously, GCC supported both v1 and v2 mapfile syntaxes, distinguished by configure-time checks.
As Solaris 11.0 introduced v2 syntax, and only newer versions are now supported, these checks are no longer necessary. The change also prevents issues during non-bootstrap builds where the build compiler's linker might differ from the stage1 compiler's linker. Mapfiles are now unconditionally used if the built compiler employs Solaris ld.
