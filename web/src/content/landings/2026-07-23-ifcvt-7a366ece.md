The `IFCVT_MULTIPLE_DUMPS` macro in GCC's ifcvt pass was unconditionally defined as 1, making its associated conditional code guards in `if_convert` always active. This macro and its guards have now been removed, and the dump code is inlined directly. This change simplifies the code by removing dead conditional logic.
