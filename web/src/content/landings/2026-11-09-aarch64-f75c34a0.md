This patch enhances the AArch64 throughput model to better account for dependencies between integer unpack operations. Previously, all unpack instructions were counted together, ignoring the sequential nature of conversions like QI to SI. The update models these dependencies by rounding up instruction counts to issue cycles, providing a more accurate performance estimate, especially for vector operations.
