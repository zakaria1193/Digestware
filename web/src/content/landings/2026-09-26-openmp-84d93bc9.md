The OpenMP `groupprivate` clause, which provides a copy of a variable per thread team, is now enabled for offloading to NVIDIA's nvptx devices. This feature aligns with Nvidia's 'shared' variable concept. The commit adds support in the NVPTX backend and Fortran frontend, while issuing a 'sorry' message for other devices like GCN or when accessing from the host unless specific conditions are met. This enables more flexible data scoping for parallel regions executed on GPUs.
