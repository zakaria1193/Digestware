The ifcvt (if conversion) pass in GCC had a latent bug where it bypassed normal PHI node update functions when factoring out operators. This led to incorrect SSA information, causing a reduction patch to ICE by incorrectly passing a single-use check. This commit fixes the issue by using the proper PHI update functions, resolving the ICE and enabling the reduction.
