The GCC Rust compiler has been updated to correctly identify and emit the extern prelude origin for core paths when generating builtin macros. Previously, the compiler would emit the core path but fail to specify its extern prelude source, always defaulting to using opening scope resolution. This change ensures more accurate generation of builtin macros by properly handling scope context.
