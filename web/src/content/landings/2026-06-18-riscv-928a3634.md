The GCC RISC-V backend gained support for CPU alias names. This new feature allows different `-mcpu=` and `-mtune=` options to map to the same canonical CPU, accommodating situations where CPU names change or have multiple marketing designations. This change introduces `struct riscv_cpu_alias_info` and `riscv_cpu_alias_table` to manage these aliases, improving the flexibility of CPU selection.
