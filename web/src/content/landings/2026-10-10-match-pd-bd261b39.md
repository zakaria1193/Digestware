This commit extends the simplification of zero tests for count-leading-zeros (.CLZ) and count-trailing-zeros (.CTZ) operations from scalar types to vector types. Additionally, it updates documentation to clarify that .CLZ/.CTZ can accept an optional second argument specifying the value returned when the input is zero. A test case for s390 has been adapted to this change.
