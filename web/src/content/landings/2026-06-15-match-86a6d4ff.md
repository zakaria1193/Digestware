The GCC `match.pd` file, which governs pattern matching for optimizations, has been updated to recognize that the condition `X < (typeof X)(X != 0)` is always false for nonnegative integer `X`. This simplification is applied by using `tree_expr_nonnegative_p` to determine if `X` is unsigned or otherwise known to be nonnegative. By directly evaluating this condition as false, the compiler can eliminate unreachable code paths and enable further optimizations.
