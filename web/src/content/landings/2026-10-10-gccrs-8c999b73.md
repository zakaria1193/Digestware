This commit adds support for Rust's atomic compare-exchange (compare-and-swap) built-in functions to the GCC Rust compiler. These operations are fundamental for lock-free data structures and concurrent programming, allowing atomic conditional updates of memory locations. The implementation involves defining new intrinsic handlers and integrating them into the compiler's intrinsic processing pipeline.
