This commit enables the vector MIN test case `vec-narrow-1.C` for x86 targets by activating the AVX512VL and AVX512DQ extensions. Previously, the default x86_64 lowering process obscured the V2DI MIN operation before the narrowing rule could be applied. Enabling these extensions ensures the test correctly exercises the narrowing transformation.
