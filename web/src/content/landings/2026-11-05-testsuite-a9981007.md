Four recently added test cases for C++ `_BitInt` support were mistakenly configured with `dg-do compile` instead of `dg-do run`. This change updates them to `dg-do run`. The commit also addresses issues within these tests: specifically, undefined behavior for signed `_BitInt(1)` operations like `-1 * -1` and `-1 % -1`, and clarifies the behavior of increment/decrement operators (`++`, `--`) for signed `_BitInt(1)`, ensuring they correctly use `-1` for operations that would otherwise be problematic.
