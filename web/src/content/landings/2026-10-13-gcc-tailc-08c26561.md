The tail call optimization (tailc) in GCC was incorrectly optimizing some function calls where the callee's return type and the caller's expected return type mismatched, particularly with `_BitInt` types on certain targets. This commit makes the optimization more conservative by punting (disabling the optimization) in cases of `_BitInt` to `_BitInt` conversions with different sizes, or when precision differs for narrowing casts, unless the target specifically handles padding bits in a way that preserves ABI compatibility. This prevents miscompilations by avoiding assumptions about type conversions at function boundaries.
