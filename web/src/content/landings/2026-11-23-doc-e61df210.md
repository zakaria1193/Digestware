The documentation for `cmls<mode>4` and `cmls_conj<mode>4` optabs has been corrected to accurately reflect their behavior. These operations are used in the vectorizer and, contrary to the previous documentation, they compute `op1 * op2 - op3` (or `op1 * conj(op2) - op3`) by subtracting the product from the third operand. This clarification ensures that code written according to the documentation will compile correctly, as some ports previously misinterpreted the operation sign.
