This patch optimizes 128-bit `TImode` (128-bit integer) moves between SSE and general-purpose registers on x86_64 systems supporting SSE2. Previously, such moves often involved costly stack operations. The new implementation leverages SSE2's `shufpd` instruction to perform these moves directly, reducing instruction count and improving performance. This is a partial fix for PR target/114544.
