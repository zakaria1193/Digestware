The COBOL frontend in GCC now generates its Bison parser output within a `cdf` C++ namespace. This change addresses a long-standing LTO (Link Time Optimization) error (PR 119215) by preventing enumerated types and other symbols from polluting the global namespace. It also standardizes location tracking by using a single `cbl_loc_t` type across both COBOL parsers, and improves cross-platform compatibility by conditionally compiling non-POSIX symbols. These improvements collectively enhance the robustness and maintainability of the COBOL frontend.
