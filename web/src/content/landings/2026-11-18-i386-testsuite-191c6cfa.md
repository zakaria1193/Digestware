This commit corrects the array size definitions in two i386 test case files related to the `vcvtph2hf8` and `vcvtph2hf8s` instructions. The `res_ref` array size was incorrectly set to `SIZE` instead of `SIZE_DST`, which could lead to buffer overflows and random test failures. The fix ensures the correct size is used, improving test suite stability.
