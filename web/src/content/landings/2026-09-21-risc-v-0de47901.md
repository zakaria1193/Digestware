The load instruction latency for the ARC-V RMX-100 processor has been updated. The previous latency value was considered a worst-case scenario, and the new value better reflects the likely case, potentially improving scheduling and performance. Additionally, the commit merges floating-point load instructions with general loads and updates branding information.
