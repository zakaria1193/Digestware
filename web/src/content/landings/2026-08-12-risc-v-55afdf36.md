This commit adds a comprehensive set of test cases for the RISC-V vwmacc.vv vector instruction, with a particular focus on register group overlap scenarios. Tests are generated for various data types (i8, i16, i32) and configurations (m1, m2, m4, mf2, mf4, mf8) to ensure correct functionality when source and destination registers overlap.
