This commit adds the `__ARM_FEATURE_SME_MOP4` feature test macro and a corresponding test case to verify its correct definition when the `+sme-mop4` extension is enabled. Documentation for the new extension flags is also updated. This complements the earlier addition of the `+sme-mop4` flag itself.
