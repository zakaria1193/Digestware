  operations that effectively act as clamps. The patterns `MIN(MAX(X, Y + CST), Y)`
  for `CST > 0` and `MAX(MIN(X, Y + CST), Y)` for `CST < 0` are recognized. In the
  first case, `Y + CST` is always greater than `Y`, so `MAX(X, Y + CST)` results in

  to `Y`. This rule simplifies code generated from inlined clamp helpers where bounds
  have already been established.

GCC's pattern matching system can now eliminate certain redundant 'clamp' expressions. Specifically, expressions like `MIN(MAX(X, Y + CST), Y)` where `CST` is positive, or its dual `MAX(MIN(X, Y + CST), Y)` with a negative `CST`, are simplified away. These patterns arise after inlining when a clamp's bounds are already satisfied by prior operations, making the clamp itself unnecessary and reducible to a simple assignment of one of the bounds.
