When adding new input archives from a linker script, the linker (`ld`) now appends them to the input file list in the order they're specified. This is important for LTO, where the compiler may not have complete symbol information for built-in functions. Maintaining the correct order ensures that symbols are resolved correctly when the linker extracts elements from the archive during LTO rescan, which can affect programs using `-lm`.
