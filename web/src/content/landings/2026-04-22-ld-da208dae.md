When adding new input archives from linker scripts during LTO, the linker used to append them to the end of the input file list, potentially disrupting the intended link order. This commit ensures that the linker now maintains the original input file order, which can influence symbol resolution and is sometimes required for correctness.  This change is relevant when using `-lm` with a `GROUP` construct.
