This commit enables the stack protector feature for the Alpha architecture by correctly defining `FRAME_GROWS_DOWNWARD`. Previously, this was left commented out, causing `-fstack-protector` to be rejected. The fix ensures the stack grows downwards, which is necessary for the canary to properly guard buffers. This change is compatible with existing glibc support and does not alter default code generation.
