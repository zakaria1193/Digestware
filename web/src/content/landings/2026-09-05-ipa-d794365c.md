The interprocedural constant propagation (IPA-ICF) pass incorrectly unified structs with different field declarations but identical offsets. This occurred when comparing ADDR_EXPRs under OEP_ADDRESS_OF, where it accepted different FIELD_DECLs with the same offset. A new flag, OEP_ADDRESS_OF_SAME_FIELD, is introduced to ensure that only identical fields are considered equivalent, thus preventing errors like the one in PR119006 where a strlen calculation failed after struct unification.
