Two minor cleanups have been applied within the `ifcvt` subsystem. The `noce_try_cond_arith` function's return type has been changed from `int` to `bool`, aligning it with its siblings and removing reliance on implicit type conversions. Additionally, `block_jumps_and_fallthru` now uses logical operators instead of bitwise ones for testing boolean flags, correcting a potential logic error and improving clarity. These changes are purely stylistic and do not alter functionality.
