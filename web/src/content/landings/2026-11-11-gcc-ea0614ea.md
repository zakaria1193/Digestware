Functions `cuDeviceGetUuid` and `cuDeviceGetUuid_v2`, which were previously added to GCC's `cuda.h`, have been removed. These functions are not part of the CUDA 8.0 specification that GCC's header targets. They are now provided in `libgomp/plugin/plugin-nvptx.c` to ensure compatibility when using older CUDA versions with specific compiler configurations.
