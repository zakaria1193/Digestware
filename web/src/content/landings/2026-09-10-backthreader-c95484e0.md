The backthreader's `adjust_paths_after_duplication` function previously performed a quadratic scan for candidate paths on every duplication. This commit optimizes this by maintaining a count of registered paths starting on each edge. If a count is one, it means no other paths start there, and the scan is skipped, significantly reducing runtime for code with many registered paths.
