The `bfd_elf32_rl78_set_target_flags` function and its associated `no_warn_mismatch` variable have been removed from `bfd/elf32-rl78.c`. This function has never been called since the RL78 port was added in 2011, and the variable it sets is consequently unused. Their removal cleans up the BFD library code for the RL78 target and resolves compiler warnings.
