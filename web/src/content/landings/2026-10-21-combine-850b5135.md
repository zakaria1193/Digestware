The combine pass now correctly optimizes assignments to bitfields that use addition, similar to how it handles bitwise OR and XOR. This optimization, particularly relevant for the i386 architecture, can significantly reduce generated code by allowing direct byte manipulation instead of intermediate register operations. A new test case demonstrates the improvement for a common scenario.
