A test case, `gcc.dg/torture/pr127377.c`, which compiles successfully but aborts at runtime on big-endian targets, has been marked as 'expected to fail' (xfail). This runtime failure, indicated by a return value of 0x70, is suspected to be related to register layout boundaries. Explicitly marking the test prevents noisy regressions in the test suite output for big-endian architectures.
