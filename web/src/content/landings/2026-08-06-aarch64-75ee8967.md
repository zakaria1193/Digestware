This change enhances the AArch64 vectorizer by enabling it to perform vector DImode high-part multiplications using Scalable Vector Extension (SVE) instructions. Previously, Advanced SIMD lacked this capability, preventing optimization of loops requiring 64x64 high-part multiplies (e.g., calculating the upper 64 bits of a 128-bit product). By leveraging SVE's UMULH and SMULH instructions on Z registers, GCC can now optimize these loops more effectively, generating more efficient machine code.
