GCC's Rust front-end gains a new straight-line BIR drop state analysis pass. This analysis inserts BIR `Drop` statements at scope exits and classifies them as static or dead based on variable initialization and move states. Function arguments are treated as initialized and their drops are scheduled before function returns.
