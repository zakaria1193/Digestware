A previous reassociation optimization that exposed rotate+xor sequences has been fixed to correctly handle `int128` and `BitInt` types. The change replaces `HOST_WIDE_INT` interfaces with `wi::` interfaces, resolving code generation issues on architectures like AArch64 and enabling the optimization for `BitInt`.
