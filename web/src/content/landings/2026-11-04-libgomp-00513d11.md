This commit introduces four new OpenMP 6.0 API routines: omp_get_device_num_teams, omp_set_device_num_teams, omp_get_device_teams_thread_limit, and omp_set_device_teams_thread_limit. These routines allow users to interact with device-side context information. The implementation avoids unnecessary data copying and corrects tests that incorrectly used older API versions within target regions. Documentation and tests have been updated accordingly.
