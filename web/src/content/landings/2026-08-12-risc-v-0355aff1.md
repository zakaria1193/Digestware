GCC gains the ability to recognize and fuse an ANDI instruction with a following ADD or ADDI instruction on RISC-V systems, provided the result register of the ANDI is used as a required dependency. This optimization also uses RTL to handle ADDIW before it might be optimized away by other passes. The new fusion is disabled by default and is accompanied by new test cases.
