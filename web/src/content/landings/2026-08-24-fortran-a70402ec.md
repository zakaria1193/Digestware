This change corrects a segfault in gfortran that occurred when an absent optional actual argument was passed to a Fortran dummy argument with the VALUE attribute. The compiler now correctly suppresses copies for absent optional arguments, preventing dereferencing of null pointers for both array and character types, thus ensuring program stability.
