When using parallel LTRANS with the -save-temps option, Makefiles generated by the LTO wrapper could produce stale object files. This change marks persistent non-cache LTRANS outputs as 'phony' in the Makefile, ensuring that Make reruns the LTRANS recipe for the current link. A new test case verifies the fix, which passed on x86_64 and AArch64.
