The gas assembler was incorrectly issuing errors related to global symbols when it encountered local symbols in the register section. The code assumed the diagnostic was about global symbols, but `S_IS_LOCAL` returns true for symbols in `reg_section`. This commit adds a check for local register symbols to avoid the incorrect error, and cleans up related testcases.
