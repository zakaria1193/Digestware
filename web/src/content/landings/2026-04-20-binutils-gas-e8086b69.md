The assembler was incorrectly issuing errors due to local register symbols being treated as global symbols. This commit adds a check to ensure that local symbols in the `reg_section` are not treated as global symbols, which avoids the incorrect diagnostic. The commit also cleans up some redundant code and test cases related to equate handling.
