This commit fixes a bug in gcov.cc where an incorrect condition was used for generating function summaries. The check `coverage->calls == 0` was always false, leading to potentially wrong reporting. The fix changes the condition to correctly check `calls_suppressed`, ensuring accurate summary generation.
