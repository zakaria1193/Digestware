The cost of comparison operations in the RISC-V backend has been adjusted to better reflect the actual cost of generating the required instructions.  The middle-end's costing mechanism did not accurately account for the lack of a dedicated COMPARE instruction on RISC-V, so the cost model is now more informed about the expense of generating the necessary constants.  This can influence optimization decisions, potentially leading to better code generation.
