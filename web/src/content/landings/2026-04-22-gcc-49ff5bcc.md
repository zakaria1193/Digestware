The middle-end of GCC uses a cost model to make decisions about which instructions to use. This commit improves the costing of `COMPARE` nodes for RISC-V. Since RISC-V doesn't have a dedicated `COMPARE` instruction, the cost is now based on the cost of generating the appropriate constants and instructions to perform the comparison. This leads to better code generation decisions, especially when dealing with different constant values.
