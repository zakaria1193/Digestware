The middle-end cost model for comparisons was inaccurate for RISC-V because RISC-V lacks a dedicated COMPARE instruction, leading to suboptimal code generation for control flow. This commit implements a `COMPARE` cost as part of `riscv_rtx_costs`, similar to `aarch64_rtx_costs`. The new cost model accounts for the cost of generating the comparison constant, leading to better optimization decisions.
