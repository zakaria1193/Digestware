The GCC Rust compiler (gccrs) has incorporated handling for `goto` statements within constant expressions by porting relevant logic from GCC's C++ frontend (`cp/constexpr.cc`). This enhancement ensures that `goto` statements, when used in contexts where constant evaluation is required, are processed correctly, resolving issues related to control flow in compile-time evaluated code.
