This change fixes an internal compiler error (ICE) in the C preprocessor (libcpp) that occurred when `__has_include` or `__has_embed` were used outside of a preprocessor directive. Previously, the parser would incorrectly attempt to read the entire file as a header name, leading to an error and a crash when encountering the closing token. The fix adds an early exit condition in `builtin_has_include_1` to prevent calling `glue_header_name` in invalid contexts, thus avoiding the ICE and correctly handling these builtins.
