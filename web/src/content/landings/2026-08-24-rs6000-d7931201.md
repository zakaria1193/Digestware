This commit introduces a new GCC mode `QDOmode` representing a 256-byte opaque data type named `__dmr2048`. This type is necessary for the SHA3 builtins on the PowerPC architecture, as these instructions operate on pairs of dense math registers. The patch defines the mode, maps it to register pairs, implements patterns for moving this data, and integrates it into the compiler's type system and built-in handling.
