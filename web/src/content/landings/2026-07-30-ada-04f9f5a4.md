This commit addresses a bug in the Ada compiler's analysis of the GNAT-specific 'Unrestricted_Access attribute when applied to overloaded subprograms. Previously, the Analyze_Attribute function incorrectly generated an error in this scenario. The fix aligns the handling of Unrestricted_Access with that of other access attributes like [Unchecked_]Access, resolving the bogus error.
