This change introduces the non-SIMD implementation of `std::clmul` and related utilities to libstdc++. Aligned with the C++23 proposal P3642R7, this feature provides support for carry-less multiplication, a fundamental operation in cryptographic and polynomial arithmetic. The implementation includes a new `std::wide_result` class and `std::widening_clmul` and `std::clmul` function templates, with exported symbols for C++29.
