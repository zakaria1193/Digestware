A bug in Fortran's type handling led to memory leaks when using parenthesized types with allocatable components. These types, when used as actual arguments or `ASSOCIATE` selectors, caused a deep copy into new storage that was never freed. This change ensures that TYPE temporaries are passed without copying or freeing their components, and that CLASS temporaries are finalized correctly, preventing the leaks.
