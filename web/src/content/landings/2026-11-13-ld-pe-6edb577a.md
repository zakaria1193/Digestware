This commit significantly optimizes the process of computing the PE build-id by changing how the linker's `pecoff_checksum_contents` function reads the output file. Previously, it read the file one byte at a time, involving frequent seeks and function calls, which was a performance bottleneck for large executables. The update now reads the file in larger, 64KB chunks using a heap buffer, falling back to a smaller stack buffer if allocation fails. This reduces I/O overhead and speeds up linking.
