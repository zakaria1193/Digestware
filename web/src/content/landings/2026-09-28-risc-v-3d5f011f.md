This commit adds a collection of new test cases for the RISC-V Vector (RVV) extension, focusing on register group overlap for the `vfwadd.vf` instruction. The tests cover various data types (f16, f32) and vector lengths (m1, m2, m4, mf2, mf4), ensuring correct handling of register resources during wide floating-point fused multiply-add operations.
