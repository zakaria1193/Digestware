This commit corrects an issue where vectorized loops with early exit conditions, specifically those resembling do-while loops (marked with `LOOP_VINFO_EARLY_BREAKS_VECT_PEELED`), were exiting one iteration prematurely. This occurred because the loop's iteration variable check was incorrectly processed relative to the loop latch. The fix ensures the loop condition is checked correctly, preventing unnecessary early exits and ensuring all intended iterations are processed before termination or branching to scalar code. This resolves an issue seen in specific AArch64 code generation scenarios.
