The vectorization recognition pattern for count-leading-zeros (`CLZ`) and count-trailing-zeros (`CTZ`) instructions now correctly handles scenarios where the 'value at zero' is not equal to the target value for the vector mode. A `select` operation is employed, similar to existing patterns, to ensure correct results when dealing with zero lanes. This fix enables vectorization for certain AArch64 code sequences.
