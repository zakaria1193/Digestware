This commit ports NEON rounding shift-by-immediate intrinsics (e.g., vrshr_n, vrsra_n) to the pragma-based framework on aarch64. This consolidation simplifies the handling of these operations by leveraging the existing framework, which was inspired by SVE intrinsics. The change removes redundant definitions from arm_neon.h and associated files, ensuring consistency in how these SIMD operations are processed.
