The Fortran compiler now correctly handles attributes for class containers by ignoring the implicit _data component's attributes. Previously, the compiler might miss or incorrectly report attributes if the last component reference was to _data, leading to incorrect error messages or missed checks for polymorphic function results and pointer assignments.
