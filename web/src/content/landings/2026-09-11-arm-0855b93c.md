This commit introduces support for missing VCVT (Vector Convert) instructions for the FP16 (16-bit floating-point) data type in the ARM toolchain. The new instructions, which handle conversions between floating-point and fixed-point formats, are mapped to existing FPv3 Half Precision encodings. The changes include updates to the assembler's configuration for ARM, the disassembler's opcode table, and test suite validation for ARMv8.2-A and ARMv8.1-m.main architectures.
