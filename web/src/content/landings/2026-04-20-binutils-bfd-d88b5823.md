The bfd library was creating a .got (Global Offset Table) section during the relocation process. This was intended to fix a crash when linking incompatible objects, but is now deemed to be too late to create sections. This commit removes the code that creates the .got section in `bfin_relocate_section` and instead reports an unresolvable relocation error if the .got section has not already been created.
