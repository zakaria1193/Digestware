This commit integrates several AArch64 NEON comparison intrinsics (e.g., `vcage`, `vceqz`, `vcgtz`) and the `vtst` intrinsic into GCC's pragma-based framework. This modernization simplifies the intrinsic handling and allows for better code generation. Additionally, redundant `__builtin_aarch64_cm*` and `__builtin_aarch64_fac*` built-in functions have been removed, as they are no longer necessary and can be replaced by standard C comparison operators.
