This commit refactors how parent predicates are handled in gccrs to significantly reduce memory consumption. Instead of copying entire predicates, which recursively clones all associated types, the `TypeBoundPredicateItem` now holds a pointer to its parent predicate. This change, motivated by memory exhaustion issues, ensures that only necessary data is copied, improving efficiency and preventing memory leaks associated with predicate cloning.
