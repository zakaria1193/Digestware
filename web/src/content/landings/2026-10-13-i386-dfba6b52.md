GCC has enabled vector conversions between _Float16 and _Float32 types for the F16C, AVX512F, and AVX512VL instruction sets. Previously, these conversions were only supported when the AVX512FP16 extension was also present. This change expands the hardware capabilities for handling these floating-point types, improving performance for applications utilizing them.
