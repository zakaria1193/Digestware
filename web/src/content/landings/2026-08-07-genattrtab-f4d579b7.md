This commit enhances `genattrtab` to generate more efficient code for machine attributes that are directly defined as functions of other attributes. Previously, such definitions were expanded and evaluated repeatedly for each instruction. The new approach directly represents these functional relationships, similar to how run-time evaluated attributes are handled, leading to more optimized generated code and reducing redundancy in attribute lookup tables.
