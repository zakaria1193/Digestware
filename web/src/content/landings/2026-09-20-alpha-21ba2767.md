This commit adds support for unaligned memory move operations for scalar integer modes on the Alpha architecture. Previously, only vector modes had `movmisalign` patterns, forcing small `memcpy` operations to be expanded inefficiently with stack slots or byte-by-byte copies. By extending `movmisalign` to scalar modes and deriving access size from the mode, small memory operations are now folded directly into unaligned loads/stores, eliminating unnecessary stack usage and improving performance.
