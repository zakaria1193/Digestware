This commit adds `-Wno-deprecated-octal-literal` to more C++ test cases that were failing due to a compiler warning. The warning is triggered by octal literals in system headers, such as `ctype.h`, when tests are configured to pass warnings for system headers. This change ensures these tests pass without affecting the warning's overall behavior for user code.
