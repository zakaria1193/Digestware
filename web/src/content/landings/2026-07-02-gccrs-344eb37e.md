GCC's Rust compiler introduces a new function, `CompileDrop::build_current_scope_drop_cleanup`, to construct statement trees for drop calls within the current scope. This facilitates the subsequent placement of these cleanup statements into `TRY_FINALLY_EXPR` constructs, streamlining the process of ensuring resources are properly released.
