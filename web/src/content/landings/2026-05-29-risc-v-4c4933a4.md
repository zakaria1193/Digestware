The RISC-V vector cost model has been updated to incorporate a scalar-to-vector unit ratio for integer vector operations. This change helps the cost model more accurately reflect actual hardware throughput, preventing vectorization from appearing overly cheap. The update introduces new fields for scalar and vector units in `riscv_tune_param` and applies the scaling to most vector body costs, excluding reductions and gather/scatter operations.
