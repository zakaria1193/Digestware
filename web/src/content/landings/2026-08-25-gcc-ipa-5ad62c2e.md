An optimization pass (DSE) was incorrectly deleting stores to up-level array references that had negative lower bounds. This happened because IPA modref analysis inaccurately flagged these stores as dead. The issue stemmed from `get_ref_base_and_extent` incorrectly shrinking the maximum size of such arrays, causing the loss of elements. This fix ensures that array references with negative low bounds are handled correctly, preventing incorrect dead store elimination.
