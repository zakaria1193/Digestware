This commit removes a long-standing, now unnecessary, configure-time dependency where `libstdc++`'s configuration waited for `libgomp` to be configured. This dependency was originally introduced to check for the presence of `omp.h` for parallel mode enablement. However, subsequent changes modified this check to rely on a string comparison rather than file existence, rendering the original dependency obsolete. Removing this link shortens the critical path in the build process, as `libstdc++` is often the last component to finish in bootstrap stages.
