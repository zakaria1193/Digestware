This commit introduces a new function, `gcc_jit_type_is_floating_point`, to the libgccjit API. This function allows users of the JIT compiler library to programmatically determine if a given JIT type represents a floating-point number, enhancing the ability to inspect and manipulate types within JIT-compiled code. It also updates the ABI version and documentation to reflect this addition.
