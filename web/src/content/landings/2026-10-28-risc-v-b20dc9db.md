The GCC compiler reverts changes that allowed register overlap for RISC-V vector widening multiply-add instructions (vwmacc[u].vv). This is to comply with the vector specification, which reserves encodings where a single register supplies operands with different effective element widths. The change affects multiple test cases and the vector instruction definitions.
