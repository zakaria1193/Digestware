This commit enhances the libstdc++ test suite's semaphore implementation to support POSIX semaphores when System V semaphores are unavailable. It uses `mmap` for shared memory and handles systems lacking `MAP_ANONYMOUS`. The change ensures tests fail loudly if neither semaphore type is available and fixes a resource leak in the existing SysV semaphore code. The semaphore class is also refactored into separate header and source files.
