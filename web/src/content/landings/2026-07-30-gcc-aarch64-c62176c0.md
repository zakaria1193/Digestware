A bug in aarch64 code generation for `max/min-of-add/sub` patterns caused incorrect results by not properly indicating that these instructions clobber condition codes. This led to the compiler removing necessary comparison instructions, resulting in a conditional select (`csel`) using stale flags. The fix adds a `(clobber (reg:CC CC_REGNUM))` to the relevant instruction patterns, ensuring that condition codes are correctly marked as modified. This preserves the necessary comparison instructions and resolves the miscompilation.
