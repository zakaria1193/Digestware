The aarch64 testsuite now allows enabling Scalable Matrix Extension (SME) without requiring Scalable Vector Extension 2 (SVE2). This is achieved by merging the ``exts_sve2`` target support variable into ``exts``, simplifying the test configuration and removing redundant checks.
