GCC's COBOL compiler now supports the `-Werror` option, which warns if a COBOL program uses 'error' as a data-item name without properly referencing the C `errno` variable. Additionally, the severity of syslog messages for unhandled error conditions has been refined, using `LOG_ERR` for fatal errors and `LOG_WARNING` for non-fatal ones, while unimplemented or unrecognized errors still use `LOG_INFO`.
