Constant evaluation of C++ virtual calls, especially with covariant return types, could lead to internal compiler errors (ICEs) due to type mismatches. This fix ensures that the result of a constexpr virtual call, including those involving result thunks for covariant overrides, is correctly adjusted to the static type of the call before being used in subsequent expressions, preventing the ICE.
