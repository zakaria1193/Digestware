primer_expert: The `rust-default-resolver.cc` and related files in gccrs manage how
  names are resolved within Rust code. Previously, prelude imports (like `std::prelude::*`)

  the prelude's contents are consistently brought into scope.

This commit refactors gccrs' handling of prelude imports by replacing specific, ad-hoc import logic with a generalized glob import in every module and crate. This change simplifies the name resolution process and ensures consistent handling of the prelude across the compiler. A new virtual member function `maybe_prelude_import` is introduced to facilitate this generalization.
