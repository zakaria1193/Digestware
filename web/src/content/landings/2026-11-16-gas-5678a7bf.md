The GNU Assembler (GAS) previously failed to correctly mark weak functions as external in DWARF debug information. This was because the check for external symbols only considered `BSF_GLOBAL`, which is cleared for weak symbols. This commit updates the DWARF emission logic to also check for weak symbols (`S_IS_WEAK`), ensuring that weak functions are properly identified as external by debuggers like GDB, resolving a bug where they were incorrectly treated as static.
