This commit refines DWARF output generation in LTO to correctly handle cases where an instance's origin tree is replaced. It modifies the external DIE hooks to accept a kind parameter and preferentially use an instance's saved abstract origin. This ensures that even when SCC unification redirects tree origins, the debugger uses the correct, saved origin information, improving the accuracy of debugging LTO-compiled code, especially for cloned and inlined entities.
