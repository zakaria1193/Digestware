This commit synchronizes the profile linking options for Darwin targets with those defined in the main GCC configuration file (`gcc/gcc.cc`). Specifically, it updates the `LINK_COMMAND_SPEC_A` macro in `config/darwin.h` to ensure consistency in how coverage information is linked into executables on Darwin systems.
