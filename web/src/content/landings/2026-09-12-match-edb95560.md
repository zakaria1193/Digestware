A new optimization pattern `minmax (a - c, b) + c -> minmax (a, b + c)` has been added to GCC's pattern matcher. This transformation is applied when the expression `b + c` is known not to overflow. This specific optimization was observed to occur in `std::vector::push_back` and helps in simplifying code by trading a subtraction and addition for a single addition. The current implementation is limited to unsigned types due to overflow checking limitations.
