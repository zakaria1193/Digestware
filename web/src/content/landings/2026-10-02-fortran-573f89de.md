The Fortran compiler's `gfc_variable_attr` function has been refactored to improve clarity and maintainability by separating the retrieval of data reference attributes from their types. Two new functions, `get_data_ref_type` and an updated `gfc_variable_attr`, now handle these distinct responsibilities, simplifying existing call sites and code logic.
