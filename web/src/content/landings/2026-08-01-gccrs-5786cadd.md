gccrs now includes basic type-checking for structs annotated with #[repr(simd)]. This change allows the compiler to understand the SIMD representation for these types, although the actual compilation of such structs is still handled as regular structs. The implementation is specific to Rust version 1.49.0, as later versions (1.50.0+) use a different internal representation for #[repr(simd)] structs.
