GCC's RISC-V backend has been enhanced with pipeline information for the MIPS i8500 processor. This allows the compiler to generate more optimized code for this specific architecture by understanding its 9-stage, triple-issue, in-order execution pipeline. The update includes definitions in core configuration files, a new machine description file, and documentation.
