GCC now optimizes certain widening multiplication overflow checks by recognizing that the imaginary part of the result is always in a limited range (0 or 1). Previously, the generated GIMPLE code for these checks included unnecessary comparisons against zero that were not subsequently optimized away. This change propagates the known range information earlier in the compilation process, leading to cleaner and more efficient machine code, and fixes a regression in the i386 backend.
