This fix addresses an issue in AArch64 SVE builtins where the FFR (First Fault Register) update was not correctly dependent on the loaded value, leading to invalid Common Subexpression Elimination (CSE). The changes modify the `expand` methods for `svldff1_gather_impl`, `svldff1_gather_extend`, `svldxf1_impl`, and `svldxf1_extend_impl`, and update the `aarch64_update_ffr_for_load` pattern in `aarch64-sve.md` to ensure the FFR update is based on the actual loaded data, thus fixing the PR126629.
