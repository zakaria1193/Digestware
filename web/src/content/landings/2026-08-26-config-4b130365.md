For 64-bit Darwin targets, the default architecture tuning has been changed from a generic setting to 'core2'. While 'core2' has been the minimum processor target for years, this change ensures that generated code takes advantage of its specific features, such as 16-byte compare-and-swap instructions, leading to improved performance.
