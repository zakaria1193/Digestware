gccrs enforces the rule that let bindings (without an `else` clause) and function parameters must use irrefutable patterns. The compiler now issues diagnostics for refutable patterns in these contexts, deferring comprehensive checks to the `PatternChecker` after type information is available. This improves compile-time safety by preventing non-exhaustive pattern matches where they are not permitted.
