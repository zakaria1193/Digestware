This commit addresses a problem in C++ alias template conversions where building an IMPLICIT_CONV_EXPR around a capture proxy caused the compiler to lose lambda scope during substitution, leading to errors. The fix ensures that capture proxies are properly resolved to their constant values using `mark_rvalue_use` and rewrites the conversion to handle NOP_EXPR/CONVERT_EXPR more effectively.
