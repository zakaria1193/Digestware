A fix has been implemented for the PE COFF linker to correctly resolve weak external symbols when a strong undefined reference to the same symbol is encountered earlier in the linking process. This resolves 'undefined reference' errors for symbols like GCC's default `operator new` or personality routines, which are often emitted as weak externals with fallbacks. The changes ensure that the linker appropriately stores symbol information and triggers weak alias fallbacks even when a strong undefined symbol is processed first.
