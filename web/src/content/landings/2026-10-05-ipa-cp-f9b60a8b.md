GCC's inter-procedural analysis (IPA) cloning pass, when used with Profile-Guided Optimization (PGO), now correctly scales the run-time metrics used for evaluating cloning opportunities. This adjustment ensures that these metrics are relative to the total program run time, aligning PGO-driven scores more closely with those derived from guessed profiles.
