This commit corrects how C++ attributes are handled for dependent template types, specifically fixing an issue on RISC-V where ABI tags were dropped. Previously, late attributes were spliced out before the target could see them, causing incorrect mangling for templates like `template <typename T> __attribute__((riscv_vls_cc(128))) void a (T) {}`. The fix ensures the target hook `insert_attributes` is called before attributes are spliced, allowing ABI tags to be correctly incorporated.
