This commit relaxes parsing restrictions in the COBOL compiler, allowing it to accept multiple consecutive periods as empty statements (void sentences). It also enables the undocumented $END-IF directive to be accepted without comment when using the Micro Focus dialect. These changes address specific parsing leniencies requested to improve compatibility.
