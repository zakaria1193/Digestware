This commit addresses an issue in the Fortran runtime library affecting the `MINLOC` and `MAXLOC` intrinsic functions. When the `MASK` argument was used in conjunction with `BACK=.true.`, the library templates did not correctly advance through the array argument, leading to incorrect results. The fix involves regenerating numerous runtime library templates after modifying the relevant `m4` macro to ensure proper array traversal under these specific conditions.
