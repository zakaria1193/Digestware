The `libga68` build process previously overwrote any user-specified `A68FLAGS` during configuration, preventing options like `-ffile-prefix-map` from being passed to the Algol 68 compiler. This change modifies `configure.ac` to default `A68FLAGS` only if it is unset, ensuring that user-defined flags are respected and aiding in the creation of reproducible builds.
