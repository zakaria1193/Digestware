The GCC configure script previously guarded checks for timing APIs like `nanosleep` and `clock_gettime` based on the `_POSIX_TIMERS` macro. This commit modifies the check to test for the APIs directly, even if `_POSIX_TIMERS` is set to -1, which indicates a non-compliant implementation rather than absent APIs. This allows detection of these APIs on systems like Darwin where they are available but not POSIX-compliant.
