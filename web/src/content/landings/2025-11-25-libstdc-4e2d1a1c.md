The `__platform_wait_t` type is now defined as `unsigned int` (32-bit) for OpenBSD and DragonFly.  This ensures that `std::semaphore` will use a 32-bit type by default.  While not currently utilizing OpenBSD's `futex(2)` or DragonFly's `umtx(2)` syscalls, this change avoids a potential ABI break if those syscalls are used in the future.
