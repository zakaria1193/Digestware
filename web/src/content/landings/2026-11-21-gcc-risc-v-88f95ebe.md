A duplicate Zihpm extension was introduced for the RISC-V spacemit-x60 core definition. This duplication arose because the K1 design builds on the rva22 profile, which already includes Zihpm, and then explicitly added it again. This caused a bootstrap build failure. The fix removes the redundant extension definition, restoring the build process.
