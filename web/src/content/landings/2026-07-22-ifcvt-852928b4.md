Several functions within GCC's ifcvt pass that manually managed bitmaps using `BITMAP_ALLOC` and `BITMAP_FREE` have been updated to use `auto_bitmap`. This RAII-style approach ensures bitmaps are automatically freed upon exiting the scope, preventing potential memory leaks from incorrect `BITMAP_FREE` calls, especially when new exit paths are introduced. This change enhances robustness without altering optimization behavior.
