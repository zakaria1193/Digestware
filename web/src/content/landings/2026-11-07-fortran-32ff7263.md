GCC's Fortran compiler had issues correctly simplifying parameterized derived types (PDTs) when they contained string components. This commit modifies `gfc_simplify_len` in `simplify.cc` to return `NULL` for such components, resolving errors and ensuring proper handling of nested PDTs. A new test case, `pdt_bug25.f90`, has been added to verify the fix.
