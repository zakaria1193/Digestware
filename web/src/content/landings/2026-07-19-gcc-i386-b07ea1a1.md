This commit introduces biased conversion intrinsics for AVX10/v2, enabling conversions between FP32 (single-precision float) and FP8 (BF8/HF8) formats with biased exponent handling. It adds support for 128, 256, and 512-bit vectors, including masked operations. The changes incorporate new intrinsic definitions, built-in types, and machine description patterns, along with test cases to verify the functionality for AI and HPC applications.
