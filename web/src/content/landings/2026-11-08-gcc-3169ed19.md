This commit refactors the handling of the `CROSSING_JUMP_P` flag by replacing the macro with a dedicated function. This change improves type safety and code clarity by ensuring the flag is manipulated through a consistent interface that operates on `rtx_insn*`. It impacts various scheduling and control flow analysis passes within GCC.
