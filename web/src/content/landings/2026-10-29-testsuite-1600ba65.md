The test `Wtrampolines-3.c`, which verifies trampoline generation, is now skipped for the powerpc64 big-endian target. This is because the PowerPC64 BE ABI uses fat function pointers, making trampolines unnecessary. The test will still run on little-endian powerpc64 and 32-bit powerpc.
