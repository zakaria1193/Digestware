GCC now optimizes divisibility checks involving inequalities, similar to how it handles equalities. Previously, an expression like `x / y * y == x` could be simplified to `x % y == 0`. This change extends that optimization to also cover `x / y * y != x`, which simplifies to `x % y != 0`. This optimization can lead to more efficient code generation, as demonstrated by an example on AArch64.
