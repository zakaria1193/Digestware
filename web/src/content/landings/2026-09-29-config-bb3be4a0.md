The AC_ZSTD Autoconf macro has been expanded to better handle zstd detection. It now supports custom installation prefixes, include, and library paths, and prioritizes pkg-config while falling back to compiler searches. The macro also enforces a minimum zstd version of 1.4.0 for usability.
