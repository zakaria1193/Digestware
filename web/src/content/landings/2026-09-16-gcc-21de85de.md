This commit introduces several new shorthand functions to aid in working with the `IFN_ASSUME` construct and associated callback edges within GCC's Interprocedural Analysis (IPA). These functions, such as `callback_ifn_assume_call_p` and `callback_call_arg_summary`, simplify checks and argument remapping logic, making subsequent development related to IPA support for `IFN_ASSUME` more manageable.
