This commit modifies the RISC-V linker's relaxation handling to pass the `elf_link_hash_entry` as an argument to various relaxation helper functions in `bfd/elfnn-riscv.c`. While not all helpers use this new argument immediately, it provides necessary context for future enhancements and ensures consistency within the relaxation process.
