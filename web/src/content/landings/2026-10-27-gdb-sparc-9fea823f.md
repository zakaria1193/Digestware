This commit introduces a handler for the PRSTATUS note within SPARC ELF32 core dump files. Previously, GDB could not parse this information, leading to incomplete or incorrect analysis of core dumps. The new handler correctly extracts the signal and process ID from the PRSTATUS note, enabling more accurate debugging.
