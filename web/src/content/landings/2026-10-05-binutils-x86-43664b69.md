This commit adds an internal pseudo-Instruction Set Architecture (ISA) bit named 'TILE' to represent a shared subset of AMX tile instructions. This distinction is necessary because AMD's ACE architecture shares some tile registers and instructions (LDTILECFG, STTILECFG, TILERELEASE, TILEZERO) with AMX_TILE, while others are exclusive to AMX.
