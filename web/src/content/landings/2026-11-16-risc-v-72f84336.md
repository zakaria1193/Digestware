The RISC-V compiler driver now correctly passes the detected CPU core name when using the -mcpu=native option. Previously, -mcpu=native expanded to -march=<detected ISA> -mtune=<detected core>, and the compiler itself (cc1) never saw the -mcpu option. This change ensures that per-core settings, such as errata workarounds, are correctly applied by passing -mcpu=<core> alongside -march.
