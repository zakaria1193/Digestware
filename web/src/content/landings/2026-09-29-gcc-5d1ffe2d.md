This commit cleans up the GCC source tree by removing duplicate include directives that had no functional effect. The patches ensure that header files are not included more than once within the same compilation unit, which can occur when a file includes all its dependencies. This is a cosmetic cleanup that reduces noise in build artifacts and potentially minor build time improvements.
