Support for C23's `_BitInt` type has been added to the rs6000 (PowerPC) architecture. This includes implementing the necessary target hooks and `libgcc` runtime support that were previously missing. The changes define how `_BitInt` types are represented using machine modes, how they are passed and returned by reference for larger sizes, and ensure correct integration with existing integer promotion rules.
