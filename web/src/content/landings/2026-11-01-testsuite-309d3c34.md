This commit adds the `-fno-signed-zeros` flag to several Floating-point Fused Multiply-Add (FMA) tests in the GCC testsuite. This change addresses failures observed on aarch64 architectures where a previous compiler change restricted negated FMA folds based on signed zero behavior. Applying the flag ensures these tests pass by explicitly disabling signed zero honor, aligning them with the expected behavior for the tested folds.
