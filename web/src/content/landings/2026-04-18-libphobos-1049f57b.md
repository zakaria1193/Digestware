To improve compatibility with the LDC compiler, the `@gcc.attributes.callingConvention` attribute has been added to libphobos. This attribute is primarily for use with LDC, and any values passed to it are ignored by GCC. The change adds a new UDA (user-defined attribute) to `libdruntime/gcc/attributes.d`.
