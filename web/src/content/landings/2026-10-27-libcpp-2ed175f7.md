This commit updates `libcpp`'s `search_line_neon` function to use the `__builtin_ctzll` intrinsic on AArch64 targets. This change is specifically intended to fix the `aarch64-w64-mingw32` build, which uses a 32-bit `long` type (LLP64 data model). By using the builtin, the code correctly handles the `long long` type, resolving the build failure.
