A new rule has been added to the GCC MATCH optimization patterns to recognize and simplify a common code sequence involving sign bit comparisons and conditional negations. The pattern `(signbit (x) cmp1 0) cmp (signbit (y) cmp2 0) ? y : -y` is now folded into a `copysign(y, +-x)` operation. This transformation preserves the magnitude of `y` while taking its sign from `x` (or `-x`), and can be emitted as `IFN_COPYSIGN` on supporting targets, leading to more efficient code for operations like `copysign` and potentially improving performance.
