The Dead Code Elimination (DCE) pass in GCC has been fixed to correctly handle calls that are marked as `no_delete`. Previously, a flawed conditional check allowed the left-hand side (LHS) of such calls to be removed, leading to incorrect code generation. This patch ensures that the LHS of calls with the `no_delete` attribute is not removed, preserving necessary operations.
