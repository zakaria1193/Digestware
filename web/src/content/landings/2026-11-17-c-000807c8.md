This commit resolves an issue in C++'s `build_invoke` function where array types were not treated consistently with pointer types concerning decay. This inconsistency caused problems for type traits such as `std::is_invocable` when using the non-intrinsic versions, leading to compilation failures. The change ensures that array types are now handled similarly to pointer types in `build_invoke`, accommodating the standard array-to-pointer decay.
