This commit corrects two issues related to big-endian code generation for ARM's `vdup` vector duplication patterns. First, it adds a `reload_completed` constraint to splits of 64->128-bit `vdup` patterns to prevent assertion errors when dealing with subregisters. Second, it fixes a big-endian specific bug where `gen_lowpart` would incorrectly select the upper 64 bits instead of the lower 64 bits when splitting a 128-bit `vdup` into its low part. The fix replaces `gen_lowpart` with `simplify_gen_subreg` for this scenario, ensuring correct big-endian behavior.
