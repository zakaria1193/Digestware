This commit updates the Fortran compiler to correctly handle the `TEAM_NUMBER` keyword for the `NUM_IMAGES` and `IMAGE_INDEX` intrinsic procedures. Previously, these procedures shared a single dummy argument for team-related information, preventing the use of keywords for different team arguments and leading to incorrect behavior with certain standard versions. The change introduces separate, optional dummy arguments for `TEAM` (of type `TEAM_TYPE`) and `TEAM_NUMBER` (of type `INTEGER`), ensuring proper keyword support and diagnostics for Fortran 2018 coarray features.
