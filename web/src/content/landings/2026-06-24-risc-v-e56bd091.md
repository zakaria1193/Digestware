This Binutils commit adds support for the RISC-V Smpmpmt (PMP-based Memory Types) extension, specifically version 0.6. This extension allows for memory attributes to be controlled at the granularity of Physical Memory Protection (PMP) regions, similar to how the Svpbmt extension works with page-table entries. Support for this extension means that developers targeting RISC-V platforms can now utilize these enhanced memory control features within their toolchain.
