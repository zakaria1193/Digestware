The common subexpression elimination (CSE) pass in GCC was generating invalid RTL code in certain scenarios, leading to an internal compiler error (ICE) on the SH architecture. The issue arose from CSE's reliance on the recognizer to reject invalid register replacements. This commit makes CSE validate subregister replacements, ensuring the generated RTL is valid, and include a new test case.
