This commit replaces several macros used for checking instruction properties (like `NOTE_INSN_BASIC_BLOCK_P`) with proper functions. These functions now take an `rtx_insn*` directly, improving type safety and code clarity. This change refactors the internal representation of notes and flags associated with instructions, contributing to a more robust compiler.
