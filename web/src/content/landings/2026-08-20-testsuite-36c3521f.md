GCC's testsuite has been updated to make vector MIN narrowing tests more stable across different targets. The positive MIN narrowing test is now restricted to AArch64 and x86 targets due to requirements for narrow vector MIN support and specific modes. Additionally, a shared-result test now checks the GIMPLE dump before target lowering can interfere, ensuring the count is independent of target-specific vector mode behavior. This resolves issues where tests might pass or fail incorrectly due to target-specific lowering.
