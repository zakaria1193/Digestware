This commit refactors how GCC's i386 backend determines if a `va_arg` should be treated as passed by reference. Previously, the `ix86_pass_by_reference` hook often defaulted to the system's default ABI (SysV on Linux), leading to incorrect handling of arguments passed by reference in functions using other ABIs (like the MS ABI). The change splits the ABI-specific logic into a new function `ix86_pass_by_reference_abi`, allowing `ix86_gimplify_va_arg` to correctly read indirect MS ABI arguments as pointers and use the explicit SysV ABI for SysV `va_list`s.
