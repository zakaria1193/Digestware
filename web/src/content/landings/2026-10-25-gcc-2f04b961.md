- term: RTL
  definition: Register Transfer Language, an intermediate representation used by GCC
    to represent code between parsing and machine-specific code generation. It's a
    Lisp-like language of expressions.

    in instruction scheduling or complex instruction emulation.

This commit refactors how local variables that are overwritten are handled in several GCC backends, including Alpha, ARC, and Or1k. It ensures that code labels are kept separate from `LABEL_REF`s, and that patterns, parallel blocks, and producer/consumer constructs are managed distinctly from the emitted instructions. This improves the clarity and correctness of RTL generation for complex operations like atomic memory accesses, compare-and-swap, and conditional moves, especially when local variables are involved in multiple assignments.
