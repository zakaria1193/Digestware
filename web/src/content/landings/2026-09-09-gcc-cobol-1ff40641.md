The implementation of COBOL's ADD and SUBTRACT operations has been significantly refactored for improved performance. Previously, these operations relied on library routines; now, they are implemented directly within the GENERIC intermediate representation. This change involves new helper functions for addition and adjusts existing ones to utilize the new direct implementation, while also removing unused test cases.
