primer_glossary:
- term: R_XTENSA_32_ABS
  definition: A relocation type for Xtensa processors that calculates a 32-bit absolute
    address using a symbol's address plus an addend stored in the relocation entry's
    r_addend field.
- term: relocation number
  definition: A unique identifier assigned to each type of relocation (e.g., R_X86_64_PC32)
    within an object file format like ELF. These numbers are used by linkers to resolve
    symbol addresses.
- term: SHT_RELA
  definition: A section type in ELF files that contains relocation entries with explicit
    addends. It is used for relocations that require more information than just the
    symbol and offset.
- term: partial_inplace
  definition: A relocation handling method where part of the relocation information
    (the addend) is stored directly within the relocated data itself, rather than
    solely in the relocation entry.

This commit reserves the relocation number 64 for the new `R_XTENSA_32_ABS` relocation type. This reservation is made ahead of the full implementation to allow other toolchain components to reference and use this number, ensuring consistency while the rest of the change is under review.
