This patch enhances the Modula2 compiler's intrinsic procedure function `VAL` by adding context filtering for its parameters. The first parameter's type and the second parameter's usage (constants, expressions, or variables) are now considered to filter out incorrect spelling suggestions. This aims to reduce noise and improve the developer experience when using the `VAL` function.
