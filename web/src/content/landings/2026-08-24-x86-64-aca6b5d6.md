This commit corrects a feature check for the SSE instructions `pinsrq` and `pextrq` on x86-64. Previously, the compiler incorrectly checked for the AVX feature instead of the SSE4.1 feature, which is when these instructions were introduced. This ensures that the compiler correctly identifies and utilizes these instructions.
