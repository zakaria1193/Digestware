This commit adds several test cases to the RISC-V backend's test suite to address an Internal Compiler Error (ICE). The ICE occurs when a widening instruction is encountered where the destination register's number of registers (`nregs`) is less than that of the source register. These new tests specifically target this scenario to ensure the compiler handles such cases correctly and avoids crashing.
