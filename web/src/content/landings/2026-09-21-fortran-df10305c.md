The Fortran compiler has refactored the process of guessing the declaration for array spans. The logic for guessing the decl for a span has been moved from a function argument to within the `build_array_ref` function body. This change ensures that a better default declaration is guessed for span-addressed arrays, preventing regressions that occurred when a previously provided declaration interfered with the default guessing mechanism.
