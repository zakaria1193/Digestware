This commit resolves an issue in GCC's C++ contract implementation where re-invoking a `constexpr` function within a contract assertion or `[[assume]]` predicate during constant evaluation led to errors. The `constexpr_global_ctx::put_value` function has been updated to correctly handle `void_list_node` entries, preventing them from being treated as state modifications.
