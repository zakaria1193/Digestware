A recent change in the GCC Analyzer caused build failures when compiling with `--enable-checking=release`. This patch fixes the issue by conditionally compiling specific code sections within `string-scan.cc`, `symbolic-bit-contents.cc`, and `symbolic-scalars.cc` only when checking is enabled. This ensures the Analyzer builds correctly in release configurations without compromising its functionality.
