The Cobol compiler now correctly reports the source code location of an invalid argument within a CALL statement. Previously, errors related to incorrect arguments would report the location of the PROCEDURE DIVISION instead of the specific argument causing the issue. This change improves diagnostic accuracy by pinpointing the exact location of the problem.
