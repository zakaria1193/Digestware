The `snapshot_symbol` function in the assembler was losing the addend (`exp.X_add_number`) when encountering local symbols.  This commit fixes this by incorporating the addend into the value of the symbol. Additionally, the code now avoids adding the symbol's value if the result will still be `O_symbol`, ensuring proper value resolution.
