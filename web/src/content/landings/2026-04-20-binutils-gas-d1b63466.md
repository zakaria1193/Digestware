The gas assembler's `snapshot_symbol` function was not correctly handling addends when encountering local symbols. This could occur when local symbols were generated during expression resolution. The fix ensures that `exp.X_add_number` is considered and the symbol's value is correctly incorporated, preventing incorrect value calculations.
