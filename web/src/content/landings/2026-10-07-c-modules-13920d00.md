This commit implements a relaxation of redefinition restrictions for imported global module entities in C++, aligning with the P1811 proposal. The compiler now skips redundant definitions of imported entities, improving compilation speed for well-formed code. While this prioritizes speed over strict ODR checking for certain ill-formed cases, it correctly handles valid redefinitions. The change affects how entities are looked up and checked after import.
