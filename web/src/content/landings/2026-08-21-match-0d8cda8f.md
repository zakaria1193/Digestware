This commit removes an optional cast (`?`) from the `mul_carry_low_sum` and `mul_carry_cross_sum` match patterns in GCC. The patterns are used where a conversion is applied to a comparison, and the cast is only truly optional for 1-bit integer types, which are not expected by these patterns. This change reduces the amount of generated code from the `genmatch` tool.
