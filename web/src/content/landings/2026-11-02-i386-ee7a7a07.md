GCC's i386 support has corrected the leaf number for the PCONFIG MKTME_KEY_PROGRAM intrinsic. The Intel SDM specifies leaf 0 for this operation, but the code was using 1, which is the identifier for TME-MK. Using the incorrect leaf number could cause a #GP(0) fault. This change updates the intrinsic's definition and a related test case to use the correct leaf number 0, ensuring proper PCONFIG execution.
