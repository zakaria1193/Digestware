The Win32 section of the linker manual has been updated to correct inaccuracies regarding pseudo-relocations. The description now uses the correct switch name, `--enable-runtime-pseudo-reloc` (without a trailing 's'), and clarifies that this option has been enabled by default in recent linker versions, contrary to previous documentation stating it needed explicit enabling.
