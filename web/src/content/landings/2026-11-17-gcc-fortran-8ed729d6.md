The Fortran compiler previously failed with an ICE when trying to describe a CHARACTER subreference array with a vector subscript. This was because the existing descriptor logic could not handle vector subscripts and would assert. The fix ensures a temporary is created for expressions with a vector subscript, resolving the compiler error.
