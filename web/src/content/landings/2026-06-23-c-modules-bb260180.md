This commit optimizes GCC's C++ module system by changing how Argument-Dependent Lookup (ADL) functions are handled. Previously, dependent ADL functions were eagerly pulled into the module's dependency graph. Now, they are marked as reachable but not immediately added as hard dependencies, allowing for lazy loading. This alteration significantly improves compilation performance for specific test cases, yielding a speed-up of approximately 24%.
