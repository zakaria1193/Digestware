GCC test cases for verifying the `-mrestrict-it` option (which limits if-conversion) have been updated to explicitly use Thumb-2 mode. This is necessary because the option only applies to Thumb-2. Previously, tests were failing or not exercising the intended functionality due to reliance on default board configurations that didn't select Thumb-2, causing incorrect if-conversion limits to be applied.
