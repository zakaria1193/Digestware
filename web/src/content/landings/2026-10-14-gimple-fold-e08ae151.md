This commit refines the `same_bool_comparison_p` function in gimple-fold to correctly test outer comparisons and handle NaNs when inverting boolean comparisons. Previously, incorrect folding occurred with certain comparisons involving NaNs or when boolean SSA names were defined by comparisons, potentially leading to wrong optimization results. New test cases are added to verify these fixes.
