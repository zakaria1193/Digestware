A new test case, `divmod-2.c`, has been added to the GCC testsuite to cover 64-bit signed divide and modulo operations involving operands at the extremes of the type range. This scenario is critical for targets using radix-2 restoring division algorithms, where intermediate remainders near the bit-width limit can cause incorrect results. The test specifically targets a gap where operands near `INT64_MIN` and divisors near 2^63 might interact problematically. This fix was motivated by an issue on MicroBlaze but is applicable more broadly.
