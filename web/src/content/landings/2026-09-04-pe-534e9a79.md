The PE+ (Portable Executable for 64-bit) linker has had its stdcall fixup machinery removed. This code was dead as Win64 has a single calling convention and never uses stdcall decorations. Removing it eliminates quadratic complexity in symbol table traversals and simplifies the linker code.
