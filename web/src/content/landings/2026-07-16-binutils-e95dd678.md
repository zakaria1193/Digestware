The `readelf.c` utility now compiles correctly with GCC 4.9, resolving an error related to missing initializers for the `Elf_Internal_Shdr` struct. Previously, an empty initializer `{}` caused a compile-time error in older GCC versions. The fix uses a C99-style designated initializer to explicitly set the required fields, ensuring compatibility.
