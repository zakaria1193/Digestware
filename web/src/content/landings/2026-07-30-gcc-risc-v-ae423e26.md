This commit expands the test suite for the RISC-V Vector extension by adding numerous test cases for the `vwaddu.vv` instruction. These tests specifically target scenarios involving register group overlap across different data types (unsigned 8-bit, 16-bit, and 32-bit) and various vector mask/multiplier configurations (m1, m2, m4, mf2, mf4, mf8).
