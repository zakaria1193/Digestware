On RISC-V, the compiler was performing a redundant `CALL_P` check in the `vxrm_unknown_p` function. Since `reg_set_p` is already used to check the VXRM definition, the `CALL_P` check is unnecessary because VXRM is marked as call-used, so `reg_set_p` always returns true when a call is encountered. This commit removes the redundant check, simplifying the code.
