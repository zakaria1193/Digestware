This commit corrects a code quality regression on the RISC-V port stemming from a change in instruction steering. The previous steering towards PLUS for certain bit manipulation sequences, which involved an outer OR and an inner AND, caused incorrect code generation. The fix adjusts the bit manipulation logic to use IOR as the outer operation and modifies the AND mask, ensuring semantic correctness and improving code quality by avoiding unnecessary instructions.
