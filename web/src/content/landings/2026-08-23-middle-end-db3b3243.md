When storing to a bit-field that occupies an entire memory unit, the compiler previously emitted a read of the memory destination before the write, even if no surrounding bits needed preserving. For non-volatile destinations, this read was optimized away, but for volatile destinations, it remained as a spurious memory access. This change modifies the store operation to directly write the value when the bit-field fills the entire unit, eliminating the unnecessary volatile read and preventing incorrect behavior with memory-mapped I/O registers that have side effects on reads.
