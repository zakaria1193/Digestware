Gfortran now permits the VALUE attribute on assumed-shape and explicit-shape array dummies, aligning with the Fortran 2008 standard. Previously, the compiler rejected these combinations, contrary to the relaxed rules. The change also refines error checking to distinguish between VALUE/DIMENSION and VALUE/CODIMENSION conflicts and ensures that VALUE array dummies are passed via a private deep copy.
