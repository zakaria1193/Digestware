ELF targets now set the dynobj field when creating a stub bfd, which is used for dynamic sections. This change allows for earlier setting of the dynamic object information. An adjustment is made for the frv target to avoid an assertion failure in _bfd_elf_link_dynobj, as the function is no longer strictly needed.
