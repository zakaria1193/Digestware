This commit enables the Alpha linker to correctly handle IFUNC symbols in non-PIC (non-Position Independent) links. It introduces a new `.rela.iplt` section to store dynamic relocations for IFUNC references, which is processed by `ld.so` or the C library startup code. The section is precisely sized to avoid issues with unused relocation slots. The linker also correctly handles IFUNC symbols defined in discarded sections and re-merges GOT entries during relaxation.
