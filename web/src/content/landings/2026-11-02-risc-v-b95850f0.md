This commit addresses a register overlap issue in RISC-V widening floating-point reduction instructions (`vfwredosum.vs` and `vfwredusum.vs`). The `vs1` operand is read with a wider element width than `vs2`, and the RISC-V vector specification reserves encodings where one register supplies operands with different widths. The change enforces a `Wn3` constraint on the `vs1` operand to ensure it does not fall within the `vs2` register group, preventing invalid instruction encodings.
