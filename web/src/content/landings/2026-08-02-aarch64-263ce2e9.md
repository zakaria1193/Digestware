This commit adds support for half-precision floating-point conditional compare instructions (FCCMP and FCCMPE) on the AArch64 architecture when the FEAT_FP16 extension is available. Previously, these instructions only supported single-precision and double-precision types. The change updates the conditional-compare patterns and expansion hooks to correctly handle HFmode (_Float16) and improves code generation for comparisons involving half-precision floats. New test cases verify the functionality.
