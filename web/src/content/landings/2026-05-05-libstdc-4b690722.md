The hash function used for managing wait states in `std::atomic::wait` has been improved to reduce collisions and pathological behavior. The previous hashing scheme led to frequent collisions, causing incorrect wakeups and performance degradation, especially under high thread contention. The new hash function provides better distribution and uses a per-process seed for increased uniqueness.
