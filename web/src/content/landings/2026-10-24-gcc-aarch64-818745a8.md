Previously, if GCC's -mcpu=native encountered an unrecognized AArch64 CPU, it would fall back to generic-armv8-a and incorporate reported extensions. This change enhances the fallback for CPUs reporting SVE2 by using generic-armv9-a as the baseline. This provides a more accurate architectural starting point, while still respecting reported extensions and carefully handling features not explicitly reported by the CPU, such as PREDRES.
