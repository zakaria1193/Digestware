This commit refactors the Abstract Syntax Tree (AST) representation for LLVM inline assembly in gccrs. It simplifies `AST::LlvmInlineAsm` to store a single template string and adjusts related visitor functions and parsing logic accordingly. This change improves the accuracy of token collection and ensures proper handling of outer attributes.
