This Fortran compiler commit corrects how the `ALLOCATE` statement handles error conditions for allocatable arrays. It refines the logic to ensure that the `STATUS` parameter is correctly set to an 'already allocated' error only when the array is indeed already allocated, even if the size calculation would otherwise cause an overflow or exceed virtual memory. Pointer arrays are handled separately, as they can only encounter a virtual memory error.
