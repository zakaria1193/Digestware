The GCC analyzer previously mishandled tainted offset checks after certain integer casts. Specifically, when an unsigned type was cast to a wider type of the same bit width, the analyzer lost the original type's lower bound of zero. This commit restores the original type information, ensuring accurate upper-bounds checking and fixing false positives in various taint-related tests.
