This commit improves error reporting in gccrs by ensuring that empty path expressions, such as those starting with `::`, trigger a diagnostic. Previously, the parser might silently return an error node, leading to internal compiler errors (ICEs) later in the process. The redundant guard in `parse_stmt_or_expr` was also removed. New test cases `empty_path2.rs` and `empty_path3.rs` are added.
