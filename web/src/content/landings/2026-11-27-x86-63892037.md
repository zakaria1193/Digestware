primer_expert: When using `-z pack-relative-relocs` and `PHDRS` in the linker script,
  an empty `.relr.dyn` section could cause problems. The `_bfd_elf_x86_size_relative_relocs`
  function removed the section but did not mark it as `SEC_EXCLUDE`. This prevented
  `elf_modify_segment_map` from dropping it from the segment map derived from PHDRS.
  This change adds the `SEC_EXCLUDE` flag before removing the section, aligning its
  behavior with other output section stripping mechanisms and fixing issues with segment
  sizing and reporting.

This commit ensures that the Binutils linker correctly excludes empty `.relr.dyn` sections from segments when program headers (PHDRS) are used. Previously, this section could remain in a segment, causing issues with segment sizing and reporting, especially when relative relocations were not needed.
