A bug in the Fortran compiler's handling of CLASS objects with non-allocatable derived type array components, which themselves contained allocatable components, led to an invalid memory free during finalization. The compiler was incorrectly attempting to deallocate components of the last component's type for all array elements. This commit modifies the finalization wrapper to skip this redundant deallocation for such structures, resolving the invalid free and potential memory corruption.
