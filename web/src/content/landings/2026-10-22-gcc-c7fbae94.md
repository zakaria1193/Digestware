The API for querying pointer alignment information in GCC has been adjusted to accept an SSA name directly, rather than requiring a `ptr_info_def` structure obtained from a `prange_storage`. This change simplifies client calls and facilitates the eventual removal of the `ptr_info_def` structure by reducing references to it.
