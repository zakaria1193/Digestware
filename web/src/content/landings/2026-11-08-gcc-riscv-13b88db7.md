This commit enhances RISC-V code generation by replacing sequences of `lui` (load immediate) and `addi` (add immediate) with `bseti` when setting a single bit. This is achieved by adjusting the arithmetic operation expander to handle single-bit constants, leading to more efficient instruction sequences. Additionally, a new, generic instruction splitter is introduced to intelligently handle complex expression transformations, specifically eliminating unnecessary sign extensions that previously degraded code quality.
