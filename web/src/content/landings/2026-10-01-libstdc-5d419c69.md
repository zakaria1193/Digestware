This commit resolves a stack corruption vulnerability in the stream extraction operator (`operator>>`) for `std::bitset`. The issue was caused by an incorrect argument to `__builtin_alloca`, which did not properly account for the size or alignment of wide characters. The fix replaces `__builtin_alloca` with a stack-allocated array, ensuring correct memory management and preventing stack corruption.
