This commit changes gccrs' metadata export mechanism to use the Abstract Syntax Tree (AST) instead of the High-Level Intermediate Representation (HIR). The HIR lacked `UseDeclaration` nodes, which are crucial for resolving some metadata. By using the AST, which already accurately represents these declarations and is used by other systems like proc macro expansion, the compiler deduplicates dumper code and improves the accuracy of exported metadata.
