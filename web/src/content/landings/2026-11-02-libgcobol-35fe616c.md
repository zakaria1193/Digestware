The build system for libgcobol has been updated to replace the deprecated `AC_LIBTOOL_DLOPEN` macro with the modern approach of passing `dlopen` directly to `LT_INIT`. This change ensures compatibility with newer versions of libtool and, crucially, enables dlopen support by default for the library. This allows for dynamic loading of libgcobol at runtime.
