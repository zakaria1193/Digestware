This change addresses a build failure in ld that occurred on hosts without the dlfcn.h header, which is necessary for plugin support. The linker now wraps existing plugin functions in a conditional check for BFD_SUPPORTS_PLUGINS and provides do-nothing stubs when plugins are not supported. Additionally, the testsuite was updated to correctly report untested cases instead of outright failures when plugin support is absent.
