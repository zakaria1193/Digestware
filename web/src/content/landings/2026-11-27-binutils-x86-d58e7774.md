Binutils introduces a new generic instruction template, `<hl>`, to simplify the definition of x86 opcodes. This template is intended to handle patterns similar to those seen with `VPINTERLEAVE{H,L}{B,W}` instructions, reducing redundancy in the opcode table definitions. The change refactors `opcodes/i386-opc.tbl` and `opcodes/i386-tbl.h` to use this new template.
