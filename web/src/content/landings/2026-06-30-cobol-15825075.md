This patch refactors COBOL data type conversions for GENERIC and libgcobol to improve consistency. It also addresses potential aliasing issues arising from pointer casting, an ongoing effort to modernize C code practices. Further changes adapt GCOBOL for big-endian architectures like S390, introducing compile-time and runtime endianness handling.
