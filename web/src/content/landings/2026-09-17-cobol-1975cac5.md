The CBL_CHECK_FILE_EXIST function in libgcobol now correctly uses the st_mtime (last modification time) to update the file existence buffer. Previously, it incorrectly used st_ctim (last status change time). This change aligns the function's behavior with its documentation and POSIX standards, ensuring accurate file status reporting.
