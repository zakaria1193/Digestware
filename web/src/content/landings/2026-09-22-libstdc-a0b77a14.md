This change optimizes the Direct Finite State Machine (DFS) NFA shape for repeating regex patterns, such as `[\w]+` or `#+`. It avoids creating unnecessary stack frames for greedy repeats, directly consuming match states when the repeated body returns to the repeat state. This optimization improves performance for various regex patterns, including email and URI matching.
