A new regression test has been added for the AIX linker emulations to verify its handling of foreign object files and retargeted outputs. The test links a fixed x86-64 relocatable object against AIX emulations, both directly and after retargeting the output to `elf32-little`. It ensures that these operations fail cleanly with the expected diagnostics and do not crash or produce invalid output files.
