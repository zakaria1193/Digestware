The binutils BFD library now correctly reflects the RISC-V specification's requirement that certain Zv extensions imply the Zve32x extension. This was achieved by reordering the `riscv_implicit_subsets` table to ensure that the Zv{b,k}* entries, which imply Zve32x, are processed before other entries that might be affected by this implication. A gas testsuite file was also updated to match.
