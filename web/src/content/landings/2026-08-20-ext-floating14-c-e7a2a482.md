A C++23 test case, `ext-floating14.C`, encountered warnings about the redefinition of the `__bfloat16` type when compiled with default x86 AVX-related options. To resolve this, the test case is now compiled with `-mno-avx512bf16` and `-mno-avxneconvert`, ensuring that the test suite can be built without these specific warnings and passes cleanly.
