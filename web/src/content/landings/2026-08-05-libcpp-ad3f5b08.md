This commit introduces an AArch64 SVE2-accelerated function for finding the next newline, carriage return, backslash, or question mark character. The new implementation leverages SVE2's vector-length agnostic capabilities to perform the search in fewer instructions, offering better scalability on wider processor implementations compared to the previous Neon-based approach. The function is compiled with a +sve2 target attribute and selected at startup via getauxval, ensuring it's used when available.
