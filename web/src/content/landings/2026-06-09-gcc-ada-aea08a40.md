The Ada compiler in GCC has corrected an error in its warning messages regarding comment style. Previously, warnings for single-space comments incorrectly suggested using the `-gnatyc` switch, which is for double-space comments. Now, the compiler issues the correct guidance to use `-gnatyC` for single-space comment checks.
