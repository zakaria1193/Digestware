This commit resolves a crash in GCC's tree-dumper that occurred when processing anonymous constants in Modula-2 code. The `m2decl_DeclareKnownConstant` function was creating an `IDENTIFIER_NODE` without setting its string, leading the dumper to dereference a null string when it attempted to print the anonymous constant's name. The fix ensures that `CONST_DECL` is built with a `NULL_TREE` name, allowing the dumper to use the declaration's generated name instead and preventing the crash. A regression test has been added.
