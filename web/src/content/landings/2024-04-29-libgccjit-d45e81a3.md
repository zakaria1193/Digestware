Libgccjit's `is_same_type_as()` function, used for checking type equality, previously failed to properly compare floating-point types. This commit updates the function to correctly handle `float` and `double` comparisons, and also includes a fix in `gcc_jit_context_new_comparison` to ensure proper type checking for comparisons, preventing incorrect code generation or runtime issues when working with floating-point values in JIT-compiled code.
