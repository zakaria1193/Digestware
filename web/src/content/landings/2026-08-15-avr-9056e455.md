This patch optimizes comparisons of AVR registers against constants. When the constant is a multiple of 256, the compiler now uses a more efficient instruction sequence for equality (EQ) and inequality (NE) checks. This change reduces the generated code size by one instruction in such cases, improving performance and code density for specific AVR targets.
