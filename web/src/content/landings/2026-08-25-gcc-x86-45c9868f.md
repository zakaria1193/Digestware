This commit addresses a performance regression in x86 SSE vector initialization for the V4SF type. The previous update inadvertently caused issues with implicit zero extension when a value was already in a register. The fix introduces improved register preferencing and utilizes idioms like `pslldq`/`psrldq` for more efficient initialization, reducing inter-unit moves and matching LLVM's approach.
