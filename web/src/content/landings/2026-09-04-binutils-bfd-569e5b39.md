This commit updates BFD's target recognition to include Windows targets that use the 'windows-msvc' OS in their triplet, such as x86_64-pc-windows-msvc. Previously, these targets, used by compilers like Clang, were not mapped to a BFD target vector, causing configuration failures. The change extends existing PE entries for i386, x86_64, and aarch64 to match '*-windows*', aligning them with MinGW triplets.
