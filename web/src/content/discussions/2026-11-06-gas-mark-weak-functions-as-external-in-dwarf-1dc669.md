This discussion revolves around a patch for the GNU Assembler (`gas`) that aims to correctly represent weak functions in DWARF debug information. The proposed change modifies the DWARF generation logic to treat weak functions (using `S_IS_WEAK`) the same way as external functions (using `S_IS_EXTERNAL`) when emitting the `DW_AT_external` attribute. This ensures that debuggers and other tools accurately identify these functions as external, resolving PR 29517. A test case is included to verify the fix.
