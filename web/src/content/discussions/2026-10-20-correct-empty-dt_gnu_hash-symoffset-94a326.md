This patch corrects an issue in Binutils' `bfd_elf_size_dynsym_hash_dynstr` function related to the `DT_GNU_HASH` table. When an object file has no exported dynamic symbols, an 'empty' hash table is generated with fixed values. However, the `symoffset` field was incorrectly set to 1, which is only appropriate if there's exactly one non-hashed symbol. The patch corrects this to report the actual count of non-hashed symbols (`dynsymcount`) when the hash table is empty, addressing PR 34736.
