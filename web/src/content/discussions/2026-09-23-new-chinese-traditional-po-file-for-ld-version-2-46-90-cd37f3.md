The Translation Project robot has announced the submission of a revised traditional Chinese PO file for the 'ld' utility, version 2.46.90. The file is available for review and inclusion in future releases. Maintainers are also informed about the availability of all other PO files for the package and encouraged to notify the robot when new distribution tarballs are ready for translator context.
