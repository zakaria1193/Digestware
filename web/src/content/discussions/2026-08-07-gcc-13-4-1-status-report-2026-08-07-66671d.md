The GCC 13 branch is open for regression and documentation fixes, with release candidate planned for Sep 4th and release on Sep 11th. This will be the last release from this branch, so contributors are urged to be cautious about backporting to avoid regressions. The focus should be on regressions introduced between GCC 13.1 and now, or critical issues in actual applications, rather than those found in automatically generated code.
