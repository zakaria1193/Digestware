This patch addresses an issue where the FreeBSD linker's hints file, typically written in little-endian byte order, is not correctly parsed on big-endian architectures like powerpc64. The change modifies the `ldelf_check_ld_elf_hints` function to detect and handle the byte order of the hints file header, ensuring compatibility across different architectures. This is a resubmission of a previous patch with a minor adjustment suggested by Jan Beulich.
