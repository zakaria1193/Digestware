primer_expert: This patch modifies the Loongarch target support in binutils. Previously,
  it used a specific mechanism called 'linker aligns' to create a BFD (Binary File
  Descriptor) for handling certain relocation types. This patch transitions Loongarch
  to use the more generic 'linker stubs' BFD implementation, which is part of common
  code shared across targets. This change means the stub BFD will be created in all
  linker modes (not just relocatable) and will be available for dynamic linking scenarios.
  The renaming from 'linker aligns' to 'linker stubs' reflects this broader applicability.

This patch refactors the Loongarch target in binutils to use the common code for creating linker stub BFDs, renaming the existing 'linker aligns' to 'linker stubs'. This change allows the stub BFD to be created in all linker modes, not just relocatable linking, making it available for dynamic sections as well. A fix to the testsuite is included to accommodate the change in orphan placement.
