This is the third version of a patch that synchronizes the zstd detection logic between Binutils and GCC. It updates the `zstd.m4` macro in the GCC configuration to a unified implementation, ensuring consistent zstd support detection and configurable search paths across both projects. The changes also add `ZSTD_LIBS` to Binutils link commands for tools using zstd via BFD and base Gold's zstd test on the final detection result.
