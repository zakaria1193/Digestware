This patch updates the build process for `libcody` and `c++tools` to conditionally apply GCC-specific compiler flags like `-fno-exceptions`, `-fno-rtti`, `-MMD`, `-MP`, and `-MF`. Previously, these flags were passed unconditionally, causing build failures on host compilers that did not support them. The changes introduce a configure-time check for flag support and adjust Makefiles to use these flags only when accepted. Additionally, `libcody`'s build system now includes `config.h` from `internal.hh`, resolving dependency issues.
