This patch implements `R_XTENSA_32_ABS`, a new 32-bit absolute address relocation type for the Xtensa architecture. This relocation is computed as `S + A` and follows the generic ABI for `SHT_RELA`, meaning the addend is solely in `r_addend`. This is the format LLVM emits for 32-bit absolute data. The change ensures that `R_XTENSA_32_ABS` is handled identically to `R_XTENSA_32` during relocation application and relaxation, allowing objects using either to be linked together. It also enables the coalescing of literals using these relocations. New command-line options (`--abs32-rela`, `--no-abs32-rela`) and a configure-time option (`--enable-r-xtensa-32-abs`) are introduced to control which relocation type the assembler emits by default.
