This series removes support for the s390-linux-gnu (31bit) architecture from glibc. The s390 31-bit architecture was deprecated in glibc 2.43 and support for compat syscalls was removed in Linux kernel 6.19. The patch series removes s390-32 specific files, moves files from s390-64 directories upwards, and adjusts common files.
