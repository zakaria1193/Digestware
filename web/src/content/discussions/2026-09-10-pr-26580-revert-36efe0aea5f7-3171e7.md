This submission reverts commit `36efe0aea5f7` which attempted to fix a test case on some MIPS targets. The reverted commit inadvertently caused new failures (`pr26580-1`, `pr26580-2`) on mips*-elf and mips-sgi-irix6 targets. The author believes these new failures are correct, indicating that these MIPS targets do not properly handle BSS symbols in shared libraries, a behavior the reverted commit might have masked.
