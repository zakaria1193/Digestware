Abhay Kandpal is pinging the mailing list for a review of a patch that adds support for the new NT_PPC_DMR note type in BFD and readelf. This note type carries the contents of Dense Math Registers (DMR) for a future PowerPC processor. The patch is a prerequisite for GDB support for these registers in core files and live processes.
