This commit addresses 'variable set but not used' warnings generated by Clang when compiling the `pe.em` and `pep.em` files, which handle PE/COFF emulation in binutils. The fix involves conditionally defining certain variables only when they are actually used, thereby cleaning up the compiler warnings without altering the linker's functionality.
