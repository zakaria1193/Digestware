Simon Marchi proposes to remove custom build rules for `rclex.c` and `mclex.c` that currently bypass the `-Werror` flag. These files are now hand-written and should be subject to the same strict warning policy as other source files. This change aims to prevent new warnings in these files from going unnoticed.
