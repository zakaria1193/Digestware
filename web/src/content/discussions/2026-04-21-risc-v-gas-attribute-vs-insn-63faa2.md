Jan Beulich proposes a patch to ensure that RISC-V architecture attributes are set before any instruction is assembled, including those resulting from `.insn` directives. The patch introduces a helper function `start_assembly` to handle attribute setting. The author also raises questions about relaxing the constraint and handling redundant or invalid attribute values.
