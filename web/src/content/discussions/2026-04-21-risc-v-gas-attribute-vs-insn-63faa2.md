This patch enforces that RISC-V architecture and privileged ELF attributes are set before any instruction is assembled, including those resulting from the `.insn` directive. It introduces a helper function `start_assembly()` to handle this initialization. The patch also raises broader questions about the necessity of this constraint and proposes potential relaxations. Further, it questions the handling of redundant or invalid `.attribute` values related to stack alignment and unaligned access.
