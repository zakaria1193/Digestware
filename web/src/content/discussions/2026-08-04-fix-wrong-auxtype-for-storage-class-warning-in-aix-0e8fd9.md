Aditya Vidyadhar Kamath submits a patch to resolve a spurious warning in BFD when debugging 64-bit AIX binaries. The warning, 'wrong auxtype ... for storage class', occurred because BFD's `_bfd_xcoff64_swap_aux_in()` function did not properly handle the `_AUX_EXCEPT` auxiliary entry, which is used for functions with exception tables. The fix modifies the function to silently skip `_AUX_EXCEPT` entries, as BFD does not need to parse their payload, thus eliminating the warning.
