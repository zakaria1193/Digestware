The Translation Project robot has submitted an updated German PO (Portable Object) file for the 'ld' linker, version 2.45.90. This file contains updated translations for the linker's user-facing messages and is requested for inclusion in the upcoming Binutils release. The robot also offers to automate future updates and requests a URL for new distribution tarballs to assist translators with context.
