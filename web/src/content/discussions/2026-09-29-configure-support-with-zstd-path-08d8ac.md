This discussion questions the necessity of custom `--with-zstd=PATH` logic in binutils' configure scripts, suggesting that `pkg-config` could achieve a similar result. The commenter notes that GCC's `--with-zstd` is more flexible, allowing separate specification of include and library paths, and is implemented via open-coded logic in `configure.ac` rather than a generalized approach. The core of the question is about the use case for binutils' specific path handling.
