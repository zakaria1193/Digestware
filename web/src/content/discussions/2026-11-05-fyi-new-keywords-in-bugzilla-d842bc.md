primer_expert: Andrea Pinski is updating GCC's Bugzilla to improve issue tracking,
  specifically addressing an increase in bugs generated by Large Language Models (LLMs).
  The new keywords (`nested-func`, `returns-twice`, `dfp`) aim to better categorize
  specific code constructs and attributes that are frequently triggering incorrect
  code generation or internal compiler errors (ICEs) due to LLM-generated inputs.
  This is a metadata/process improvement for bug triage.
primer_glossary:
- term: LLM
  definition: Large Language Model, an AI system trained on vast amounts of text data,
    capable of generating human-like text and code. In this context, LLMs are being
    used to fuzz test GCC, but are also producing buggy code or triggering ICEs.
- term: ICE
  definition: Internal Compiler Error. An error that occurs within the compiler itself
    during the compilation process, usually indicating a bug in the compiler rather
    than the user's code.
- term: fuzzers
  definition: Programs that provide invalid, unexpected, or random data as input to
    a computer program. Fuzzing is a technique used to discover bugs and vulnerabilities.
- term: nested function
  definition: A function defined inside another function. While not a standard C feature,
    GCC supports it as an extension.
- term: returns_twice attribute
  definition: A GCC attribute that indicates a function might not return normally
    (e.g., due to `longjmp` or `exit`). Compilers need to be aware of this for correct
    code generation.
- term: DFP
  definition: Decimal Floating-Point. A data type that represents decimal numbers
    with a fixed precision, often used for financial calculations. GCC has support
    for DFP extensions.

Andrea Pinski has introduced new keywords in GCC's Bugzilla to better categorize specific types of bugs, prompted by an increase in issues generated by LLMs. The new keywords are `nested-func` for issues related to nested functions (including those used by Ada and Fortran front-ends), `returns-twice` for problems with the `returns_twice` attribute or `Wclobber` warnings, and `dfp` for decimal floating-point issues. Pinski notes that while `nested-func` and `returns-twice` are new, `dfp` is an existing keyword that was underutilized.
