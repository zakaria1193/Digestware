  optimization decisions, improving performance. AutoFDO is a form of PGO that uses
  profiles automatically generated from running the application. GCOV is a GCC tool

  and smaller file sizes.

Dhruv Chawla proposes a new version 4 of the AutoFDO GCOV profile format. The redesign focuses on backward compatibility, extensibility, and reduced file size. The proposed format is section-based, allowing partial reads and forward compatibility via typed location records.
