  (PDB) file format generated by the GNU linker (`ld`), specifically within the Debug

  to specifically trigger and verify this alignment behavior.

Oleg Tolmatcev proposes a patch for the GNU linker (`ld`) that ensures the PDB (Program Database) Debug Information (DBI) source-info substream is properly aligned to 4-byte boundaries. This involves rounding up the substream size and zeroing out any padding. A corresponding test case is also added to verify this behavior.
