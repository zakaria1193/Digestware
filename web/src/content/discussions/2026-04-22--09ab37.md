primer_expert: This patch series deals with glibc's dynamic linker and its interaction
  with the kernel's Transparent Huge Page (THP) feature. The goal is to enable THP
  for segments loaded by the dynamic linker when THP is configured to use madvise.
  This involves changes to the dynamic linker's memory mapping logic (_dl_map_segment_align,
  _dl_postprocess_loadcmd), and requires coordination with kernel's THP page size.
primer_general: Transparent Huge Pages (THP) is a Linux kernel feature that aims to
  improve performance by using larger memory pages (typically 2MB) instead of the
  standard 4KB pages. This reduces TLB misses and improves memory access times. Glibc's
  dynamic linker needs to be aware of THP to properly align memory segments and make
  use of THP when loading shared libraries and executables. The 'madvise' setting
  allows applications to advise the kernel about how to manage memory, including whether
  to use THP for specific memory regions.
