This patch removes the 'pcmpbc' instruction from the MicroBlaze opcode table because it is not documented in any official manuals (UG984, UG081), is not recognized by QEMU's decoder, and is not emitted by GCC. Its removal ensures the opcode table accurately reflects supported instructions, preventing unknown opcodes from being misinterpreted as valid instructions.
